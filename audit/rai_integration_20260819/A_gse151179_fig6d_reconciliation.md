## 3. Independent re-derivation from the raw series matrix (this session)

Full script: `scripts/A_gse151179_fig6d_reconciliation_repro.py`. Genes were
pulled directly from `GSE151179_series_matrix.txt.gz` probe values via the
GPL23159 probe→symbol map (all 8–9 needed genes recovered on the array), then
within-cohort per-gene z-scored and averaged into module scores — the same
procedure both source scripts describe.

### 3a. Claim 1 (manuscript wording), reproduced from raw data

| Contrast | n (after vs before) | Cohen's d | Test | P |
|---|---|---|---|---|
| **All 52 samples, `collection before/after rai`, thyroid_diff module — as published** | 17 vs 35 | **−0.889** | Welch t (script's actual test) | **0.00053** |
| Same contrast, Mann-Whitney (caption's stated test) | 17 vs 35 | −0.889 | MWU | 0.00041 |
| Tumours only (drop 13 non-neoplastic thyroid) | 17 vs 22 | −0.369 | MWU | 0.046 |
| **Lymph-node-metastasis only (tissue held constant)** | **17 vs 5** | **−0.127** | MWU | **0.493** |
| CONFOUND — non-neoplastic thyroid vs lymph-node-metastasis (any timing) | 22 vs 13 | −2.177 (LN-met lower) | MWU | 9.8×10⁻⁶ |

Cross-tabulation of `collection before/after rai` × `tissue type` (reproduced
independently, matches `04d_FIG6D_BLOCKING.md` exactly):

| Tissue type | Before | After |
|---|---|---|
| non-neoplastic thyroid | 13 | 0 |
| primary tumour | 17 | 0 |
| synchronous lymph node metastasis | 5 | 0 |
| lymph node metastasis (post-RAI, all 3 sub-labels) | 0 | 17 |

**Verdict on Claim 1**: the whole-series number is real and reproduces closely
(d = −0.889 to −1.01 depending on exact gene list/probe-collapse method used, P
in the 10⁻⁴ range both ways) — this is not a fabrication. But timing and tissue
type are perfectly nested in this series (no sample is both, as `04d` already
found and this session independently confirms): every "after" sample is a
lymph-node metastasis and 37 % of "before" samples are non-neoplastic thyroid.
Holding tissue type constant (lymph-node-metastasis-only) collapses the effect
to d = −0.13, P = 0.49 — indistinguishable from null. The dominant signal in
the unrestricted contrast is normal-thyroid-vs-metastasis tissue identity
(d = −2.18 to +1.92 depending on sign convention), not a radioiodine effect.

### 3b. Claim 2 (audit wording), reproduced from raw data

| Contrast | Unit | n (Yes vs No) | Cohen's d (Yes−No) | Test | P |
|---|---|---|---|---|---|
| Sample-level, all tumour specimens, 8-gene panel | specimen | 19 vs 20 | — | — | — |
| **Patient-level (one mean per patient), tumour specimens, 8-gene panel — PRIMARY** | patient | **16 vs 16** | **+0.373** | MWU | **0.534** |
| Adjusted OLS: panel z ~ uptake + CIBERSORT purity class + driver class | specimen | 19 vs 20 | β = +0.035 | OLS Wald | 0.881 |
| Negative control: non-neoplastic thyroid samples, same patient-level uptake label | specimen | 6 vs 7 | +0.653 | MWU | 0.181 |

This session's from-scratch numbers (d = 0.3732, P = 0.5343 patient-level;
d = 0.6529, P = 0.1807 negative control) match `04b_GSE151179_INDEPENDENCE.md`
to three decimal places, independently confirming that audit's arithmetic and
methodology.

**Critical structural finding, independently confirmed**: `rai uptake at the
metastatic site` is not a per-specimen measurement. Every sample carrying this
label (all 52 samples do) shows the identical value across all specimens from
one patient — including that patient's non-neoplastic thyroid and pre-RAI
primary-tumour specimens, which cannot themselves have a "metastatic-site
uptake" reading. This confirms it is a **patient-level clinical outcome label
copied onto every specimen row**, not a tissue-specific measurement. That is
exactly why the primary test must be run at the patient level (n = 32
patients, not n = 39 specimens) and why the non-neoplastic-thyroid "negative
control" produces a nonzero, same-direction effect (d = +0.65) — it is picking
up the same patient-level label, not a false-positive tissue effect. Under
CIBERSORT-purity adjustment the association further shrinks to β = 0.035,
P = 0.88.

**Verdict on Claim 2**: null, and the null is not an artefact of power alone —
the effect that does exist collapses almost completely (0.373 → 0.035) after
adjusting for tumour purity, meaning what little signal exists is plausibly
attributable to thyrocyte-content confounding of the panel score rather than a
uptake-specific biology.

## 4. Reconciliation table

|---|---|---|

### Are these the same comparison?

**No — genuinely different comparisons, not merely different roundings of the
same fact.** Claim 1 measures a **cross-sectional tissue-identity difference**
(normal thyroid + primary tumour vs lymph-node metastasis) that happens to be
perfectly aligned with a "before/after RAI" label in this series because of how
specimens were collected, not because radioiodine changed the tumour biology.
Claim 2 measures the field that most directly asks the RAT (radioiodine)
question — whether the metastatic lesion actually took up iodine — restricted
correctly to tumour tissue and to one row per patient, and finds no
association, an association that further disappears under purity adjustment.

They are not in mathematical conflict (different fields, different subsets,
different n) — but they **cannot both be used to support the same sentence**.
The manuscript sentence at `NC_v2:124` uses Claim 1's number ("d≈−1.0,
P≈10⁻⁴") but its rhetorical claim ("shifted toward a DM1-like thyroid-
differentiation state" in "post-RAI refractory tumours", "names the same
biology that defines RAI-refractory progression") is a claim about
radioiodine-refractory *biology*, which only Claim 2's field actually tests —
and Claim 2 is null.

### Which is the more defensible primary claim?

**Neither survives as an anchor for a radioiodine-refractoriness claim, and
Claim 2 is the more defensible number to report if either must appear.**

- Claim 1's apparent effect is fully explained by a tissue-type confound that
  is structurally perfect in this dataset (timing and tissue type share zero
  overlapping cells in the 2×6 cross-tab). No amount of restating this number
  makes it a radioiodine-refractoriness signal; it is a normal-thyroid /
  primary-tumour vs lymph-node-metastasis contrast that would appear in any
  reasonable thyroid-differentiation score regardless of RAI history.
- Claim 2 uses the field that actually measures the construct the manuscript
  is trying to support (radioiodine reaching and being retained by disease),
  is correctly unit-of-analysis-adjusted (patient, not specimen), and remains
  null after adjusting for the most obvious rival confounder (tumour purity).
  A null result on n = 32 patients is a weaker foundation for a strong claim,
  but it is the *honest* answer to the question the manuscript is implicitly
  asking, whereas Claim 1 answers a different question altogether.

This session's independent reconstruction from the raw GEO deposit confirms
`04d_FIG6D_BLOCKING.md`'s "P0 fatal" call: GSE151179 does not currently support
the manuscript's Fig 6D / Abstract sentence as written, on either candidate
field. If a GSE151179 panel is retained in Fig 6D at all, the only analysis
that holds tissue type constant while testing the timing/refractory contrast
(lymph-node-metastasis-only, d = −0.13, P = 0.49) is null, and the analysis
that most directly tests RAI-effect (met-site uptake, patient-level,
purity-adjusted) is also null (β = 0.035, P = 0.88). Both null results should
be disclosed together if the dataset is kept in the manuscript; the d≈−1.0
number should not be used as a stand-alone anchor sentence in the Abstract or
Fig 6D caption in its current (tissue-confounded, mislabeled-test) form.

## 5. Minor reporting discrepancies noted in passing (not the primary question, flagged for completeness)

- The manuscript caption states "Mann-Whitney p = 0.0001"; the underlying
  script (`track_b_lite_phase4_continue.py`) actually ran a **Welch t-test**
  (column name `t`), not Mann-Whitney. Both tests give a similar order-of-
  magnitude P (this session: t P = 0.00053, MWU P = 0.00041) so the
  significance call is not overturned, but the named test does not match the
  test that was run, which is itself an evidence-lock violation (a p-value
  must be reported with the test that produced it).
- The published d = −1.01 (repo TSV) vs this session's independently
  recomputed d = −0.889 differ by roughly 12%. Both use an 8-gene
  "thyroid_differentiation"-type module and the same before/after split; the
  residual gap most likely traces to a difference in cross-cohort vs
  within-GSE151179-only z-scoring baseline, or probe-collapse method
  (mean vs. max-signal probe). This does not change the substantive verdict
  (large, confounded, tissue-driven effect) but the exact figure used in the
  caption should be regenerated from a single, explicitly documented pipeline
  before resubmission rather than carried over from the dossier-building
  script.
