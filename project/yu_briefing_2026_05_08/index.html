1. 임상 문제 (왜 이 paper가 중요한가)

한 줄: 갑상선암 환자 ~23%는 BRAF/RAS 변이가 없어 현재 ATA risk framework로 분류 안 되고, RAI(방사성요오드) 치료 결정 근거가 mechanistically untethered 상태.

1.1 갑상선암 = 가장 빨리 증가하는 endocrine malignancy

SEER 2024 기준 PTC (papillary thyroid carcinoma)는 지난 30년간 가장 빠르게 증가하는 endocrine cancer. 5년 OS >98%지만 5-20%가 recurrence/persistent disease, 10%가 distant metastases. (Haugen 2016 ATA Guidelines)

1.2 현재 ATA risk framework의 한계

2015 ATA + 2025 update는 clinico-pathological feature (tumor size, multifocality, ETE, LN burden) + BRAF V600E single molecular modifier만 사용. Bethesda III/IV indeterminate cytology가 FNA의 15-30% — major diagnostic gap.

1.3 BRAF/RAS-negative dark matter (Xing 2014)

TCGA-THCA에서 28.4%, Korean cohort에서 37.8%가 BRAF/RAS-negative. 이 영역은 현재 어떤 molecular framework로도 sub-stratify 안 됨 — 그래서 Xing 2014 NEJM이 "molecular dark matter"라 명명.

핵심 unmet need: Dark matter 환자의 RAI 치료 결정 = mechanism 없이 clinico-pathological feature만으로 진행. 분자 axis 없이는 fusion-targeted therapy 후보 식별도, 후성유전 기반 RAI re-induction 후보도 발굴 불가.

4.2 67-gene candidate pool (TIERA67) → 8-gene 선정 logic

TIERA67은 thyroid-relevant 7개 카테고리에서 67개 후보를 모은 풀:

  • TDS-core (16) — thyroid differentiation
  • MAPK-output (10)
  • Thyroid driver genes (12) — BRAF, NRAS, HRAS, KRAS, RET, NTRK1/3, ALK, PAX8, PPARG, TERT, EIF1AX
  • Aggressive-disease markers (10)
  • Dedifferentiation/EMT (10)
  • Light immune-stromal (5)
  • Thyroid-lineage extras (4)

8-gene panel은 TDS-core sub-category에서 canonical RAI-uptake biology (Yoo et al. 2016 PLOS Genet) 기반 선정 — Landa 2016 ATC-silenced gene list 접근 이전에 결정 (reverse-causality 차단 핵심).

왜 이 점이 reviewer 방어에 중요한가: 만약 8-gene panel을 "Landa ATC silenced gene 보고 만들었다"고 의심받으면 panel-driven circular inference. 본 paper는 Yoo 2016 RAI biology prior로 먼저 만들고 → 나중에 Landa와 5/8 overlap 발견 → independent paths converging to same biology framing.

S1.1 8-gene panel scoring algorithm

def score_panel(expr, gene_map):
    """expr: rows=samples, cols=genes (after gene_map applied)
    Returns: RAI_8 score (= mean within-sample-z), DM1_like (= -RAI_8)"""
    sub = expr.loc[:, list(gene_map.values())]
    # within-cohort z (per gene, across cohort samples)
    cohort_z = (sub - sub.mean(axis=0)) / sub.std(axis=0).replace(0, 1)
    # Average across panel
    rai = cohort_z.mean(axis=1)
    return DataFrame({"RAI_8": rai, "DM1_like": -rai})

# DM1/DM2 cluster
def kmeans_dm(scores, seed=42):
    km = KMeans(n_clusters=2, n_init=10, random_state=seed).fit(scores[["RAI_8"]])
    # DM1 = cluster with LOWER mean RAI_8
    dm1_label = int(np.argmin(km.cluster_centers_.flatten()))
    return Series(np.where(km.labels_ == dm1_label, "DM1", "DM2"))

S1.2 Cohort-level Cohen's d × DerSimonian-Laird meta

def cohens_d(a, b):
    sd_pool = sqrt(((n1-1)*var(a) + (n2-1)*var(b)) / (n1+n2-2))
    d = (mean(a) - mean(b)) / sd_pool
    se = sqrt((n1+n2)/(n1*n2) + d**2/(2*(n1+n2)))   # Hedges-Welch
    return d, se

def random_effects_pool(d_list, se_list):
    w_fe = 1/se**2
    d_fe = sum(w_fe*d) / sum(w_fe)
    Q = sum(w_fe*(d-d_fe)**2)
    df = len(d) - 1
    tau2 = max(0, (Q-df) / (sum(w_fe) - sum(w_fe**2)/sum(w_fe))) if Q > df else 0
    w_re = 1/(se**2 + tau2)
    d_re = sum(w_re*d) / sum(w_re)
    se_re = sqrt(1/sum(w_re))
    return d_re, se_re, ci95

A1. 8-gene panel 선정 (TIERA67 → 8)

TIERA67 67-gene candidate pool → 8-gene panel curation flow. 좌측 7 categories (TDS-core 16, MAPK 10, Driver-anchor 12, Aggressive 10, Dediff 10, Immune 5, Lineage 4) → 가운데 TIERA67 통합 67 genes → 우측 8-gene panel은 TDS-core sub-category에서 Yoo 2016 RAI biology prior로 선정. ★ Landa 2016 ATC silenced gene list 접근 이전 결정 — reverse-causality 차단.
Panel size sensitivity (5-fold CV AUC, TCGA n=504). 8-gene = 0.962 (selected, ★) / 10-gene = 0.972 (Δ=+0.010 NS) / 12-gene = 0.969 (Δ=+0.007 NS) / 16-gene full TDS-core = 0.975 (Δ=+0.013 NS). → 8-gene panel이 임상 deployable size + statistical performance trade-off 최적.
항목내용
데이터TCGA-THCA RNA-seq n=504 (Cell 2014 cohort), Yoo 2016 K2 PRJEB11591 n=235 reference, Landa 2016 ATC silenced gene list (post-hoc validation)
왜 이 분석BRAF/RAS-negative dark matter 안에서 mechanism-based stratification에 쓸 작은 panel이 필요. 너무 크면 임상 deployable 어렵고 (RNA cost), 너무 작으면 robustness 손실. Trade-off 정량화가 핵심.
분야 일반적 용도Curated gene panel selection은 임상 transcript signature 만들기의 표준 (예: Oncotype DX 21-gene, MammaPrint 70-gene, BRS 273-gene). 보통 (a) biological prior로 후보 풀 만들기 → (b) cross-validated AUC로 size 결정 → (c) leak-control 검증.
방법 상세① 7-category prior로 67 후보 (TIERA67) 모음: TDS-core 16 / MAPK-output 10 / Driver-anchor 12 / aggressive 10 / dediff-EMT 10 / immune-stromal 5 / lineage-extras 4. ② 8-gene panel = TDS-core sub-category에서 canonical RAI biology (Yoo 2016) 기반 직접 선정 — RandomForest 등 supervised feature selection 안 씀 (panel-driven inference 차단). ③ Panel size sensitivity: 8/10/12/16-gene 5-fold CV AUC 비교. ④ Critical: Landa 2016 ATC silenced list 접근 이전에 panel 결정 — reverse-causality 차단

A2. KMeans k=2 cluster (DM1/DM2 발견)

KMeans k=2 cluster assignment in 8-gene panel space (TCGA n=504). 빨강 = DM1 (lower RAI, suppressed differentiation, n=180), 초록 = DM2 (higher RAI, retained, n=320). X marker = cluster centers; 점선 = decision boundary. Mean silhouette score > 0.4 양 cluster 모두 — well-separated.
항목내용
데이터TCGA-THCA n=504 (8-gene × 504 matrix). 추가 검증: Korean K2 (n=235), Lee (n=632), 오늘 추가 — TCGA-PTC GDC (n=513), 4 GEO cohorts (n=206), CCLE (n=24).

분야 일반적 용도Lloyd 1957/1982의 KMeans는 transcriptome subtyping의 표준. 예: PAM50 breast cancer subtype (Parker 2009), TCGA pan-cancer subtype calls. 일반적으로 (a) feature scaling → (b) k 선택 (elbow / silhouette / gap) → (c) seed sensitivity → (d) cross-cohort reproducibility.
방법 상세① 8-gene panel을 within-sample-z (cohort-mean 0, cohort-SD 1)로 정규화. ② RAI_8 = z-score 평균. ③ KMeans k=2 (n_init=10, random_state=42) on RAI_8 1D vector. ④ Cluster 정의: 평균 RAI_8 낮은 쪽 = DM1 (suppressed differentiation), 높은 쪽 = DM2. ⑤ Silhouette score 검증.
Softwaresklearn.cluster.KMeans, scipy
결과TCGA n=504 silhouette score > 0.4 양 cluster. DM1 = 비교적 lower-RAI; DM2 = retained differentiation. 오늘 NComm push에서 4 GEO cohort (n=206) + CCLE (n=24)에서도 같은 cluster 재현.
한계(a) KMeans는 spherical cluster 가정 — 실제 transcriptional state는 continuum 가능. (b) k=2 선택 자체에 prior 있음 (k=3, k=4 검증 안 함 — 다만 sub-A vs sub-B sub-clustering으로 부분 검증). (c) Within-sample-z는 cohort-specific shift를 cancel — cohort 간 absolute scale 비교에는 부적합.

A8. DerSimonian-Laird random-effects meta-analysis

DerSimonian-Laird random-effects schematic. 좌측: 5 cohort effect sizes (point ± 95% CI). 우측: fixed-effects vs random-effects pool 비교. Random-effects는 τ² between-study variance를 추정해서 conservative pool — heterogeneity 반영해 CI 넓어짐. ★ 본 paper에서는 TCGA + MSK 두 cohort에서 I²=0%로 heterogeneity 검출 안 됨 → fixed/random 결과 거의 동일.
항목내용
데이터Cox HR + log-SE from TCGA (HR 2.30) + MSK (HR 2.67). 오늘 NComm push: per-cohort Cohen's d × 5 contrasts (4 GEO cohorts).
왜 이 분석Single-cohort underpower 또는 cohort-specific bias 우려 시, 여러 cohort 결과를 통계적으로 pool해서 더 강력한 추정. Between-cohort heterogeneity (I²) 정량화.
분야 일반적 용도DerSimonian & Laird 1986 — 의학 meta-analysis의 표준. Random-effects는 "between-study variance (τ²)"를 추정해서 fixed-effects보다 conservative. Cochrane review 기본 method.
방법 상세① 각 study에서 effect size (log HR 또는 Cohen's d) + SE 추출. ② Inverse variance weighting (fixed-effects). ③ Q statistic (homogeneity test): Q = Σ wᵢ(dᵢ − d_FE)². ④ τ² = max(0, (Q − df) / c) where c = Σwᵢ − Σwᵢ²/Σwᵢ. ⑤ Random-effects weight wᵢ_RE = 1/(seᵢ² + τ²). ⑥ Pool: d_RE = Σ(wᵢ_RE · dᵢ) / Σwᵢ_RE. ⑦ I² = max(0, (Q−df)/Q) × 100%.
Softwarestatsmodels.stats.meta_analysis (Python); R metafor::rma
결과TCGA + MSK pooled HR 2.53 [1.31-4.89], Cochran I²=0% (no detectable heterogeneity). 오늘 NComm push: ATC vs PDTC d_RE = −1.19 [−1.89, −0.49], p=8.7×10⁻⁴ (Landa GSE76039 single-cohort effect).
한계(a) k=2 cohort meta는 τ² 추정 신뢰도 낮음 (적어도 k≥5 권장). (b) Korean OS missing → meta input pool 축소. (c) Hedges-Welch SE for Cohen's d는 small-sample bias correction이지만 perfect 아님. (d) Cohort 수가 적을 때 random-effects의 advantage가 fixed-effects 대비 작음.
