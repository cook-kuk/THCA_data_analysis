L1. Discovery — clustering + 마커 식별

Phase A · Fig 1 · Fig 2

무엇을

  • 513 TCGA-THCA primary tumour의 RNA-seq 발현에 대해 unsupervised clustering
  • BRAF/RAS driver-negative residual에 한정해서 clustering (driver만으로 설명 안 되는 transcriptomic axis 찾기)
  • 각 cluster를 정의하는 marker gene 식별
  • cluster boundary가 batch / sample subsetting에 robust한지 검증

어떻게 (도구 / 방법)

  • scanpy 1.12.1 (Python single-cell 분석 라이브러리, bulk에도 적용 가능)
  • Leiden algorithm (community detection 알고리즘) K = 2 forced + resolution = 0.5
  • Marker DEG: per-cluster Wilcoxon rank-sum (비모수 양측 검정) + BH FDR
  • Bootstrap consensus (1,000-iter 재샘플링 후 cluster 일관성 측정) — concordance matrix
  • PCA + UMAP visualization
DM1 n=403 + DM2 n=110 · 41개 cluster-defining gene (FDR < 1×10⁻³⁰) · bootstrap concordance > 0.92

v6 ULTIMATE에서 cluster orientation 정정: DM1 = 분화 (well-differentiated, RAS-like, FVPTC), DM2 = 탈분화 (dedifferentiated, BRAF-like, cPTC/TCV/DHGTC).

L2. Validation — Cross-validation + External transfer

Phase B · Fig 6 · SuppFig 12 · Multi-cohort forest

무엇을

  • 8-gene panel을 TCGA-THCA에서 5-fold CV로 학습/검증
  • 완전 다른 cohort (5개)에 transfer
  • PDTC/ATC trajectory 일관성 외부 검증 (GSE76039)
  • 가장 큰 cross-platform cohort (GSE213647) 검증

어떻게

  • scikit-learn 1.8.0 LogReg(C=1.0, max_iter=2000) + RF(n_estimators=300)
  • 5-fold StratifiedKFold (계층화 5등분 교차검증) random_state=42
  • per-fold leave-one-cohort-out ComBat-seq (RNA-seq batch effect 보정) — leak 방지
  • BRAF V600E single-feature LogReg baseline → ΔAUC 비교
  • External transfer: 학습은 TCGA에서, 평가는 다른 cohort에서
  • Decision curve analysis (Vickers DCA) — net benefit vs 임계값
LogReg CV AUC = 0.954 / RF 0.975 / BRAF baseline 0.822 → ΔAUC = +0.132 · GSE76039 direction-correct AUC 0.974 · GSE213647 aggressive AUC 0.672 (cross-platform 감소) · 5-cohort 2/5 robust (DIA-AUC > 0.85)

L3. Biology — DEG + GSEA + Trajectory + Hot/Cold

Fig 3 · Fig 5 · scRNA

무엇을

  • DM1 vs DM2 differential expression (full transcriptome)
  • Hallmark pathway enrichment
  • PTC → PDTC → ATC dedifferentiation trajectory
  • scRNA-seq cell-type breakdown
  • Hot/cold immune composite
  • Immune evasion gene panel (PD-L1, IDO1, CTLA4, HLA, B2M)

어떻게

  • DEG: DESeq2-like Wilcoxon rank-sum + BH FDR (비모수 양측, 다중 검정 보정)
  • GSEA: gseapy 1.13 prerank (사전 랭킹된 gene list 기반 enrichment) with MSigDB Hallmark v2024.1.Hs (Broad Institute의 51개 well-curated pathway 모음) — nperm = 1000
  • Trajectory: pseudotime 추정 → DM cluster 할당 + RAI score 상관
  • scRNA: per-cell DM signature score → per-patient dominant DM → cell-type fraction
  • Hot/Cold composite: cytolytic activity (GZMA × PRF1 geometric mean — effector T/NK cell 활성) + Hallmark IFN-γ + immune-cell fraction → z-norm 평균
  • Immune-evasion: per-sample mean expression of CD274, PDCD1, CTLA4, IDO1, HLA-A/B/C, B2M
GSEA: Inflammatory NES = +1.93 / IFN-γ +1.92 / TNFA +1.85 / Allograft +1.89 (FDR < 1×10⁻¹⁵) / OxPhos −1.90 (FDR=0) · Trajectory: pseudotime ↔ RAI Spearman ρ = 0.74 (p < 1×10⁻¹⁵) · scRNA: 57:1 immune dominance ratio · Hot/Cold composite Cohen's d = +1.683 (Mann-Whitney p = 4.0×10⁻¹⁸)

L4. Clinical — Cox + Alternative Endpoints + Histology

Fig 2 · FIX3 · TCGA-CDR

무엇을

  • DM1/DM2 cluster이 OS / PFI / DSS / DFI 4개 endpoint에 대해 독립적인 prognostic 인자인지
  • age + stage + sex 보정 후 효과 유지되는지
  • Histology subtype enrichment (cPTC / FVPTC / oxyphilic / columnar)
  • Bethesda category cross-tab
  • Age 분포, TDS / RAI score 분포

어떻게

  • lifelines 0.30 CoxPHFitter (penalty=0.01 — small-event 안정화, Firth-like correction)
  • Cox multivariable regression (다변량 Cox 회귀, 여러 covariate 동시 보정)
  • Fisher exact test (작은 표본 contingency table 정확 검정) for histology enrichment
  • Mann-Whitney U-test (두 그룹 비모수 비교) for age, TDS, RAI
  • Endpoint source: TCGA-CDR (TCGA Clinical Data Resource — Liu 2018 Cell, OS/DSS/DFI/PFI 표준 endpoint 모음)
OS Cox: HR 0.82 (DM1/DM2, age + stage 보정 후 not significant — TCGA-THCA의 ~16 OS event 한계) · rai_score_recalc continuous best (nominal p < 0.05) · Age violin Mann-Whitney p < 1×10⁻⁸ (Δ=13y) · Histology Fisher p < 0.05 (4 subtype 모두)

DM1/DM2 cluster가 OS independent prognostic이 아닌 점은 honest limitation #3 (TCGA-THCA의 exceptional prognosis 때문). RAI-responsiveness가 더 적절한 clinical endpoint.

L5. TERT — 4-group survival + Bootstrap + LOO + Multivariate Cox

★ R8 honest reframe · Fig 8 · v17_actual

무엇을

  • cBioPortal thca_tcga_pub mirror에서 TERT promoter mutation 36명 회수
  • Liu-Xing 4-group (BRAF only / RAS only / TERT⁺ / Triple-neg) 생존 분석
  • TERT⁺ 단독 logrank
  • univariate Cox HR 측정
  • ★ stage + age + sex 보정 multivariate Cox
  • 1,000-iter stratified bootstrap robustness
  • 36-patient leave-one-out (LOO) sensitivity
  • DM × TERT cross-tab (Fisher) — 두 axis가 독립적인지

어떻게

  • multivariate_logrank_test (lifelines, 다군 logrank)
  • CoxPHFitter with L2 penalizer 0.01 (Firth-like correction)
  • bootstrap: numpy random.choice resample × 1,000 → per-iter logrank → p-value 분포
  • LOO: 36명 TERT⁺ 한 명씩 제외 → 4-group logrank 재계산
  • Fisher exact: DM-clustered 178 sample 안에서 TERT⁺ 5명 vs WT
  • scripts: v17_ACTUAL_robustness.py, v17_ACTUAL_figures.py
  • output: results/v17_actual/A1A_cox_unadjusted.tsv, A1A_cox_full_multivariate.tsv, A1B_bootstrap_logrank.tsv, A1C_loo_logrank.tsv, A1C_influence_score.tsv
4-group multivariate logrank p = 3.78×10⁻⁵ · TERT-vs-WT logrank p = 4.92×10⁻⁶ · univariate Cox HR = 6.31 (95% CI 2.34–17.04, p = 3×10⁻⁴) → multivariate Cox HR = 1.88 (95% CI 0.58–6.09, p = 0.29) · bootstrap median p = 2.6×10⁻⁵ (93% iter p < 0.05) · LOO worst-case p = 7.5×10⁻⁴ (모두 36개 LOO p < 10⁻³) · DM × TERT Fisher p = 0.65 (underpowered) → 두 axis 독립

honest reframe: TERT⁺를 "독립 stage-and-age-independent prognostic marker"가 아니라 "Stage III/IV identification을 위한 molecular handle"로. univariate signal은 stage / age confounding이 거의 전부.

L6. Drug — PRISM 4,517 compounds + Mechanism class enrichment

Fig 7 · CCLE thyroid 11 lines

무엇을

  • PRISM Repurposing 19Q4 4,517 compound × thyroid CCLE 11 lines
  • per-compound DM1 vs DM2 차별 약물 반응
  • MOA별 enrichment count (어떤 mechanism class가 DM1 / DM2 selective인가)
  • BRAF concordance 검증 (4/4 BRAF 라인이 DM1?)

어떻게

  • cell-line cluster assignment: within-thyroid-cohort z-score median split (5 vs 5)
  • per-compound: ΔLFC = DM1_mean_LFC − DM2_mean_LFC + Mann-Whitney p-value
  • BH FDR correction (Benjamini-Hochberg false discovery rate) — 4,517 multiple test 보정
  • MOA enrichment: 각 mechanism class 안 compound 수 (DM1 vs DM2)
  • Source: figshare 9393293 (file IDs 20237709/20237715/20237718)
BRAF concordance 4/4 perfect · 0 compounds at FDR < 0.1 (n=5 vs 5 underpowered) · nominal mechanism-class signals: MEK inhibitor (nobiletin ΔLFC = −0.72, p = 0.016) DM1-selective · HMGCR inhibitor (procaine ΔLFC = −0.39, p = 0.032) DM1-selective · Topo-I idarubicin ΔLFC = −1.85 (p = 0.095, underpowered)

honest framing: n=5 vs 5는 single-drug FDR-grade discovery에 부족. Mechanism class direction (MEK + HMGCR DM1-selective)이 biologically coherent + v14 LDLR-axis와 일치 → "hypothesis-generating, not finalised clinical recommendation"으로 명시.

v6 ULTIMATE · 4 independent evidence layers

무엇을

  • 0.954 CV AUC가 circular validation인지 확인 + leak-free 재구성

어떻게 (4가지 독립 증거)

  • U2A — WHO 2022 매핑: 2022 WHO 분류로 histology 재라벨링 → DM 분포
  • U2C — Pu 2021 direction concordance: 외부 published signature와 direction 일치 측정
  • U1D — methylation cross-modality: TCGA 450K methylation → met-DM cluster → aggressive histology 분포
  • U1C — GSE213647 dm-score: cPTC > PDTC > ATC 분포 패턴
  • De-circularization (v6 ULTIMATE 4 leak-free variant):
    • Variant A: TIERA67-8gene (Thyroid Immune-Excluded RAS-Associated 67 genes 중 8 gene 빼고 47 gene)
    • Variant B: MAPK + immune + EMT (30 genes, 8-gene과 zero overlap)
    • Variant D: BRS71-8gene (BRS 71-gene 중 8-gene 빼고 26 gene)
    • Variant C: immune-only 5 genes (control — biology specificity 입증용)
U2A: DM2 = 85.6% BRAF-like cPTC, DM1 = 77.5% RAS-like FVPTC → DM1=분화 confirmed · U2C: 88.9% (8/9) signature gene direction concordant · U1D: 모든 aggressive histology 100%가 met_DM2 · U1C: cPTC > ATC dm-score (DM1=분화) · Leak-free Variant A AUC 0.962 / B 0.925 / D 0.957 / C 0.664 (붕괴) · ΔAUC vs BRAF +0.111 ~ +0.130

v5의 cluster orientation 표기는 4개 독립 증거 모두 반대로 확인 → v6 ULTIMATE에서 정정. 0.954 circular figure는 더 이상 claim 안 함; honest range AUC 0.92–0.96.

SuppFig 1, 2, 3, 4

어떻게

L11. Signature stability — 5-method ARI + sub-sample bootstrap

v17p2 robustness_5method_ARI

무엇을

  • Leiden 외에 다른 clustering method (k-means / hierarchical / spectral 등) 5개로도 같은 cluster가 나오는지
  • sample을 무작위로 50% / 70% / 90% 뽑아 다시 clustering → 일관성

어떻게

  • 5 method (Leiden / k-means / hierarchical_ward / spectral / GMM) 각각 K=2 fit
  • 각 method 쌍에 대해 ARI (Adjusted Rand Index — 두 partition 일치도, -1 ~ +1) + NMI (Normalized Mutual Information)
  • Sub-sample: 50/70/90% sample subset × 100회 → cluster stability 비율
  • output: v17p2/tables/robustness_5method_ARI.tsv, sample_subsample_stability.tsv
5-method ARI 평균 0.85 (Leiden vs k-means / hierarchical 모두 0.8 이상) · 50% subsample stability 92% · 90% subsample stability 99%
