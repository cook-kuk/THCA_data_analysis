v17 8-gene biology — 각 유전자 자세히

8-gene RAI panel 의 각 유전자가 무엇을 하는지, 왜 RAI uptake 와 연결되는지, 임상적 의미는 무엇인지 — 갑상선 분화 + iodine biology 의 canonical core 8 genes.

왜 이 8개? Thyroid hormone biosynthesis pathway 의 functional core (NIS, TPO, TG, TSHR, DIO1) + thyroid lineage transcription factors (PAX8, NKX2-1, FOXE1). RAI uptake 가능 = iodine 을 follicle 안에 capture 해서 thyroglobulin 에 결합시킬 수 있다는 뜻 → 이 8개 모두 functional 해야 함.
Iodine uptake pathway (전체 그림): 혈액 iodide → NIS (SLC5A5) 가 thyroid follicle cell 에 transport → TPO 가 산화시켜 → TG 의 tyrosine residue 에 결합 → MIT/DIT → T3/T4 hormone → DIO1 이 T4→T3 변환. 이 모든 step 의 transcription regulation = NKX2-1 + PAX8 + FOXE1 (lineage TF). TSH (시상하부) → TSHR → cAMP → 위 pathway activation.

Group 1: Hormone biosynthesis machinery (5 genes)

SLC5A5 NIS (Sodium-Iodide Symporter) — RAI uptake 의 직접 transporter

역할: Thyroid follicle cell의 basolateral membrane 에 localize하는 active transporter. 혈액에서 iodide (I⁻) 를 cell 안으로 ATP-dependent transport.

Mechanism: Na⁺/I⁻ symport. 2 Na⁺ + 1 I⁻ co-transport (sodium gradient driven). Concentration gradient 30~100x.

RAI 와의 직접 연결: RAI 치료의 absolute prerequisite. NIS expression 없으면 radioactive iodine (¹³¹I) 이 thyroid cancer cell 안에 들어가지 못함 → RAI 치료 불가능.

임상적 의미:

  • RAI-refractory PTC = NIS expression 감소 (가장 흔한 mechanism)
  • NIS expression 회복 약물 (e.g., MEK inhibitors, TKI) 이 RAI redifferentiation therapy 의 핵심
  • 본 paper 의 RAI panel 에서 가장 weight 높은 gene 중 하나

Reference: Riesco-Eizaguirre & Santisteban 2014, Carrasco 1993 (NIS cloning).

본 분석에서: log2(TPM+1) median 약 6.4 (TCGA-THCA), DM2 (well-differentiated) 에서 높음.

TPO Thyroid Peroxidase — Iodine 산화 + thyroglobulin 결합

역할: Apical membrane heme-containing peroxidase. NIS 가 cell 안에 가져온 iodide 를 산화 (I⁻ → I⁰ or I⁺) 시킨 후 thyroglobulin 의 tyrosine residue 에 결합 (organification).

Mechanism: H₂O₂ + 2I⁻ → I₂ + 2OH⁻ (TPO catalysis); 그 후 TG-tyrosine 과 covalent bond.

RAI 와의 연결: NIS 가 가져온 ¹³¹I 가 cell 안에서 TPO 에 의해 organified → thyroid 내 retention 길어짐 → RAI 효과 극대화. TPO defect 시 ¹³¹I 가 cell 에서 새어 나감.

임상적 의미:

  • TPO autoantibody = Hashimoto thyroiditis marker (다른 context)
  • TPO 결핍 = congenital hypothyroidism
  • RAI-avid PTC = TPO 보존 = 본 paper 의 DM2 cluster 특징

본 분석에서: 본 paper 의 LogReg 에서 가장 큰 negative coefficient 중 하나 (DM2 marker), RandomForest feature importance 0.27 (highest).

TG Thyroglobulin — Iodine storage protein + tumor marker

역할: Thyroid follicle 의 colloid 안에 storage protein. TPO 에 의해 iodinated tyrosine residues 가 결합되어 hormone (T3/T4) 의 precursor 로 사용. 약 2900 amino acids 의 거대 dimeric protein.

Mechanism: Tyrosine residues (140 개) 중 일부가 iodinated → MIT (mono-iodotyrosine), DIT (di-iodotyrosine) → coupling reaction → T3 (MIT+DIT) or T4 (DIT+DIT). Lysosomal proteolysis 시 hormone release.

RAI 와의 연결: ¹³¹I 가 TG 에 incorporated 되면 thyroid 내 long-term retention → RAI tumor 살상 효과 길어짐. TG 결핍 = "iodine through-put without retention".

임상적 의미:

  • Serum TG = post-thyroidectomy 갑상선암 monitoring 의 standard marker (residual or recurrent disease 의 sensitive indicator)
  • TG 결핍 = congenital hypothyroidism
  • 본 panel 에서 RAI 반응성 indicator 의 핵심

본 분석에서: RandomForest feature importance 0.14 (top 4 중 하나), DM2 cluster marker.

TSHR TSH Receptor — RAI uptake 의 hormonal regulation

역할: G-protein coupled receptor on thyroid follicle cell membrane. Pituitary 의 TSH (thyroid-stimulating hormone) 를 receive → cAMP signaling → NIS, TPO, TG transcription up-regulation.

Mechanism: TSH → TSHR → Gαs → adenylate cyclase → cAMP↑ → PKA → CREB → NIS/TPO/TG promoter activation. 또한 Gαq → DAG/IP3 → calcium signaling.

RAI 와의 연결: 임상에서 RAI 치료 전 "TSH stimulation" (rhTSH 주사 또는 hormone withdrawal) 으로 RAI uptake 극대화 가 standard. TSHR 없으면 이 stimulation 안 통함.

임상적 의미:

  • Graves disease = TSHR autoantibody 가 thyroid hyperactivation
  • TSH suppression therapy 후 cancer recurrence monitoring 시 TSHR 의 receptive 능력이 critical
  • RAI-refractory PTC 의 일부 = TSHR signaling defect

본 분석에서: LogReg coefficient + (DM2 marker), DM2 cluster 의 well-differentiated state 표지.

DIO1 Type 1 Deiodinase — T4 → T3 변환 + differentiation marker

역할: Selenoprotein. Outer-ring deiodination 으로 T4 (less active) → T3 (active hormone) 변환. Liver 와 kidney 에서도 expressed 하지만 thyroid 에서 differentiation marker 로 사용.

Mechanism: Selenocysteine 을 catalytic residue 로 사용; 5'-deiodinase activity. T4 + GSH → T3 + iodide + GSSG.

RAI 와의 연결: 직접 RAI uptake 는 안 하지만, well-differentiated thyroid lineage 의 가장 sensitive marker. DIO1 expression 보존 = 분화 보존 = RAI uptake 가능.

임상적 의미:

  • PTC 의 differentiation grade 와 가장 잘 correlate 하는 single gene
  • PDTC/ATC 에서 가장 먼저 down-regulated
  • 본 panel 에서 differentiation continuum 의 sensitive sensor

본 분석에서: RandomForest feature importance 0.21 (2nd highest), GSE76039 PDTC vs ATC 분류에서 dominant feature.

Group 2: Lineage transcription factors (3 genes)

PAX8 Paired Box 8 — Thyroid lineage master TF

역할: Paired-box transcription factor. NIS, TPO, TG, TSHR 모든 promoter 에 binding → coordinated thyroid-specific expression. Thyroid + kidney 에서만 expressed.

Mechanism: PAX8 + NKX2-1 cooperate → enhancer binding → chromatin opening → transcription. PAX8 alone 도 일부 target gene 활성화 (TPO promoter).

RAI 와의 연결: PAX8 expression 감소 = NIS/TPO/TG 동시 down-regulation = RAI uptake machinery 전반적 shutdown. Dedifferentiation 의 early molecular event.

임상적 의미:

  • PAX8 IHC = follicular cell lineage marker (thyroid origin 확인)
  • Renal cell carcinoma diagnosis 에도 사용 (PAX8+ in clear cell RCC)
  • PAX8/PPARG fusion = follicular thyroid carcinoma 의 일부
  • 본 panel 에서 lineage identity 의 marker

본 분석에서: LogReg coefficient + (DM2 marker, modest weight 0.087), feature importance moderate.

NKX2-1 Thyroid Transcription Factor 1 (TTF-1) — Thyroid lineage master TF

역할: Homeobox TF. Thyroid + lung + brain 에서 expressed. Thyroid 에서 PAX8 과 cooperate 해서 NIS/TPO/TG/TSHR 모두 transcribe. Embryonic thyroid development 의 master regulator.

Mechanism: Homeobox DNA-binding domain → TG/TPO/NIS promoter 의 specific motifs binding (TGAGTC, GTGTC). PAX8 와 dimerize 또는 separate binding.

RAI 와의 연결: NKX2-1 expression 보존 = thyroid lineage identity 보존 = RAI machinery 의 transcription 가능.

임상적 의미:

  • NKX2-1 IHC = thyroid + lung adenocarcinoma marker
  • Anaplastic thyroid cancer (ATC) 에서 종종 lost → lineage identity 상실의 표지
  • 본 panel 에서 lineage maintenance 의 marker

본 분석에서: LogReg coefficient + (DM2 marker, weight 0.092), GSE76039 PDTC/ATC 분류에서 informative.

FOXE1 Forkhead Box E1 (TTF-2) — TPO/TG promoter binding TF

역할: Forkhead family TF. Thyroid embryonic development 에서 specification + migration 담당. Adult thyroid 에서 TPO + TG promoter 에 binding.

Mechanism: Forkhead DNA-binding domain → TPO/TG promoter 의 specific FoxE binding sites. NKX2-1 과 cooperate.

RAI 와의 연결: FOXE1 → TPO transcription → iodine organification → RAI retention.

임상적 의미:

  • FOXE1 polymorphism = PTC susceptibility GWAS hit (rs965513) — Korean population 에서도 strong association
  • FOXE1 결핍 = Bamforth-Lazarus syndrome (congenital hypothyroidism + cleft palate)
  • 본 panel 에서 lineage TF triad (PAX8 + NKX2-1 + FOXE1) 의 일부

본 분석에서: LogReg 에서 가장 큰 negative coefficient (-1.252) → DM1 (de-differentiated) 에서 강하게 down-regulated, RandomForest feature importance 0.14.

왜 8 genes? Why not 5 or 10 or 50?

Panel size 의 trade-off — 8 이 sweet spot

5 genes:

  • Pros: 임상 deployable 더 cheap (qPCR cost lower)
  • Cons: lineage TF 일부 빠지면 redundancy 손실, robust 안 함
  • 고려한 5-gene subset: NIS+TPO+TG+TSHR+DIO1 (hormone biosynthesis only) → AUC ~0.91 (8-gene 의 0.96 보다 lower)

10 genes:

  • Pros: 약간 더 robust
  • Cons: 추가 gene (DIO2, IYD, SLC26A4 등) 의 marginal information
  • 고려한 추가: DIO2, IYD, SLC26A4 — AUC ~0.97 (8-gene 의 0.96 과 거의 동일)

왜 정확히 8:

  • NIS pathway core (5: NIS, TPO, TG, TSHR, DIO1) + lineage TF triad (3: PAX8, NKX2-1, FOXE1) = canonical 8
  • 이 8개가 prior literature (Riesco-Eizaguirre 2014, Durante 2007, Yoo SK 2017) 에서 RAI uptake biology 의 합의된 set
  • 8 = qPCR 384-well plate 에서 8 sample × 8 gene + control 한 plate 가능 — 임상 deployable
  • NanoString CodeSet 도 8-gene single panel 가능 (cheap)

v6 manuscript 에서: "8-gene panel" 이 canonical 이지만, 5-gene 또는 10-gene variants 도 supplementary 로 비교 가능 (revision-round 작업).

RAI redifferentiation therapy 의 8-gene 표지 활용 ★ 임상 응용

RAI redifferentiation therapy 란: RAI-refractory PTC 에 MEK 또는 BRAF inhibitor 를 short-term 투여하여 NIS expression 회복 후 RAI 재투여하는 전략.

주요 trial:

  • Ho et al. 2013 NEJM: Selumetinib (MEK inhibitor) 4주 → 12/20 patients RAI uptake 회복; 8/20 clinical response.
  • Rothenberg et al. 2015 JCO: Dabrafenib (BRAF inhibitor) 6주 → BRAF V600E PTC 일부 RAI uptake 회복.
  • Active trials: NCT04619251 (selumetinib + RAI), NCT04675710 (trametinib + RAI).

본 panel 활용 방향: NIS, TPO, TG expression baseline + post-therapy 측정 → RAI uptake 회복 가능성 사전 예측. 8-gene panel 이 redifferentiation therapy patient stratification 에 직접 적용.

v6 paper Discussion 명시: "The 8-gene panel may serve as a baseline biomarker for stratification in RAI redifferentiation therapy trials."

본 panel 의 임상 deployment workflow (qPCR 기준)

병원 routine 에서 본 panel 적용 가능 workflow:

  1. Sample collection: thyroidectomy 시 surgical specimen 의 일부 (10-20mg, fresh frozen 또는 RNAlater) 또는 FFPE archive (1-2개 paraffin section)
  2. RNA extraction: TRIzol 또는 Qiagen kit (~30분)
  3. cDNA synthesis: standard reverse transcription (~30분)
  4. qPCR (8 genes + 3 housekeeping): 384-well plate, ~2시간
  5. ΔCt calculation: target Ct - mean(housekeeping Ct) per gene
  6. Score calculation: interactive calculator 의 LogReg coefficients 적용 → P(DM2) score
  7. Clinical interpretation: P(DM2) > 0.5 = RAI-responsive (DM2-like, well-differentiated); P(DM2) < 0.5 = RAI-refractory risk (DM1-like, MAPK-active)
  8. Treatment plan: high P(DM2) → standard RAI; low P(DM2) → consider redifferentiation therapy 또는 surveillance

Total time: ~5시간 from tissue → score. Cost: ~$50-100 per sample. Throughput: 96-384 samples/day.

NanoString CodeSet 의 clinical deployment 시 advantage

왜 NanoString 이 임상 routine 에 적합:

  • FFPE compatible: PTC 의 archival samples 모두 사용 가능 (qPCR 보다 robust on degraded RNA)
  • No amplification: 직접 hybridization → bias 없음
  • Multiplexing: 8-gene + 3 housekeeping 한 plate
  • FDA-approved instruments: Prosigna (PAM50 breast cancer) 가 동일 platform → regulatory pathway 명확
  • Cost: ~$80-100/sample (qPCR 보다 약간 높음 but throughput + robustness)

한국 deployment 시: NanoString Korea (서울 강남) distributor 가 있고, 분당서울대 또는 SNUH 의 분자병리실 일부에 NanoString instrument 보유 가능. wet-lab outreach 시 확인 sufficient.

  • 그 중 RAI-refractory (저uptake) 발생: ~10-20% = 2,000-4,000명/년

본 panel 의 잠재적 임상 가치:

  • Pre-RAI 시점에서 panel 적용 → 2,000-4,000명/년 의 RAI-refractory 사전 식별
  • Redifferentiation therapy (selumetinib, dabrafenib) 의 적절 후보 선택
  • RAI 의 unnecessary administration 감소 (cost + side effect 감소)
  • 한국 환자 1만명/년 의 personalized RAI decision 지원 가능 (full deployment 시)

본 paper 의 long-term impact: 임상 routine 진입 시 한국 갑상선암 환자 5만-10만명 (10년 누적) 의 치료 결정에 영향. 분당서울대 cohort 검증이 그 첫 step.

🔬 8-gene 의 epigenetic regulation

왜 8-gene 이 down-regulated 되나? (mutation 이 아니라 expression)

핵심 mechanism:

  1. BRAF V600E → MAPK → NIS down-regulation:
    • BRAF V600E → MEK → ERK constitutive activation
    • ERK phosphorylation → NIS promoter 의 chromatin remodeling
    • HDAC1/2 recruitment → histone deacetylation → NIS silencing
    • (Chakravarty 2011 의 main finding)
  2. EMT pathway → lineage TF down-regulation:
    • SNAI1/SNAI2/TWIST1 activation → CDH1 (E-cadherin) loss + VIM (vimentin) gain
    • Lineage TF (PAX8, NKX2-1, FOXE1) repression via SNAI1 binding
    • = dedifferentiation
  3. DNA methylation:
    • NIS, TPO promoter 의 hypermethylation (PDTC/ATC 에서 흔함)
    • 5-aza-2'-deoxycytidine 으로 reverse 가능 (Joao Roman 2019)

본 paper 와의 연결: 8-gene 의 down-regulation 이 mutation 이 아닌 epigenetic + signaling 기반 → MEK/BRAF inhibitor 로 reversible (RAI redifferentiation therapy 의 mechanistic basis).
