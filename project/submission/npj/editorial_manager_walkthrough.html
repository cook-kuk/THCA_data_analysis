🛠 Common errors + 즉시 해결

Error: "File upload failed"
  • Main manuscript: 50 MB limit. 본 v6 PDF = 3.2 MB → OK.
  • Figure individual: 20 MB limit. 본 figures < 1 MB each → OK.
  • Supplementary ZIP: 100 MB. 본 reviewer_bundle.zip = 16 MB → OK.
  • Format support: PDF, DOCX, PNG, TIFF, EPS only. JPG/GIF 안 됨.
  • Fail 시: browser cache clear → re-login → retry
Error: "Author affiliation incomplete"

Yu Hyeong Won 교수님 affiliation placeholder 그대로면 EM 가 알람.

Hour 0 brief 의 답에서 받기. 만약 못 받으면 default placeholder 그대로 제출 가능 (revision 시 fix). 그러나 ideally Hour 0-12 안 fill.

Error: "Manuscript exceeds word limit"

npj Article: 5,000 words main text. 본 paper ~3,800 → 안전.

EM 의 word count 가 figure legends + references 도 포함시키면 ~5,500 가능 → trim 필요. Advanced setting 에서 exclude 가능.

Error: "Submission saved but cannot proceed"

Required field 비어 있음. EM "Required Items" tab 에서 missing list 확인. 보통:

  • Funding statement → "No funding to disclose"
  • Ethical approval → "Not applicable (TCGA + GEO public data)"
  • Data availability statement → 명시
Error: "Manuscript blinding insufficient" (double-blind 인 경우)

npj 보통 single-blind 이지만 double-blind 옵션 있음. Double-blind 시:

  • 본문에서 "[author's institution]" 같은 self-reference 제거
  • Acknowledgements 의 specific name 제거
  • Code: anonymous_code.zip 사용 (GitHub URL 대신)

🇰🇷 한국 저자 특별 가이드

한국 저자 EM 등록 시 주의사항
  • Last name / first name 입력: EM 가 "Family name" + "Given name" 분리 요구. 한국 이름 "국승호" → Family: Cook, Given: Seungho. 또는 Family: Kook, Given: Seungho (transliteration 일관성 중요 — Pubmed 와 동일하게).
  • Affiliation 영문 표기: "서울대학교 융합과학기술대학원" → "Graduate School of Convergence Science and Technology, Seoul National University". SNUH (Seoul National University Hospital) 와 헷갈리지 않게 명확히.
  • 분당서울대 영문 표기 (협력 시): "Seoul National University Bundang Hospital" (= SNUBH). "Department of Surgery" 또는 "Department of Surgery, Endocrine Surgery Section". 유형원 교수님께 confirm.
  • Email domain: kukshomr@gmail.com (개인) OK. snu.ac.kr 계정 있으면 더 좋음 (institutional 신뢰도).
한국에서 Editorial Manager 접속 시 issue
  • Time zone: EM 은 ET (US Eastern). KST = ET + 13h or 14h (DST). Submission deadline 이 ET 기준이면 한국에서는 다음날 오후 1-2시.
  • Browser: Chrome / Edge 권장. Safari 일부 form field 호환성 issue 보고됨.
  • 한글 character 입력: Title / abstract 영문이면 OK. Author name 등록 시 한글 입력은 metadata 에 깨질 수 있음 → 영문만.
  • Network: 한국 ISP 일부에서 EM 접속 느림 (springer 서버 위치). 새벽 시간대 권장.

Desk reject 시 next step

npj desk reject 받으면 (보통 7-48시간 안):

  1. Editor reasoning 확인 (보통 짧은 이메일)
  2. Reasoning 에 따라 venue change:
    • "out of scope" → BMC Cancer / Frontiers Oncology
    • "too preliminary" → Endocrine-Related Cancer (specialty)
    • "insufficient external validation" → Korean cohort 받은 후 재제출
  3. Cover letter 만 재작성하면 manuscript transferable
Revision round 처리 가이드

"Major Revision" 또는 "Minor Revision" 받으면:

  1. Reviewer comments 한 줄씩 분석
  2. Response letter 작성 (각 comment 에 point-by-point): 
    Reviewer #1 Comment 1: "..."
Authors' Response: We thank the reviewer for...
We have addressed this by [specific change in manuscript].
Manuscript change: [page X line Y] "[new text]"
  3. Manuscript 에 changes 표시 (track changes 또는 highlighted)
  4. Korean cohort 결과 받았으면 통합 → Fig 10 추가
  5. Resubmit
