**핵심 결과 3가지**

1. **DM1/DM2 transcriptomic axis 발견**
   BRAF/RAS 변이 분류와 통계적으로 구별되는 새 분류 axis (Spearman ρ = 0.49 — substantial overlap이지만 redundant 아님). 차별화-면역 상태 연속체.

2. **8-gene RAI 반응성 패널** (NIS, TPO, TG, TSHR, PAX8, NKX2-1, FOXE1, DIO1)
   5-fold CV AUC 0.954. BRAF V600E 단독 (AUC 0.822) 대비 ΔAUC = +0.132. 임상 즉시 적용 가능한 RAI 결정 지원 도구.

3. **TERT 4-group survival**
   cBioPortal `thca_tcga_pub` mirror에서 TERT promoter mutation 36명 회수. 4-군 (BRAF / RAS / +TERT / Triple-neg) stratification logrank p = 4.92×10⁻⁶. Liu–Xing (JAMA Oncol 2017) framework을 TCGA에서 확인.
