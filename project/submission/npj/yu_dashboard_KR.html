1. 한 페이지 요약

핵심 contribution. 갑상선암 (PTC, 유두암) 의 8-gene RAI-responsiveness panel — TCGA-THCA 178명 driver-negative subset에서 발견한 DM1/DM2 분류축을 8개 갑상선 분화 marker (NIS/SLC5A5, TPO, TG, TSHR, PAX8, NKX2-1, FOXE1, DIO1) 만으로 5-fold CV AUC 0.954 로 재현 가능. BRAF V600E status 단독 (AUC 0.822) 대비 ΔAUC = +0.132 향상.

이번 sprint의 새 layer 3개. (i) 4개 외부 cohort meta-analysis pooled AUC 0.980 (95% CI 0.87–1.00, I² = 0%) — GSE27155, GSE29265, GSE33630, GSE76039 모두 AUC ≥ 0.96. (ii) Decision Curve Analysis — 8-gene panel이 BRAF-only 대비 임상 의사결정 threshold 0.05–0.95 전 구간에서 net benefit 우위. (iii) Subgroup robustness — age/sex/stage/histology 9개 subgroup 중 7개에서 AUC ≥ 0.85 (Male n=46, FVPTC n=57 두 subgroup만 marginal). 이 세 layer = npj reviewer가 가장 좋아하는 evidence (clinical utility + external validation + subgroup defense).

정직한 약점. TERT promoter mutation 4-group 분석은 multivariate Cox 후 stage + age 보정 후 HR = 1.88 (p = 0.29) — univariate는 강했지만 stage와 age로 거의 다 잡힘. v3에서 reframe: TERT⁺는 Stage III/IV 분자 marker 로 보고 (independent prognostic axis 아님). 8-gene panel 자체에는 영향 없음.

2. 진짜 기여 3개 + 정직한 약점 3개

✅ 진짜 기여 (npj reviewer 설득용)

  1. 8-gene RAI panel. CV AUC 0.954 vs BRAF-only 0.822, 5-cohort meta pooled 0.980. 임상 implementation 가능 — RNA-seq, microarray, NanoString 모두에서 작동.
  2. DM1/DM2 transcriptomic 분류축. Driver-negative residual 178명에서 발견한 unsupervised cluster — 41 marker FDR < 1e-30, 17개 cross-table outlier가 BRAF/RAS dichotomy 와 statistically distinct (Spearman ρ = 0.49). 즉 BRAF/RAS와 redundant 하지 않은 진짜 새 axis.
  3. Hot/Cold immune separation (Cohen's d = +1.683). Cytolytic + IFN-γ + immune fraction composite score 가 DM1/DM2 를 깨끗이 분리 (Mann-Whitney p = 4×10⁻¹⁸). 4-pathway proper preranked GSEA + scRNA + immune evasion + composite all coherent.

⚠ 정직한 약점 (limitations 정직 명시)

  1. TERT 4-group은 stage-handle. Univariate p = 4.92×10⁻⁶ → multivariate (stage+age+sex) p = 0.29. 정직 reframe: "TERT⁺ as molecular handle for Stage III/IV". 자세히는 §4 참고.
  2. Wet-lab validation 부재. 모든 결과 in silico — 8-gene panel 의 임상 deployment 는 prospective biopsy cohort 검증 필요. 분당서울대 outreach 진행 중.
  3. External cohort proxy label. 4개 GEO cohort 에 DM1/DM2 ground truth label 이 없어서 unsupervised differentiation-axis stratification 을 proxy 로 사용 — 즉 pooled AUC 0.980 은 8-gene panel 이 cohort 내 differentiation axis 와 align 한다는 의미이지 독립 ground truth 와 일치한다는 의미 아님. v4 manuscript Limitations 에 명시.

5. TERT 4-group · 정직 reframe

Univariate 결과 (강함, R8 첫 결과). 4-group multivariate logrank p = 3.78×10⁻⁵; TERT⁺ univariate Cox HR = 6.31 (95% CI 2.34–17.04, p = 3×10⁻⁴); LOO sensitivity = 36 patient 모두 leave-out 해도 p < 0.001 (single event 효과 아님).

Multivariate 결과 (약함, R8 정직). Stage + age + sex 보정 후 HR = 1.88 (95% CI 0.58–6.09, p = 0.29). 즉 stage 와 age 가 신호의 대부분을 잡음. TERT⁺ patient는 median age 64.6 (vs 46), 61% Stage III/IV (vs 21–32%) — confound 확인.

v3 reframe. "TERT⁺ as molecular handle for Stage III/IV identification" — independent prognostic axis 아님 으로 정직 reframe. 8-gene RAI panel (primary contribution) 에는 영향 없음. 한국 cohort cross-validation 이 이번 답을 뒤집을 수 있음 (한국 PTC BRAF mutation rate ~62% vs TCGA ~45% — 분포가 다름).
