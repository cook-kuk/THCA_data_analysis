1.4 Leak-free CV design (★ critical — v6 의 핵심)

v5 의 문제: cluster 정의에 8-gene 이 포함된 채 8-gene 으로 prediction → circular validation, AUC 0.974 가 인공적으로 높음.
v6 fix: 4 가지 leak-free cluster 변형으로 재검증 — 각각 8-gene 을 cluster 정의에서 완전히 제외:
  • R1-A (TIERA67-minus-8gene) → 5-fold CV AUC 0.962
  • R1-B (zero-overlap 30-gene MAPK+immune+EMT) → 0.925 ★ 가장 강한 anti-circular evidence
  • R1-C (5-marker pure-immune) → 0.664 — by design, immune ≠ differentiation axis
  • R1-D (BRS71-minus-8gene) → 0.957

1.5 Korean K2 pilot data flow (PRJEB11591)

  1. ENA FTP API → 262 run metadata (K1A_prjeb11591_runs.tsv)
  2. Per run: download R1 FASTQ only (~1.3 GB) → 3-way 병렬
  3. kallisto pseudoalignment (single-end, -l 200 -s 30, 8-gene mini-index 93 transcripts)
  4. FASTQ 즉시 삭제 (peak storage ~7 GB)
  5. abundance.tsv 누적 → 8-gene TPM matrix → within-sample-centered → TCGA LogReg 적용

1.6 Normalization / batch effects

  • TCGA training: GDC STAR counts → log2(TPM+1) → StandardScaler (TCGA-fit μ/σ)
  • Cross-platform transfer (microarray → RNA-seq): rank-based or platform-specific quantile normalization NOT used; raw log2 expression kept and feature-by-feature StandardScaler applied (TCGA-fit μ/σ for all). 검증된 transfer success: GSE76039 = 0.935.
  • Mini-index TPM inflation (Korean K2): per-sample TPM 분모가 93 transcripts 만이라 절대값 inflated. 우회: within-sample-centered profile.
  • ComBat / batch correction NOT applied for cross-cohort (의도적 — v5.2 LODO ComBat 분석에서 leak artifact 가 발견됨, memory note 참조).

2.5 Other models / scores

  • Hot/Cold immune composite: per-sample z-score 평균 of (cytolytic_score + Hallmark_Interferon_Gamma + Hallmark_Inflammatory_Response) → DM1 vs DM2 Cohen's d.
  • Decision Curve Analysis: Vickers-Elkin net benefit at thresholds 0.05–0.95 step 0.01.
  • 4-cohort meta-analysis: random-effects logit-AUC pooling (DerSimonian-Laird), I² heterogeneity.
  • Bootstrap stability: 1,000 sub-sampling iterations of Leiden cluster (sample_frac=0.8, varied seed) → per-sample concordance score.
  • Bootstrap survival p-distribution: 1,000 stratified bootstrap, leave-one-out across 36 TERT⁺ patients.

2.6 왜 LogReg / RF 만 쓰고 deep learning 안 썼나

의도적 선택:
  • n = 178 (driver-negative) → deep model overfit 위험 큼
  • 8 feature → linear separator 충분 (manifold 가 단순)
  • 해석 가능성 (coefficient sign + magnitude) = clinical adoption 의 prerequisite
  • CV AUC 가 이미 0.96+ → ceiling 근처, 추가 모델 복잡도 의 marginal gain 작음
  • deep model 적용 시 training-validation gap 더 벌어질 가능성 (R2 R1-A 의 absolute training AUC 0.972 vs 5-fold CV 0.964; LogReg 의 gap 작음)

⚠ 4. 주의점 — 정직 framing (이 paper 의 진짜 limit)

4.1 DM1/DM2 자체의 정체

DM1/DM2 는 임상 ground truth 가 아닙니다. Unsupervised Leiden cluster (TCGA 178 driver-negative 에서 발견). 의사가 라벨링한 게 아니라 데이터에서 emergent 한 두 transcriptomic state. 8-gene panel 의 LogReg 는 이 cluster 를 recover 하는 능력을 측정. → "DM1/DM2 prediction AUC 0.962" 자체는 임상 유효성 증거가 아님, "cluster definition 이 8-gene 으로 reproducible" 의 증거.

4.3 통계적 제약

  • TERT survival: 16 OS event 만 (TERT⁺ 6 / wildtype 10) → multivariate Cox 의 power 작음 (HR=0.95 의 95% CI [0.20, 4.59] 매우 wide). 진짜 effect 가 어디 있는지는 더 큰 cohort 필요.
  • Subgroup forest: 9 strata 중 2 개 (FVPTC, Male) AUC < 0.85; 95% CI 가 cover 하므로 sampling variability 일 가능성이 있지만 small-n 의 한계.
  • Korean K2 pilot: n = 9 (현재 16) → 통계적 inference 안 함, descriptive 만.
  • Multiple testing: 41 cluster-defining gene FDR < 1×10⁻³⁰ (Benjamini-Hochberg over 19,000 expressed genes) — 충분히 보수적. 그러나 8-gene panel 자체는 별도 multiple-testing correction 안 함 (single hypothesis).

4.5 일반화 한계

  • Population: 모든 training cohort 가 Western (TCGA, GSE 다수). 한국 cohort 검증은 K2 pilot (n=9) → 262 진행 중 + 분당 contemporary outreach.
  • Era: TCGA = 2010 년대 초 sample. Yoo 2016 도 동시기. 12+ 년 후의 임상 환경 (contemporary diagnostic + treatment paradigm) 적용 가능성 = 분당 outreach 로 검증.
  • Modality: bulk RNA-seq 학습. FFPE qPCR / NanoString 으로의 platform calibration 필요 (wet-lab 검증 outreach 진행 중).
  • Histology: cPTC + FVPTC + 일부 PDTC/ATC. FTC, MTC, anaplastic 변형 등은 underrepresented.

Modality 설명

TCGA (The Cancer Genome Atlas, NIH 미국 국립암센터의 대규모 암 유전체 지도. 33개 암종, 약 11,000명)의 갑상선암 코호트. 환자 한 명당 다음 4가지가 같이 측정됨:

  • bulk RNA-seq (대량 RNA 시퀀싱 — 종양 조직 전체의 평균 발현량 측정): Illumina HiSeq + GDC STAR Counts. TPM (Transcripts Per Million, RNA-seq 발현량 정규화 단위)로 정량. → DM1/DM2 발견의 input.
  • WES (Whole-Exome Sequencing, 전체 엑손만 시퀀싱) + MAF (Mutation Annotation Format): BRAF V600E, RAS hotspot 변이 콜링. → driver_anchor 라벨링.
  • 450K methylation array (Illumina Infinium 450K — DNA 메틸화 측정): Cross-modality 검증에 사용.
  • clinical metadata: age, sex, AJCC stage, OS event/days, histology subtype.

우리가 쓴 부분

  • 513 primary tumour (이미 수술된 1차 종양만; metastasis / normal 제외)
  • RNA-seq → log₂(TPM+1) → driver-negative residual에 unsupervised clustering
  • WES MAF → driver_anchor (BRAF / RAS / unknown / NTRK / TP53 분류)
  • clinical → age, stage, OS event/days, Bethesda category

모델 / 방법

  • Preprocessing: log₂(TPM+1) (RNA-seq 표준 변환 — 분포 정규화) + gene-symbol 매칭 + ComBat-seq (RNA-seq batch effect 보정) per-fold leave-one-cohort-out (v5.2 protocol — leak 방지)
  • Clustering: scanpy (Python single-cell 분석 라이브러리, bulk에도 적용 가능) 1.12.1 → Leiden algorithm (community detection 알고리즘) K = 2 forced + resolution = 0.5 → DM1 (n=403) + DM2 (n=110)
  • Stability: 1,000-iter bootstrap consensus matrix → concordance > 0.92
  • 8-gene panel: scikit-learn (Python ML 라이브러리) 1.8.0 LogReg(C=1.0, max_iter=2000, random_state=42) + RF(n_estimators=300, random_state=42, n_jobs=2)
  • Cross-validation: 5-fold StratifiedKFold (5등분 교차 검증, class 비율 유지) random_state=42

성능

  • LogReg 5-fold CV AUC = 0.954 (held-out fold; DM1/DM2 cluster identity 예측). v6 leak-free 재학습 = 0.962 [0.940–0.979].
  • RandomForest 5-fold CV AUC = 0.975 (held-out fold)
  • BRAF V600E single-feature 5-fold CV baseline AUC = 0.822 (v5) / 0.849 (v6 leak-free) → ΔAUC = +0.113 ~ +0.132
  • Top RF feature importance: TPO (0.27), DIO1 (0.21), TG (0.14), FOXE1 (0.14)
  • v6 ULTIMATE 4 leak-free variant 재구성 → honest 5-fold CV AUC range 0.92–0.96 (circular 0.954 figure는 더 이상 claim 안 함)
  • External held-out GSE76039 (PDTC+ATC, n=37): AUC = 0.935 [0.824, 1.000]
  • Pooled meta-analytic (4-cohort random-effects): AUC = 0.980, I² = 0%
  • Korean K2 pilot (n=9, PRJEB11591): ground-truth label 부재 → AUC 측정 X. Predicted p(DM2) distribution 만 (mean 0.898, 9/9 DM2). TCGA training-cohort 5-fold CV AUC = 0.963 ± 0.026 (within-sample-centered, scale-invariant for cross-cohort).

v5 preprint의 0.954는 cluster 정의에 8 gene이 포함돼 있어 자기상관 (circular). v6 ULTIMATE에서 4개 leak-free variant (TIERA67, MAPK+immune+EMT, BRS71, immune-only)로 재구성 → honest AUC 보고.
