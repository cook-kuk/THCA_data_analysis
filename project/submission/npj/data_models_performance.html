A. TCGA-THCA — primary discovery cohort

bulk RNA-seq WES MAF 450K methylation clinical n = 513

Modality 설명

TCGA (The Cancer Genome Atlas, NIH 미국 국립암센터의 대규모 암 유전체 지도. 33개 암종, 약 11,000명)의 갑상선암 코호트. 환자 한 명당 다음 4가지가 같이 측정됨:

  • bulk RNA-seq (대량 RNA 시퀀싱 — 종양 조직 전체의 평균 발현량 측정): Illumina HiSeq + GDC STAR Counts. TPM (Transcripts Per Million, RNA-seq 발현량 정규화 단위)로 정량. → DM1/DM2 발견의 input.
  • WES (Whole-Exome Sequencing, 전체 엑손만 시퀀싱) + MAF (Mutation Annotation Format): BRAF V600E, RAS hotspot 변이 콜링. → driver_anchor 라벨링.
  • 450K methylation array (Illumina Infinium 450K — DNA 메틸화 측정): Cross-modality 검증에 사용.
  • clinical metadata: age, sex, AJCC stage, OS event/days, histology subtype.

우리가 쓴 부분

  • 513 primary tumour (이미 수술된 1차 종양만; metastasis / normal 제외)
  • RNA-seq → log₂(TPM+1) → driver-negative residual에 unsupervised clustering
  • WES MAF → driver_anchor (BRAF / RAS / unknown / NTRK / TP53 분류)
  • clinical → age, stage, OS event/days, Bethesda category

모델 / 방법

  • Preprocessing: log₂(TPM+1) (RNA-seq 표준 변환 — 분포 정규화) + gene-symbol 매칭 + ComBat-seq (RNA-seq batch effect 보정) per-fold leave-one-cohort-out (v5.2 protocol — leak 방지)
  • Clustering: scanpy (Python single-cell 분석 라이브러리, bulk에도 적용 가능) 1.12.1 → Leiden algorithm (community detection 알고리즘) K = 2 forced + resolution = 0.5 → DM1 (n=403) + DM2 (n=110)
  • Stability: 1,000-iter bootstrap consensus matrix → concordance > 0.92
  • 8-gene panel: scikit-learn (Python ML 라이브러리) 1.8.0 LogReg(C=1.0, max_iter=2000, random_state=42) + RF(n_estimators=300, random_state=42, n_jobs=2)
  • Cross-validation: 5-fold StratifiedKFold (5등분 교차 검증, class 비율 유지) random_state=42

성능

  • LogReg CV AUC = 0.954 (DM1/DM2 cluster identity 예측)
  • RandomForest CV AUC = 0.975
  • BRAF V600E single-feature baseline AUC = 0.822 → ΔAUC = +0.132
  • Top RF feature importance: TPO (0.27), DIO1 (0.21), TG (0.14), FOXE1 (0.14)
  • v6 ULTIMATE 4 leak-free variant 재구성 → honest range AUC 0.92–0.96 (circular 0.954 figure는 더 이상 claim 안 함)

v5 preprint의 0.954는 cluster 정의에 8 gene이 포함돼 있어 자기상관 (circular). v6 ULTIMATE에서 4개 leak-free variant (TIERA67, MAPK+immune+EMT, BRS71, immune-only)로 재구성 → honest AUC 보고.

B. cBioPortal thca_tcga_pub — TERT promoter mutation

MAF (Sanger-validated) n = 36 / 504

Modality 설명

cBioPortal (Memorial Sloan Kettering이 운영하는 cancer genomics 포털)의 thca_tcga_pub study는 TCGA-THCA Cell 2014 publication MAF (Mutation Annotation Format — TCGA Network 2014 논문에 첨부된 MAF, Sanger sequencing으로 검증됨)의 mirror. 일반 GDC 다운로드에서는 빠져 있는 TERT promoter mutation (TERT 유전자의 promoter region 변이 — chr5:1295228 C228T, chr5:1295250 C250T)이 들어가 있음.

v1 sweep에서는 이 study를 놓쳤다가 v2에서 회수. 회수 audit log: results/v17_tert_recovery/v2/FINAL_recovery_audit.md (9-source attempt 모두 기록).

우리가 쓴 부분

  • 504명 중 36명 (7.1%)에서 TERT promoter mutation (C228T 또는 C250T) 콜 회수
  • TCGA-THCA의 다른 데이터 (clinical OS, quad_group)와 sample_id로 join
  • 4-group: BRAF only (n=250) / RAS only (n=48) / TERT⁺ (n=36) / Triple-neg (n=170)

모델 / 방법

  • lifelines (Python 생존 분석 라이브러리) 0.30 — multivariate_logrank_test (다군 logrank 검정)
  • CoxPHFitter (Cox 비례위험 회귀 fitter) with L2 penalizer 0.01 (Firth-like correction — small-event 안정화)
  • covariates: stage (I/II/III/IV), age, sex (multivariate adjustment)
  • robustness: 1,000-iter stratified bootstrap + 36-patient LOO (별도 v17_actual sprint)

성능

  • 4-group multivariate logrank p = 3.78×10⁻⁵
  • TERT-vs-WT alone logrank p = 4.92×10⁻⁶
  • TERT⁺ event rate 16.7% (6/36) vs 2.1% (10/468) WT
  • univariate Cox HR = 6.31 (95% CI 2.34–17.04, p = 3×10⁻⁴)
  • ★ multivariate (stage+age+sex) Cox HR = 1.88 (95% CI 0.58–6.09, p = 0.29 — 통계적 유의 X)
  • bootstrap median p = 2.6×10⁻⁵ (95% CI 3.2×10⁻¹⁵ – 0.21; 93% iter p < 0.05)
  • LOO worst-case p = 7.5×10⁻⁴ (모두 36개 LOO p < 10⁻³)

honest reframe: TERT⁺를 "독립 prognostic"이 아니라 "Stage III/IV 식별을 위한 molecular handle"로. univariate signal은 stage / age confounding이 대부분.

C. GSE76039 (Landa 2016) — PDTC + ATC external validation

bulk RNA-seq n = 37

Modality 설명

Landa I et al. _J Clin Invest_ 2016 (MSKCC PDTC/ATC cohort)의 RNA-seq. 갑상선암 spectrum의 dedifferentiated end (PDTC + ATC) 만 모은 cohort. 일반 PTC가 아니라 고분화/저분화 trajectory의 끝점만 측정.

우리가 쓴 부분

  • 37 sample (PDTC + ATC subset, 본 분석에 사용)
  • trajectory analysis (분화도 연속체 분석): TCGA-THCA cPTC + FVPTC + GSE76039 PDTC + ATC = 합쳐서 n=670

모델 / 방법

  • TCGA-THCA에서 학습한 8-gene LogReg 모델을 GSE76039에 그대로 적용 (transfer)
  • RAI score correlate with pseudotime (Spearman ρ test)

성능

  • raw PDTC-vs-ATC labelling AUC = 0.026 → direction-correct interpretation: AUC 0.974 (PDTC = DM2-like / ATC = DM1-like 방향)
  • RAI score range: PDTC 8.34–11.65 vs ATC 2.89–7.62 (PDTC > ATC, R3 reframe)
  • pseudotime ↔ rai_score_recalc Spearman ρ = 0.74, p < 1×10⁻¹⁵

"perfect-separation, opposite-direction" 결과를 정직하게 reframe: 8-gene panel이 histology label (PDTC/ATC)을 그대로 분류하는 게 아니라 분화도 연속체 (DM2 = preserved differentiation)를 정확히 잡음.

D. GSE184362 — single-cell RNA-seq (Hot/cold immune evidence)

scRNA-seq 66,000 cells / 7 patients

Modality 설명

scRNA-seq (single-cell RNA sequencing — 단일 세포 단위로 RNA 발현 측정). bulk와 다른 점: 한 종양 안의 세포 종류 (tumour cell vs T cell vs macrophage vs fibroblast 등) 비율 + 각 세포의 발현 패턴 분리해서 볼 수 있음. Tumor microenvironment (TME — 종양 미세환경, 종양 + 면역 + 기질세포) 분석에 표준.

우리가 쓴 부분

  • 7명 환자 × 평균 ~9,400 cells = 총 66,000 cells
  • per-patient dominant DM (DM1-skewed vs DM2-skewed) 분류
  • cell type 분류 (B_cell, T_cell, macrophage, fibroblast, tumour, ...)

모델 / 방법

  • per-cell DM signature score 계산 (8-gene 발현 mean)
  • per-patient dominance 분류
  • cell type fraction within dominant_dm 계산

성능

  • immune-cell dominance ratio = 57 : 1 (DM1-skewed vs DM2-skewed patients)
  • scRNA가 bulk hot/cold composite Cohen's d = +1.683 결과를 single-cell 수준에서 confirm

Bulk RNA-seq의 hot/cold composite (cytolytic + IFN-γ + immune fraction)가 단지 평균이 아니라 실제로 면역세포 비율 차이라는 걸 single-cell에서 직접 확인.

microarray bulk RNA-seq 총 ~400+

H. PRISM Repurposing 19Q4 — 약물 스크린 (Fig 7)

drug screen (cell viability) 4,517 compounds × 5 vs 5

Modality 설명

PRISM (Profiling Relative Inhibition Simultaneously in Mixtures) Repurposing 19Q4 — Broad Institute의 대규모 약물 스크린. 여러 cell line을 barcode로 표지 + pool 한 후 약물 처리 → cell viability 측정. 4,517 compounds (FDA-approved + clinical investigational + tool compounds 포함).

Source: figshare article 9393293, file IDs 20237709/20237715/20237718 (replicate-collapsed log-fold-change matrix).

우리가 쓴 부분

  • 11 PRISM-covered CCLE thyroid lines
  • 5 DM1 vs 5 DM2 split
  • 4,517 compound 모두 검사 → 각 compound의 DM1 mean LFC vs DM2 mean LFC

모델 / 방법

  • per-compound: ΔLFC = DM1_mean_LFC − DM2_mean_LFC (음수일수록 DM1-selective)
  • Mann-Whitney p-value (DM1 vs DM2 LFC 분포)
  • MOA (Mechanism of Action — 약물의 작용 기전, 예: MEK inhibitor) 별 enrichment count (DM1 vs DM2)
  • BH FDR correction

성능

  • per-compound: 0 compounds at FDR < 0.1 across 4,517 (n=5 vs 5 underpowered)
  • mechanism-class (MOA): MEK inhibitor (e.g., nobiletin ΔLFC = −0.72, p = 0.016) nominal DM1-selective
  • HMGCR inhibitor (e.g., procaine ΔLFC = −0.39, p = 0.032) nominal DM1-selective
  • idarubicin (Topo-I) ΔLFC = −1.85 (p = 0.095, underpowered)

honest framing: n=5 vs 5는 FDR-grade single-drug discovery에 부족. mechanism-class direction (MEK + HMGCR)이 biologically coherent하고 v14 LDLR-axis 관찰과 일치 → "hypothesis-generating for future targeted screens, not finalised clinical recommendation"으로 명시.

K. v17_actual robustness — bootstrap + LOO (derived from TCGA-THCA)

derived analysis 1,000 bootstrap + 36 LOO

Modality 설명

데이터셋이 아니라 derived analysis. v17_ACTUAL sprint에서 honest reframe (Fig 8) 위해 추가한 robustness 검정 layer.

방법 / 모델

  • 1,000-iter stratified bootstrap: 각 iter마다 TERT⁺ 36명 + WT 468명을 stratified resample → 4-group multivariate logrank → p-value 분포
  • 36-patient LOO: TERT⁺ 36명 한 명씩 빼고 (n=503 → n=502) 4-group logrank 재계산
  • script: v17_ACTUAL_robustness.py, v17_ACTUAL_figures.py
  • output: results/v17_actual/A1B_bootstrap_logrank.tsv, A1C_loo_logrank.tsv, A1A_cox_full_multivariate.tsv

성능 (Fig 8 robustness companion 패널)

  • bootstrap median p = 2.6×10⁻⁵; 95% CI 3.2×10⁻¹⁵ – 0.21; 93% iter p < 0.05
  • LOO worst-case p = 7.5×10⁻⁴; 모두 36개 LOO p < 10⁻³
  • → 4-group separation은 single-event-driven 아님

"6 events 만으로 p < 10⁻⁵라니 의심스럽지 않냐?"는 reviewer 공격 미리 답하기. 한 명 빼도 separation 유지 → 통계적 stability 입증.

L. TCGA-CDR (Clinical Data Resource) — 다중 임상 endpoint

clinical / curated n ~ 504

Modality 설명

TCGA-CDR (TCGA Clinical Data Resource — Liu 2018 Cell, OS / DSS / DFI / PFI 4가지 표준 임상 endpoint를 curated 형태로 제공). 원본 clinical metadata에는 누락이나 inconsistency가 있어서 CDR이 표준.
