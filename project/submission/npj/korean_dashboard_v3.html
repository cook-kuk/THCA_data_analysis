🧊 K2.5 — Cohort preservation type (frozen vs FFPE) DONE

Reviewer 의 흔한 첫 질문 — "FFPE 에서도 작동하나?" 에 한 화면으로 답하기 위한 분석. 13 cohorts × 2,125 samples 전체 preservation type breakdown.

핵심 결론 3 줄:

  1. Manuscript 의 모든 trained / 5-fold CV / external held-out / pooled meta AUC 는 100% fresh-frozen 위에서 측정된 결과. preservation type confound 가 train-test mismatch 에서 발생할 가능성 ≈ 0.
  2. Korean K2 (PRJEB11591 n = 260) 도 전부 fresh-frozen (SNU-GMI biobank). 따라서 K2 = "frozen → frozen" cross-population validation. preservation 변수가 깨끗하게 통제된 비교.
  3. FFPE direct exposure 는 MSK-IMPACT 2017 (n = 93) 한 cohort 만이고, 그것도 transcriptomic panel test 가 아니라 BRAF/TERT mutation prevalence reference 용. 즉 panel 자체가 FFPE 에서 작동하는지는 이번 paper 의 scope 가 아님 — limitation 단락에 그렇게 정직하게 적기.

✅ Bottom line

현재 v6 manuscript 의 모든 headline 숫자는 frozen-only ecosystem 안에서 self-consistent. preservation type 은 confound 가 아님. FFPE 일반화는 paper 의 limitation 으로 정직하게 적고, K3D Korean retrospective FFPE 디자인 (v18 sprint, 메모리 등록) 으로 follow-up.

📚 PRJEB11591 의 진짜 의미 — 왜 이 cohort 가 중요한가

cohort 자체의 academic context

PRJEB11591 = Yoo SK et al. PLoS Genetics 2016 published Korean cohort. Korean PTC 의 transcriptomic + mutational landscape 를 본격적으로 characterize 한 첫 paper 중 하나. 인용 빈도 높음 (Google Scholar 200+ citations).

왜 본 paper 에 critical 한가:

  • (1) Korean ethnic-specific BRAF rate: TCGA 56% vs Korean 62-70% — 우리 8-gene panel 의 Korean transferability 직접 test 가능
  • (2) BRS classification 비교: Yoo 2016 paper 에서 BRAF-like/RAS-like 분류 published — 우리 DM1/DM2 axis 와 직접 cross-validate 가능
  • (3) EGA DAR 의 stepping stone: PRJEB11591 활용 + cite = Yoo SK 와의 academic relationship 시작 → EGAD00001004845 (Yoo 2019 advanced cohort) DAR endorsement 가능성
  • (4) Park YJ group 과의 alignment: Han SC et al. ENM 2023 의 BL/RL framework 가 Yoo 2016 위에 build → 우리 paper 가 그 framework 의 deployable extension 으로 positioning 가능
