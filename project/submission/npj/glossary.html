A. 질병 / 병리

PTC — Papillary Thyroid Carcinoma
갑상선 유두암. 가장 흔한 갑상선암 (전체의 80% 이상). 이 논문의 분석 대상.
cPTC — classical PTC
고전적 (classic) 형태의 PTC. 가장 흔한 변이. 일반적으로 BRAF mutation 동반.
FVPTC — Follicular Variant PTC
PTC의 여포(follicle) 변이. RAS mutation 비율 높고 cPTC보다 indolent (얌전).
IEFVPTC — Invasive Encapsulated Follicular Variant PTC
피막을 침범한 캡슐형 FVPTC. 2022 WHO 분류에서 별도 entity.
TCV — Tall Cell Variant
키 큰 세포형 PTC. Aggressive 변이로 분류.
DHGTC — Diffuse High-Grade Thyroid Carcinoma
미만성 고등급 갑상선암. 2022 WHO 신규 분류.
PDTC — Poorly Differentiated Thyroid Carcinoma
분화도 낮은 갑상선암. PTC와 ATC 사이 중간. RAI 부분 반응.
ATC — Anaplastic Thyroid Carcinoma
미분화 (anaplastic) 갑상선암. 가장 공격적, RAI 무반응. 본 논문 trajectory의 끝점.
histology · histology subtype
조직형 / 조직학적 변이. 현미경으로 본 형태 분류 (cPTC vs FVPTC vs PDTC vs ATC).
aggressive variant
공격적 변이. Stage III/IV로 진행하기 쉬운 형태 (TCV / DHGTC / PDTC).
WHO 2022
2022년 WHO 갑상선암 분류 update. IEFVPTC, DHGTC 등 새 entity 추가.

B. 임상 / 치료

RAI — Radioactive Iodine (= ¹³¹I therapy)
방사성요오드 치료. 갑상선 수술 후 잔여 종양 / 전이 제거에 사용. 갑상선 분화 세포는 요오드를 흡수 → 방사선 치료 효과. 이 논문의 핵심 임상 endpoint — "RAI에 잘 반응할지" 예측이 목표.
RAI uptake · rai_score
방사성요오드 흡수. 8개 분화 유전자 표현량으로 환산한 score (= 잘 반응할수록 높음).
RAI-R — RAI-Refractory
RAI 무반응 (저항성). 표준 치료 실패 → 진행성 환자.
Bethesda category
Bethesda 갑상선 세포검사 분류. I (검체부족) ~ VI (악성). 본문에서는 stage 보정 시 사용.
Stage I/II/III/IV
AJCC 병기. I (초기) ~ IV (전이). TERT⁺ 환자는 Stage III/IV에 enriched (61% vs 21–32% 이외).
TROP2-ADC · SETHY · STRAP
TROP2 단백질을 표적하는 항체-약물 접합체. SETHY = NCT06235216 (2024-09 시작), STRAP = NCT07521670 (2026-05 예정). 둘 다 molecular sub-stratification 없이 등록 → 본 8-gene panel을 correlative biomarker로 제안.
ADC — Antibody-Drug Conjugate
항체-약물 접합체. 항체가 종양 표면 단백질에 결합 → 약물 (cytotoxin) delivery. Sacituzumab govitecan이 대표.
IHC — Immunohistochemistry
면역조직화학. 조직 절편에 항체로 단백질 발현 시각화. TROP2 IHC = TROP2 단백질이 있는지 검사.
OS — Overall Survival
전체 생존. 임상 endpoint 중 가장 hard. TCGA-THCA는 ~16 OS event밖에 없어 power 낮음.
NCT_______
ClinicalTrials.gov 등록 번호. NCT06235216 = SETHY, NCT07521670 = STRAP.

C. 유전자 / 단백질 (8-gene panel)

NIS / SLC5A5
Sodium-Iodide Symporter. 갑상선 세포가 요오드를 흡수하는 단백질. RAI 효과의 직접 결정 인자.
TPO — Thyroperoxidase
갑상선 과산화효소. 요오드 organification (단백질 결합) 효소. 분화 마커.
TG — Thyroglobulin
갑상선글로불린. 요오드 저장 단백질. 갑상선 분화 핵심 마커.
TSHR — TSH Receptor
갑상선자극호르몬 수용체. TSH 신호 받는 수용체. 분화 세포 마커.
PAX8 · NKX2-1 · FOXE1
갑상선 lineage transcription factor. 갑상선 발달과 분화 유지에 필수.
DIO1 — Deiodinase 1
탈요오드화 효소 1. T4를 활성형 T3로 변환. 갑상선 분화 마커.
BRAF V600E
BRAF 유전자의 600번 아미노산 valine→glutamate 치환. PTC에서 가장 흔한 driver mutation (~60%). MAPK 경로 활성화.
RAS hotspot
HRAS / KRAS / NRAS의 12, 13, 61번 codon mutation. FVPTC와 강하게 연관.
TERT promoter (chr5:1295228 C228T, chr5:1295250 C250T)
텔로머라제 역전사효소 promoter region 변이. 텔로머라제 활성화 → 무한 분열. PTC에서 ~7% (TCGA-THCA n=36/504).
TROP2 / TACSTD2
Trophoblast Cell Surface Antigen 2. ADC 표적 단백질. PTC에서 BRAF V600E와 연관.
DUSP5/6, FOSL1, ETV4/5, MET
MAPK 경로 target genes. BRAF가 켜지면 같이 올라가는 downstream 유전자들. DM1 cluster의 핵심 marker.
HLA-DRA, FOXP3, MMP9
염증/면역 마커. DM1 cluster에서 inflammatory hot 상태 의미.
CDKN2A
세포주기 inhibitor. Senescence + dedifferentiation 마커. DM1에 enriched.
PD-L1, PDCD1, CTLA4, IDO1, B2M
면역 회피 (immune evasion) 유전자들. Checkpoint inhibitor 표적. DM1 (hot)에 enriched.

D. 변이 분류 / 분자 분류 시스템

BRS · BRS52 — BRAF-RAS Score (52 genes)
BRAF-like vs RAS-like 분류기. Chakravarty 2011, TCGA 2014. 52-gene 발현으로 두 그룹 분류. 본 논문은 BRS의 ~10% 오분류를 보여줌.
BRS-like / RAS-like
BRS 점수에 따른 두 분류. BRS-like = BRAF mutation과 가까운 발현 패턴.
DM1 / DM2 — Dark Matter 1/2 (저자 axis)
본 논문에서 발견한 unsupervised transcriptomic axis. DM1 = 분화 (well-differentiated, RAS-like, FVPTC, panel-high), DM2 = 탈분화 (dedifferentiated, BRAF-like, cPTC/TCV/DHGTC, panel-low). v6 ULTIMATE에서 정정된 표기 — v5 preprint는 반대로 표기됨.
4-group · quad_group — Liu-Xing 4-genotype framework
BRAF only / RAS only / TERT⁺ / Triple-negative. Xing 2014, Liu 2017 framework.
TDS — Thyroid Differentiation Score (Yoo 2017)
갑상선 분화도 점수. 16개 gene signature. 본 논문에서는 stage 보정 시 사용.
driver-negative residual · dark matter (저자 용어)
canonical driver mutation이 없는 환자 군. ~30% of TCGA-THCA. BRS framework가 stratify 못 함 → DM1/DM2 axis가 추가 정보 제공.

E. 코호트 / 데이터셋

TCGA — The Cancer Genome Atlas
미국 NIH가 만든 대규모 암 유전체 지도. 33개 암종 ~11,000 환자.
TCGA-THCA
TCGA의 갑상선암 코호트. 513 primary tumour. 본 논문의 primary discovery cohort.
cBioPortal
MSK 가 운영하는 cancer genomics 포털. TCGA를 비롯한 여러 study mirror.
thca_tcga_pub
cBioPortal study ID. TCGA-THCA Cell 2014 publication MAF의 mirror. 본 논문 TERT 36명 회수 source.
GSE76039
Landa 2016 PDTC + ATC cohort (n=37). External trajectory validation 사용.
GSE184362
scRNA-seq 7명 환자, 66,000 cells. Hot/cold immune 증거.
GSE213647
632 sample bulk RNA-seq cohort. 가장 큰 외부 검증 cohort. cross-platform AUC 0.672 (TCGA in-sample 0.962보다 낮음 → limitation으로 명시).
GSE27155 / GSE33630 / GSE29265 / GSE126698
다른 외부 검증 cohort들 (microarray + bulk RNA-seq).
CCLE — Cancer Cell Line Encyclopedia
암 세포주 백과사전 (Broad Institute). 갑상선 세포주 13개 (PRISM 검사 가능 11개).
PRISM — Profiling Relative Inhibition Simultaneously in Mixtures
Broad Institute의 대규모 약물 스크린. 19Q4 release = 4,517 compounds × 수백 cell lines.
MAF — Mutation Annotation Format
Mutation 정보 표준 파일 형식. TCGA / cBioPortal에서 mutation 데이터 배포 형식.
BAM
Binary Alignment Map. Read alignment 결과 binary file. TERT 변이를 raw BAM에서 re-call하지 않은 점이 한계.
SNUH / Bundang
서울대학교병원 / 분당서울대학교병원. 한국 cohort cross-validation outreach 대상.
EGA · DAR
European Genome-phenome Archive / Data Access Request. 한국 cohort 데이터 접근 신청 절차.

F. Bioinformatics 도구 / 워크플로

kallisto
RNA-seq pseudo-alignment 정량 도구. Read를 transcript에 매핑해서 발현량 (TPM) 계산. 빠르고 정확.
scanpy
Python single-cell RNA-seq 분석 라이브러리. Leiden clustering / UMAP / marker discovery 모두 여기서.
Leiden algorithm
community detection 알고리즘. K=2 forced + resolution 0.5로 DM1/DM2 partition.
UMAP
Uniform Manifold Approximation and Projection. 고차원 data를 2D 시각화. Fig 1c와 trajectory 시각화.
PCA
Principal Component Analysis. 주성분 분석. UMAP의 input으로 사용.
ComBat-seq
RNA-seq batch effect 보정. 다른 cohort 합칠 때 platform / lab 차이 제거. 본 논문은 leak-free하게 per-fold 적용.
LODO — Leave-One-Dataset-Out
cohort 단위로 빼고 학습. Cross-cohort batch correction을 leak 없이 하기 위한 protocol. v5.2에서 도입.
DIAL — Direction Identifiability After Leave-out (저자 framework)
cluster orientation이 batch / leak에 의해 뒤집히는지 audit. v5.2 critical fix의 결과.
gseapy
Python GSEA (Gene Set Enrichment Analysis) 도구. Preranked GSEA 수행.
plotly
interactive figure 라이브러리. 본 논문의 모든 figure를 plotly로 그림 → HTML / PDF / PNG export.
kaleido
plotly figure를 static image (PNG / PDF) 로 export. 0.2.1 버전 사용 (v1+은 chrome 의존).
lifelines
Python 생존 분석 라이브러리. Kaplan-Meier + Cox + logrank. v17_ACTUAL sprint에서 정식 multivariate Cox 도입.
pandoc
document 변환 도구. markdown → HTML / PDF / docx.
jupytext · nbconvert
Jupyter notebook 변환 도구. .py ↔ .ipynb / .ipynb → HTML.
random_state = 42 · np.random.seed(42)
재현성을 위한 고정 random seed. 본 논문 모든 분석에 적용.

G. 통계 / 머신러닝 / 모델

AUC — Area Under the (ROC) Curve
분류기 성능 지표 (0.5 = 랜덤, 1.0 = 완벽). 본 논문 8-gene panel CV AUC = 0.954.
ΔAUC
두 분류기의 AUC 차이. 8-gene panel (0.954) vs BRAF V600E baseline (0.822) → ΔAUC = +0.132. 본 논문의 headline 수치.
NRI / IDI
Net Reclassification Index / Integrated Discrimination Improvement. 두 분류기 비교 임상 지표. ΔAUC를 보완.
5-fold CV · StratifiedKFold
5-fold 교차 검증 (cross-validation). Data를 5등분하고 4개로 학습 / 1개로 검증을 5번 반복. Stratified = class 비율 유지.
ROC curve
Receiver Operating Characteristic. Sensitivity vs (1 - Specificity) 곡선. AUC가 그 아래 면적.
LogReg — Logistic Regression
로지스틱 회귀. 본 논문 8-gene panel의 primary 모델.
RF — Random Forest
랜덤 포레스트 (300 trees). Secondary 모델, AUC 0.975.
Spearman ρ
Spearman rank 상관계수 (-1 ~ +1). 본 논문 DM-score vs BRAF mutation indicator ρ = 0.49.
Mann-Whitney · U-test
두 그룹 비모수 비교. Hot/cold composite p = 4.0×10⁻¹⁸.
Fisher exact
2×2 contingency table 정확 검정. DM × TERT crosstab p = 0.65 (underpowered).
Cohen's d
두 그룹 평균차 / 표준편차 = 효과크기. 0.8 이상이면 large. 본 논문 Hot/Cold composite d = +1.683 = very large.
FDR — False Discovery Rate (Benjamini-Hochberg)
다중 검정 보정. p-value를 q-value로 보정. Hallmark FDR < 1×10⁻¹⁵.
NES — Normalized Enrichment Score
GSEA의 정규화 enrichment 점수. +면 up-regulated, −면 down-regulated. 본 논문 Inflammatory NES = +1.93.
GSEA · preranked GSEA
Gene Set Enrichment Analysis. 미리 ranked gene list를 pathway에 enrichment test. Preranked = 사전에 sort 된 input 사용.
Hallmark v2024.1.Hs
MSigDB의 Hallmark pathway 모음 (51개). 가장 well-curated. v2024.1 = human.
ssGSEA
single-sample GSEA. Sample 단위로 pathway score. Hallmark IFN-γ score 계산에 사용.
z-normalised / z-score
평균 0, 표준편차 1로 정규화. 다른 단위/스케일 score 합칠 때 사용.
TPM — Transcripts Per Million
RNA-seq 발현량 정규화 단위. log2(TPM+1) 변환 후 분석.
log2 fold change · LFC · ΔLFC
log2 비율. 두 그룹간 발현량 차이. PRISM 약물 분석에서 ΔLFC = DM1 - DM2 LFC.
ARI — Adjusted Rand Index
두 partition 간 일치도 (-1 ~ +1). v5 vs v6 ULTIMATE 변이체 비교 시 사용.
ARC · circular validation
Circular validation. Cluster 정의에 사용한 feature를 또 그 cluster 예측에 쓰는 자기상관. v5 → v6 ULTIMATE에서 4개 leak-free variant로 재구성 → honest range AUC 0.92~0.96.
n_estimators = 300
RF 트리 개수. 본 논문 RF 모델 hyperparameter.

H. 생존 분석 (Fig 8 / R8)

KM — Kaplan-Meier
생존 곡선 (시간에 따른 생존 비율). 95% CI band 함께 표시.
logrank test
두 (또는 그 이상) KM 곡선 비교 검정. 본 논문 4-group multivariate logrank p = 3.78×10⁻⁵.
Cox proportional hazards · Cox regression
위험비 (HR) 회귀 모델. Covariate 보정 가능 (stage / age / sex).
HR — Hazard Ratio
위험비. 1보다 크면 ref 대비 위험 ↑, 작으면 ↓. 본 논문 TERT⁺ univariate HR = 6.31 → multivariate HR = 1.88.
univariate vs multivariate
단변량 (한 변수만) vs 다변량 (여러 변수 보정). Univariate 6.31 → multivariate 1.88로 떨어진 게 본 논문 honest reframe의 핵심.
95% CI — 95% Confidence Interval
95% 신뢰구간. HR 1.88 (95% CI 0.58–6.09) → CI가 1을 포함 → 통계적으로 유의 X.
Firth correction · Firth-like correction (lifelines penalizer)
small-event 보정. Event 수가 적을 때 (TERT⁺ 6 events) Cox HR이 불안정 → L2 penalty (lifelines penalizer = 0.01) 적용.
bootstrap
resampling 기반 robustness 검정. 1,000회 stratified resample → median p = 2.6×10⁻⁵, 93% iter p < 0.05.
LOO — Leave-One-Out
한 명씩 빼고 다시 계산. 36명 TERT⁺ 각각 빼고 logrank 재계산 → worst-case p = 7.5×10⁻⁴ (모두 p < 10⁻³). "single patient에 의해 driven 된 결과 아님"을 보여주는 가장 강력한 robustness 증거.
event
사건 (사망 / 재발 / 전이). Survival의 outcome. TERT⁺ 36명 중 6 events / 전체 504명 중 16 events.
stage-confounded
병기에 의한 교란 (confounding). TERT⁺의 univariate signal이 사실은 stage / age 차이 때문 → 보정 후 사라짐.

I. 면역 / 약물 (Fig 5 + Fig 7)

hot tumour / cold tumour
면역세포가 많은 / 적은 종양. Hot = checkpoint inhibitor 잘 반응. DM1 = hot, DM2 = cold (Cohen's d = +1.683).
cytolytic activity
세포독성 활성. GZMA × PRF1 (granzyme A × perforin 1) geometric mean. Effector T cell + NK cell 활성 proxy.
IFN-γ — Interferon gamma
인터페론 감마. Th1 면역 cytokine. 면역 활성 강력 마커. Hallmark IFN-γ Response = 51 hallmark의 핵심.
TNF-α — Tumor Necrosis Factor alpha
종양괴사인자 알파. 염증 cytokine. Hallmark TNFA_Signaling_Via_NFKB로 측정.
NF-κB
Nuclear Factor kappa B. 염증 / 생존 transcription factor.
Allograft Rejection (Hallmark)
이식 거부반응 pathway. 강한 immune-active signature. DM1 NES = +1.89.
OxPhos — Oxidative Phosphorylation
산화적 인산화 (미토콘드리아 에너지 대사). DM2 (cold)에 enriched (NES = -1.90).
immune evasion
면역 회피. PD-L1 / IDO1 / CTLA-4 등으로 면역세포의 공격을 피하는 mechanism. DM1에 upregulated.
checkpoint inhibitor
PD-1/PD-L1, CTLA-4 차단 항체. Pembrolizumab / Nivolumab / Ipilimumab 등. Hot tumour에 더 효과.
MOA — Mechanism of Action
작용 기전. 약물이 어떻게 작동하는지 (예: MEK inhibitor / HMGCR inhibitor).
MEK inhibitor
MEK kinase 차단 약물. MAPK 경로 차단. Trametinib 등. DM1 (MAPK-active) selective.
HMGCR inhibitor · statin
스타틴 (콜레스테롤 합성 효소 차단). Procaine / atorvastatin. DM1 selective (mechanism class).
nobiletin · procaine · idarubicin
PRISM 19Q4 screen에서 본 논문이 명시한 specific compound. 통계적 underpowered (n=5 vs 5)지만 mechanism direction coherent.
Topo-I — Topoisomerase I (inhibitor)
DNA topoisomerase I 차단. Irinotecan / SN-38 / Sacituzumab govitecan payload.
scRNA-seq — single-cell RNA sequencing
단일 세포 RNA 시퀀싱. 세포 단위 발현 측정. Tumour microenvironment composition 분석.

J. Submission / 학술 / 출판 용어

npj — Nature Partner Journals
Nature 가 파트너 학회와 공동 출판하는 OA journal 시리즈. npj Precision Oncology = 본 논문 target venue.
Brief Report · Article
npj 글 형식. Brief Report ≤ 3,000 단어 + 4 figure / Article ≤ 4,000 단어 + 6+ figure. 본 논문은 v6 ULTIMATE 4,452 단어 → Article로 격상.
Editorial Manager
npj가 사용하는 submission 포털. editorialmanager.com/npjpo.
cover letter
submit 시 동봉하는 편집장 제출 letter. 핵심 contribution + scope match + suggested reviewers 포함.
Significance Statement
npj 요구사항. ≤120 단어로 lay summary.
Suggested reviewers
본 논문 제안: Yuri Nikiforov / James Fagin / Ricardo Lima / Mingzhao Xing.
CRediT taxonomy
Contributor Roles Taxonomy. 14가지 role (Conceptualization / Methodology / Software / ...). 본 논문 author contribution 분류 기준.
co-corresponding / co-first
공동 교신저자 / 공동 1저자. 본 논문은 Seungho Cook (1st + co-corresponding) + Yu Hyeong Won (senior + co-corresponding).
double-blind review
이중 익명 심사. Reviewer/Author 서로 모름. anonymous_code.zip 의 author identifier 모두 제거된 이유.
revision round
심사 후 수정본 재제출. 일반적으로 1–2회. Korean cohort cross-validation은 revision round에 추가 예정.
R0/R1/R2/R3/R4/R5/R6/R7/R8
Result 0 ~ 8. 논문 본문의 결과 단원. R6 = 8-gene panel headline, R8 = TERT honest reframe.
S1 ~ S15
Supplementary Figure 1 ~ 15.
F2 / F3 / F4 / F1B / F3A (script naming)
본 논문 v17_FINAL sprint의 task code (Tier-Phase-letter). e.g. F1B = TIER F1, task B (Fig 8 builder).
v3 / v5 / v6 / v6 ULTIMATE
Manuscript 버전. v6 ULTIMATE = 본 논문의 최종 (cluster orientation 정정 + de-circularization + GSE213647 cross-platform 모두 반영).
