왜 이 sprint? (Circular validation 의 정체)

본인이 6개월 sprint 끝에 catch 한 issue 를 정직하게 풀어 봅시다. 직전 paper 의 핵심 주장 흐름은 이랬습니다:

  1. TIERA67 (67-gene 분화 panel) 으로 TCGA-THCA 513 sample 을 unsupervised Leiden clustering → DM1 vs DM2 cluster 출현.
  2. 8-gene RAI panel (NIS, TPO, TG, TSHR, PAX8, NKX2-1, FOXE1, DIO1) 으로 logistic regression train → DM1/DM2 예측, 5-fold CV AUC = 0.954.
  3. BRAF V600E single-feature baseline (AUC 0.822) 대비 ΔAUC = +0.132 → "8-gene 이 BRAF 보다 우월".
왜 이게 circular 인가? (8-gene ⊂ TIERA67 의 의미)

TIERA67 panel 은 67개 분화 관련 genes 의 집합인데, 본인이 manuscript 에서 "8-gene panel" 이라 부르는 8개 genes (DIO1, FOXE1, NKX2-1, PAX8, SLC5A5, TG, TPO, TSHR) 전부가 그 67 안에 포함되어 있습니다. 즉:

  • DM1/DM2 cluster = TIERA67 의 67 genes 가 만든 partition
  • 그 67 안에 8-gene panel 의 8개가 이미 들어감 (8/55 unique genes after de-dupe, ≈15%)
  • 8-gene 으로 그 cluster 를 예측 = 8 features 가 자기 자신을 포함한 67-feature 공간의 partition 을 예측
  • = autocorrelation, not prediction

비유: 학생 100명을 67개 시험문제로 평가해서 "상위" / "하위" 그룹으로 나눈 후, 그 67문제 중 8개만 다시 줘서 "상/하" 예측 → 당연히 잘 맞음.

이걸 npj reviewer 가 spot 하면 desk reject 또는 major revision. 6개월의 work 가 reputation hit 으로 끝날 수 있음.

그러면 무엇을 해야 했나? (REAL FIX 의 핵심)

두 가지 옵션:

  1. 옵션 A — 진짜 fix: cluster 정의에서 8-gene 을 완전히 빼고 (TIERA67 - 8) 새로 cluster 만들고, 새 cluster 를 8-gene 으로 예측. 이게 진짜 prediction. 4-8주 invest.
  2. 옵션 B — 그대로 submit + reviewer 가 catch 하길 기도. 위험.

본인 결정 = 옵션 A. 이번 sprint 의 목적: 진짜 leak-free re-validation.

하지만 한 가지 더 미묘한 question: "TIERA67 - 8" 이라도, 남은 47 genes 가 8-gene 과 biologically correlated 이므로 (모두 thyroid differentiation program), 여전히 implicit leakage 가 있다는 의심 가능. 그래서 본 sprint 는 4가지 cluster 변형 (R1-A/B/C/D) 을 비교:

  • R1-A: TIERA67 minus 8-gene (47 genes, same biology — partial-correlation expected)
  • R1-B: 30-gene MAPK + immune + EMT (8-gene 과 zero overlap; functional level distinct)
  • R1-C: 5 immune markers only (differentiation-orthogonal axis)
  • R1-D: BRS71-like minus 8-gene overlap (BRS framework gold standard)

R1-B 가 가장 critical: 8-gene 과 functional level 에서 완전히 다른 genes 로 cluster 했을 때 8-gene 이 여전히 그 cluster 를 잘 예측하는가? 그렇다면 진짜 prediction.

Critical observation #2 (paper 의 strongest point): R1-B AUC 0.925. v6 에서 추가된 단락 (Methods 섹션)

Leak-free cluster re-derivation (R1). To rule out the possibility that the 8-gene panel's predictive performance is autocorrelation arising from the inclusion of these 8 genes in the original 67-gene cluster-defining panel, we generated 4 alternative cluster definitions, each excluding the 8-gene panel: (R1-A) TIERA67 minus 8-gene = 47 differentiation genes; (R1-B) 30-gene MAPK + immune + EMT functional panel with zero overlap; (R1-C) 5 pure-immune markers (orthogonal axis); (R1-D) BRS-framework genes minus 8-gene overlap. Each variant was clustered using Leiden K=2 (resolution swept; KMeans-on-centroids fallback if Leiden produced K≥3), n_neighbors=15, random_state=42, on all 500 TCGA-THCA primary tumours. Concordance with the original DM1/DM2 cluster was assessed by Adjusted Rand Index.

Leak-free CV AUC (R2). For each leak-free cluster, the 8-gene LogReg + RF were trained via 5-fold StratifiedKFold (random_state=42) and bootstrap 95% CI computed from 1000 iterations. The BRAF V600E single-feature baseline was derived from the sample_master driver_anchor column.

🔬 GSE151180 probe-mapping guide (revision-round 무기, 1-day work)

왜 이 cohort 가 critical?

GSE151180 = "Gene and miRNA expression in radioiodine-refractory and radioiodine-avid PTCs" (Nadal 2021). n=47 (41 RAI-refractory + 6 RAI-avid).

  • 본 8-gene panel 의 가장 직접적 clinical ground truth: RAI uptake 자체가 ground truth label (DM1/DM2 cluster proxy 가 아님)
  • 현 R3-B 결과: probe-level matrix (62,976 probes × 47 samples), gene symbol mapping 안 됨 → AUC 측정 deferred
  • 1-day work 으로 GPL21575 (Agilent) probe-symbol annotation 추가 → 전체 8-gene 적용 가능
Step-by-step probe-symbol mapping (revision round)
  1. GPL annotation 다운로드: 
    https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GPL21575
→ Annotation file (gz) 다운로드
  2. Probe → Symbol mapping table 추출: 
    import pandas as pd
gpl = pd.read_csv("GPL21575.annot.gz", sep="\t", skiprows=27, low_memory=False)
mapping = gpl[["ID", "Gene symbol"]].dropna()
  3. GSE151180 series matrix 의 probe ID 와 매핑: 
    expr_probe = pd.read_csv("GSE151180_series_matrix.txt.gz", ...)  # probe-level
expr_gene = expr_probe.merge(mapping, left_index=True, right_on="ID")
expr_gene = expr_gene.groupby("Gene symbol").mean()  # collapse multiple probes
  4. 8-gene 추출 + R1-A trained LogReg apply: 
    genes_8 = ["SLC5A5","TPO","TG","TSHR","PAX8","NKX2-1","FOXE1","DIO1"]
X_ext = expr_gene.loc[genes_8].T  # samples × 8
X_scaled = scaler.transform(X_ext)
p_DM2 = model.predict_proba(X_scaled)[:, 1]
y = [1 if "refractory" in label else 0 for label in metadata.RAI_status]
auc = roc_auc_score(y, p_DM2)
  5. Bootstrap 1000-iter 95% CI 적용
  6. 결과 expected: AUC 0.7-0.85 정도 (clinical ground truth = noisier than histology, n=47 small)

예상 timeline: 4-6시간 (download + mapping + analysis + figure). 1일 work 충분.
