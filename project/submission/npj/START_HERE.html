한 줄 요약 — BRAF V600E (PTC에서 가장 흔한 driver mutation, 600번 아미노산 V→E 치환, 약 60% 환자가 갖고 있음)만 보고 RAI (Radioactive Iodine, 방사성요오드 치료. 갑상선 수술 후 잔여 종양 제거)를 결정하는 현재 표준에 도전했고, 8-gene panel이 실제로 더 잘 한다는 것을 정직하게 검증했고, TERT (Telomerase Reverse Transcriptase. promoter mutation은 텔로머라제 활성화 → 무한 분열)는 stage-confounded (병기에 의한 교란)임을 드러내고 reframe 했고, 지금 npj (Nature Partner Journals) Precision Oncology submit 직전이다.
ΔAUC = +0.132 Cohen's d = +1.683 multivariate p = 3.78×10⁻⁵ HR 6.31 → 1.88 2일 sprint

위 4개 통계 수치 의미: ΔAUC = 두 분류기 AUC 차이 (높을수록 본 논문 panel이 BRAF baseline보다 잘 함). Cohen's d = 효과 크기 (0.8 이상이면 large; +1.68은 very large). multivariate p = 4-군 stage/age/sex 보정 후 logrank p-value. HR = Hazard Ratio (위험비), univariate vs multivariate 차이가 honest reframe의 핵심.

起 기 · 시작 — 문제 정의

RAI 결정에 BRAF V600E 하나로는 부족했다

PTC (Papillary Thyroid Carcinoma, 갑상선 유두암 — 가장 흔한 갑상선암, 전체의 80%+)에서 RAI 치료 결정은 지금도 BRAF V600E 변이 한 개에 의존한다. 그런데 두 가지 사실이 알려져 있다 — BRS (BRAF-RAS Score, 52-gene 발현 분류기. Chakravarty 2011 + TCGA 2014) 분류기는 ~10%를 잘못 분류하고 (Landa 2016 (MSKCC PDTC/ATC cohort)의 BRAF/RAS-like-by-expression subset이 대표 사례), 전체 코호트의 ~30%는 BRAF/RAS 변이 자체가 없다 (driver-negative residual).

그리고 지금 진행 중인 두 thyroid TROP2-ADC (TROP2 단백질을 표적하는 항체-약물 접합체. 갑상선암 ADC trial) trial — SETHY (NCT06235216, 2024-09 등록 시작), STRAP (NCT07521670, 2026-05 예정) — 둘 다 molecular sub-stratification 없이 등록받고 있다. STRAP은 TROP2 IHC (Immunohistochemistry, 면역조직화학 — 항체로 단백질 발현 시각화)조차 안 본다.

질문 하나로 정리하면: BRAF V600E보다 더 잘 하는 quantitative pre-RAI biomarker가 있는가?

承 승 · 발전 — DM1/DM2 axis + 8-gene panel

513명 TCGA-THCA를 다시 분석해서 axis를 찾고 8-gene panel을 만들었다

TCGA (The Cancer Genome Atlas — NIH 미국 국립암센터의 대규모 암 유전체 지도. 33개 암종 ~11,000명)의 갑상선암 코호트 (TCGA-THCA, 513 primary tumour)에 대해 driver-negative residual (BRAF/RAS 변이 없는 환자군)에서 unsupervised clustering (정답 라벨 없이 그룹 자동 발견)을 돌렸다.

구체적으로 Leiden algorithm (community detection 알고리즘. K=2 forced + resolution 0.5)로 clustering → 두 transcriptomic state가 bootstrap-stable (1,000번 sub-sample resample 시 cluster 일관성 유지)하게 (concordance > 0.92) 나왔다. 이걸 DM1/DM2 axis라 부른다 (DM = "Dark Matter" — driver-negative residual에서 처음 발견됐다는 의미의 작업 명칭).

BRAF/RAS 변이와는 Spearman ρ (rank 상관계수, -1 ~ +1) = 0.49 — 겹치지만 동일하지 않은 sub-axis. 17명 outlier (2명은 BRAF mutation인데 DM2-like, 15명은 RAS mutation인데 DM1-like)가 이 axis가 mutation status의 재진술이 아님을 증명한다.

이 axis 위에 canonical thyroid-differentiation 8-gene (NIS / SLC5A5 (sodium-iodide symporter, 요오드 흡수 단백질), TPO (thyroperoxidase, 요오드 organification 효소), TG (thyroglobulin, 요오드 저장 단백질), TSHR (TSH receptor, 갑상선자극호르몬 수용체), PAX8 / NKX2-1 / FOXE1 (갑상선 lineage transcription factor), DIO1 (deiodinase 1, T4→T3 변환 효소)) 으로 LogReg (Logistic Regression, 로지스틱 회귀 — 분류용 ML 모델) 학습 → 5-fold CV (Cross-Validation, 교차 검증 — data를 5등분, 4개로 학습 / 1개로 검증, 5번 반복) AUC (Area Under ROC Curve, 분류기 성능 0.5~1.0) = 0.954.

BRAF V600E 단일 feature baseline AUC 0.822 대비 ΔAUC = +0.132. 외부 검증 (Landa 2016 PDTC + ATC, n=37, GSE76039 (Gene Expression Omnibus 데이터셋 ID))에서 direction-correct AUC (PDTC-vs-ATC raw labelling은 AUC 0.026이지만 방향 해석으로 0.974) = 0.974.

DM1과 DM2의 hot/cold immune separation은 Cohen's d (효과 크기 = 평균차/표준편차. 0.8 이상이면 large) = +1.683 (Mann-Whitney p (두 그룹 비모수 비교 p-value) = 4.0×10⁻¹⁸)로 거대하다 (very large 효과 크기) — checkpoint immunotherapy (면역관문 차단제, PD-1/PD-L1/CTLA-4 inhibitor) stratification 후보까지 자연스럽게 따라온다.

轉 전 · 반전 — TERT는 stage-confounded

TERT 4-group 결과를 honest reframe 했다

cBioPortal (MSK가 운영하는 cancer genomics 포털)의 thca_tcga_pub (TCGA-THCA Cell 2014 publication MAF의 mirror) mirror에서 36명 TERT-promoter mutated 환자를 회수했다. Liu-Xing 4-genotype framework (BRAF only / RAS only / TERT⁺ / Triple-negative — Xing 2014, Liu 2017 JAMA Oncol) 4-group multivariate logrank (다변량 보정 logrank test) p = 3.78×10⁻⁵. 여기서 멈췄으면 깔끔한 결과였다.

그런데 정직하게 audit 했더니 — TERT⁺ 환자는 median age 64.6 (vs 46.1) + Stage III/IV 61% (vs 21–32%). Stage + age + sex로 multivariate Cox (다변량 Cox 회귀 — 여러 covariate 동시 보정) 보정을 하면 univariate (단변량) HR (Hazard Ratio, 위험비. 1보다 크면 ref 대비 위험 ↑) 6.31 (95% CI (Confidence Interval, 신뢰구간) 2.34–17.04, p = 3×10⁻⁴)가 multivariate (보정 후 다변량) HR = 1.88 (95% CI 0.58–6.09, p = 0.29)로 떨어진다.

HR 95% CI가 1을 포함 → 통계적으로 유의 X. TERT는 우리 코호트에서 stage-and-age-independent prognostic이 아니다. (쉽게 말해: TERT 환자가 사망률 높은 게 사실 진짜 TERT 때문이 아니라 그 환자들이 원래 stage III/IV / 노령이라 그렇다.)

그래서 R8 (Result 8 — 논문 본문 8번째 결과 단원)을 reframe했다 — TERT⁺를 "독립 aggressive prognostic"이 아니라 "Stage III/IV identification을 위한 molecular handle (분자 식별 표지)"로. 1,000-iter bootstrap (resampling 기반 robustness 검정) (median p = 2.6×10⁻⁵, 93% iter p < 0.05) + 36-patient leave-one-out (LOO, 한 명씩 빼고 다시 계산) (worst-case p = 7.5×10⁻⁴, 모두 p < 10⁻³)로 4-group separation 자체가 single-event-driven은 아님을 확인. Reviewer가 던질 가장 명백한 공격을 미리 답한 셈이다.

추가로 v6 ULTIMATE에서 cluster orientation 자체도 정정했다 — v5 preprint의 표기 (DM1=MAPK-active, DM2=canonical-differentiation)는 4개 독립 증거 (WHO 2022 (2022년 WHO 갑상선암 분류 update) 매핑, Pu 2021 direction concordance, methylation cross-modality, GSE213647)에 의해 반대로 확인됐다. DM1 = 분화, DM2 = 탈분화가 진짜.
