section 2 · pipeline 1 · rna-seq

RNA-seq pipeline — kallisto + STAR + DESeq2 + ComBat-LODO

Reference path는 /data/thca/reference_kallisto (512G SSD bind mount). STAR alignment 시 Pod D K2 /tmp 실패 lesson 이후 강제: --tmpdir /workspace/_tmp --compress. Batch correction은 LODO ComBat (v5.2 critical fix — 잘못된 ComBat은 DIAL=0.494 leak artifact 만든다).

# RNA-seq → DEG (canonical block)
kallisto quant -i reference_kallisto/idx.kidx \
  -o results/v17_korean/kallisto/${SAMPLE} \
  -t 8 --pseudobam \
  ${FASTQ_R1} ${FASTQ_R2}

STAR --runThreadN 8 \
  --genomeDir /data/thca/reference_star \
  --readFilesIn ${R1} ${R2} \
  --outTmpDir /workspace/_tmp/star_${SAMPLE} \
  --outSAMtype BAM SortedByCoordinate \
  --outBAMcompression 6

# GNU parallel pattern
parallel --tmpdir /workspace/_tmp --compress \
  -j 4 run_kallisto.sh {} :::: samples.txt

# DEG with ComBat-LODO
limma::removeBatchEffect(M, batch=cohort, design=group)
# (NOT plain ComBat — that leaks per v52_lodo_finding)
