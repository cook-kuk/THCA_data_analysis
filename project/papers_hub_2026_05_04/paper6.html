0.2 v52 forensic re-audit — 무엇이 발견됐나

제출 직후 self-audit으로 LODO (Leave-One-Domain-Out) ComBat 절차를 다시 검증. 핵심 차이: ComBat normalization을 fold 안에서 fit하느냐 fold 밖에서 fit하느냐.

Original v15 setup. ComBat normalization을 전체 cohort에 fit한 뒤 LODO split. 즉 batch mean/var 추정 시 holdout fold 정보가 사용됨.
Leak vector. 결과적으로 holdout fold의 batch identity가 normalization 단계에서 모델에 "주입"됨 — adversarial discriminator가 batch를 못 맞추는 게 당연. DIAL 0.494는 mid-range로 보이지만 leak이 깔린 floor.
v52 fix. ComBat를 LODO 안쪽에서 fit (each fold의 train만 사용). batch identity가 holdout으로 새지 않음.
Result. 5/5 THCA classifier 모두 DIAL=0.000 — batch와 분리된 진짜 biology signal만 잔존. 즉 v15 0.494는 leak artifact.
Critical: Algorithm framework (DIAL metric, adversarial discriminator setup)은 다른 tissue에서 valid. THCA-specific 0.494 headline만 무효. Framework paper는 살아남되 THCA experiment는 retract/revise.
0.494 vs 0.000 의미: 0.494는 "절반은 batch, 절반은 biology"로 보였지만 실제로는 "batch가 leak되어 있어 적당히 mid-range처럼 보였을 뿐". 0.000이 진짜 답: THCA classifier들이 batch를 거의 안 보고 biology만 본다. Headline은 의외의 방향으로 더 강력해진 셈 — but with caveat that we re-derived this honestly.

2. 비전공자 배경

DIAL = Domain-Invariant Adversarial Learning. 다른 cohort (TCGA / GTEx / Korean) 사이의 batch effect 를 adversarial training 으로 제거하면서 분류 능력은 유지하는 ML framework. 분류 model + domain discriminator (cohort 가 어디 속하는지 맞추는 model) 의 적대적 학습. v15 NeurIPS 2025 submission 의 핵심 contribution.

v5.1 의 0.494 가 무엇이었나. THCA cohort 에서 trained DIAL classifier 를 다른 cohort (Korean K2 또는 외부 GEO) 에 transfer 하면 DIAL score 가 0.494 로 flip. v15 manuscript 의 해석은 "domain-invariant generalization 의 inverse" — algorithm 이 cohort information 을 너무 강하게 제거해서 transfer 시 reverse-direction 으로 작동.

v52 forensic re-audit 가 발견한 것. 적절한 LODO (Leave-One-Domain-Out) ComBat normalization 적용 — train domain 에서 normalize 한 mean/variance 를 test domain 에 직접 적용하지 않고 test domain 만 따로 normalize — 시 모든 5/5 THCA classifier 의 DIAL=0.000. 즉 0.494 는 generalization signal 이 아니라 normalization leak.

한 줄 요약. "The v5.1 number that motivated the manuscript was a normalization-leak artifact. The algorithmic framework on other tissues is not invalidated; the THCA-specific headline is."

16. 한국어 풀어쓰기 (방법 · 결과 · 의미)

16.1 DIAL 이 무엇인가

DIAL = Domain-Invariant Adversarial Learning. 다른 cohort 들 (TCGA / GTEx / Korean) 사이의 batch effect 를 adversarial training 으로 제거하면서도 분류 능력은 유지하는 ML framework. Specifically: (a) 분류 model + (b) domain discriminator (cohort 가 어디 속하는지 맞추는 model) 의 적대적 학습 — 분류 model 은 정확히 분류하면서 동시에 cohort information 을 발설하지 않도록 학습. v15 NeurIPS 2025 submission 의 핵심 contribution.

16.2 v5.1 의 0.494 가 무엇이었나

THCA cohort (TCGA-THCA) 에서 trained DIAL classifier 를 다른 cohort (Korean K2 또는 외부 GEO) 에 transfer 하면 DIAL score 가 0.494 로 flip. v15 manuscript 의 해석: "domain-invariant generalization 의 inverse" — 즉 알고리즘이 cohort information 을 너무 강하게 제거해서 transfer 시 reverse-direction 으로 작동. v15 submitted 2026-04-27.

16.3 v52 forensic re-audit 가 발견한 것

제출 후 (post-NeurIPS deadline) forensic re-run: 적절한 LODO (Leave-One-Domain-Out) ComBat normalization 을 적용하면 — 즉 train domain 에서 normalize 한 mean/variance 를 test domain 에 직접 적용하지 않고, test domain 만 따로 normalize 하면 — 모든 5/5 THCA classifier 의 DIAL=0.000 (true_biology, no flip). 즉 v5.1 의 0.494 는 cross-cohort generalization signal 이 아니라 normalization leak — train + test 의 mean/variance 가 normalization step 에서 mixed 되면서 spurious flip pattern 생김.

16.4 왜 이게 다음 paper 의 자산인가

  • Pattern 1 "Forensic re-audit" archetype. Submitted 후에도 result 를 retest 할 권리 / 의무. Paper 7 의 핵심 사례.
  • Leakage-control checklist source. 7-item check (LODO ComBat / pre-batch split / sample-vs-feature CV / domain stratification / random-panel control / permutation test / leakage simulation) — 다른 cross-cohort method paper 들이 사전에 적용 가능.
  • Methods paper 후보: "Leakage-control checklist for cross-cohort transcriptional classifiers — a forensic case study of the THCA DIAL=0 finding." Paper 7 와 co-publish 가능.
  • Algorithm framework 자체는 valid on other tissues (BRCA / LUAD 등) — THCA-specific failure 만 documented.

17. 이 연구의 한계 (구체적, 솔직하게)

  1. NeurIPS submission cycle 후 발견 — retraction 절차 복잡. Manuscript 자체는 이미 NeurIPS review process 진입 — 자체 retraction 으로 못 pull. 대신 downstream paper 가 v5.1 number cite 안 함 으로 차단.
  2. Single-tissue (THCA) failure → 다른 tissue 의 algorithm validity unknown. v52 finding 은 THCA-specific normalization leak — BRCA / LUAD 등 다른 tissue 에서도 같은 leak 가 있는지 미검증.
  3. v52 finding 자체가 unpublished. Memory anchor (v52_lodo_finding) 만 — peer-reviewed publication 부재. Methods paper 로 publish 해야 reference 가능.
  4. Leakage-control checklist 가 incomplete. 7-item check 에 더해 다른 leak source (label leak / temporal leak 등) 가능성 — comprehensive checklist 작성 추가 작업 필요.
  5. 알고리즘 framework 의 fundamental limitation 인지 모호. v5.1 의 leak 가 (a) 단순 normalization implementation bug 인지 (b) DIAL 알고리즘 자체의 limitation 인지 분리 어려움.
