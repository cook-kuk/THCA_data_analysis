사전 사용법 — 한국어 1차 + 영문 parallel

how to use this glossary · KR primary + EN parallel + acronym + 1-line definition + usage

5개 트랙 · 30+ 페이지가 동시에 굴러가는 상황에서 용어 혼선은 가장 흔한 reviewer-paper risk이다. 이 사전은 다음 4 규칙을 강제한다.

  • 한국어 표기를 1차로 쓰고, 처음 등장 시 괄호로 영문 + 약어를 병기한다. 예: 분화 신호 (thyroid differentiation score, TDS).
  • 약어는 처음 등장 시 항상 확장한다. 예: HLA-I (human leukocyte antigen class I) — abbreviation theater 금지.
  • 같은 개념의 두 한국어가 충돌하면 본 사전 표기를 따른다 — 예: "면역-친화" 대신 "면역원성 (immunogenicity)" 사용.
  • Voice-protected 어휘는 reviewer-safe 표현으로만 사용한다 — Hook/Aim/Disc 3.1 등은 본인 키보드로만 작성.
Sibling 페이지 연결: 약어 풀네임은 acronym registry 로, venue별 용어 차이는 editorial guidelines comparison 으로 cross-check. Reviewer 응답에서의 용어 일관성은 reviewer Q&A bank 에 묶어둔다.
