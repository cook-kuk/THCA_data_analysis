Dataset Lifecycle & Onboarding Protocol

Onboarding 3-step

Step 1 · Manifest 등록
data_registry/manifests/master_dataset_catalog.csv에 row 추가 (id, source, n, modality, zone, license, citation)
Step 2 · Zone 배정
5 zones (A discovery / B validation / C spatial-image / D pan-cancer-ICI / E Korean-HLA) 중 하나 배정; 다중 zone 사용 시 primary zone 명시
Step 3 · Boundary audit
scripts/boundary_audit/ 재실행 → exit 0 confirm; sample leak / batch effect / manifest-actual mismatch 검증
Step 4 · Provenance log
사용 paper / track / fact-bearing claim과 함께 기록 (위 Cohort × Track matrix)
Step 5 · Storage placement
large raw data는 /data/thca/<cohort>/; processed는 project/results/... (bind mount); /tmp 금지
Step 6 · Backup checkpoint
RunPod에서 process한 결과는 정기적으로 /data bind mount로 sync; pod terminate 시 volume loss 방지
