운영 룰 — 절대 위반 금지

5 strict rules · enforced across all 10 deliverables

Rule 1 · 절대 fabricate 금지

5단계 evidence 라벨링

모든 claim은 다음 중 하나로 라벨링:
file-backed 실제 내부 파일에 있는 수치
internal claim 메모리/회의 노트 — verification 필요
public proxy 공개 데이터에서 추론
literature 출판 논문 출처 명시
hypothesis 제안 단계, 아직 증명 안 됨

Rule 2 · TCGA ≠ CTC

Biomarker layer 절대 혼합 금지

TCGA는 mutation/transcriptomic subtype/survival/immune deconvolution/RAI proxy만 지원. TCGA는 CTC count, CTC morphology, CTC EMT stage, CTC sequencing 어느 것도 지원 안 함. Layer 분리: CTC morphology / CTC DNA-RNA / ctDNA-cfDNA / tissue NGS / tissue H&E-IHC / spatial transcriptomics / public bulk / outcomes — never blend.

Rule 3 · 정직한 paper / 자신감 있는 deck

Paper vs Grant tone 구분

Manuscript 문서: 엄격한 paper 언어, hype 금지. Grant/deck: bold but plausible. 같은 사실, 다른 톤.

Rule 4 · 직접 사용 가능

구체적 deliverable

모든 deliverable = 실제 파일, 깔끔한 파일명, 표, 체크리스트, 명시적 next actions, 한국어 + 영어 title.

Rule 5 · Closure battery 잠금

Image-DM1 path = DROPPED

2026-05-04 closure battery verdict D: ResNet50 Spearman 0.022 ≈ random 0.031, FM projected gain < GO threshold +0.28. Paper 1 image-DM1 angle 폐기. Pod B/G1/G2/G3 파이프라인 폐기. Resurrect 금지.
