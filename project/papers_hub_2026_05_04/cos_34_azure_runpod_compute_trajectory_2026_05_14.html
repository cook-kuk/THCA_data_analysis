8. RunPod usage patterns — mandatory tmpdir + compress

8.1 The /tmp lesson

Pod D /tmp overflow killed a 9-hour STAR pipeline mid-run. Container disk (where /tmp lives) is ephemeral and small relative to /workspace. GNU parallel + STAR + arcasHLA all default to /tmp for intermediates. Mandatory flag on every dispatch: --tmpdir /workspace/_tmp --compress. label: memory v17_pod_D_k2_star_tmp_failure

8.2 Per-tool tmpdir override

ToolDefault tmpdirOverride flagWhy mandatory
GNU parallel/tmp--tmpdir /workspace/_tmp --compressMulti-GB intermediates per job × dozens of jobs
STAR./STARtmp--outTmpDir /workspace/_tmp/STAR_${SAMPLE}Genome index + alignment buffers (multi-GB)
arcasHLA/tmp--temp /workspace/_tmp/arcas_${SAMPLE}BAM index extracts + read partitions
samtools sort-T /tmp/sort-T /workspace/_tmp/sort_${SAMPLE}External merge sort with large fanout
