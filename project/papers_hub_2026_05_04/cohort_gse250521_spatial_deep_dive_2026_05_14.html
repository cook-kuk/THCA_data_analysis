7 · Reviewer Q&A — spatial signal interpretation, ROI definition, rescue closure

예상 reviewer 질문 + 본문 답안

Q1 — 16-sample spatial 이 일반화 가능한가?

16 slides 4-stage 는 small cohort 이지만, stage-axis 자체가 inverted-V 라는 비선형 pattern 으로 4 stage 간 분리됨. discovery / replication 용도로만 사용. 일반화 주장은 bulk (GSE286332 n=18, TCGA n≈500 transfer, K2 n=260) cohort 들과의 cross-modality 일관성에 의존.

Q2 — LR diversity 2,512 가 어떻게 산출되는가?

MOSCOT optimal transport + Squidpy ligand-receptor module 로 슬라이드별 active LR pair 수 산출, LPTC 슬라이드 median 이 ≈ 2,512. 정확한 threshold (p-value, expression cutoff)는 Methods 본문 명시.

Q3 — TLS-like 라는 표현을 쓰는 이유?

Bulk RNA-seq + spatial 만으로는 organized lymphoid follicle 의 구조-level 확정 불가. BCL6 / CXCR5 / CCR7 / MS4A1 / JCHAIN 의 coordinate up + CXCL13 ligand colocalization 은 follicular maturation 시그니처와 일치하지만, IHC / IF 구조 confirmation 은 미수행. paperable 범위에서 "TLS-like structures" 표현 유지.

Q4 — MAPK rescue 가 왜 spatial 에서만 fail 하나?

spatial 에서는 (i) tumor / immune / stroma 가 동일 spot 내 혼재, (ii) optical/handling QC noise 가 크게 들어옴. v17 full+spatial+detection residual ρ=+0.007 + random module raw median +0.099 (percentile 0.545) 는 bulk 에서의 anti-correlation 이 spot-level 에서는 deconvolution 한계로 인해 잡히지 않는 가설을 지지. v18 KNN lag rescue 까지 시도해도 null — 정직하게 close.

Q5 — ROI definition (LPTC vs PTC 구분)?

Lu 2023 원 metadata 의 pathologist-annotated stage label 을 그대로 사용. LPTC = locally advanced PTC, ATC = anaplastic. 본 paper 본문에 stage definition 명시. LPTC 슬라이드 안에서도 normal-adjacent zone 은 별도 subset 처리.

Q6 — Spatial replication 이 cross-modality 라서 의의가 있는가?

GSE286332 (bulk, n=18) → GSE250521 (spatial, 16 slides) 은 modality 가 독립이고 cohort 가 독립인데 동일 ligand pair (CXCL13↔CCR6/CCR7) 가 같은 환경 (HT-overlap / LPTC stage) 에서 등장하는 cross-modality co-finding. 이중-cohort independent replication 의 일종.

Q7 — Paper 2 image-DM1 (Paper 2 main) 과 spatial 의 관계?

image-DM1 closure 는 H&E patches 의 DM1 score prediction (CLAM AUC 0.83±0.14). spatial transcriptomics 는 H&E 같은 슬라이드에서 transcriptomic-level DM1 / TDS overlay 를 제공. 두 modality 는 같은 stage 축 (N→PTC→LPTC→ATC) 위에서 sign 일치 — image projection 의 분자 정합.

Q8 — Spatial rescue closure 가 reviewer 에게 negative 한 인상은?

오히려 strength. v15-v18 단계별 시도 + closure 는 selective reporting 회피의 증거이며, MAPK × Panel anti-correlation 의 근거를 TCGA+Lee bulk + cross-cohort pooled (v14 ρ=-0.327 [-0.376, -0.278] n=1,287 5 cohorts) 에 한정함으로써 claim 의 명확한 boundary 를 제공.
