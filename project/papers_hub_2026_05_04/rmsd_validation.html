- Our AF prediction: GADGVGKSAL (KRAS G12D 10-mer, position 7-16 of KRAS protein)
- 1Q94 reference: AIFQSSMTK (different test peptide, 9-mer)
Both peptides occupy the same HLA groove but have different anchor residues and middle sequence. The 2.80 Å divergence is mostly due to side-chain differences in the middle (P3-P7) where the peptides differ. The N+C anchors should still be in the same pockets.

4 · Why this matters

  • Validation: AF-Multimer MSA mode produces structurally-correct pMHC predictions even WITHOUT GPU. Sub-Å RMSD on HLA core is the gold standard.
  • Anchor pocket geometry: The HLA α1/α2 helices that form the peptide-binding groove are correctly placed (their RMSD is 0.84 Å). This means peptides predicted to anchor at P2/P9 will be correctly positioned in the right pockets.
  • Production scale-up: The deployment script deploy_alphafold_runpod.py for 30 candidate complexes is verified — RunPod RTX A6000 ~$1.50 will give 30 such pMHC structures with similar sub-Å accuracy.
  • For drug docking: The AF-Multimer pMHC can serve as a docking template for small-molecule inhibitors targeting the peptide-MHC interface (e.g. KRAS inhibitor companion design).
  • For TCR design: Add a TCR Vα + Vβ chain to the FASTA → AF-Multimer can predict the full TCR-pMHC complex (the geometry already validated).

5 · Method

# Bio.PDB structural superposition
from Bio.PDB import PDBParser, Superimposer
af_struct = parser.get_structure("af", af_pdb)
ref_struct = parser.get_structure("ref", "1Q94.pdb")

# Get Cα atoms from HLA chain (A in AF, D in 1Q94)
af_hla_atoms = [atom for residue in af_chains["A"] if "CA" in residue]
ref_hla_atoms = [atom for residue in ref_chains["D"] if "CA" in residue]

# Kabsch superposition on HLA Cα
sup = Superimposer()
sup.set_atoms(ref_hla_atoms[:275], af_hla_atoms[:275])
hla_rmsd = sup.rms  # = 0.836 Å

# Apply transformation to entire AF structure
sup.apply(af_struct.get_atoms())

# β2m + peptide RMSDs are then computed on the transformed coordinates

7 · Honest limitations

  • Peptide RMSD comparison is not direct — the two peptides are different sequences. We can only compare HLA + β2m core.
  • Real validation needs SAME peptide in AF prediction + crystal structure. For KRAS G12D specifically, no public X-ray crystal exists with HLA-A*11:01 + GADGVGKSAL.
  • Single AF model + 2 recycles (converged via tolerance). 5 model variants × 5 recycles each would give ensemble; not run here.
  • "unrelaxed" PDB — small steric clashes possible. Amber relaxation would polish geometry but doesn't change overall structure.
  • 1-residue offset in peptide registry possible — we used naive 1:9 alignment.
