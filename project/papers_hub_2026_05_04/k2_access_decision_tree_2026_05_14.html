Q2 Why not TCGA-LUAD/BRCA 대신 K2 (다른 cancer type 으로 cross-validate)? THCA 의 DM1/DM2 stratification 은 thyroid-specific signature (TG/TPO/SLC5A5 등) 에 의존. Cross-cancer 검증은 methods-route fallback (Branch C) 으로 보유, 단 main 검증은 same-cancer external 이 표준. K2 가 그 표준.
Q3 What if K2 fails? (실패 시 robustness) Branch B/C/D 모두 사전에 mapped. PARTIAL → npj/Cell Rep Med · NO → Paper 1 ST1 흡수 + methods-route · ALT → 한국 4-center pool. 실패가 paper 자체를 무효화하지 않음.
Q4 Sample size justification (n ≥ 50 floor 근거) UNI-final overall LOTO=0.852 · 95% CI [0.78, 0.91] 추정 · 외부 검증에서 ≥ 0.78 confirm 위한 minimum N = 50 (Hanley & McNeil 1982 공식 기반). Bundang internal pilot (n=59) 와 통합 시 N=100+ 가능.
Q5 Scanner / staining batch effect UNI-final 은 Mass General H&E foundation model 로 staining/scanner variation 에 부분 robust. K2 의 분당 scanner vs original 의 scanner 차이는 supp figure 로 명시. Stain normalization (Macenko / Reinhard) optional 비교.
Q6 FFPE quality (2015-2016 vintage) 10 slide pilot staining test (Week 3) 가 일차 floor. Pass rate < 50% 시 NO 분기 자동. ≥ 70% 시 full inventory. Pilot 결과 자체가 supp methods 에 명시.
Q7 Why bunch 분당 prospective n=30 가 K2 보다 약함? 분당 자체 = same-center, K2 = different-center → 후자가 external generalization 강함. 단, 분당 prospective 는 H&E + RNA 두 layer 의 동시 prospective 통제 → 다른 axis 에서 강함 (Branch B fallback).
Q8 한국 imaging consortium (4-center pool) feasibility Branch D long-shot. Yu network 가 1차 평가. 9월 grant cycle 에 consortium 안건화 가능. Paper 2 의 main paper 위상은 Branch A 가 가장 빠름.
Q9 K2 가 SNU 소유인데 분당이 access 권한 있나? K2 (PRJEB11591) 는 European Nucleotide Archive (ENA) public RNA-seq · H&E slide 는 SNU-GMI / 분당 SNUH 보관. Yu 가 SNU 갑상선외과 network 활용 가능 (Yoo 2016 저자 그룹). 이 결정이 본 페이지의 핵심.
