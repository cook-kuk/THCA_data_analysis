02Rules

Promotion requires intervention plus response readout plus a deployable output

Paperable

Coherent mechanism, replication, and a figure/table story.

Paired pre/post, responder vs non-responder, or orthogonal validation strengthen this lane.

Validation-ready

Cheap orthogonal assay or external cohort is feasible.

This is the sweet spot for biomarkers, potency/QC, and combo ranking.

BD-ready

Output changes a decision or becomes a product artifact.

Companion diagnostic, batch release, candidate ranking, or responder selection.

05Agent Pipeline

Search, filter, score, route, gate
1. Search GEO by modality keyword families
   - vaccine / neoantigen / mRNA / ICI / TCR
   - CAR-T / CAR-NK / TIL / TCR-T / exhaustion / potency
   - bispecific / checkpoint / ADC / radioligand
   - PARP / MEK / ERK / hormone / epigenetic
   - oncolytic / radiotherapy / cytokine / myeloid / stroma

2. Filter by study geometry
   - keep intervention + control
   - keep pre/post or responder/non-responder
   - prefer paired human samples, then humanized models, then informative preclinical systems

3. Score evidence
   - paired design
   - sample size
   - orthogonal validation
   - independent replication
   - clinical actionability

4. Route to task
   - response ranking
   - potency / QC
   - resistance mapping
   - target prioritization
   - combo prioritization

5. Gate output
   - paperable only if mechanism + replication + clear figure exist
   - validation-ready only if a cheap orthogonal test exists
   - BD-ready only if the output guides a decision or workflow
Important. Atlas-only or descriptive studies stay background unless they convert into a decision artifact. This keeps the agent from generating pretty but non-actionable GEO summaries.

07Decision Summary

Build order
PriorityBuildReason
1neoantigen / vaccine / ICI triage engineBest overlap between paperability, validation, and BD
2cell-therapy potency / QC scorerClear industrial use case and strong translational value
3PARP / kinase / endocrine / epigenetic response rankerBest reusable cross-cancer validation layer
4bispecific / ADC / target-selection moduleUseful commercial and mechanism module, but should stay modular
5oncolytic / radioligand reserve moduleInteresting but lower-density and more heterogeneous
Bottom line. GEO is a source for building a therapy triage engine, not a magic therapy discovery engine. The winning product is a reproducible decision system with modality-specific routes.
