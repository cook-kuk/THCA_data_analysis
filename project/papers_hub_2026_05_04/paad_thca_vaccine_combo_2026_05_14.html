PAAD × THCA 백신 콤보 — PAAD는 MRD vaccine-first, THCA는 backbone + selection.

PAAD (췌장)와 THCA (갑상선)는 cancer vaccine 관점에서 서로 다른 lane으로 정렬된다. PAAD는 resected/MRD 상황에서 백신을 일차 무기로 쓰고, THCA는 backbone-and-selection을 먼저 잠근다. 두 lane 모두를 가로지르는 절대 gate가 하나 있다 — HLA presentation failure는 백신 NO-GO. 이 페이지는 그 두 lane을 한 화면에서 정렬하고, CROSS-Neo platform, Paper 1 (DM1), HLA #1 (HT-overlap) 의 cross-track 연결을 잠근다.

GREEN — Strategy consolidation

두 lane은 독립 시나리오가 아니다. PAAD-MRD와 THCA-backbone-selection은 같은 vaccine hub (CROSS-Neo / KG-GA / Darwin-RL) 위에서 운영되며, 단일 platform의 두 application으로 본다. cancer-type 별 첫-수술 후 시간선, biomarker readiness, HLA gate, 그리고 neoantigen prediction layer를 공유.

RED — HLA presentation failure = vaccine NO-GO

tumor cell에서 HLA-I 발현이 손실되거나 antigen-processing machinery (TAP1/TAP2/B2M/PSMB8/PSMB9)가 collapse하면 — 어떤 neoantigen이든 presentation이 끊겨 백신 효능이 원천 차단된다. 이는 priority gate 가 아니라 absolute gate. PAAD든 THCA든 동일하게 적용.

GOLD — PAAD = resected / MRD vaccine-first

PAAD에서 백신의 가장 합리적 자리는 R0 resection 후 MRD. metastatic 단계는 tumor burden + 면역 억제 미세환경 (myeloid-rich stroma)으로 백신 단독 효능을 기대하기 어렵다. MRD 상황에서 ctDNA-guided + KRAS hotspot (G12D/G12V) neoantigen 백신이 가장 강한 가설.

GOLD — THCA = backbone-and-selection-first

THCA는 PAAD 와 다르다. 일반 PTC는 면역원성이 낮고 driver 단조롭다. 그래서 backbone (RAS=98% DM1 / BRAF=1% DM1 axis)을 먼저 잠그고 그 위에서 candidate 환자 selection을 한다. backbone 없이 백신부터 추진하면 진단 catchment가 흐려진다.

PAAD · MRD vaccine-first

왜 MRD인가

PAAD는 metastatic 단계에서 백신 단독으로 면역 turn-on 이 어려운 cancer type 중 하나. R0 resection 후 MRD 구간이 가장 합리적인 vaccine window — tumor burden 이 가장 낮고, ctDNA로 residual disease 정의 가능, 그리고 KRAS hotspot이 단조롭다.

  • R0 resection 후 6–12주 — adjuvant chemo 시작 전 또는 병행
  • ctDNA positive 환자 → MRD high-risk 군 우선 enrollment
  • KRAS G12D / G12V neoantigen 비중이 ~50% 이상 (population HLA × hotspot grid)
  • 면역 turn-on 효과는 burden 이 낮을 때 가장 잘 catch
Key candidate cohorts

TCGA-PAAD bulk + ICGC PACA-AU/-CA + 한국 ATC vs PAAD-resection registry (gating). PRJEB / GSE PAAD adjuvant cohorts.

PAAD · expected effect

예상 효과 & 운영 모드

백신 단독 효능은 modest 예상 — MRD relapse-free survival hazard ratio ~0.6–0.8 구간이 reasonable 가설. 단, ICI (anti-PD-1) 또는 anti-CD40 와 조합 시 stack-up 가능. 즉 PAAD lane 의 본 게임은 combo platform.

THCA lane — backbone-and-selection-first

THCA · backbone-first

왜 backbone 부터?

THCA는 일반 PTC가 indolent, 면역원성이 낮고, driver 단조로움. 그래서 PAAD 같이 곧장 MRD 백신으로 가지 않는다. 먼저 RAS=98% DM1 / BRAF=1% DM1 backbone axis 위에서 백신 candidate가 될 환자군을 정의한다.

  • Round 5 (DM1 deep dive): RAS-driven THCA 의 98%는 DM1 high; BRAF-driven 은 1%
  • DM1 axis = follicular variant (FVPTC) phenomenon (OR=17.9, p=3e-31)
  • K2 88.8% DM2 cohort = Korean overdiagnosis paradigm — backbone 먼저 안 잠그면 백신 lane을 잘못 깐다
  • Backbone + selection 이 잠긴 다음 ATC / PDTC / DTC-RAI-refractory 에서 vaccine candidate 도출
Tie to DM1 (Paper 1)

RAS=98% DM1 axis는 백신 lane 의 selection layer로 직결. RAS-driven RAI-refractory DTC 가 vaccine candidate 의 1차 후보군.

FAIL · HLA-I loss

HLA-A/B/C complete loss

RNA-seq + IHC 두 layer 에서 HLA-I 발현이 detection limit 이하. CD8 priming 자체가 불가능. 백신 시도해도 효과 없음.

FAIL · B2M loss

B2M somatic mutation / loss

β2-microglobulin (B2M) loss → MHC-I 표면 발현 불가. 어떤 epitope이든 표면 noload. PAAD 의 약 10–15%, ATC 의 일부에서 관찰.

FAIL · APM collapse

antigen-processing machinery collapse

TAP1/TAP2/PSMB8/PSMB9 / ERAP1 발현이 IFN-γ stimulation 후에도 회복 안 됨 → epigenetic silencing. 백신 무효.

PASS · 정상 presentation

HLA-I + APM 정상

HLA-I IHC ≥1+, B2M intact, TAP1/PSMB8 baseline 발현 + IFN-γ-inducible. 이 케이스만 백신 lane 으로 진입.

NO-GO 의 의미

이 gate 는 priority 1 점이 아니라 binary. HLA presentation 실패 환자는 prediction score 가 아무리 높아도 (CROSS-Neo, BAR-Neo, KG-GA) — 백신 lane 에서 제외. 대신 cell therapy / CAR-T (HLA 비의존 lane) 으로 재배정. 이는 PAAD lane 과 THCA lane 양쪽에 동일 적용.

Reviewer Q&A — cancer-type selection · vaccine timing · HLA gate threshold

vaccine reviewer 가 가장 자주 묻는 3 question family

Q1 · cancer-type selection

왜 PAAD 와 THCA 를 묶었나?

두 cancer 가 nominally 다르지만, vaccine platform 관점에서는 동일 prediction → triage → MD/structure 파이프라인 위에 올라간다. PAAD = MRD vaccine-first, THCA = backbone-and-selection-first 라는 lane 분리만 다르고, 나머지는 공유. 한 platform 의 두 application 으로 본다.

Q2 · vaccine timing

PAAD = MRD, THCA = ATC/RAI-refractory 가 맞나?

맞다. PAAD metastatic 단독 단계는 burden + stroma 때문에 백신 효능 낮음 → R0 resection 후 MRD 가 합리적. THCA 일반 PTC 는 surgery+RAI 가 효과적이므로 백신 추가 가치 marginal → ATC / RAI-refractory / RAS-driven advanced 에서 백신 lane.

Q3 · HLA gate threshold

HLA presentation failure 의 cutoff 는?

HLA-I IHC ≥1+ (membrane) + B2M intact (IHC) + RNA-seq TPM >5 (HLA-A/B/C 평균) + APM (TAP1/PSMB8) baseline 발현. IFN-γ challenge 후에도 회복 안 되면 NO-GO. ICI 시기에 활용된 LOHHLA / RNA allele-specific 도 함께.

Q4 · BD upside

BioNTech / Moderna 가 이미 KRAS 백신 시장에 진입했는데?

맞다. mRNA-LNP KRAS 백신 시장은 BNT / Moderna 가 글로벌 1위. niche 는 — (1) 한국인 HLA-C*08:02 + KRAS G12D grid (Asian-specific), (2) PAAD vs THCA cross-cancer platform, (3) CROSS-Neo prediction layer 의 explainability. 시장 1위는 어렵지만 한국 trial / BD niche 는 명확.

Q5 · cell therapy 와의 관계

HLA failure 환자는 어디로?

cell therapy (CAR-T / TIL) lane. HLA 비의존 (CAR-T) 또는 HLA-restored prime + vaccine retry. cell_therapy_hard_dossier (sibling 페이지) 가 4 modality (CAR-T / CAR-NKT / TIL / blinatumomab) 의 evidence matrix 를 잠금.

Q6 · evidence depth

현 단계 evidence 등급은?

(1) CROSS-Neo platform retro AUPRC 0.933 (KG_GA_evolved), strict no-overlap reliability 는 BAR-Neo confidence, (2) GADGVGKSAL / HMTEVVRHC = REPLICATED_PASS (MD upgrade), (3) ICI Phase C v2 4-cohort sign-consistent. 즉 backbone evidence 강함, 단 prospective vaccine trial 은 미진행 — decision support 단계.
