1 · Hero — Foundation model literature scan

2023-2026 · pathology + spatial + multi-omics · CTC-specific is open gap

Top-line — proposal-defensible architecture

Public-data FM 을 backbone 으로 쓰고, 우리는 CTC-specific encoder + CTC↔tissue bridge module 만 새로 학습한다. 이렇게 하면 30억/3년 budget 내에서 full FM 사전학습 주장 없이 claim ceiling을 유지 가능. UNI(이미지) + Nicheformer(spatial) + 커스텀 CTC ViT + CLIP-style bridge. 결론적으로 reviewer Q "이게 진짜 FM인가?" 에 대해 "public FM에 anchored 한 domain extension" 으로 답하는 것이 가장 안전.

5 · CTC-specific foundation models — open gap

현재 거의 없음 · proposal 의 white-space

  • lit CTC computational paper 들은 대부분 enrichment vendor 가 자체 학습한 image classifier (CELLSEARCH의 image review tool, Parsortix imaging, RareCyte CyteFinder 등) — foundation model 아님
  • lit Public CTC pretrained model 거의 없음 (DeepCellSpot, CTCellect 등 task-specific 분류기만 존재)
  • ic 따라서 우리 제안서의 "CTC encoder + bridge" 는 white-space — 단, FM scale (수억 parameter, 수십만 CTC) 학습은 30억 budget으로 불가
  • ic 현실적인 framing: 우리는 CTC encoder를 새로 학습하되, pretrained image FM (UNI/Virchow)을 frozen backbone으로 두고 head만 학습

9 · AI bridge model — CTC features ↔ tissue ecology

proposed novelty · CLIP-style contrastive learning

아키텍처의 핵심 학습 가능 컴포넌트는 CTC-tissue bridge module. 이는 (1) CTC patch embedding (from blood smear / cell-block IHC) 과 (2) matched tissue spatial niche embedding 사이의 CLIP-style contrastive alignment를 학습한다.

ComponentInputOutputTraining dataNotes
CTC encoder CTC patch (50×50 µm) + marker panel (PAX8/TG/EpCAM/VIM/TWIST/CD45) CTC embedding (256-d) n=50 patients × ~100 CTC ≈ 5K CTC images ic UNI frozen + small head; data augmentation 필요
Tissue niche encoder Visium HD spot + UNI patch embedding Niche embedding (256-d) GSE250521 16 slides + 우리 cohort n=50 tissue ic Nicheformer frozen + projection
Bridge (contrastive) (CTC, paired tissue niche) pairs Alignment score ~n=50 × ~50 niche × ~100 CTC pairings hyp CLIP-style InfoNCE loss; positive pairs = same patient + same timepoint
Downstream task Bridge output + clinical variables EMT state transition / residual-risk score Aim 1+2 cohort outcomes hyp Stage 3+ task — not initial pretrain claim

ic Bridge module은 "novel" 한 새 module 이며, 우리 cohort의 paired (CTC, tissue) 데이터가 unique함을 활용. Reviewer Q: "왜 이게 useful? scRNA-seq 갖고도 안 되는가?" → 답: scRNA-seq 는 fresh tissue 만 가능, CTC + FFPE archived tissue 는 우리만 paired 보유. (hyp)

13a · Deep-dive — per-model reviewer dossier

각 모델의 강점/약점/우리 사용 적합도

13a.1 UNI (Mass General + Harvard 2024)

lit ViT-L · ~307M parameters · 100K+ WSIs (Mass General 등) · DINOv2 self-supervised. file 우리 cohort에서 Paper 2 image-DM1 N=59 mean AUC 0.83 ± 0.14 (pooled 0.75). HuggingFace gated research license. 강점: 가장 광범위 검증, 우리가 이미 운영 중. 약점: text alignment 없음. 우리 사용: 이미지 backbone primary — frozen + head fine-tune.

13a.2 CONCH (Mahmood lab BWH 2024)

lit Vision-language contrastive · 1.17M image-text pairs · CLIP-style. HuggingFace gated. 강점: 임상 보고서 ↔ patch alignment. 약점: 우리 cohort에 paired text annotation 없음. 우리 사용: deprioritized — Aim 3 clinical-report integration 단계에서 다시 검토.

13a.3 PRISM (MSK 2024)

lit ~1B parameters · 1M WSIs · image only · self-supervised. Not openly released. 강점: 가장 큰 모델 scale. 약점: API/weight 미공개 — fine-tune 불가. 우리 사용: reference only — proposal benchmark 비교 차트에서만 언급.

13a.4 Virchow (Paige.AI 2024)

lit 632M parameters · 1.5M+ WSIs (Memorial Sloan Kettering 기반) · hierarchical. HuggingFace gated research license. 강점: pan-cancer downstream 검증 다수. 약점: UNI 대비 marginal — 비교 필요. 우리 사용: UNI 대안 backbone 으로 sensitivity check (Stage 1).

13a.5 Phikon (Owkin 2023)

lit ~85M (ViT-B) · TCGA 6,000+ WSIs · self-supervised. HuggingFace open. 강점: 가벼움 · open license · TCGA-trained. 약점: scale 작음 · 신규 cohort 일반화 약함. 우리 사용: Stage 1 backbone sensitivity 비교용.

13a.6 TITAN (BWH 2024)

lit ~600M · 335K WSIs + 보고서 · vision + clinical-text. HuggingFace gated. 강점: CONCH 후속, 보고서 alignment 강화. 약점: 우리 cohort 보고서 없음. 우리 사용: Aim 3 후보.

13a.7 Nicheformer (2024)

lit 57M cells single-cell + spatial · transformer encoder · niche-level representation. 강점: spatial-native FM · 우리 GSE250521 + 신규 Visium HD에 fine-tune 가능. 약점: 신규 — production-grade 미확인. 우리 사용: Aim 2 spatial backbone primary.

13a.8 Geneformer (Theodoris 2023)

lit 30M cells (Genecorpus) · BERT-style · rank-encoded. 강점: 가장 mature single-cell FM 중 하나. 약점: 비-cancer 데이터 비중 크다. 우리 사용: CTC scRNA-seq encoder 가능시 baseline 비교.

13a.9 scGPT / scFoundation / scELMo

lit CELLxGENE 33M+ · 50M · LLM-anchored. 강점: 가장 큰 single-cell foundation. 약점: tissue/CTC paired 데이터 없음. 우리 사용: 후속 generative perturbation simulation 옵션.

13a.10 CHIEF (2024 Nature)

lit 60K WSIs from 19 cancers (including thyroid). 강점: pan-cancer + thyroid 포함. 약점: closed weight 가능성. 우리 사용: Paper 11 pan-cancer DM1 (file) 와의 호환성 검토.

13a.11 PathChat (2024 Nature)

lit WSI + multi-turn dialogue. 강점: multimodal Q&A demonstration. 약점: deployment 라기보다 demo. 우리 사용: reviewer demo 후보 only.
