한국 PTC over-diagnosis — 닫혀가는 창문, 그러나 지금이 기회.

한국은 1999 년 NHIS screening 도입 이후 PTC 진단이 폭증했고, 2014 년 KMA 가 ultrasound screening 에 반대 권고를 내며 흐름이 바뀌었다. 현재 active surveillance (AS) 가 임상 표준으로 부상 중이며, MAeSTro / MASTER / KoMPASS cohort 가 그 흐름을 받쳤다. 이 환경은 자가-소멸 자연 실험이다 — 현재 surgery cohort 의 quasi-experimental window 가 닫히고 있으며, 이 안에서만 도출 가능한 reproducible causal evidence가 우리 platform 의 archival value 이다. 평결 — Causal evidence window 닫히는 중, 그러나 지금이 archival 기회

verdict · 2026-05-14 · over-diagnosis epi framing

GOLD — 창문은 닫히고 있다 (self-extinguishing natural experiment)

한국은 AS vs surgery 의 의사 결정 흐름이 빠르게 바뀌고 있고, surgery cohort 크기가 축소 중이다. 현재 BABA 5,000 + MAeSTro/MASTER/KoMPASS + CTC 62 의 조합으로만 도출 가능한 quasi-experimental causal evidence는 지금이 archival 기회다. Samsung grant 의 "30억 main story" 가 이 창문을 잡는 전략이다.

BLUE — 다른 over-treated cancer 로 transfer 필요

창문이 닫혀도 우리 platform 이 archival value 를 유지하려면 다른 over-treated cancer (low-risk prostate / DCIS / indolent lymphoma) 로 framework transfer 가 필요. Samsung 의 "future direction" 은 이 transfer 가 핵심. 한국 PTC 의 자가-소멸 자체가 framework reproducibility 의 stress test.

한국 PTC over-diagnosis 역사 — 1999 → 2014 → 2026

timeline · NHIS screening → KMA recommendation → AS standard

한국 PTC 발생률은 1999 년부터 폭증하여 2011 년 인구당 발생률이 세계 1위가 됐다. 그러나 사망률은 같은 기간 거의 변화 없음 → over-diagnosis 의 교과서적 사례로 국제적으로 인용된다.

1999NHIS 국가건강검진 도입

National Health Insurance Service 건강검진에 ultrasound 가 광범위하게 포함. 갑상선 결절 발견율이 급증.

1999-2011PTC 진단율 15배 증가

같은 기간 사망률은 거의 unchanged. Ahn et al. NEJM 2014, Vaccarella et al. NEJM 2016 에서 over-diagnosis 의 표본 사례로 보고.

2014.03KMA: ultrasound 일상 screening 반대 권고

대한의사협회가 무증상 성인에 대한 ultrasound 일상 screening 에 반대 권고. 진단율이 즉시 plateau.

2015-2020Active surveillance 임상 수용 확대

Ito 2003 (Kuma Hospital) framework 가 한국 임상에 본격 도입. PTMC (papillary thyroid microcarcinoma) 가 AS 의 1차 타깃.

2020-2024MAeSTro / MASTER / KoMPASS cohort 가동

Multi-institutional AS cohort 가 본격적으로 데이터 축적. AS 가 surgery 와 동등한 outcome 임을 증명.

2026 (present)AS 가 표준 부상 — surgery cohort 축소

AS uptake 가 PTMC 의 대다수에서 1차 선택. Surgery cohort 가 점차 high-risk (extra-thyroidal extension, BRAF+, TERT+) 로 enrichment.

~2030 (proj.)Surgery cohort = high-risk 만 남음 (window 닫힘)

PTMC surgery 가 급감. 우리가 보유한 BABA 5,000 + MAeSTro/MASTER/KoMPASS quasi-experimental window 가 사실상 닫힘. causal evidence 는 archival 자료가 됨.

Active surveillance vs surgery dynamics — MAeSTro / MASTER / KoMPASS

AS vs surgery · 한국 cohort · uptake trend · surveillance bias warning

한국 AS 운동의 3 개 main cohort. Samsung grant 의 quasi-experimental target trial emulation 의 main exposure cohort 들이다.

MAeSTro

Multi-center Active SurveillancE TRial On thyroid cancer

대표 PI 박영주 (SNU), 다기관 prospective AS cohort. PTMC 환자가 main, follow-up >5 년. Tumor growth + lymph node metastasis 가 endpoint.

Samsung 가치: AS arm 의 primary exposure data + outcome trajectory.

MASTER

Management of Asymptomatic small papillary Thyroid carcinoma in adults

다기관 등록 (Asan/Samsung Medical/세브란스 등). MAeSTro 와 partial overlap, 다른 환자집단 포함.

Samsung 가치: External validation cohort. MAeSTro 결과 transferability.

KoMPASS

Korean Multi-center Papillary thyroid cancer Active Surveillance Study

한국 다기관 AS cohort. Patient-reported outcome 과 cost-effectiveness 데이터.

Samsung 가치: Patient-reported outcome + cost dimension.

Question

"10년 후 AS 가 표준이 되어 한국 PTC surgery cohort 가 사라지면, 이 모델의 임상가치는 어떻게 됩니까?"

Answer (3 layers)

Layer 1: Transfer asset

Framework 자체 (target trial + DR learner + DM1-like dark matter + image surrogate + CTC readout) 가 prostate / DCIS / indolent lymphoma 로 transfer.

가치: over-treated cancer 의 일반화된 causal triage stack — 한국 PTC 가 닫혀도 다른 cancer 에서 살아남는다.

Layer 2: Reproducible causal framework

"한국 PTC = 자가-소멸 자연 실험" 이라는 연구 자체가 causal evidence 의 archive. 미래 cohort 가 닫혀도 우리가 잡은 quasi-experimental result 는 reproducibility benchmark 가 된다.

가치: "이 시기에만 가능한 evidence" 의 archival 자료 — 미래 연구자가 우리 framework 를 inherit.

Layer 3: Framework asset

분자 axis (DM1 dark matter) + image axis (H&E → DM1) + immunology axis (HT-overlap) + causal axis (target trial emul) 의 4-axis framework 가 PTC 외에 transferable.

가치: "platform" 가치 — 한 cohort 에 종속되지 않고 새 cohort 에 plug-in.

Honest one-liner: "10년 후 한국 PTC surgery cohort 가 사라지면, 이 모델은 한국 PTC 모델로서는 임상가치 축소. 그러나 over-treated cancer 의 causal triage framework 로서는 prostate / DCIS / lymphoma 로 transfer 가능 — 그 transfer 가능성이 framework 자체의 archival 가치다."
안 솔직하게 답하면 안 되는 이유: 평가관/reviewer 가 이미 한국 over-diagnosis 환경을 알고 있다. "transferable + archival + framework" 의 3-layer 가 honest framing. 70% 이상 ROI 약속은 거짓말.
