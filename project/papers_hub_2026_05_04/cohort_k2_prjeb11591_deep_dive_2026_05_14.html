STRONG — Korean overdiagnosis paradigm 확보

K2 n=260, 88.8% DM2 는 한국 갑상선 cohort 의 overdiagnosis paradigm을 분자 phenotype 으로 잡아내는 가장 큰 단일 reference. arcasHLA imputation 으로 RNA-seq 만 가지고 DPB1*05:01 56% 같은 critical allele 까지 회수했고, AFND South Korea pool 대비 HLA allele ratios 0.93-1.22 p>0.16 으로 population-level allele distribution 의 baseline match 도 확보.

4 · HLA boundary vs AFND — K2 baseline match

Korean baseline = AFND South Korea pool · ratio range 0.93-1.22, all p>0.16

Boundary statement

K2 HLA allele distribution 은 AFND South Korea pool 대비 모든 검정 allele 에서 ratio 0.93-1.22 사이, binomial p>0.16. 즉 K2 는 Korean 인구 baseline 의 대표 sample로 기능. 어떤 thyroid disease enrichment 도 "Korean population deviation" 으로 해석하지 않는다.

Why this matters

Paper 2 HLA dossier (HT-isolated PTC) 와 Paper 4 GD HLA (Korean GD pan-Asian) 가 모두 Korean cohort 에서 HLA-II axis 를 다룬다. K2 boundary 가 baseline-match 이라는 정직한 명시는 두 paper 의 allele frequency 가 아닌 expression-level / autoimmune-context 가 main wedge 임을 명확히 한다.

K2 boundary used in

Paper 1 (DM1 Korean generalization), Paper 2 HLA dossier limitations, Paper 4 GD HLA Korean context, Track 3 HLA #1 command room, Track 4 Korean GD command room.

Future SNP-based confirmation

cookHLA 가 SNP 입력 필요로 deferred 상태. Bundang outreach 가 성사되어 SNP-array 또는 WGS 데이터 확보 시 secondary HLA imputation 으로 arcasHLA RNA-only 결과 보강.

9 · Reviewer Q&A — public dataset, baseline choice, calibration, overdiagnosis

예상 reviewer 질문 + 본문 답안

Q1 — K2 가 public 데이터인데 왜 Korean cohort 의 main reference 인가?

K2 (PRJEB11591) 는 한국 SNU-GMI 의 prospective cohort 이지만 PUBLIC 으로 풀린 갑상선 RNA-seq 중 가장 크고 균질한 reference 다 (n=260). public 이라는 점이 access 의 reproducibility 를 보장. Bundang SNUH outreach 가 성사되면 secondary prospective validation 으로 추가.

Q2 — AFND South Korea pool 을 baseline 으로 쓴 이유?

AFND (Allele Frequency Net Database) 의 South Korea pool 은 갑상선 disease-free Korean 인구의 reference 권역으로 사용된다. K2 vs AFND ratios 0.93-1.22 binomial p>0.16 → K2 가 인구 일반 분포의 sample 임을 검증.

Q3 — Within-sample-centered 가 over-fit 가능성은?

Within-sample-centered 는 cross-cohort scale difference 제거 가 목적이고, 모델 fit 자체에는 영향을 주지 않는다. 같은 형식으로 TCGA 에서 train 한 model 을 K2 / GSE286332 / Mun 에 적용해 모두 AUC 0.9 권역 유지 (Round 3 ROC AUC ≥ 0.85 all cohorts).

Q4 — 88.8% DM2 가 단순 임상 선택 bias 일 가능성?

일부 임상 진료 패턴 (검진 빈도, 작은 tumor 도 수술) 의 결과인 것은 사실이며, 이게 한국 overdiagnosis paradigm 의 정의. 그러나 D4-P2 TCGA transfer 에서 GSE286332 HT-overlap signature 가 TCGA DM2 클러스터에 OR up to 5× p=6e-10 으로 enriched 되는 것은 동일 분자 axis 가 임상 context 와 독립적으로 작동한다는 증거. 따라서 K2 의 88.8% DM2 는 임상 + 분자 axis 의 합성.

Q5 — DPB1*05:01 56% 의 임상-functional 의미?

Kim 2014 Korean GD HLA #1 finding 의 replication. K2 cohort 에서는 alle frequency 자체가 Korean baseline 과 일치 (AFND 비교에서 p>0.5). 즉 K2 에서 DPB1*05:01 56% 는 "한국 평균을 정확히 반영" 의 의미이며, allele-level enrichment 가 아닌 cohort-level baseline match 으로 framing.

Q6 — arcasHLA RNA-only imputation 의 정확도 limit?

HLA class I 은 ≥4-digit 정확도 95%+ (multi-cohort literature), HLA class II 는 90% 권역. 따라서 본 paper 에서는 (i) cohort-level allele frequency comparison (AFND match) 와 (ii) class II module expression (CIITA → HLA-DR/DP/DQ co-up) 의 두 축에 한정해 사용. 개별 sample 의 ≥6-digit allele assignment 는 회피.

Q7 — Bundang outreach 가 paper accept 의 prerequisite 인가?

아니다. Paper 1 / Paper 2 HLA / Paper 4 GD 모두 K2 + TCGA + GSE286332 + Mun proteogenomic 의 4-pillar 만으로 main claim 을 닫는다. Bundang 은 future prospective validation 으로 limitations 에 명시. v17_marathon_mode_post_pillar1: 본격 paper-writing 단계, new analysis는 paper-blocking only.

Q8 — Pod D failure 가 K2 cohort 의 분석 quality 에 영향을 주는가?

FASTQ 는 /data/thca/PRJEB11591_fastq/ 에 보존되어 있어 raw data 영향 없음. STAR 실행 자체가 9hr 안 mid-run 종료된 것이라 STAR output 의 partial 결과만 폐기. arcasHLA 결과는 분리된 run 이라 보존. 분석 quality 는 영향 없음, 다만 STAR-based downstream (read count, splice junction) 은 새 pod 에서 재실행 필요.
