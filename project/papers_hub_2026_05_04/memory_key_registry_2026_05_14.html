how this registry works · in-room usage

등록부 사용법 — 어떤 anchor가 어떤 결정과 paper claim을 어떻게 backing하는가

memory anchor는 단순 메모가 아니다. 각 anchor는 paper claim · 결정 큐 · reviewer Q&A · 발표 슬라이드와 한 줄로 연결돼 있다. 이 페이지는 발표 중 "그 anchor 어디 있죠?" 질문에 대한 즉시 응답기. 4가지 사용 패턴이 있다 — (1) reviewer Q&A에서 인용, (2) 결정 큐 backing, (3) honest reframe의 출처 확인, (4) 신규 분석 paper-blocking 판정.

패턴 1 · paper claim backing예: TERT HR 7.57 → v17_tert_recovery_v2 + Paper 1 outline lock
패턴 2 · 결정 큐 trace예: K2 H&E 4-주 ask → v17_K2_vs_bundang_distinction + paper_numbering_2026_05_04
패턴 3 · honest reframe예: H13 polarity 정정 → dm1_round4_2026_05_08 body 안 주석
패턴 4 · paper-blocking 판정예: 새 분석 요청 → marathon 룰 v17_marathon_mode_post_pillar1 + v17_sprint_vs_marathon_violation
패턴 5 · reviewer war room예: phospho null → dm1_round3 phospho note + Q&A bank
패턴 6 · cross-cut bridge예: HLA #1 ↔ Paper 1 sub-B → v17_D6P7_dm1_subB_NBNR
