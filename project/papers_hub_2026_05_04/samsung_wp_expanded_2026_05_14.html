two-line judgement

Reviewer Q&A — budget defense + dependency + risk

expected questions, prepared answers

Q1 · "왜 WP1이 40% 비중인가? Pretrain은 이미 commodity 아닌가?"

A: WP1 12억 중 compute가 6억, 인건이 4억, 데이터/라이선스가 2억. Commodity pretrain은 commodity backbone만 — thyroid + 한국 cohort + multi-omics fine-tune은 commodity 아니다. 그리고 WP4 transfer가 WP1 checkpoint에 직접 의존 (prostate/DCIS/indolent lymphoma) — WP1 부실하면 WP4 무너진다.

Q2 · "WP3 양자 부분이 왜 있는가? 3억은 낭비 아닌가?"

A: 3억은 전체 10%이며 negative result도 paper로 보고하는 honest commit를 명시. 양자가 우위 없다는 정직한 측정 자체가 약점 #4 답안이다. 우위 있으면 npj Quantum Inf, 없으면 IEEE QCE — 어느 쪽이든 paper output. "양자가 잘 한다"가 아니라 "양자가 잘 하는지 측정한다"가 framing.

Q3 · "Self-extinguishing data를 어떻게 닫나? 한국 PTC overdiagnosis 시대는 끝났다."

A: WP4가 직접 답안. 동일 architecture + counterfactual framework가 low-risk prostate (Gleason 6 AS), DCIS, indolent lymphoma 3 cancer로 transfer. 같은 framework가 다른 overtreated cancer에서 작동하면, 한국 PTC 코호트는 first proof — 미래 cohort 없이도 platform 가치 유지.

Q4 · "Target trial emulation이 small-N에서 의미 있나? Event ~5%."

A: 3-way 추정량 (IPW + DR + causal forest) sign+CI 합의 + E-value/tipping-point sensitivity로 robustness 측정. BABA 5,000례 추가 시 effective N 2배 ↑. 만약 E-value <1.3이면 "weak claim" cap을 미리 박아둠 — 약한 결과는 약하게만 보고.

Q5 · "Monitoring schedule emulation은 어떻게 양 arm에 적용하나?"

A: 양 arm 환자 모두 3-6-12-24-36개월 fixed grid에 outcome ascertain. AS arm은 본인 monitoring, Surgery arm은 EHR 기반 emulated visit. KS test로 schedule 분포 균등성 검증, p<0.05이면 schedule-stratified subgroup 분석으로 보강.

Q6 · "외부검증 1곳만으로 충분한가?"

A: 한국 cohort 단독 → 외부 1곳 + WP4 transfer 3 cancer = 사실상 4 외부 결과. 외부검증 1곳은 한국 외 또 다른 cohort (KoMPASS or 일본 BBJ), transfer는 cancer-axis 외부 — 두 축 모두에서 generalization 측정.

Q7 · "30억 budget 분포 정당성?"

A: 인건 32% · compute 35% · 데이터/IRB 14% · NISQ 6% · 외부 5% · 학회/dissemination 4% · contingency 4%. AI/ML 과제 평균 분포 (compute 30-40%, 인건 25-35%) 안에 있음. WP3 NISQ 6%는 honest sidecar — 우위 없으면 적게 쓴 것이 정당화.

Q8 · "Co-PI 1인 + 박사후 2 + RA 3으로 36개월에 4 WP 가능한가?"

A: WP1 (박사후 1 + RA 1, 18개월), WP2 (Co-PI + 박사후 1 통계학자 + RA 1, 24개월), WP3 (Co-PI 시간 30% + RA 1, 12개월), WP4 (Co-PI + 박사후 2 + RA 3, 12개월) — FTE-month 환산 약 162개월, 6명 × 36개월 = 216 FTE-month 안에 있음. Buffer 25%.

Q9 · "WP 사이 dependency가 너무 강하면 한 WP 실패가 전체를 무너뜨린다."

A: Critical path = WP1 → WP4 (pretrain → transfer)와 WP2 → WP4 (propensity → validation) 두 개만. WP3는 독립. WP1 실패 시 WP4 transfer는 commodity backbone (scGPT/geneformer pretrained)으로 fallback — WP4 자체는 죽지 않음. WP2 실패 시 WP4는 outcome-only 분석으로 축소 — venue 한 단계 하락.

Q10 · "12 milestone 너무 많지 않나?"

A: 36개월 / 12 milestone = 평균 3개월/milestone. 각 milestone은 명확한 deliverable + gate. Tracking이 분기별 가능 — Samsung evaluator도 분기 보고 + 연차 보고 둘 다 가능. 너무 적으면 (예: WP당 1 milestone) 진척 측정 불가, 너무 많으면 (예: WP당 6 milestone) admin overhead.

Q11 · "결과가 negative면? Honest commit이 grant에 어떻게 보이나?"

A: Negative result 보고 commit은 grant agency가 점점 선호하는 신호 (replication crisis 시대). WP2 결과 null이면 "한국 PTC AS-vs-Surgery는 effect 없음"이 paper로 보고됨 — 임상적으로도 의미 있는 결론. WP3 양자 우위 없으면 "NISQ는 이 task에서 우위 없음" — 양자 community 기여.

Q12 · "70%까지 가는 마지막 추가 한 단계는?"

A: 외부검증 1곳 + transfer 3 cancer 중 최소 1곳에서 사전 데이터 평등 합의 letter. 즉, 제안서에 "외부 cohort access pre-confirmed"가 적혀 있으면 reviewer 가 access 약점을 잡을 수 없음. 이게 60-65% → 65-70%로 가는 단일 lever.

Cross-WP dependency map

WP1 → WP4

WP1 thyrofm checkpoint가 WP4 transfer (prostate/DCIS/lymphoma)의 backbone. WP1 실패 시 commodity scGPT/geneformer fallback — venue 한 단계 하락.

WP2 → WP4

WP2 propensity + outcome model이 WP4 BABA validation에 직접 적용. WP2 protocol drift 시 WP4 분석 다시.

WP1 ⟂ WP3

WP3 양자는 WP1 pretrain feature를 input으로 받을 수 있으나 의존 아님 — 독립 baseline 기준으로도 비교 가능.

WP1 ⟂ WP2

WP1 multi-omics는 WP2 outcome model의 covariate set 보강 — optional dependency. WP2는 EHR-only로도 동작.

WP3 ⟂ WP4

WP3는 WP4 transfer와 무관 — 완전 sidecar.

외부검증 ↔ 모든 WP

외부 1곳은 WP2 (counterfactual) + WP4 (transfer) 둘 다 사용. Single-source dependency — 미리 합의 letter 확보가 단일 lever.
