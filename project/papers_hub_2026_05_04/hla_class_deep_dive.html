Implications for neoantigen vaccine design

  • ★ Class I (CD8) vaccines are the priority: kill tumor cells directly, larger and balanced corpus, more reliable benchmarks.
  • Class II (CD4) helper-arm vaccines are essential for in-vivo T-cell expansion — but our class-II prediction is preliminary due to curation bias.
  • For multi-epitope vaccines (e.g. our 10-epitope concatemer), include both class I and class II peptides — but trust class I scores more.
  • Class II improvements require: standardized assays (IEDB CD4 framework) + balanced negative recruitment + cross-curator harmonization.
