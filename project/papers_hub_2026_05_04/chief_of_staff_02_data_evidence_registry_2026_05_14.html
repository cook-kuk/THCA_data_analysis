Section 1 · evidence classification rubric

5 evidence classes — never blended.

본 페이지의 every row는 다음 5개 class 중 정확히 하나에 속한다. 같은 dataset이 두 class를 모두 지지하더라도 두 row로 분할해서 보고한다.

class 1

internal data — file-backed

local disk에 파일이 존재. ls/wc -l로 검증 가능. 본 페이지의 catalog row count, manifest line count, 파일 크기, 디스크 path 모두 이 class.

class 2

internal claim — requires verification

memory MEMORY.md index, 회의록, audit doc에 적혀있으나 본 페이지가 직접 byte-level 재확인 안 함. e.g. "TCGA-THCA n=505 → 7 vulnerability labels" 같은 derived 수치.

class 3

public proxy

TCGA, GEO, GTEx 등 공개 cohort에서 도출. 본인 환자 데이터가 아니므로 clinical claim에 직접 사용 금지. cohort/ancestry/assay context 명시.

class 4

literature-backed

출판된 논문에 명시된 fact. PMID/DOI 또는 cohort identifier 동반. e.g. Yu 2024 IJS PTC n=62.

class 5

hypothesis · proposal

아직 데이터로 잠기지 않은 가설/제안. Samsung proposal 내 미래 cohort, Lumenix brand layer, BioDarwin scaffolding 등.

layer-mix rule

Never blend layers

CTC morphology / CTC DNA-RNA / ctDNA / tissue NGS / tissue H&E·IHC / spatial transcriptomics / public bulk RNA-seq / single-cell / outcome — 9 layer never blend (자세히는 Page 03).

Examples of TCGA ↔ CTC blends to BLOCK

  • "TCGA n=505에서 CTC count가 X였다" — TCGA에 CTC count 없음. WRONG.
  • "TCGA에서 mesenchymal CTC 86%였다" — Li 2022 cohort 출처, TCGA 아님. WRONG attribution.
  • "GSE250521 spatial niche가 liquid biopsy를 예측한다" — spatial vs liquid 별개. FORBIDDEN.
  • "TCGA score를 임상에 적용한다" — public proxy vs clinical claim. FORBIDDEN per master context §4.
  • "arcasHLA n=260 결과로 Paper 1 cancer 결론을 보강한다" — arcasHLA는 Paper 2 ONLY. BOUNDARY VIOLATION.
  • "Yu 2024 n=62 CTC 결과로 본 cohort RAI 예측을 한다" — Yu cohort ≠ 본 repo. cohort transfer FORBIDDEN.
  • "Sato 2021 ctDNA detection rate가 본 환자에 적용된다" — n=22 small + cohort difference. WRONG generalization.

Claim transfer checklist

모든 cross-cohort transfer 전에 다음 7개 항목을 확인:

  1. donor cohort = recipient cohort? (no → cohort transfer caveat 필수)
  2. sample type 같음? (CTC ↔ tissue ↔ ctDNA ↔ spatial 다른지 명시)
  3. assay 같음? (microarray ↔ RNA-seq ↔ scRNA ↔ proteomics 다른지 명시)
  4. ancestry / sex / age 분포 비슷? (Korean ↔ USA mixed ↔ Saudi 다른지)
  5. outcome timeline 일치? (5-year ↔ 10-year ↔ progression-free vs overall)
  6. tumor stage / grade range 일치? (PTC ↔ PDTC ↔ ATC mix 명시)
  7. HLA / driver / pathway boundary 일치? (Paper 1 vs Paper 2 zone)
