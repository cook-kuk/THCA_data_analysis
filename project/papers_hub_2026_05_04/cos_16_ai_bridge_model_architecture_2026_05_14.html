01Verdict / hypothesis

Hypothesis: CTC EMT-phenotype features (혈액)과 tissue niche features (조직)은 같은 환자에서 co-encode 가능한 latent representation을 가진다. CLIP-style contrastive learning이 둘을 동일 공간에 align한다.

02The bridging problem

CTC는 single-cell 혈액 관측; tissue는 anchored spatial niche. 같은 환자가 둘 다 가짐 → 두 modality를 공유 잠재공간에 매핑하면 (a) blood-only prediction (b) blood → tissue inference (c) AS heterogeneous effect 모두 풀린다.

2-1. Modality 비교

특성CTC (blood)Tissue (FFPE/fresh + ST)
Spatial resolutionsingle-cell, no spatial10x Visium 또는 GeoMx ROI
Sample frequencyserial (pre / 2wk / 3mo / 6mo)once, surgical
Phenotype layerEMT markers + IHC + targeted DNA/RNAspatial transcriptomics + niche
Information richnessstate of individual cells in circulationmicroenvironment context
Public data scale매우 제한적TCGA / HTAN / CELLxGENE 풍부

2-2. 왜 bridge가 가치 있는가

  • 혈액에서 조직 추론: 조직 biopsy 없이 niche 상태 추정 가능성
  • Serial sampling 활용: 조직은 1회, CTC는 4회 → 동적 추적
  • AS 결정 지원: baseline CTC × tissue 정보로 progression-risk subgroup
  • Cross-modality transfer: tissue-rich public data로 CTC encoder 정규화

2-3. Bridging이 실패하는 경우

Bridge collapse: CTC encoder와 tissue encoder가 trivial representation으로 수렴 (e.g., 평균 embedding으로 cosine similarity 1). 이는 contrastive learning의 알려진 실패 모드이며, BarlowTwins-style decorrelation loss + temperature scheduling으로 mitigate. 실패 시 fallback: CTC-only model (Aim 1) + tissue-only model (Aim 2) 각각의 baseline 유지.

04CTC encoder (E_C)

Transformer over CTC patch + targeted DNA/RNA panel. EMT-aware tokenization.

4-1. Input modalities

  • CTC patch image: high-resolution fluorescence + brightfield (CD45-negative, EpCAM/CK/VIM/etc multi-channel) — 256×256 patches per detected CTC
  • IHC channel readout: per-channel intensity vector (E-cadherin, N-cadherin, vimentin, Snail/Slug, ZEB1, PAX8, TG, CD45) — categorical + continuous
  • Targeted DNA panel: BRAF V600E, TERT promoter, RET/NTRK/ALK fusion, RAS — variant calls
  • Targeted RNA panel: EMT pathway transcripts, thyroid lineage, immune escape — log-normalized counts

4-2. Tokenization scheme

Per-CTC token sequence

[IMG]
CTC patch ViT embed (16-patch grid → 196 tokens)
[IHC]
channel intensity vector → 1 token per channel (10 tokens)
[DNA]
variant indicator vector → 1 token per gene (12 tokens)
[RNA]
log-normalized count → 1 token per transcript (50 tokens)
[CLS]
aggregator token for CTC-level representation

4-3. Architecture

  • 6-layer transformer, 8 heads, hidden 512
  • Modality embedding (image / IHC / DNA / RNA) added to position embedding
  • Pre-LN + GELU + dropout 0.1
  • CLS-token output → z_C (512-d)

4-4. Patient-level aggregation

여러 CTC가 검출되는 환자는 CTC-level z_C를 attention-pooling으로 patient-level z_C^P로 집계. Yu 데이터에서 환자당 평균 CTC는 ~5-15개 수준.

4-5. CTC-side pretrain

공개 CTC 이미지는 매우 제한적이며 (대부분 proprietary CellSearch/CanPatrol 출력) cross-cancer CTC public dataset은 small. 따라서 E_C는 (a) UNI image encoder를 시작점으로 CTC patch에 domain-adapt, (b) Yu 62 cohort에서 self-supervised pretrain (SimCLR-style), (c) targeted DNA/RNA는 random init + Yu fine-tune. Pretrain breadth는 명확히 제한적이며, "foundation"이라고 부르지 않는다.

05Tissue spatial encoder (E_T)

UNI (이미지) + Nicheformer (spatial transcriptomics) 또는 Visium HD foundation 모델. 이쪽은 공개 pretrain이 풍부해 진짜 foundation-level이다.

5-1. Backbone 선택

ModuleSourcePretrain scale사용 이유

NicheformerTheis lab 2024~100M spatial spotsspatial niche representation
scGPTWang lab 202433M cells (CELLxGENE)scRNA prior, fallback
Visium HD foundation10x Genomics 2025HD-resolution STfuture option

5-2. Input pipeline

  • FFPE H&E WSI → tissue mask → 256×256 patches at 0.5 μm/pixel
  • UNI ViT embedding → 1024-d per patch
  • Spatial transcriptomics → spot-level expression vector → Nicheformer embedding 512-d
  • Patch × ST alignment via coordinate matching
  • Spatial transformer (8-layer) over aligned tokens → tissue-level z_T (512-d)

5-3. ROI selection (Yu lab)

Surgery arm 환자의 FFPE block에서 사전 정의된 5-niche ROI (invasive front / core / lymphovascular / immune / CAF) 추출. 각 niche에서 sub-token화하여 niche-aware tokenization.

06Contrastive bridge head (B)

CLIP의 image-text contrastive loss를 CTC-tissue paired sample에 적용. 같은 환자 같은 timepoint pair = positive; 다른 환자/timepoint = negative.

6-1. Loss formulation

L_contrast = -log( exp(sim(z_C, z_T) / τ) / Σ_k exp(sim(z_C, z_T_k) / τ) ) sim(a, b) = a · b / (||a|| · ||b||) τ = learnable temperature (initialized 0.07)

6-2. Decorrelation regularization (BarlowTwins-style)

L_decorr = Σ_i (1 - C_ii)² + λ · Σ_{i≠j} C_ij² C = cross-correlation matrix of z_C and z_T over batch

이 항은 bridge collapse를 막는다. Empirically Δ ablation에서 수렴 안정성 큰 영향.

6-3. Combined loss

L_total = L_contrast + α · L_decorr + β · L_downstream α=0.05, β=1.0 (typical CLIP+regularization setup)

6-4. Pair construction strategy

  • Positive: 같은 환자, 같은 timepoint의 (CTC, tissue) pair
  • Hard negative: 같은 niche의 다른 환자 (false-positive 위험 방지)
  • Easy negative: 다른 niche 다른 환자
  • Batch size 32 (n 작아서 mini-batch contrastive 위험 → MoCo-style queue로 negative pool 확대)

08Fine-tune on Yu data

n=50 PTC × pre/2wk/3mo × matched FFPE → ~150 paired CTC-tissue pairs.

8-1. Data structure

8-2. Training regimen

  • 5-fold leave-one-patient-out (LOPO) for outer evaluation
  • Within each fold: 80/20 train/val split
  • Adam optimizer, cosine schedule, lr 1e-4 → 1e-5
  • ~50-200 epochs, early stopping on val contrast loss
  • Augmentation: image (crop/flip/jitter), DNA/RNA (random masking 10%)

8-3. Identifiability concerns

n=150 paired는 representation alignment 학습에 절대적으로 부족할 수 있다. Reviewer 2가 즉시 공격할 지점. 대응: (a) Stage 1/2 pretrained encoder를 freeze한 채 bridge head만 학습 (parameters 적음), (b) permutation null test (cross-patient shuffle → contrastive loss random baseline 비교), (c) bridge embedding의 patient-cluster identifiability test.

11Validation strategy

Leave-one-patient-out + permutation null + E-value for causal claims. cos_14 도구 연동.

11-1. LOPO

  1. 각 fold에서 한 환자 전체 (모든 timepoint) leave out
  2. 나머지 49 환자에서 학습
  3. Held-out patient에서 (a) blood-only PFS, (b) niche inference, (c) CATE 평가
  4. 50-fold 결과 aggregate → mean ± std

11-2. Permutation null

  • (CTC, tissue) pair를 cross-patient random shuffle
  • Shuffle된 데이터로 동일 학습 → contrastive loss / downstream metric 분포
  • 실제 데이터 metric이 permutation null의 95-percentile 밖이면 bridge가 signal-bearing
  • 1000회 permutation

11-3. Bridge identifiability test

  • 학습된 z_C가 환자 ID를 예측할 수 있는지 (over-specific) — linear probe accuracy
  • z_C가 timepoint를 예측할 수 있는지 — temporal coherence
  • z_T-anchored retrieval: 같은 환자 다른 timepoint CTC가 top-k retrieval에 들어오는지

11-4. Causal claim validation

Downstream task (c) HTE에서 CATE가 z_joint에 의존한다고 주장하려면 E-value 보고 필수. cos_14 §7과 동일 framework.

15Reviewer Q&A

Q1. "왜 n=50이 foundation model인가?"

아닙니다. Foundation은 Stage 0a/0b/1 (UNI / Nicheformer / TCGA-PanCancer pretrain)에만 적용되는 단어입니다. Yu 50 환자 fine-tune은 domain-adapted multimodal model이며, thyroid는 first downstream task로 명시합니다. Reviewer 2가 "왜 foundation인가"를 물으면, 본 architecture는 답을 두 부분으로 분리합니다 — pan-cancer foundation backbone + thyroid domain fine-tune.

Q2. "Bridge가 identifiable한가?"

Permutation null test로 검증합니다. (CTC, tissue) pair를 cross-patient shuffle한 데이터에서 contrastive loss / downstream metric 분포를 계산하고, 실제 데이터가 그 분포의 95-percentile 밖이면 bridge가 signal-bearing이라고 보고합니다. 추가로 z_C-anchored cross-timepoint retrieval (같은 환자 다른 timepoint top-k retrieval)으로 identifiability을 직접 확인합니다. Identifiability이 실패하면 본 페이지 §14에 명시된 fallback (CTC-only + tissue-only separate baselines)으로 보고합니다.

Q3. "Public-data ablation은?"

§13 ablation table 그대로. (a) tissue-only, (b) blood-only, (c) no-bridge concat, (d) full bridge 4-variant. 각 variant의 LOPO C-index와 niche F1을 보고. Full bridge의 incremental value가 (c) no-bridge concat 대비 통계적 의미가 없으면 main claim에서 빼고 robustness check로만 보고.

Q4. "HTE interpretability는 어떻게 보장하는가?"

Causal forest의 subgroup CATE를 보고할 때 (i) SHAP 또는 attention attribution으로 z_joint의 어느 dimension이 dominant인지, (ii) 그 dimension이 clinical variable과 어떻게 연관되는지 (post-hoc linear regression of z_joint dimension on clinical features), (iii) E-value로 unmeasured confounder의 robustness 평가. "Black box CATE"가 아니라 "clinical-feature-anchored CATE"로 framing.

Q5. "공개 CTC 데이터가 거의 없는데 어떻게 정당화하는가?"

동의합니다. 본 architecture는 CTC side에서 foundation level pretrain을 약속하지 않습니다. CTC encoder E_C는 (a) UNI image encoder cross-domain adapt + (b) Yu 62 self-supervised SimCLR-style pretrain만 사용하며, 이는 "domain-adapted CTC representation"으로 명시합니다. Tissue side만이 진짜 foundation pretrain입니다.

Q6. "Quantum-inspired sidecar와 어떻게 연결되는가?"

Bridge head에서 small-N high-D representation alignment는 tensor network / quantum kernel sidecar의 대상 ablation입니다. 그러나 이는 clinical performance improvement 주장이 아니라 NISQ future-proofing benchmark입니다 (memo §4). Classical bridge + quantum-inspired bridge를 같은 LOPO benchmark에서 보고하고, 우위가 없으면 negative result로 보고합니다.
