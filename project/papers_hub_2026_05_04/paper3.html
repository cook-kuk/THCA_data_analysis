📝 한국어 설명 (방법 · 결과 · 의미 풀어쓰기)

왜 thyroid cancer 에 ICI vulnerability 가 의미 있나

전체 PTC 의 ~95% 는 surgical resection + RAI 치료로 cure 되지만 ~4% 는 high-risk recurrent / metastatic 으로 진행. 이 4% 안에 (a) BRAF V600E + TERT driver-positive aggressive type, (b) BRAF/RAS-negative dark matter driver-unknown type 이 같이 있다. Driver-positive 는 BRAF inhibitor (dabrafenib + trametinib) 등 targeted therapy 가 후보. Driver-negative dark matter 환자는 targeted therapy 후보 없음 — 면역치료 (PD-1 / PD-L1 inhibitor) 가 마지막 옵션. 그러나 thyroid 는 (a) tumor mutational burden 평균 낮음, (b) MHC-I / MHC-II 발현 cohort heterogeneity, (c) ICI clinical trial 매우 적음 — ICI 후보 집단 정의 자체가 unsolved.

왜 "ICI vulnerability" 만 OK 이고 "ICI response predictor" 는 K1 kill 인가

"Response predictor" 는 ICI 받은 환자의 outcome 을 예측하는 model — 이걸 만들려면 ICI-treated thyroid cancer cohort raw RNA-seq + treatment outcome 데이터가 필요. 전세계 부재. 따라서 어떤 signature 가 thyroid 의 ICI response 를 예측한다고 못 한다. 대신 "vulnerability profile" = HLA loss / neoantigen burden / immune ecotype 의 분자 marker 만으로 ICI 후보 prioritize. 이건 published immune-oncology 의 framework 안에서 (TIDE Jiang 2018 / IMPRES Auslander 2018 / TIS Ayers 2017 / etc.) thyroid-specific 적용. K1 kill switch 는 manuscript / cover letter / abstract 어디에도 "predictor" 라는 단어 사용 시 즉시 paper 파기.

왜 chmod 444 frozen 인가

Track A (디자인 phase) 는 12 주 execution 의 청사진 - 어떤 cohort 어떤 signature 어떤 method 어떤 figure 어떤 verdict matrix. 이 디자인 자체가 manuscript 의 backbone — 만약 marathon 중 design 을 마음대로 수정하면 (a) reviewer Q1 "왜 ICI predictor 라고 안 했나" 의 사전 답변이 흔들림, (b) signature DIAL audit plan 이 post-hoc selection bias 가능, (c) scope creep 으로 Paper 1 마라톤 displacement. chmod 444 + tar.gz + sha256 으로 lock — Track B unlock 시까지 read-only. unlock 조건 3개 모두 충족 (Paper 1 bioRxiv + Paper 2B Pillar II/III + 명시적 명령) 시에만 chmod 644 로 변경.

⚠️ 이 연구의 한계 (구체적, 솔직하게)

  1. thyroid ICI raw cohort 부재 (전세계). 이건 paper 의 K1 kill switch 의 근거 — "predictor" 라고 못 하는 핵심 이유. 일부 thyroid PD-1 trial (NCT04645966 등) 은 결과 미공개 / cohort 작음 / 전공조회 controlled access 필요.
  2. Pan-cancer ICI signatures 의 thyroid sign-flip 가능성. TIDE Jiang 2018 / IMPRES Auslander 2018 / TIS Ayers 2017 등은 melanoma / NSCLC / urothelial 에서 검증 — thyroid 에서 sign 이 같은 방향인지 미검증. K5 kill switch 가 이 risk 를 명시적으로 보호.
  3. dbGaP / EGA controlled access 신청 + 응답 시간. Pan-cancer ICI cohort (Liu 2019 / Riaz 2017 / Hugo 2016) 대부분 controlled access — 신청 후 응답 3–6개월. 12-week execution 안에 못 맞출 가능성.
  4. scRNA atlas 의 PDTC/ATC undersampled. Pu 2021 (PMC8754658) 도 PDTC/ATC < 5K cell — sc-derived signature 가 underpowered. K2 kill switch.
  5. cookHLA 사용 못함 (Paper 4 reserved). Paper 3 의 HLA module 은 OptiType / Polysolver / arcasHLA / xHLA 4가지 imputation consensus 만 — cookHLA 의 cross-disease 강점 활용 못 함. 이건 Paper 4 boundary discipline.
  6. integrated readiness score 의 reproducibility. G6 hard gate (cross-cohort r ≥ 0.6) 가 통과해야 publish 가능. Pan-cancer ICI cohort 의 thyroid transfer 가 약하면 score 정의 자체가 흔들림.
  7. "vulnerability" 가 임상적으로 actionable 하지 않을 수 있음. ICI clinical trial 등록 기준 / treatment outcome 측정 / safety profile 등 임상 transition 은 이 paper 의 scope 외.
