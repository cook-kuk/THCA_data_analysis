30-second scan — editor가 첫 30초에 보는 5개

cover letter → abstract → fig 1 → reference count → cohort 한 줄

01NOVELTY

"이것이 정말 새로운가?"

One-sentence "first to show X" 가 abstract 첫 줄에 있는가. 우리 case: "DM1 = third axis beyond BRAF/RAS, 4-pillar replicated."

02FIT

"이 venue 독자에게 맞는가?"

Nat Commun cancer = broad cancer-bio + clinical implication. 우리 case: pan-cancer reach (11 lineages) + thyroid clinical anchor.

03IMPACT

"reviewer 3명을 끌어올 만한 자석인가?"

Single high-impact number. 우리 case: TERT OS HR=7.57 [2.74, 20.91] p=9.3e-5; XGB 5-fold AUC=0.984.

04DATA

"cohort/scale이 충분한가?"

n + external + replication 3-tuple. 우리 case: TCGA n≈500 + Mun n=336 + Lee + Landa multi-cohort + K2 n=260.

05HONESTY

"limitations이 신뢰감을 주는가?"

9 disclosed nulls (HLA-II OR 1.02 p=0.84; phospho null; spatial rescue fail; ViT-L LOTO 0.308 artifact). Honest negatives wall이 reviewer trust 부스트.

Reject signals — editor의 instant kill 5개

desk-reject 사유 빈도 상위 · NC/NCancer 패턴

RED · KILL ON SIGHT

5 reject signals

  1. OVERCLAIM — "we discover a new cancer pathway" 식 cure/causal 단어. Editor는 1초 desk reject. 우리 방어: claim ladder + bounded language ("prognostic stratifier", "decision support").
  2. CHERRY-PICK — single cohort hero result, external 없음. 우리 방어: 4-pillar (RNA + protein + methylation + image), Mun sign-match 7/7, pan-cancer 32 lineages.
  3. NO EXTERNAL — TCGA-only validation. 우리 방어: Mun 2025 n=336 + Lee + GSE286332 + K2 PRJEB11591 + GSE250521 spatial.
  4. VAGUE MECHANISM — "we show association" 끝. 우리 방어: BRAF V600E β=0.37 ≈ RET fusion β=0.39 vs RAS β=0.27 (mechanistic decomposition v13/v14).
  5. INCONSISTENT NUMBERS — abstract vs table vs figure 다른 N. 우리 방어: number cosmos page = single source of truth; H13 polarity correction registered.
GREEN · OUR DEFENSE STATUS

방어 layer 5종 모두 라이브

  1. Claim ladder — submission_packet_builder + brutal_grade_card 운영판. 각 claim의 evidence-tier 잠겨있음.
  2. Multi-pillar — DM1 robustness deep dive page에 12 contrasts × 4 cohorts × RNA+protein 10/12 FDR<0.01.
  3. External cohorts — data_registry_map_2026_05_14 + cohort_gse286332/k2/gse250521 deep dives 모두 라이브.
  4. Mechanism — driver_split_atlas + eight_gene_forensic_audit + axis_depmap_vulnerability deep dive.

Editor demographic — Nat Commun cancer editor profile

typical · 5-15y editorial · PhD molecular biology · 60% desk-reject rate

BACKGROUND

PhD molecular biology / oncology, 통상 5-15년 editorial experience. 본인은 bench scientist 출신. Wet-lab mechanism 무드를 빠르게 감지.

WORKLOAD

주당 30-50 submission · 평균 2-3분 desk screen → desk reject 60% → reviewer 2-3명 invitation 단계 진입은 40%. 30초 scan이 결정적.

PRIORITIES

impact > methods > novelty > fit. Single-cohort hero result는 즉시 의심. Multi-cohort + external + 4-pillar 패턴을 가산점으로 인식.

RED FLAGS

Cell/Nature reject 후 즉시 NC 재제출 표시 · cite 오류 · 숫자 inconsistency · 한국 기관-only cohort (외부 generalizability 의심).

GREEN FLAGS

Multi-institution + multi-modal + 외부 replication + honest limitations + suggested reviewer 3명 diverse (geo + expertise).

BIASES

"Thyroid is solved" prior 존재 (TCGA 2014 Cell). DM1 = third axis 논지 + Mun 2025 protein replication + pan-cancer로 prior 균열.

Honest disclosure handling — 9 nulls를 surface하는 법

"limitations" 단락 + 메인 본문 inline · editor trust booster

HLA-II OR=1.02 p=0.84

Phase C ICI 4 cohorts에서 HLA-II 입력은 null. HLA-I OR=1.35 p=0.014만 load-bearing. → "We report HLA-I-specific association; HLA-II was null." Reviewer Q14 미리 차단.

Phospho-layer null

Mun 2025 phospho는 RNA/protein 신호를 replicate 못함. → "Phospho layer did not replicate, suggesting transcriptional/translational axis."

Spatial rescue fail v16-v18

GSE250521 MAPK × Panel raw +0.208 → adjusted +0.035. Reviewer cherry-pick 차단용 caveat.

ViT-L LOTO 0.308 artifact

TSS confound 인정 + UNI overall LOTO 0.852로 robust 결과 분리. Methods atlas에 분리 wiring.

TSS-only LR within RAS-like AUC=1.000

Confound 가능성. Paper 2 limitations에 명시. UNI image-only는 별도 result.

K2 88.8% DM2 paradox

Korean overdiagnosis paradigm으로 reframe. Drawback이 아닌 unique cohort opportunity로 surface.

Permutation null p=0.29 (Round 7)

"panel honest, not lucky" — thyroid-matched null p=0.007 (Round 8)로 정정. Round 7 단독 cite 금지.

Methylation polarity flip H13

r9_1 master 기준 DM1=HIGH-β/silenced. 초기 Round 4 d=-1.75은 label-flip artifact. Fig 포팅 시 sign flip 필수 — 본문 + supplementary 명시.

UCEC INVERSE pan-cancer

11 lineages 중 UCEC만 inverse 방향. "tissue-specific exception"으로 명시 — pan-cancer overclaim 차단.
