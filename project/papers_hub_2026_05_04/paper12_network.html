0. network 사고 흐름 — 36 candidate · 7 modules · state-conditional Δr

0.2 7 modules · 137 edges · 5 hubs — 어떻게 추출?

Substrate. TCGA-THCA n=572 RNA-seq (full cohort, mut/clinical 선택 안함)
Pairwise correlation. Spearman r between each candidate gene pair (35×35).

0.3 state-conditional Δr — DM1 회로의 어떤 게 다른가

Paper 12의 가장 중요한 분석 결정. 단순 co-expression이 아니라 DM1-high vs DM1-low subset에서 같은 edge가 어떻게 다르게 작동하는지를 본다.

ApproachWhat it answersLimit
전체 cohort co-expression"이 gene pair가 평균적으로 같이 켜지나?"State-specific 회로 못 봄
DM1-high vs DM1-low Δr"DM1 lineage-silenced state에서 회로가 어떻게 재배선되나?"Cross-sectional이라 perturbation 인과는 추정
Δr의 해석: 큰 Δr (e.g., DM1-high에서 r=0.7, DM1-low에서 r=0.0) = state-dependent rewiring. "이 회로는 lineage-silenced 상태에서만 켜진다"는 read out. 단 perturbation 없으므로 "회로 작동의 인과" 아니라 "회로 활성화의 association".

2. 비전공자 배경

이 페이지는 "우리가 후보로 추린 36 개 유전자가 갑상선암 안에서 어떻게 함께 행동하는가" 를 보는 페이지다. Paper 9 의 synthetic-lethal vulnerability map 과 Paper 10 의 triangulation scoreboard 가 36 개 후보를 추렸다 — DDR · SFK · JAK/STAT · 대사 · NAD salvage · ion channel · TROP2 ADC · lineage TF anchor 등 8 개 class.

그 36 개 후보가 정말 한 회로를 이루는지를 알려면, 같은 cohort 안의 환자들 사이에서 한 유전자가 올라갈 때 다른 유전자가 같이 올라가는지 (= positive Pearson r) 또는 반대로 내려가는지 (= negative Pearson r) 를 본다. 이것을 모든 쌍에 대해 한 매트릭스로 그린 것이 co-expression matrix (F12.01) 이고, 비슷한 패턴끼리 묶은 그룹이 module 이다.

비전공자 비유. 36 개 후보 = 회사의 36 명 직원. Pearson r = 두 사람이 같은 시간대에 출근/퇴근하는 정도. Module = 같은 부서. Hub = 다른 부서들과도 연락이 가장 많은 매니저. State-conditional Δr = "회사가 위기 모드 (DM1-high) 일 때만 두 사람이 같이 일하기 시작하는 경우". 그게 SL 설계에서 가장 흥미로운 회로다.

§ 01 — Candidate × candidate co-expression matrix

Pearson r in TCGA-THCA, hierarchically clustered, class-color-coded ticks. Black lines mark module boundaries.

이 그림이 paper 12 의 workhorse 다. 매트릭스를 읽는 법:

  • Lineage TF (FOXE1·NKX2-1·PAX8·HHEX) 가 함께 묶이고, 대부분의 다른 class 와 강한 음의 상관 (anti-correlate). lineage-collapse 신호가 candidate panel 의 가장 큰 분산 축.

  • DDR (PARP1/2 · ATR · CHEK1/2) 은 별도 module. 더 느슨하게 coordinated → replication stress addiction 이 inflammatory program 과 동시에 켜지지 않고 state-conditional 로 작동한다는 가설과 정합.

6. 한계 · 다음 행동

6.1 한계 (limitations)

  • Bulk RNA only. 모든 Pearson 은 bulk. cell-type composition 의 산물일 수 있고, within-cell coupling 과 cell-cell co-presence 를 분리하지 않는다.
  • TCGA-THCA only. 현재 매트릭스는 TCGA-THCA n=572 단일 cohort. PTC-dominant. ATC/PDTC subtype 에서 hub 위계가 다를 가능성이 크다.
  • Module cutoff sensitivity. 7 modules 는 average-linkage + 특정 cutoff 의 산물. 다른 cutoff/방법 (Ward, Louvain on edge graph) 에서는 module 갯수가 변한다.
  • Δr threshold informal. § 07 의 state-conditional 분석은 visual 만. permutation 통제 + multi-test 보정 부재.
  • Self-dependency in DM1. DM1_like 에 PAX8/NKX2-1/FOXE1 이 들어가 있어, PAX8 의 hub 위치는 partly definitional. lineage TF anchor 를 빼고 DM1 을 재정의한 sensitivity 분석은 후속.

6.2 다음 행동 (post-marathon)

External cohort replication. 같은 35-candidate × 35 매트릭스를 GSE76039 (PDTC/ATC) · GSE65144 · GSE286332 에서 재현. hub ranking 의 robustness 확인.
DepMap state-conditional dependency. Hub 5 개 (LYN · NAMPT · TACSTD2 · KCNN4 · PAX8) 의 CRISPR essentiality 와 cell line 의 DM1_like 점수 사이 상관. state-conditional dependency 가 있다면 SL claim upgrade.
Permutation-controlled Δr. § 07 의 Δr matrix 를 sample-label permutation null 에 대해 검정 → 통계적으로 유의한 state-conditional edge 만 separate.
Single-cell deconvolution. THCA single-cell atlas (Pu 2021 등) 에서 hub edge 가 epithelial 안에 있는지 vs immune-stroma co-presence 산물인지 검증.
Combinatorial pharmacology cross. Hub × hub 약물 조합 (LYN ↔ NAMPT 등) 의 PRISM / DepMap drug screen 결과로 dual-hit 효율 확인. SL 가설을 약물 단계까지 번역.
Marathon mode 와 호환성. 본 페이지도 새 분석을 추가하지 않는다 — 기존 산출물 (paper12_network/figures + corr_matrix + modules + edges_top + summary.json) 만 시각·서술화한 visualization atlas. 위 다음-행동 5 개는 모두 6/13 manuscript writing marathon 종료 후의 별도 trajectory.
