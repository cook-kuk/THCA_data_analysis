0.1 왜 H&E → DM1을 시도했나 (motivation)

RNA-seq 없이 routine H&E pathology slide만으로 DM1 cluster를 읽을 수 있다면 임상 적용 폭이 매우 넓어진다. 가설은 분명했다 — "DM1은 lineage-silenced state이고, lineage-silenced 조직은 morphology가 다를 것" → tile-level CNN이 그 morphology signature를 학습 가능?

Pre-registrationHypothesis + closure battery + NO-GO threshold 사전 lock
Resource budget~85 min CPU + RunPod ~$30 (capped)

0.2 closure battery — 왜 random보다 낮음 (bounded below)

NO-GO 판정은 "AUC가 0.5 근처"가 아니라 "tile-level prediction이 random shuffle보다 underperform"이라는 더 강한 negative이다. 즉 "신호 없음"이 아니라 "체계적 mis-alignment".

Closure battery setup. 다층 baseline — random shuffle, slide-level mean predict, naive ImageNet feature, 사전훈련 ResNet50, end-to-end CNN.
Result. Tile-level prediction이 random shuffle baseline보다 bounded below — 즉 H&E feature가 DM1 score와 anti-aligned 또는 noise-amplified.
Dominant cause analysis. Depth-confounding(tumor cellularity) + slide-level batch + tile sampling 등 가능한 원인 모두 closure로 탐색. 각각 contribute하지만 통합적으로 "이 dataset에서는 morphology→DM1 signal이 없다"가 결론.
NO-GO 확정 2026-05-04. Pre-registered threshold 미충족 + dominant cause 분리 가능 + alternative methods 모두 same direction → publish as negative-feasibility finding.

2. 비전공자 배경

Visium spatial transcriptomics (Visium) 는 한 spot 마다 (한 spot ≈ 50 μm × 50 μm) 의 mRNA 측정 + 같은 spot 위에 매칭된 H&E 영상 tile (224 × 224 px) 을 동시에 보유. 즉 분자 (RNA) 와 형태 (H&E) 가 1:1 spatial alignment 로 paired. 가설: H&E tile 의 morphology 만 보고 → 그 spot 의 8-gene RAI 점수 (depth-residualized DM1_like_score_resid) 를 예측 가능하다. 이게 됐으면 routine H&E (sequencing 없이) 만으로 RAI loss 를 진단 가능 — 임상 application 의 dream scenario.

6. Dominant failure cause (verdict D = full 폐기)

  1. Depth-residualization removes morphology-visible signal → 신호 자체가 stain↔depth artifact 였음 (residualization 정당화)
  2. Spot-level ST molecular label과 tile-level H&E 의 본질적 mismatch at hires-Visium (224–672 px) resolution. Foundation model upgrade 도 (1)+(2) 못 풂.
