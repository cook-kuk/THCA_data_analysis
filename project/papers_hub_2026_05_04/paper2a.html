📝 한국어 설명 (방법 · 결과 · 의미 풀어쓰기)

가설이 무엇이었나

Visium spatial transcriptomics (Visium) 는 한 spot 마다 (한 spot ≈ 50 μm × 50 μm) 의 mRNA 측정 + 같은 spot 위에 매칭된 H&E 영상 tile (224 × 224 px) 을 동시에 보유. 즉 분자 (RNA) 와 형태 (H&E) 가 1:1 spatial alignment 로 paired. 가설: H&E tile 의 morphology 만 보고 → 그 spot 의 8-gene RAI 점수 (depth-residualized DM1_like_score_resid) 를 예측 가능하다. 이게 됐으면 routine H&E (sequencing 없이) 만으로 RAI loss 를 진단 가능 — 임상 application 의 dream scenario.

5-failure-mode 분석 — 어디서 막혔나

실패 가능 원인을 5개로 가정하고 하나씩 disprove:

  1. (1) 모델이 약해서? ResNet50 ImageNet pretrained 가 그래도 약하지 않은 baseline. 또 raw 9-dim RGB 가 ResNet50 (r=0.061) 보다 더 잘 (r=0.224) → 모델 약함은 아닌 듯.
  2. (2) Tile size 가 작아서? 224 → 448 swap 시 r 0.022 → 0.017 (worse). 672 cancelled. Scale 도 핵심 아님.
  3. (3) Depth-residualization 이 morphology-visible signal 을 제거? raw 9-dim RGB r=0.224 vs resid r=0.080 — 그렇다. 그러나 raw 신호의 정체는 stain darkness ↔ sequencing depth artifact (염색 진한 spot 에서 RNA 도 더 많이 잡힘). residualization 이 정당한 step. 즉 residualize 안 하면 spurious correlation, residualize 하면 morphology signal 약해짐 — 이게 (3)+(4) 의 fundamental coupling.
  4. (4) Spot-level ST molecular label 과 H&E tile content 의 fundamental mismatch? Stage ordinal (PT/PTC/LPTC/ATC) r = −0.05, ATC binary AUROC = 0.689 (BORDERLINE) — gross morphology 만 잡힘. ATC 의 anaplastic morphology 는 self-evidently visible 하므로 새 발견 아님. 분자 (transcriptional) 단위 의 신호는 H&E tile 에 fundamentally encoded 안 되어 있음 at hires Visium resolution.
  5. (5) Foundation model 업그레이드? UNI / CONCH / Virchow2 의 projected gain (+0.05 ~ +0.15) 도 GO threshold (+0.28) 미달. (3)+(4) 가 dominant 라서 모델 강화로 못 풂.

→ Verdict D (full 폐기). 이 dataset (Visium hires) + 이 task (depth-residualized DM1 axis prediction) 의 조합은 안 풀린다 — 다른 dataset (full-res WSI + matched RNA-seq) + 다른 task (population-level only, not spot-level) 까지 가야 시도 의미가 있다.

왜 이 NO-GO 가 "발견" 인가 (negative result publication)

이 결과는 다음 스튜디오 / 다음 paper 에게 actionable upper bound 를 제공:

  • "Visium hires (~50 μm spot) 에서 H&E tile 만으로 spot-level transcriptional axis 를 predict 하려는 시도는 sample-level 에서 정량화된 r ≤ 0.08 의 floor 가 있다."
  • "Foundation model upgrade 만으로 이 floor 를 못 넘긴다 (projected +0.05 ~ +0.15 < threshold +0.28)."
  • "Stain↔depth artifact 가 raw signal 의 dominant 원인 — residualization 정당."
  • "ATC vs non-ATC binary 만 H&E tile 로 잡힘 — anaplastic morphology 의 self-evident 신호이지 새 발견 아님."

이 정보를 manuscript supplement (Methods Supplementary X) 로 박제 → Paper 1 / Paper 2B 가 image-DM1 가설을 reviewer 가 묻기 전에 사전에 차단. 또 Paper 7 (v18 agentic_research) 의 Pattern 4 = "Pre-registered failed hypothesis as supplement" 의 case study.

⚠️ 이 연구의 한계 (구체적, 솔직하게)

  1. 단일 cohort 만 테스트. GSE250521 (28 slides) + GSE230424 (4 slides) + GSE248205 (8 slides) = 모두 Visium hires (~50 μm spot). Scanner-level WSI (40× / 80×) 는 시도 못함 (TCGA WSI 다운로드 marathon 동안 차단). 따라서 결론은 "Visium hires 에서" 의 한정.
  2. Foundation model (UNI / CONCH / Virchow2) 직접 시도 못함. HF gated access blocked + RunPod stuck pulling image. Projected gain (+0.05 ~ +0.15) 은 publication baseline 에서 추정 — 직접 실측 아님. UNI 가 +0.20 까지 갈 가능성도 배제 못 함 (단, 그래도 GO threshold +0.28 미달).
  3. Residualization variants 5개 만. log_counts / log_ngenes / no_resid / rank_norm / epi-top50 — 다른 normalization (per-slide standardization / spot-neighbor smoothing 등) 미시도.
  4. Tile size 224 / 448 / 672 만. 더 큰 tile (1024 / 2048) 또는 multi-scale fusion 미시도. 단 spot 자체가 ~50 μm 라 큰 tile 은 spot 외 영역 포함 = label noise.
  5. Aggregation strategy 3개 만. mean / top25%mean / highrisk_frac — slide-level top25 0.209 가 가장 나음. attention-pooling / MIL 미시도.
  6. "Pre-registered failed hypothesis" 자체가 unpublished. 이 NO-GO 가 manuscript supplement 으로만 박힐 예정 — 별도 negative-result paper 로 못 publish (single-cohort, single-task 라 venue 부족).
