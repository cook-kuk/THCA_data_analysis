★ Result · partial LOSO fix: ESM2-35M does NOT improve within-source CV (0.828 vs biophys 0.854; biophys captures length+aromatic+H well). But for the WORST cross-source case — leaving NEPdb out — ESM2 lifts AUROC 0.403 → 0.476 (+0.073, beats random by ~5%). For IMPROVE leave-out: 0.512 → 0.545 (+0.032). For TESLA: roughly unchanged. ESM2 partially fixes the cross-source bias for the most divergent source. Larger ESM2 (650M / 3B) on GPU would likely do better; ESM2-35M on CPU is the cheap version.

HONEST: ESM2 fix is partial. NEPdb (biophys 0.40 → ESM2 0.48) and IMPROVE (0.51 → 0.55) improve. TESLA flat. Even with ESM2, no LOSO source crosses AUROC=0.6. The remaining gap is real distribution shift across curators (NEPdb's 15,614 negatives vs other sources' positive bias is too strong for any feature representation alone). Real fix needs per-source class re-balancing or domain-adversarial training.

What this means for the paper

  • Within-source benchmark: biophys-only RF AUROC=0.854 remains the headline number — beats ESM2-35M (0.828)
  • Cross-source (LOSO): ESM2 lifts the worst case from 0.40 → 0.48 (NEPdb), small but meaningful
  • For Cell Rep Med / NAR Database Issue: report both. The story = "biophysics captures within-source signal well, but cross-source generalization needs sequence-LM features even at 35M parameters"
  • Next: ESM2-650M on GPU (Azure burst ~$5) — likely closes another 5-10% AUROC gap
  • Next: domain-adversarial or per-source weighted training
