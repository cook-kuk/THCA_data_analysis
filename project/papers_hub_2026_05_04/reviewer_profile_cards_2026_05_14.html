R1 · METHODOLOGIST

Archetype 1 — Stats / power / sensitivity guard

"Did the authors do the test correctly? Power? Multiple comparison? Null distribution? Robust to perturbation?"

WILL ATTACK

  • TDS-16 overlap — "Panel-8 ⊂ TDS-16의 90% capture, 새로움 없음"
  • Knock-out n-1 floor — "single-gene 의존 검사"
  • Label-permutation null — "p=0.29 (Round 7) 의심"
  • Multiple testing correction — "12 contrasts FDR 명시?"
  • Power for n=18, n=59, n=260 cohorts

OUR EVIDENCE STACK

  • TDS-16 ρ=0.954 Spearman — Panel-8 ≈ TDS-16 (Q13 lock)
  • Knock-out n-1 floor d=1.54 — no single gene drops below threshold (Round 8)
  • Thyroid-matched null p=0.007; label-perm p<1e-4 (Round 8 정정)
  • FDR<0.01 in 10/12 contrasts across 4 cohorts (DM1 robustness deep dive)
  • Cluster stability 97.4% ≥0.9 bootstrap; XGB 5-fold AUC=0.984

RESPONSE PATTERN

steelman → numeric: "The reviewer correctly highlights that...", numeric counter (ρ=0.954, d=1.54, p<1e-4)로 즉시 cap. Methodologist는 숫자에 약함.

R2 · CLINICIAN

Archetype 2 — Actionability / clinical relevance guard

"Will this change practice? What about the patient in front of me? Is this validated in a Korean / Asian clinical context?"

WILL ATTACK

  • Thyroid context — "low-mortality cancer, why do we care?"
  • MAPK-i feasibility — "off-label MAPK-i for non-anaplastic thyroid?"
  • Clinical workflow — "어떤 환자에게 어떤 시점에?"
  • HLA-II OR 1.02 p=0.84 — "null이 main에 들어가지 않았나"
  • Korean overdiagnosis — "Western audience와 무관 아닌가"

OUR EVIDENCE STACK

  • TERT OS HR=7.57 [2.74, 20.91] p=9.3e-5 — high-risk subset 명확
  • RAS=98% DM1 / BRAF=1% DM1 — MAPK-i (selumetinib, AZD-0364 등) 선택
  • K2 PRJEB11591 88.8% DM2 — Korean overdiagnosis paradigm bench
  • Yu BABA n=5,000 + 62 CTC — clinical validation pillar 확보 (Samsung-tied)
  • RAI-refractory axis (GSE151179) thyroid_diff d=-1.01 Bonferroni-significant — RAI 실패 case 의 immunogenomic phenotype

RESPONSE PATTERN

clinical anchor → driver split: TERT/HR 한 줄 → driver split (RAS=98% DM1) → 치료 옵션 (MAPK-i druggable). Clinician은 actionability에 반응.

R3 · DOMAIN EXPERT

Archetype 3 — Prior literature / cite accuracy / mechanism guard

"Have they read the right papers? Is the cite accurate? Does the mechanism make biological sense?"

WILL ATTACK

  • Krishnamoorthy 2025 reference — "4 facts 모두 틀림, misattribution"
  • Landa 2016 missed — "PDTC/ATC continuum 원전을 cite 했어야"
  • 8-gene 5/8 ATC overlap — "reverse causality 아닌가"
  • BRS / TDS-16 prior work — "redundant"
  • Mun 2025 cite handling — "they replicate vs they cite"

OUR EVIDENCE STACK

  • Cite save register — Krishnamoorthy 2025 → Landa 2016 JCI 126(3):1052-1066 즉시 교체
  • 5/8 ATC overlap, reverse-causality 3-layer block: (a) DM1 in cPTC d=+1.50 (early), (b) TCGA-only RNA replicated in Lee Normal vs ATC, (c) HM450 methylation H13 polarity-locked → silencing precedes ATC dedifferentiation
  • Mun 2025 protein: sign-match 7/7, 5/7 r<-0.5 along PTC→PDTC→ATC — replication, not just cite
  • TDS-16 ρ=0.954: Panel-8 differentiates as a robust 8-subset subspace
  • BRAF V600E β=0.37 ≈ RET fusion β=0.39 vs RAS β=0.27 (d≈+2.0) — mechanism decomposition (deconv v5-v14)

RESPONSE PATTERN

cite save → 3-layer block: 먼저 cite 정정 (Landa 2016 즉시 표기), 그 다음 reverse-causality 3-layer block을 한 번에 deploy. Domain expert는 cite-accuracy에 가장 민감.

R4 · COMPUTATIONAL

Archetype 4 — Cohort handling / batch / leakage guard

"ComBat? LODO? TSS confound? Did they leak? UNI vs ViT-L, which one is the result?"

WILL ATTACK

  • ComBat vs LODO — "ComBat이 label leak"
  • TSS confound — "TSS-only LR within RAS-like AUC=1.000 이상함"
  • UNI/ViT-L discrepancy — "ViT-L LOTO 0.308이면 결과를 못 믿겠음"
  • K2 PRJEB11591 cohort handling — "Korean 만으로?"
  • arcasHLA imputation — "RNA-imputed HLA의 신뢰도"

OUR EVIDENCE STACK

  • v5.2 LODO ComBat DIAL=0.000 — 5 THCA classifier 모두 true_biology (v5.2 critical fix memo)
  • TSS-only LR within RAS-like AUC=1.000 — confound disclosed (Methods boundary table), UNI image-only는 별도 primary
  • UNI overall LOTO 0.852 = primary; ViT-L LOTO 0.308 = artifact disclosed; image FM head-to-head page 별도
  • K2 PRJEB11591 n=260, 88.8% DM2 — pre-registered Korean overdiagnosis benchmark; AFND South Korea pool baseline
  • arcasHLA Kim 2014 DPB1*05:01 56% Korean replication; RNA-seq imputation cookHLA-deferred (SNP 필요) — boundary 명시

RESPONSE PATTERN

boundary table → external: Methods boundary table에 each confound을 line-itemize → external 4 cohort 안에서 sign-match 7/7 표시. Computational은 boundary clarity에 반응.

R5 · HOSTILE

Archetype 5 — Wants you dead. Will attack anything.

"Is this even novel? Are these authors qualified? Why thyroid? Why these venues? Why now?"

WILL ATTACK

  • "Just an extension of TCGA-THCA 2014"
  • "DM1 = noise" (Round 7 p=0.29 cherry-pick)
  • "Korean overdiagnosis bias = the whole story"
  • "BRAF/RAS dichotomy explains 99%" — false but reviewer-deployed
  • "Methylation polarity flip 자체가 의심"

OUR EVIDENCE STACK

  • Never accept misattribution — Sun-Tzu rebuttal playbook deploy
  • Steelman the strongest version — "The reviewer makes a fair point that..." → then counter
  • Cite the steelman — TCGA-THCA 2014 (n≈500, RNA-only) vs our 4-pillar n=336+ × 4 modalities
  • Round 8 thyroid-matched null p=0.007 (not Round 7 p=0.29; cite Round 7 단독 금지)
  • RAS=98% DM1 / BRAF=1% DM1 — driver dichotomy를 우리가 reproduce + extend
  • H13 polarity correction registered; r9_1 master locked; supplementary에 sign-flip 명시

RESPONSE PATTERN

steelman → numeric → cite: 절대 misattribution 수용하지 않음. Sun-Tzu 36 stratagem mapping: "borrow knife" (cite Mun 2025 protein replication 직접), "deceive the heavens" (positive frame Korean overdiagnosis as paradigm). Hostile은 steelman 후 numeric에 무력.

Detection in first paragraph — 4 단서

reviewer 첫 50-100 단어 · archetype 추정 → response 선택

STATS JARGON

"power", "FDR", "permutation", "stability bootstrap", "confidence interval" 빈도 ≥2 → R1 Methodologist.

CLINICAL JARGON

"actionable", "practice", "guidelines", "ATA", "RAI", "BABA", "active surveillance" 빈도 ≥2 → R2 Clinician.

CITE COUNT + NAME

저자 이름 3+ drop ("Landa", "Caturegli", "Krishnamoorthy") + cite 5+ → R3 Domain.

TOOL / BATCH KEYWORD

"ComBat", "Harmony", "LODO", "UNI", "ViT-L", "STAR", "arcasHLA" 빈도 ≥2 → R4 Computational.

NONE OF ABOVE + AGGRESSIVE TONE

4단서 모두 약함 + "unconvinced", "fails to", "overclaim", "speculative" → R5 Hostile.

HYBRID

실제 reviewer는 R1+R3 (Methodologist-Domain), R2+R4 (Clinician-Computational) 혼합 빈번. 강한 archetype 단일 + 약한 archetype 1개 detect 후 strong-first response.

FALSE-POSITIVE TRAP

"This is a beautifully written paper, however..." → 90% Hostile prelude. 부드러운 첫 줄에 속지 말 것.

DETECTION OUTPUT

Archetype 추정 후 universal 9 deploy → archetype-specific 추가 → confirm/disconfirm via response receipt.
