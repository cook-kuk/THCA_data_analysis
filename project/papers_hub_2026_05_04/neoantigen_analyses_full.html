Three big findings: (1) biophysics-only RF AUROC = 0.839 on the leakage-free split — sets the bar for any new neoantigen predictor on this corpus. (2) TCRs binding the same peptide are sequence-closer in CDR3β (Lev μ 9.0 vs 10.4, p=1e-32) — public/clonotype hypothesis confirmed; structural RMSD points the same way (μ 7.5Å vs 8.0Å) but only marginally significant on 79 ESMFold loops. (3) Balachandran 2017 Foreignness/Agretopicity AUROC ≈ 0.53 on TESLA — barely above random. Modern features (BigMHC immunogenicity score, RNA expression, HLA binding stability) are needed for production-grade prediction.

Honest take: Foreignness (Balachandran 2017 Nature) and Quality(F/A) reach AUROC ≈ 0.53 on TESLA — only modestly above random. Inverse Agretopicity actually has AUROC 0.43 (worse). This is the foundational neoantigen-quality framework but on TESLA's tested-but-many-non-validated corpus, it doesn't do much. Confirms the field's intuition that newer ML scores (BigMHC, NetMHCstabpan, PRIME) outperform.
