Lumenix verdict

Lumenix는 현재 5개 HTML scaffolding + 2개 Python builder + 3개 markdown이다. evidence-bearing run output (e.g. trained model checkpoint, validated cohort score table, peer-reviewed reproduction)은 본 directory 내 존재 증거가 없다. brand 사용은 "analytical OS positioning"으로만 허용하고, paper나 grant body에 "Lumenix가 X를 했다"는 식의 evidence claim은 금지.
