"Defer cite" rule — 인용을 보류해야 하는 경우

  • Yu 2024 PDF 본문 미확인: 87% / EMT predominance / 2주·3개월 timepoint 등 핵심 숫자는 abstract만으로 본문 인용 금지. main text에서는 "prior PTC CTC studies report measurable detection and EMT phenotypes" 정도로 일반화.
  • Krishnamoorthy 2025 Nat Comm: 4 facts 모두 wrong-attribution. 모든 위치에서 Landa 2016 JCI로 대체.
  • JAK inhibitor / mycophenolic acid / AZD7762 / Alisertib / selumetinib combo: 약 이름 직접 claim 금지. perturbation class hypothesis로만 인용.
  • CELLxGENE cell count: snapshot마다 달라짐. "approximately ~33M cells (CZ CELLxGENE Discover, [accessed date])" 형식.
  • HTAN dataset id: 특정 dataset id 확인 없으면 generic "HTAN collections"로 표기.
  • TUMORFISHER 2026: Recent publication; full ref 확인 후 인용. 미확인 시 secondary support로만.
  • Local 연구계획서_삼성.docx 및 Yu 2024 PDF: source_context_index.md에 NOT FOUND 명시. 원문 확보 전에는 모든 cite가 abstract-level reference에 머무름.
