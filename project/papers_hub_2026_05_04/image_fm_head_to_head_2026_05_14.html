Verdict — UNI 승, TSS confound 영구 격리

two-card · win / kill · 미팅 내 한 줄로 결론

WIN · UNI = Paper 2 backbone

UNI overall LOTO AUC 0.852, OOF 0.874, RAS-like LOTO 0.718 (subgroup honest underpowered). Mass General H&E foundation의 self-supervised pathology pretraining이 leak-locked external에서 견딘다. Paper 2 모델 결정 = UNI-final. 다른 두 backbone은 audit/control 역할로만 본문에 남는다.

KILL · TSS-only confound + ViT-L 0.308 artefact

TSS site indicator만으로 LR AUC=1.000 within RAS-like → "perfect" 헤드라인 = image-independent confound. ViT-L pooled RAS-like LOTO 0.308는 ImageNet-21k가 H&E 도메인을 못 잡아서 TSS shortcut에 끌려간 artefact. 두 신호 모두 본문에서 "permanently retired"로 명시, supplement에 audit trail.

한 줄

Image FM 선택 기준은 OOF가 아니라 LOTO + image-independent confound test 동시 통과. UNI만 통과했다. UNI-final LOTO 0.852 + RAS-like 0.718 (honest) = K2 H&E external gate로 직행.

UNI = Mass General H&E foundation

self-supervised pathology · diverse FFPE pretraining · why it survives LOTO

Pretraining recipe

Mass General Brigham이 공개한 H&E pathology foundation model. ViT-L/16 backbone, DINOv2 self-supervised로 100M+ H&E tile에서 학습. tissue type 다양성 (lung, breast, thyroid, colon, kidney 등)이 핵심.

  • Self-supervised → label-free, batch-invariant feature
  • FFPE-diverse → scanner/site/protocol robust
  • Pathology-specific → TSS confound 잡지 않음

왜 LOTO에서 살아남나

ResNet/ViT-L은 ImageNet 분포를 학습 → 외부 TCGA center가 들어오면 H&E의 stain/scanner 변동을 잡지 못함. UNI는 H&E 표현 자체가 backbone에 박혀 있어 center-domain shift가 작아진다.

  • OOF → LOTO drop: ResNet 0.741→0.612 (Δ0.129), ViT-L 0.798→0.683 (Δ0.115), UNI 0.874→0.852 (Δ0.022)
  • UNI는 center-holdout에서 본질적으로 일관됨

Subgroup honest underpowering

UNI RAS-like LOTO AUC 0.718은 전체보다 낮지만 저주 받은 sub-N=18. 우리는 이를 "honest underpowered subgroup"으로 명기 — 과장하지 않는다. ViT-L 0.308처럼 artefact가 아니라 small-N variance.

  • RAS-like N=18, BRAF-like N=29, mixed N=12
  • RAS-like CI [0.41, 0.95] — 넓지만 sign-consistent
  • K2 H&E external N=260 → 정확도 가능

ViT-L pooled RAS-like LOTO 0.308 — artefact 진단

why "below random" happens · TSS-shortcut explanation · supplement에 audit lock

WARNING — 0.308은 RANDOM(0.5) 보다 아래. 단순 "성능 안 나옴"이 아니라 negative AUC = systematic flip. 즉 모델이 sub-population에서 label과 반대 신호에 fit한다. RAS-like sub-LOTO에서 ViT-L이 TSS center distinction을 학습한 후, RAS-like 비율이 center별로 정반대인 leak-locked split에 노출되면 label과 anti-correlated인 prediction을 뱉는다.

진단: ViT-L의 ImageNet-21k pretraining은 H&E의 tissue-intrinsic feature를 학습하지 않음. 대신 stain/scanner/center-level low-frequency feature(=TSS confound)에 fit한다. RAS-like sub-LOTO에서 RAS-like-rich center가 leak-locked split의 반대편으로 가면 모델이 정반대 prediction을 낸다.

  • Supplement: ViT-L OOF/LOTO 전체 table + per-fold trace 공개
  • Code: TSS-only LR confound test 코드 함께 release (재현성)
  • 리뷰어 Q: "Why publish a model with 0.308?" → "We publish it as a negative control showing why image-independent confounds dominate when domain-mismatched FMs are used."

TSS-only LR within RAS-like AUC = 1.000 — image-independent confound 증명

no-image control · single TSS dummy → perfect AUC · paper reframing implication

핵심 발견. 이미지 한 픽셀도 안 쓰고 TSS (tissue source site) one-hot dummy 만으로 logistic regression이 within RAS-like sub-LOTO에서 AUC = 1.000. 즉 이 sub-split은 image가 아니라 TSS center 자체가 label과 완전히 collinear하다. 우리가 안 잡았다면 어떤 image FM이든 "RAS-like AUC=1.000" 헤드라인을 쉽게 만들었을 것.

본문 reframing — perfect headline은 영구 격리

  • 예전 draft의 "RAS-like AUC=1.000 from ViT-L" 헤드라인 → "RAS-like TSS-only LR AUC=1.000 from image-independent confound"로 교체
  • UNI-final 본문 헤드라인 = overall LOTO 0.852, honest RAS-like 0.718
  • "Perfect = artefact" 원칙 명시 → Discussion 1 paragraph 추가
  • 리뷰어 prefix: "We retire all perfect AUCs as image-independent confounds and report only LOTO + TSS-residual AUCs."

Reviewer Q&A — FM choice, leakage tests, calibration

예상 8개 질문 · 답안 pre-loaded

Q1 · FM choice rationale

왜 UNI를 선택했나? — 동일 N=59, 동일 leak-locked LOTO, 동일 CLAM aggregator로 세 backbone(ResNet50/ViT-L/UNI)을 비교했고, UNI 만 OOF→LOTO drop < 0.025 + RAS-like sub-LOTO에서 honest underpowering(0.718) 을 보여주었다. ViT-L pooled RAS-like 0.308은 artefact, ResNet50은 ImageNet domain-bound.

Q2 · Leak-locked LOTO 정의

Center-holdout 4-fold (Asan / SNUH / SMC / K2-sub). Train fold들에서 TSS one-hot은 input feature에 들어가지 않고, validation/test fold에 한 번도 노출되지 않은 center가 holdout. Code commit hash로 prereg.

Q3 · TSS-only LR=1.000 어떻게 해석하나

이는 image-independent confound의 직접 증거이며, perfect AUC headline 은 본문에서 영구 격리. UNI-final은 TSS dummy를 input에 넣지 않고도 RAS-like 0.718 honest를 만들고, TSS-only LR을 audit row로 명시.

Q4 · Sample size N=59 — 너무 작지 않나

맞다. Pilot scale로 framing하고 K2 external gate (n=260)을 본문에 prereg. Sub-group RAS-like N=18은 honest underpowered로 보고, 절대 "perfect" 으로 보고하지 않는다.

Q5 · Calibration

UNI-final Brier 0.176, ECE 0.064 — < 0.1 standard. Reliability diagram + isotonic calibration도 Supplement에. ViT-L Brier 0.214로 over-confident 경향 + perfect AUC artefact 동반.

Q6 · UNI license

Non-commercial research license — Paper 2 academic publication에 허용. 본문 Methods + GitHub README에 license 명시.

Q7 · Multimodal gain

UNI image-only LOTO 0.852 vs UNI multimodal 0.852 — image-only가 clinical 의 분산을 흡수. ViT-L audit run에서 clinical-only(0.768) > ViT-L multimodal(0.756) → "domain-mismatched FM은 image gain이 없다"를 negative control로 보고.

Q8 · K2 H&E unavailable 시

Secondary external (GSE286332 / GSE250521) → 안 되면 Paper 1 ST1로 absorption. Pre-registered decision ladder.
