Paper 1 · DM1 dark matter statistics block

Cox · Logistic · XGB · time-dep ROC · DESeq2 · limma · GSEA · methylation · random-effects forest · null

Statistics block (paste-ready)

Survival

Overall survival was modelled with a Cox proportional-hazards model (Python lifelines v0.27) using TERT promoter mutation status as the primary exposure and age, stage, and BRAF V600E status as covariates. Hazard ratios are reported with 95% confidence intervals computed from the Cox variance estimator. The proportional hazards assumption was checked with Schoenfeld residuals. TERT⁺ OS HR = 7.57 [95% CI 2.74, 20.91], p = 9.3 × 10⁻⁵.

Classification

Binary classification of DM1 vs DM2 used (i) logistic regression with L2 regularisation (scikit-learn) and (ii) XGBoost gradient-boosted trees. ROC AUC was computed with 5-fold stratified cross-validation. LogReg AUC = 0.903 (perfect-calibrated); XGB 5-fold AUC = 0.984 (TPO 53% feature gain). Time-dependent ROC for TERT_or_DM1 at 1 year = 0.83. Calibration was assessed using Brier score and calibration intercept/slope; isotonic regression was used to recalibrate when slope deviated from 1.

Differential expression

RNA-seq differential expression analysis used DESeq2 (R/Bioconductor) on raw counts with size-factor normalisation and Wald test; for microarray cohorts, limma with empirical Bayes moderation was used. Cohen's d effect sizes were computed for visualisation; per-gene |d| ranges from TPO = 1.33 to SLC5A5 = 0.72.

GSEA

Gene Set Enrichment Analysis (GSEA, MSigDB Hallmark + KEGG + Reactome) was performed with the fgsea R package using log2 fold-change ranks; BH FDR < 0.05 was the significance floor.

Methylation

HM450 β-values were transformed to M-values (logit) for hypothesis testing. The 8-gene panel was scored as mean M-value across the eight CpG-promoter probes. Polarity correction H13: the r9_1 master reference orientation is applied; DM1 = HIGH-β / silenced (cPTC d = +1.50; Landa GSE76039 PDTC vs ATC d = +3.47).

Meta-analysis

Random-effects forest meta-analysis (R metafor v3.8, DerSimonian-Laird) for cross-cohort Spearman ρ pooling. MAPK × Panel-8 pooled ρ = −0.327 [95% CI −0.376, −0.278], n = 1,287, 5 cohorts, I² = 72.9%.

Null tests

  • Permutation null (random feature sets, Round 7): p = 0.29 — panel is honest, not lucky.
  • Thyroid-matched null (Round 8): p = 0.007 — the Round-7 0.288 used an unfair non-thyroid pool.
  • Label-permutation null: p < 10⁻⁴ (10⁵ shuffles).
  • Knock-out n−1 floor: d = 1.54 (removing any single gene still yields panel effect).
  • TDS-16 ρ = 0.954 (8 ⊂ TDS-16, 90% capture).
  • Cluster stability: 97.4% iterations ≥ 0.9.

LODO discipline (v5.2)

Under proper leave-one-cohort-out ComBat batch correction (v5.2 critical fix), all five THCA classifiers return DIAL = 0.000, i.e. true biology, overturning the v5.1 DIAL = 0.494 flip leak artifact. All downstream Paper-1 analyses adopt v5.2 LODO ComBat.

Paper 2 · Histology → DM1 statistics block

LOTO · bootstrap AUC CI · multimodal logistic · DeLong · TSS confound

Statistics block (paste-ready)

Image foundation model evaluation

UNI v1 patch embeddings + CLAM attention aggregation were evaluated with leave-one-TSS-out (LOTO) cross-validation. Mean ROC AUC across LOTO folds was the primary metric. UNI LOTO mean AUC = 0.852; ViT-L from-scratch baseline = 0.308 (near-chance).

TSS confound proof

A center-label-only classifier reached AUC = 1.000, demonstrating that the TSS / center label is fully predictable and that within-center evaluation would overstate biology. LOTO is therefore the required evaluation protocol.

Bootstrap confidence intervals

Per-cohort and per-fold AUC 95% CIs were estimated with 1,000 bootstrap resamples (stratified by class). External validation cohort (n = 59) yielded mean AUC 0.83 ± 0.14 (pooled 0.75).

Multimodal logistic regression

Incremental value of image features over clinical baseline was tested with multimodal logistic regression. Clinical-only vs clinical + image AUC was compared with the DeLong test (paired). Net reclassification improvement (NRI) and integrated discrimination improvement (IDI) were reported.

Closure architecture

Per v19 (2026-05-08), the previous "closure architecture-bound" hypothesis was overturned; UNI is gated and ViT-L + CLAM PASS_LAUNCH_PAPER2.

Spatial transcriptomics (Lu 2023 GSE250521)

MOSCOT optimal-transport spatial alignment + Squidpy ligand-receptor analysis (16 samples). Significance threshold: BH FDR < 0.05 on permutation-derived LR scores. Inverted-V LR diversity peaks at LPTC (median 2,512 significant LR pairs); CXCL13 ↔ CCR6/CCR7 TLS axis.

HLA #1 · HT-isolated PTC statistics block

DEG · Cohen's d · BH FDR · TLS scoring · BCR clonal · transfer test (signature + OR)

Statistics block (paste-ready)

Cohort

GSE286332 Korean PTC vs PTC + HT (n = 18). RNA-seq raw counts processed with DESeq2 (Wald test); microarray cohorts processed with limma.

Differential expression

Differential expression was tested with DESeq2 (negative-binomial Wald) at BH FDR < 0.05. 10,380 genes significant. Wilcoxon rank-sum was used as a non-parametric sanity check for selected genes.

Effect size

Cohen's d was computed for each gene and pathway score. HLA-II axis (HLA-DRA/B/DPA/B/DQA/B mean) d = +3.65; 8-gene panel d = −1.6; TLS gene signature d = +1.96; IGHV clonality d > 0.5; AICDA expression up.

Pathway analysis

GSEA on Hallmark + KEGG ran with fgsea. IFN-γ response FDR = 2 × 10⁻⁴.

TLS scoring

TLS gene-set score = mean z-scored expression of the TLS-12 signature (Cabrita 2020). Significance tested by Wilcoxon rank-sum with BH FDR.

BCR clonal analysis

BCR repertoire reconstructed from bulk RNA-seq with MiXCR; IGHV clonal richness and Shannon diversity computed per sample. Effect sizes reported as Cohen's d between groups.

Transfer test (D4-P2 → TCGA-THCA)

GSE286332 PTC + HT signature was scored on TCGA-THCA tumours; signature-quartile × DM stratification was tested with logistic regression. DM2 enrichment OR up to 5×, p = 6 × 10⁻¹⁰ (Bonferroni controlled).

HLA #2 · Korean GD / Pan-Asian statistics block

HLA allele frequency comparison · chi-squared · arcasHLA confidence · ratio + 95% CI

Statistics block (paste-ready)

HLA imputation

HLA class I (HLA-A/B/C) and class II (HLA-DRB1/DPB1/DQB1) alleles were imputed from RNA-seq using arcasHLA (default parameters); per-locus call confidence was reported. cookHLA was deferred (SNP input required). K2 PRJEB11591 cohort: n = 260.

Allele frequency comparison

Allele frequencies were compared to AFND South Korea baseline using chi-squared tests; ratios and 95% CIs were computed under the Wilson score interval. K2 vs AFND ratios = 0.93–1.22, all p > 0.16 (honest null). DPB1*05:01 frequency in K2 = 56% (replicates Kim 2014).

Pan-Asian comparators

Pan-Asian comparators (China, Japan, Taiwan, Korea PTC studies) are visualised as forest plots of allele frequencies with country-specific 95% CIs. Paper 4 backlog: 4/4 gating — (1) Paper 1 bioRxiv, (2) Paper 2 A/B/C complete, (3) explicit "Track B 시작", (4) Pan-Asian comparator coverage.

Honest reporting

Within-cohort frequencies cannot demonstrate disease-vs-population association without population comparator; this is disclosed transparently.

Samsung 30억 · Causal K-Thyro statistics block (target trial emulation)

Hernán-Robins · doubly robust learner · causal forest · IPW · E-value · tipping point · effective n

Statistics block (paste-ready)

Target trial emulation (WP1)

Following Hernán & Robins, the target trial is specified with eligibility criteria, treatment definition, treatment-assignment timing, follow-up start (time zero), outcome, and analysis plan. The observational analogue is constructed with cloning, censoring, and inverse-probability-of-censoring weighting (IPCW). Pre-specified emulation diagnostics check positivity, exchangeability, and consistency.

Doubly robust learner + causal forest (WP2)

Heterogeneous treatment effects are estimated with a doubly robust (DR) learner — augmented inverse-probability weighting with cross-fitting (Chernozhukov et al.) — and with causal forests (Wager-Athey). Implementation: EconML (DRLearner, CausalForestDML) and DoWhy. Nuisance functions (propensity, outcome) are estimated with gradient-boosted trees with 5-fold cross-fitting. Variance is reported with the influence-function-based variance estimator.

Inverse probability weighting

Propensity-score IPW is used as the primary weighting method; stabilised weights are reported and trimmed at the 1st/99th percentile. Standardised mean differences (SMD) are reported before/after weighting (SMD < 0.10 threshold).

Unmeasured confounding (WP3)

VanderWeele's E-value is computed for the primary estimate and the lower CI bound. Tipping-point analysis varies unmeasured-confounder prevalence and effect to identify the minimal confounder strength required to nullify the result. Sensitivity to outcome-misclassification is also reported.

Effective sample size

For weighted analyses, effective sample size n_eff = (Σw)² / Σw² is reported alongside crude n.

Validation (WP4)

Self-extinguishing transfer learning is evaluated against Yu BABA 5,000 cohort + CTC 62 sub-cohort, with prospective endpoint replication. DM1 axis is used as a stratification variable; subgroup-specific ATE is reported with multiplicity correction.
