Boundary audit script — exit-0 required before Paper 1 commit

scripts/boundary_audit/run_all.sh · 5 zone leak check · GitHub Actions

# scripts/boundary_audit/run_all.sh #!/usr/bin/env bash # Yu × Cook lab boundary audit — exit 0 required before Paper 1 commit set -euo pipefail REPO_ROOT=$(git rev-parse --show-toplevel) MANIFEST=$REPO_ROOT/data_registry/manifests/master_dataset_catalog.csv LINEAGE=$REPO_ROOT/data_registry/manifests/sha256_lineage.tsv ZONE_MAP=$REPO_ROOT/data_registry/manifests/zone_membership.tsv echo "[1/5] manifest 존재 확인" test -f $MANIFEST || { echo "❌ master_dataset_catalog.csv 없음"; exit 2; } test -f $LINEAGE || { echo "❌ sha256_lineage.tsv 없음"; exit 2; } test -f $ZONE_MAP || { echo "❌ zone_membership.tsv 없음"; exit 2; } echo "[2/5] SHA256 lineage 검증 (parent SHA matches)" python $REPO_ROOT/scripts/boundary_audit/verify_lineage.py --strict echo "[3/5] sample-id 누설 (train/val/test 교집합 = ∅)" python $REPO_ROOT/scripts/boundary_audit/check_sample_leak.py --strict echo "[4/5] batch effect leak (cohort × split 균형)" python $REPO_ROOT/scripts/boundary_audit/check_batch_leak.py --strict echo "[5/5] label leak (DM1/DM2 ground truth not in features)" python $REPO_ROOT/scripts/boundary_audit/check_label_leak.py --strict echo "✅ boundary audit passed (exit 0)" exit 0

검증 항목 1) SHA256 lineage parent 검증 — 모든 transform 파일이 부모 dataset SHA 명시. 2) Sample-id 교집합 = ∅ (train / val / test). 3) Batch 분포 균형 (cohort × split). 4) Label leak (DM1/DM2 ground truth feature 에 포함 안됨).
