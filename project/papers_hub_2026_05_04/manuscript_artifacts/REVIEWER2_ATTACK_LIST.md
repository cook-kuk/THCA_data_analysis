## Pre-emptive responses to comments not yet anticipated

- **"Why not GPU?"** — All current analyses are CPU-only on a 8-core system to maximize accessibility. ESM2-650M GPU is the highest-priority next experiment.
- **"Why not NetMHCpan/MHCflurry?"** — Binary licensing constraints on this environment. Wrappers exist; deployment instructions in Supplementary.
- **"Bootstrap CI is too small"** — 200 samples is the runtime-limited fallback. 1000 samples deployable but not run in this round.
- **"Where's the comparison to Müller / NeoRanking baseline?"** — NeoRanking benchmark records (n=26) are too small for a meaningful comparison; we report this honestly.
