↔ Paper 1 (DM1)

RAS=98% DM1 axis ↔ MAPK resistance lane

Paper 1 Round 5 DM1 axis (RAS=98% / BRAF=1%) 는 therapy-spectrum 의 resistance / combo meta lane 과 직결. RAS-driven THCA 의 vaccine candidate + MAPK inhibitor combo selection 이 동일 backbone.

  • RAS-driven RAI-refractory DTC → vaccine + MAPK combo
  • BRAF-driven ATC → MAPK inhibitor + anti-PD-1 (KEYNOTE-158)
  • MAPK resistance signature = Paper 1 R5 axis 의 자연 follow-up
  • combo prioritization framing 의 cancer-type 적용
↔ HLA #1 (HT-overlap)

HT-overlap → HLA-II → vaccine + ICI 응답성

HLA #1 finding (HT-overlap PTC 에서 HLA-II d=+3.65, IFN-γ FDR=2e-4) 가 therapy-spectrum 의 neoantigen / mRNA / ICI lane 과 직결. HT-overlap subtype 이 vaccine + ICI 응답성 favorable host.

  • HT-overlap PTC = CD4 priming + IFN-γ ready
  • neoantigen / mRNA 백신 lane 의 candidate-friendly subgroup
  • ICI Phase C v2 4-cohort 의 HLA-I OR=1.35 와 axis 일치
  • therapy-spectrum 의 response prediction framing 의 hero subgroup
↔ Paper 3 (ICI)

ICI vulnerability axis

Paper 3 (ICI vulnerability dark thyroid) 의 ATC d=+2.53 myeloid signal + Phase C v2 cross-cohort 4/4 sign-consistent 가 therapy-spectrum 의 ICI resistance signature 와 axis 공유.

  • ATC immunogenomic phenotype = ICI vulnerable
  • RAI-refractory DTC = partial-ATC phenotype (axis 일치)
  • Phase C v2 HLA-I OR=1.35 + IFNG OR=1.53 = load-bearing
  • therapy-spectrum 의 ICI lane 의 thyroid arm
↔ HLA failure → cell therapy

HLA NO-GO → CAR-T / TIL lane 으로 재배정

HLA presentation failure 환자는 vaccine NO-GO → therapy-spectrum 의 engineered cell therapy lane (CAR-T / CAR-NKT / TIL) 으로 재배정. 두 platform 의 patient-flow 가 단일 routing.

  • HLA-I loss / B2M mutation → CAR-T 우선
  • HLA-I LOH → LOH-aware CAR-T 또는 TIL
  • APM silencing → epigenetic prime + vaccine retry
  • patient-flow = vaccine first → HLA gate → cell therapy fallback

Reviewer Q&A — platform vs single-target · cancer-type scope · BD valuation

therapy-spectrum reviewer 의 3 question family

Q1 · platform vs single-target

왜 single-therapy 가 아니라 platform 인가?

단일 therapy paper 는 BD ceiling 이 낮고 cross-cancer extension 이 어렵다. therapy-spectrum platform 은 5 framing × 5 lane 의 grid 위에서 동일 immunogenomic re-analysis pipeline 을 운영. 단일 paper 의 single-target 으로는 매번 다시 빌드해야 하지만, platform 으로 잡으면 동일 base 위에서 paper-after-paper.

Q2 · cancer-type scope

cancer-type scope 가 너무 넓지 않은가?

맞다 — 그래서 anchor 를 통해 narrow 화. GSE290722 (CAR-T B-cell malignancy) 가 1차 anchor, KRAS mRNA-LNP (PAAD / 일부 NSCLC / 일부 CRC) 가 2차 anchor. 모든 cancer-type 을 다루는 게 아니라 5 best lane × 1-2 anchor 에 집중. paper output 은 cancer-type-specific.

Q3 · BD valuation

BD valuation 의 근거는?

(1) CAR-T pharma 의 companion biomarker market 은 단일 license $2–5M, (2) mRNA-LNP KRAS 의 HLA-C*08:02 grid niche 는 niche-license 가능, (3) CD137-ADC hepatotox signature 는 ADC pharma 의 unmet need (개발 중지 사례). 절대 가치는 BD landscape 분석 필요하지만, 단일 paper 보다 multi-output 가 BD ceiling 높음.

Q4 · Yu lab fit

Yu lab + therapy-spectrum 의 fit 은?

Yu lab 의 종양면역학 + 임상 cohort 강점 ↔ therapy-spectrum 의 response prediction + cohort re-analysis. CAR-T 한국 임상 + TIL cohort + CAR-NKT 국내 사 연계 의 3 lane 모두 fit. Samsung 30억 과제와도 직결.

Q5 · GSE290722 안정성

GSE290722 anchor 가 너무 좁지 않은가?

좁다 — 그래서 cross-cohort validation 이 필수. 한국 CAR-T cohort + Lemberger 류 multi-center CAR-T cohort + (가능 시) Iovance TIL cohort 를 추가. anchor 단일성은 limitation, 단 GSE290722 의 endpoint 정의가 가장 명확.

Q6 · venue strategy

venue 는 어디?

(1) durability predictor = Nature Med / Nat Cancer reach, (2) escape mechanism = Cell / Cancer Cell, (3) ICI lane = Cancer Discov / JCO, (4) combo prioritization = Cell Rep Med / Cancer Discov, (5) potency QC = Cytotherapy / Mol Ther. 한 platform 의 multi-paper venue 다양화.
