3 · Core question

single biological hypothesis · perturbation × phenotype × genotype

Core scientific question

Does thyroidectomy perturb the circulating tumor-cell EMT state, and do persistent postoperative CTC or cfDNA genetic maps identify residual-risk biology in papillary thyroid cancer?

이 문장은 세 가지를 동시에 한다. (1) perturbation: thyroidectomy = controlled human perturbation. (2) phenotype: CTC-EMT state transition. (3) genotype: cfDNA/CTC NGS clone map. 셋 중 하나만 빼도 "PTC CTC 측정"으로 되돌아가서 reviewer가 "이미 다 했다"고 친다. 셋 모두를 paired serial로 측정해야 새 layer가 된다.

4 · Why thyroid as the sharp wedge

PTC CTC = hardest CTC detection · solving here = pan-cancer credibility

PTC CTC가 어려운 이유는 명확하다. (1) thyroid cell 자체가 small, fragile, low-shedding 특성. (2) PTC overall 예후가 좋아 CTC 풍부도가 낮음. (3) thyroid-specific surface marker가 breast EpCAM 같이 신뢰성 높지 않음 (PAX8/TG/TTF1은 nucleus/cytoplasm이라 CTC enrichment에 약점). (4) BRAF/TERT 단순 mutation은 풍부하지만 mutation alone으로 state heterogeneity 설명 안 됨 (TCGA 274 BRAF tumors → 7 vulnerability labels, 최대 label 33.2%). 이게 풀리면 breast/lung/prostate는 자동으로 풀린다 — 그래서 wedge.

9 · The gap that becomes the proposal

no public dataset jointly provides all 4 layers

선행 문헌과 자체 pilot을 종합하면, 다음을 동시에 가진 공개 데이터셋은 존재하지 않는다.

Layer 1
PTC serial blood pre/post thyroidectomy

Yu 2024가 가장 근접하나 NGS 없음. Tarasova 2024는 단면. Sato 2021은 BRAF 한 mutation만.

Layer 2
CTC EMT phenotype transition

Yu 2024 + Li 2022 + TUMORFISHER가 부분적으로 다룸. Serial × paired는 N=62가 최고.

Layer 3
CTC genome map

TCGA-THCA = tissue only. Tarasova = advanced cohort plasma. CTC-enriched NGS는 thyroid에서 거의 없음.

Layer 4
Clone tracking pre→post

완전히 비어 있다. 이게 우리가 채우는 layer.

Gap statement

No strong public dataset jointly provides PTC serial blood pre/post thyroidectomy + CTC EMT phenotype transition + CTC genome map + clone tracking. The proposal exists because this 4-layer void exists.

10 · Aims — 3-aim structure

N≈50 hard wedge · matched tissue · AI bridge

Aim 1 · phenotype × genotype on blood

CTC morphology + targeted DNA/RNA serial mapping pre/post thyroidectomy

N≈50 PTC, serial blood at T0 (pre-op), T1 (2 wk), T2 (3 mo), T3 (6-12 mo / Tg-trigger).

  • CTC E/EM/M state per timepoint
  • BRAF/TERT/RET/NTRK panel on CTC-enriched fraction
  • orthogonal cfDNA (ctDNA) for low-shedding patients
  • strict CD45- / PAX8 lineage gating
Aim 2 · matched tissue ecology

Tumor-normal NGS + tissue spatial transcriptomics ROI

For all enrolled patients: FFPE + normal blood/saliva NGS; for n≈20 high-risk subset: 10x Visium or GeoMx ROI on tumor invasive front.

  • tumor clone identity anchor
  • tissue ecology niche (HLA-low / barrier-high / CD8-excluded)
  • H&E + IHC (PAX8, Ki-67, PD-L1, CD8) on every case (free signal)
  • fresh tissue biopsy fragment frozen for future single-cell
Aim 3 · AI bridge foundation model

CTC features ↔ tissue ecology features → recurrence prediction

Pan-cancer pretraining (TCGA 11k + HTAN + CELLxGENE-thyroid) → PTC downstream fine-tune. PTC = first downstream task, not the entire foundation.

  • cross-modal alignment loss between blood CTC features and tissue ecology features
  • recurrence/persistence prediction (secondary endpoint, exploratory)
  • pan-cancer Phase 2/3 transfer roadmap (breast/lung/prostate)
  • Lumenix/BioDarwin agent stack integration

11 · 5 reviewer weaknesses + canned answers + WP adjustment

causal_kthyro_weakness_audit.md 기반 · reviewer 2가 던질 가장 어려운 5문장과 그 답

W1 · small-N × target trial × event rate

"Effective sample size for AS→progression counterfactual estimand가 몇입니까? Sensitivity analysis에서 unmeasured confounding이 어느 정도면 결과가 뒤집힙니까?"

Aim 3에 E-value tipping-point analysis를 명시. AS vs surgery counterfactual을 primary endpoint로 두지 않고, CTC state transition을 primary로 두며 progression은 exploratory secondary. doubly robust learner는 bootstrap 1000회 CI를 보고하고, E-value > 1.5에서만 신호로 받아들임. PTC progression event는 enrichment (LN+, LVI+, ETE+, BRAF/TERT) 기반 sub-cohort에서만 분석.

WP3 · 통계 sub-task: target trial protocol + E-value + tipping point

W2 · "Foundation model" word vs N=50

"왜 이게 foundation model입니까? Pan-cancer pretraining 후 thyroid fine-tuning이라면 foundation이지만, thyroid only는 domain model입니다."

제안서 첫 페이지에 "pan-cancer pretraining (TCGA 11k + HTAN + CELLxGENE 33M cells) → PTC = first downstream task"를 명시. 단일 질병에 묶이지 않음. PTC는 hard wedge proof-of-concept이며, 같은 backbone이 breast/lung/prostate로 transfer 가능함이 Aim 3 마지막에 보여짐. Phase 2/3 expansion roadmap을 budget separately.

WP1 · pretraining 명시 + PTC = downstream task framing

W3 · AS vs Surgery monitoring confound

"AS군이 6개월마다 ultrasound + Tg하는 것 자체가 progression detection을 올리지 않습니까? Treatment 효과인지 monitoring intensity 효과인지 어떻게 구분합니까?"

제안서 1쪽에 "monitoring schedule을 두 arm에 동일하게 emulate"한다고 명시. AS arm과 surgery arm 모두에서 동일한 Tg/US/CTC blood timepoint를 강제한다. detection bias / surveillance bias에 대한 informative censoring sensitivity analysis를 secondary methods section에 박는다. progression이 secondary exploratory인 이유와 직접 연결된다.

WP2 · IRB protocol: matched monitoring + censoring sensitivity

W4 · Quantum-inspired sidecar justification

"Tensor network / quantum kernel이 small-N high-D에서 classical low-rank kernel을 어떻게 능가합니까? Clinical performance 주장 가능합니까?"

Clinical performance 주장 안 한다. NISQ-era 의료 AI future-proofing pilot benchmark로 framing. Classical baseline (logistic / gradient boosting / contrastive) 대비 우위 없으면 negative result로 보고. Budget 비중도 ~1.5억 (전체 3억 sidecar)로 제한.

(a) 현재 누적된 quasi-experimental cohort에서 재현 불가능한 causal evidence를 추출 — 이것 자체가 과제의 일회성 가치. (b) 인과 framework는 다른 overtreated cancer (low-risk prostate, DCIS, indolent lymphoma)로 transfer — Future Direction에 명시. (c) thyroid wedge에서 만든 CTC-Spatial foundation의 backbone은 pan-cancer로 가니까 모델 자체는 지속 가치.

14 · Risk register

IRB · logistics · vendor · AS-surgery bias · spatial cost overrun

R1 · IRB delay

serial blood + genomic + germline finding handling = consent 복잡. 8-12주 buffer 권장. Mitigation: IRB pre-submission Q&A 1차 + amendment 2회 예산.

R2 · serial blood logistics

T2 (3개월) · T3 (6-12개월) drop-off 위험. Mitigation: 외래 동선 + thyroidectomy follow-up 표준 스케줄과 일치 + CRC 사전 contact.

R3 · CTC platform vendor lock

CanPatrol / Parsortix / RareCyte 중 선택 후 lock. 변경 시 assay re-validation 필요. Mitigation: Year 1 Q1에 platform pilot 5명 → lock.

R4 · AS vs surgery selection bias

active surveillance에 진입한 환자는 baseline risk가 낮음 → confounding. Mitigation: propensity matching + monitoring schedule emulation (W3 답안).

R5 · spatial vendor cost overrun

10x Visium / Xenium 단가 변동 + sample fail rate. Mitigation: stage-gate at Y1 Q3; high-risk subset only.

R6 · publication race

Yu 2024 + Tarasova 2024 → 다른 그룹도 진입 가능. Mitigation: 4-layer joint는 진입장벽 높음. Year 1 결과로 bioRxiv preprint 1차.

16 · Honest disclosure — "70% 이상 거짓말"

public pilot ≠ CTC biology proof · TCGA ≠ CTC · 60-70% 권역 honest assessment

Things the proposal does NOT claim

1. Public pilot은 CTC biology를 증명하지 않는다 — feasibility / marker selection만 한다.
2. TCGA-THCA 505명은 tissue NGS이지 CTC count가 아니다.
3. GSE250521 spatial 16 slides는 tissue ecology이지 CTC shedding을 증명하지 않는다.
4. AI bridge는 N=50 thyroid 데이터로 학습되는 모델이지 그것만으로 "foundation"이 아니다 — pan-cancer pretraining이 그 무게를 진다.
5. CTC NGS는 모든 PTC에서 통하지 않을 수 있다 — CTC-high subset feasibility로 stage-gate.
6. cfDNA는 early PTC에서 LOD 미만일 수 있다 — Sato 2021의 22명 작은 N이 우리도 직면할 현실.
7. 추가 임상 deployment는 본 30억 과제 범위 밖이다 — Phase 2/3로 분리.
