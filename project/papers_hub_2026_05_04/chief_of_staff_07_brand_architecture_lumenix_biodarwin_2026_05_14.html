2. 왜 회사 이름에서 "AI"를 빼는가

naming 패턴 분석 · 2026 trend

2020년 초반 AI 스타트업의 1차 물결은 "X.ai" / "XAI" / "AI-X" 패턴이 흔했다. 그러나 2024–2026 두 번째 물결의 best-in-class는 회사 이름에서 AI를 뺐다. AI는 도구일 뿐 정체성이 아니라는 시그널 + trademark/검색 충돌 회피 + 회사가 AI를 넘어 확장될 가능성에 대비하는 보험. literature

EXTERNAL · COMPANY

Lumenix (1순위) · Lumen (2순위)

법인명 / BD 표기 / 논문 affiliation / 투자유치 자료에 노출되는 외부 이름. Lumenix가 trademark 안전성이 더 높을 가능성, Lumen이 더 짧고 강력. 둘 중 하나는 trademark 사전조사 통과해야 한다. hypothesis

  • 법인 등록: 미국 Delaware C-corp 또는 한국 주식회사 (Yu-Cook 공동 PI 구조에 따라 결정)
  • 도메인: .com (primary), .ai (vanity), .bio (sub-brand)
  • USPTO Class 42 (computer/scientific) + Class 44 (medical) 동시 출원
INTERNAL · ENGINE

BioDarwin

엔진 코드네임. 가설을 evolutionary selection으로 도태시키는 메타포 (Darwin은 적절한 namesake — selection pressure + variation + retention). agentic AI framework의 내부 통합 layer. internal claim

  • repository 이름: biodarwin/
  • 주요 모듈: hypothesis_pool, selection_pressure, retention_layer, ablation_audit
  • 외부 BD 자료에는 "Lumenix BioDarwin engine" 형식으로 등장 가능
  • 특허/상표 출원 우선순위: 회사명 다음으로 BioDarwin
INTERNAL · AGENTS

BioFeynman / BioMendel / BioBayes / BioCurie / BioFisher / BioTuring / DataHyena

개별 agent 모두 과학자 namesake. 각 agent는 specific responsibility (mechanism / genetics / uncertainty / experiment / statistics / code / data hunting)에 대응. agent 이름이 사람 이름이라 팀 내부에서 "BioFeynman한테 물어봐" 같은 자연스러운 대화 가능. internal claim

  • 외부 BD 자료에는 agent 이름 직접 노출하지 않음 (engine = BioDarwin만 노출)
  • 학회/논문에서는 method paper로 별도 공개 가능 (BioDarwin paper)
  • DataHyena는 별명 — 학회 자료엔 "data ingestion agent"로 표기
