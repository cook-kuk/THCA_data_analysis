2. 비전공자 배경

임상에서 PTC 환자의 약 22–30% 가 Hashimoto 갑상선염 (HT, lymphocytic thyroiditis) 동반. 기존 관점은 "단순 inflammatory 환경 → tumor microenvironment 영향" 정도였는데, 이 paper 는 GSE286332 (Korean PTC vs PTC+HT n=18, Lim 2025 Frontiers Endocrinol) 의 분자 분석으로 HT-overlap 자체가 distinct molecular subtype 을 정의 함을 보임.

4. Hypothesis

Hashimoto's thyroiditis—overlap PTC defines a mechanistically distinct DM2 sub-population characterized by (a) HLA-II antigen presentation up-regulation, (b) antigen-driven B cell clonal expansion + TLS formation, and (c) IFN-γ / Type I diabetes / autoimmune transcriptional program. The HLA-II → P(DM1) pathway is mediated by autoimmune mechanism, distinct from generic immune infiltration.

10. 한국어 설명 (방법 · 결과 · 의미 풀어쓰기)

10.1 왜 Hashimoto 가 단순 동반질환이 아니라 "mechanism" 인가

임상에서 PTC 환자의 약 22–30% 가 Hashimoto 갑상선염 (HT, lymphocytic thyroiditis) 동반. 기존 관점은 "단순 inflammatory 환경 → tumor microenvironment 영향" 정도였는데, 이 paper 는 GSE286332 (Korean PTC vs PTC+HT n=18, Lim 2025 Frontiers Endocrinol) 의 분자 분석으로 HT-overlap 자체가 distinct molecular subtype 을 정의 함을 보임:

  • 10,380 DEGs (padj<0.05, n=18): PTC+HT 가 정상 분화 (PAX8 / NKX2-1 / FOXE1 / 8-gene RAI 모두 down) + B cell / T cell / antigen presentation (HLA-II / IGHV / CXCL13 / AICDA 모두 up) 의 distinct profile.
  • HLA-II Cohen d = +3.65 — 압도적 module up. p=4×10⁻⁴. 8-gene RAI Cohen d = −1.60 (PAX8 d=−2.32 / NKX2-1 d=−1.92 / FOXE1 d=−1.75).
  • GSEA Hallmark IFN-γ Response NES=+1.80 FDR=2×10⁻⁴ + KEGG Type I diabetes NES=+1.92 FDR=0 — 자가면역 transcriptional program 활성화.

10.2 왜 HLA-II 가 mediator 인가 (단순 marker 가 아니라)

Mediation analysis (Baron-Kenny + 5,000-iter bootstrap) 로 GSE286332 n=18 에서 PTC+HT → P(DM1) ↓ 의 인과 경로 dissect:

  • HLA-II 가 140% mediator — over-mediation (c_direct sign flip). 즉 PTC+HT 가 P(DM1) ↓ 시키는 효과의 거의 전부가 HLA-II 경로로 explain. residual direct effect 는 opposite sign 으로 작게 남음.
  • 8-gene RAI 가 63% partial mediator — 두 axis 의 convergence: PTC+HT 가 (a) HLA-II 를 통해 immune-mediated dedifferentiation, (b) 8-gene 을 통해 TF-backbone collapse 둘 다 driving.
  • Generic immune-proxy (control) 는 26% (NS p=0.18) — generic infiltration 으로는 설명 안 됨.

임상적 의미: HT-overlap PTC 의 dedifferentiation 은 stromal / generic immune infiltration 의 부수 효과가 아니라 HLA-II 를 통한 antigen presentation 활성화 → 특정 thyroid antigen 에 대한 면역반응 → tumor cell dedifferentiation 의 인과 경로. 이는 면역치료 가능성 을 시사 (Paper 3 ICI vulnerability 의 substrate).

10.3 왜 BCR / TLS / AICDA 가 antigen-driven 의 증거인가

TLS (tertiary lymphoid structure) = 만성 inflammation 환경에서 형성되는 lymphoid neogenesis. Cabrita 2020 12-gene signature (CXCL13 / CCL19 / CCL21 / CD79B 등) 으로 정량화. PTC+HT d=+1.96 (p<0.001) — 매우 강한 organized lymphoid structure 형성. IGHV clonality (Shannon entropy collapse, d=−0.58) 는 clonal expansion 의 증거. AICDA (activation-induced cytidine deaminase) 는 somatic hypermutation enzyme — antigen-driven affinity maturation 의 핵심 enzyme. PTC+HT 에서 +1.42 up. 3가지 같이 보면: 정상 thyroid antigen (TPO / TG / TSHR 등) 에 대한 자가면역 → B cell 이 organized lymphoid structure 형성하고 → BCR repertoire clonal expansion + somatic hypermutation 으로 affinity 진화 → tumor 미세환경에서 antigen-driven adaptive immune response. 이건 Hashimoto 갑상선염의 자가면역 메커니즘이 PTC 에서 그대로 작동 한다는 분자 증거.

10.4 왜 TCGA n=500 으로 generalize 되나

GSE286332 PTC+HT signature (top 150 up + 50 down DEGs, padj<0.01, |LFC|>1) 를 TCGA n=500 에 Z-mean scoring + Bimodality coefficient = 0.552 (right at threshold) — bimodal distribution 시사. 5 threshold (GMM / Otsu / top-20 / top-30 / residualized Otsu) 모두 DM2 enrichment OR 0.20–0.29 (DM2 가 3–5× HM-like rate). top-30 OR=0.20 p=6.4×10⁻¹⁰. Korean replication: Lee 2024 GSE213647 n=632 → HM-like 22.8% (Otsu 28.2%) — TCGA range 매치. 즉 Korean GSE286332 단일 cohort 에서 도출한 signature 가 (a) TCGA (mostly EUR) 에 동일 sign 으로 transfer, (b) 다른 Korean cohort 에 prevalence 매치. cross-population generalization 의 증거.
