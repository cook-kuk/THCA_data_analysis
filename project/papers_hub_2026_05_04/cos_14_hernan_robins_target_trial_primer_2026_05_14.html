01한 줄 verdict

Target trial emulation은 RCT가 비현실적인 임상 결정에 대해 observational data로 reviewer-safe causal answer를 만드는 표준 framework이다.

Hernán & Robins (2016, Am J Epi 183(8):758-764) "Using Big Data to Emulate a Target Trial When a Randomized Trial Is Not Available"가 원전이다. AS vs Surgery in low-risk PTC는 윤리적 RCT가 매우 어렵고(POMC 등 시도는 enrollment 어려움 보고), 동시에 한국 MAeSTro/MASTER/KoMPASS 코호트가 "사후 emulation에 필요한 baseline + treatment timing + outcome"을 모두 가진다. 이 페이지는 그 emulation을 reviewer가 인정할 수 있는 형식 통계 언어로 정리한다.

02왜 target trial emulation인가

"우리는 RCT를 흉내내는 것이 아니라, 실제로 정의된 가상 trial의 protocol을 명시하고 그 protocol에 맞춰 관측데이터를 분석한다."

2-1. 정통 인과추론 standard 위치

접근강점약점본 과제 활용
RCTinternal validity gold standardAS vs Surgery PTC는 enrollment 어렵고 윤리 부담참조 frame만, 직접 수행 X
Naive observational comparison편리immortal time bias, selection bias, indication confounding금지
Propensity score matching onlybalance check 용이monitoring/follow-up emulation 빠짐component로만 사용
Target trial emulation7-component protocol이 RCT 논리 그대로여전히 unmeasured confounding 한계main framework
Mendelian randomization유전 instrument로 unmeasured 우회PTC AS 결정 instrument 없음해당 안 됨

2-2. 왜 reviewer가 좋아하는가

  • Hernán-Robins 2016은 Am J Epi에 게재된 표준이며, NEJM/Lancet/JAMA 모두 target trial emulation 논문을 통과시켜 왔다(예: Hernán 2018 NEJM Statin-CKD; Dickerman 2019 NEJM Aspirin; Petito 2020 JAMA cardiology).
  • Reviewer 2가 "당신은 RCT가 아닌데 왜 causal 주장을 하는가"를 물을 때, target trial emulation은 protocol level에서 RCT-equivalent emulation을 명시해 답한다.
  • Bias 종류별로 명시된 대응(immortal time / lead time / selection / detection)이 존재하여 method section의 hostility를 줄인다.

2-3. AS vs Surgery에 적용했을 때의 의미

"한국 PTC AS 도입 이후 누적된 quasi-experimental cohort"는 사실상 시간이 지나면 재현 불가능한 자산이다 (메모 causal_kthyro_weakness_audit §5 자기소멸 자산). Target trial emulation은 이 시한부 자산에서 가장 강한 인과 추정을 뽑아내는 표준 통계 도구다.

03Target trial emulation의 7-component framework

Hernán-Robins는 모든 emulation을 7개 protocol component로 분해한다. 각 component를 명시적으로 정의하지 않으면 emulation이 아니다.

1

Eligibility criteria

가상 trial에 들어갈 자격. 관측 cohort에서 동일 기준으로 필터링. 예: low-risk PTC, cN0, T1a-T1b ≤1.5cm, no ETE, no high-risk variant, age ≥18.

2

Treatment strategies

비교할 처치 arm을 well-defined intervention으로 정의. 예: Arm A = active surveillance with 6mo US + Tg; Arm B = immediate thyroidectomy. 단어가 모호하면 emulation 실패.

3

Assignment procedure

RCT에서는 randomization. Emulation에서는 baseline covariate-conditional assignment를 가정. propensity score + IPW로 emulate.

4

Outcome

일관된 시간 기준의 outcome. AS 연구에서 progression 정의는 가장 민감하므로 protocol에 prespecified로 박아야 한다.

5

Follow-up period

각 환자의 time zero(eligibility 충족 + treatment 선택 시점)와 administrative censoring 종료 시점을 정의.

6

Causal contrast

ITT(intention-to-treat) vs per-protocol을 둘 다 산출. 임상에서는 per-protocol이 흥미롭지만, ITT가 robust한 base.

7

Analysis plan

IPW + outcome regression(g-formula) + DR learner + causal forest + sensitivity. 사전등록 권장.

Source: Hernán MA, Robins JM. Using Big Data to Emulate a Target Trial When a Randomized Trial Is Not Available. Am J Epidemiol. 2016;183(8):758-764.

05Doubly robust (DR) learner

Outcome regression이 틀려도 IPW가 맞으면 추정량이 consistent. 거꾸로도 마찬가지. 둘 중 하나만 맞으면 된다.

5-1. 직관

  • IPW (inverse probability weighting): 각 환자에게 1/propensity score 가중치 부여 → assignment 불균형 보정
  • Outcome regression (g-formula): covariate 주어진 outcome 기대값 직접 회귀
  • DR estimator: 둘 다 사용하되, model misspecification에 대해 robust → double robustness property

5-2. 수식 형태

ATE_DR = E[ A·(Y − m₁(X)) / e(X) − (1−A)·(Y − m₀(X)) / (1−e(X)) + m₁(X) − m₀(X) ]

여기서 e(X)는 propensity score, m_a(X)는 treatment a 하의 outcome regression.

5-3. 본 과제 사용 방식

요소본 과제 적용
e(X) 추정XGBoost / GBM (clinical + 분자 covariate)
m_a(X) 추정survival forest 또는 Cox + flexible spline
Cross-fitting5-fold cross-fitting으로 overfitting bias 차단 (Chernozhukov 2018)
OutputATE estimate + 95% CI (asymptotic 또는 bootstrap)

References: Bang & Robins 2005 Biometrics 61:962-973 (DR estimator); Chernozhukov et al. 2018 Econometrics Journal 21:C1-C68 (double machine learning).

06Causal forest (Wager-Athey 2018)

Heterogeneous treatment effect를 nonparametric하게 추정하는 random forest 변종. AS의 "어떤 환자에게 효과가 다른가"를 찾는 도구.

6-1. 핵심 아이디어

  • 표준 random forest는 outcome을 예측. Causal forest는 treatment effect τ(x) = E[Y|X=x, A=1] − E[Y|X=x, A=0]를 추정.
  • 각 leaf에서 local treatment effect 추정 → asymptotically Gaussian, 신뢰구간 제공.
  • Honest splitting (split 결정과 추정에 서로 다른 sample 사용)으로 overfitting 차단.

6-2. 본 과제 사용 시 의미

QuestionCausal forest로 답하는 것
"어떤 PTC 환자가 AS에서 progression 위험이 낮은가?"τ(x)가 작은 subgroup → AS 적합
"어떤 PTC 환자가 immediate surgery에서 더 이득을 보는가?"τ(x)가 큰 subgroup → 즉시 수술 적합
"CTC EMT-positive 환자에서 AS arm vs Surgery arm의 차이는?"covariate에 CTC feature 포함 시 즉시 산출 (Aim 1 + WP2 integration)

Source: Wager S, Athey S. Estimation and Inference of Heterogeneous Treatment Effects using Random Forests. J Am Stat Assoc. 2018;113(523):1228-1242. Software: grf R package; EconML Python.

n 경고: Causal forest는 outcome event 수 수백 단위가 필요. AS PTC progression rate ~5%에서 n=500/arm 시 ~25 event/arm → subgroup heterogeneity 신뢰구간 매우 넓다. §9에서 ESS로 직접 다룬다.

07E-value (VanderWeele 2017)

"어떤 strength의 unmeasured confounder가 있어야 관측된 효과를 설명해 없앨 수 있는가?"를 정량화하는 sensitivity standard.

7-1. 정의

E-value = RR + sqrt( RR · (RR − 1) )

여기서 RR은 관측된 risk ratio. E-value는 "exposure-confounder RR 과 confounder-outcome RR 이 동시에 도달해야 하는 최소값"의 기하학적 표현.

7-2. 해석 예시

관측 RRE-value의미
1.52.37RR=2.37의 confounder 2개 동시에 작용해야 효과 사라짐 → 비교적 robust
2.03.41RR=3.41 confounder 필요 → 매우 robust
1.21.69비교적 약한 confounder도 효과 설명 가능 → fragile
1.11.43매우 약한 confounder도 효과 설명 가능 → 결과 의심 권장

7-3. 본 과제 활용

  • ATE 추정량과 95% CI 하한 모두에 대해 E-value 보고 → reviewer 2의 "unmeasured confounding은?" 질문에 즉시 답.
  • "monitoring intensity 차이가 RR=X 만큼의 confounder일 가능성"에 대해 E-value 위치로 정량 평가.
  • Discussion에서 "E-value=2.37이므로 surgeon preference나 patient anxiety가 unmeasured confounder로 RR=2.37 이상 강도여야 효과가 설명된다"고 명시.

Source: VanderWeele TJ, Ding P. Sensitivity Analysis in Observational Research: Introducing the E-Value. Ann Intern Med. 2017;167(4):268-274. evalue-calculator.com

08Tipping point analysis

"어느 수준의 confounder가 들어와야 추정 효과가 null을 넘는가"의 직접 그래프. E-value의 시각화 사촌.

8-1. 절차

  1. 관측 ATE 추정량 = τ̂
  2. 가상의 unmeasured confounder U를 추가하고, U의 prevalence와 U-treatment / U-outcome RR을 grid로 sweep
  3. 각 (RR_U-A, RR_U-Y) 조합에서 corrected τ̂를 다시 계산
  4. corrected τ̂ = 0 (또는 임상 null threshold)에 도달하는 경계를 contour plot으로 표시

8-2. 본 과제 visual deliverable

그래프해석
x축: RR(U → AS assignment)"수술 선호 surgeon 노출이 AS-vs-Surgery 결정에 얼마나 영향"
y축: RR(U → progression detection)"동일 surgeon 노출이 progression detection에 얼마나 영향"
contour = corrected ATEnull 횡단선이 그래프 어디인지 = robustness 정도

References: Rosenbaum 2010 (Observational Studies); Liublinska & Rubin 2014 Stat Med 33(24):4170-4185.

09Effective sample size (ESS) — 솔직 평가

정직: AS in low-risk PTC progression event는 5년 ~5% 수준. n이 충분하지 않으면 모든 causal estimator의 분산이 폭발한다. 본 페이지는 그 한계를 숨기지 않고 reviewer에게 먼저 제시한다.

9-1. ESS 계산 (rule-of-thumb)

Required N per arm ≈ ( z_α/2 + z_β )² · ( p₀(1-p₀) + p₁(1-p₁) ) / (p₁ − p₀)²

9-2. 본 과제 시나리오 power 표

가정 (5y progression rate)Δ (HR 1.5)Per-arm N (80% power, α=0.05)Notes
AS=5%, Surgery=3.4% (HR≈1.5)약 1.6pp~ 2,400매우 큼, 단일 코호트로 비현실
AS=7%, Surgery=4.7%약 2.3pp~ 1,600여전히 어렵지만 multi-cohort pooled로 도달 가능
AS=10%, Surgery=6.7%약 3.3pp~ 1,100high-risk enriched cohort 가능성
AS=15%, Surgery=10%약 5.0pp~ 700high-risk subgroup만 분석 시 도달
AS=20%, Surgery=13.3%약 6.7pp~ 500MAeSTro+MASTER+KoMPASS pooled 도달 가능

9-3. 본 과제 대응 전략

  • Primary endpoint는 progression(composite)으로 잡아 event rate 상승
  • Multi-cohort pooled emulation (MAeSTro + MASTER + KoMPASS) 명시 → 합산 N target ≥1,000/arm
  • Secondary는 hazard ratio + ITT survival difference로 보고 (continuous outcome 신뢰구간이 binary 점추정보다 안정)
  • Honest claim: "본 과제는 ATE에 대한 narrow CI를 약속하지 않는다. 신뢰구간이 넓더라도, target trial protocol의 사전등록 + E-value/tipping point가 reviewer에게 답을 준다."
Memo causal_kthyro_weakness_audit §1: ChatGPT가 끝까지 안 짚은 약점. ESS를 미리 자기 입으로 말하지 않으면 Reviewer 2가 통째로 흔든다.

10Surveillance bias closure — monitoring schedule emulation

AS vs Surgery에서 가장 위험한 함정. AS군은 6개월 ultrasound로 자주 진찰 → progression detection이 monitoring intensity의 함수가 된다. 이를 안 닫으면 모든 causal estimate가 surveillance artifact라고 공격당한다.

10-1. 문제 정의

  • AS군 = 6개월마다 US + Tg + 임상 → 작은 종양 성장도 잘 발견
  • Surgery군 = 초기 수술 후 3개월/6개월/12개월/24개월 post-op follow-up → 다른 cadence + 다른 modality
  • "AS군에서 progression이 더 많이 보인다"는 (a) AS treatment 효과 (b) monitoring intensity 효과 (c) lead-time bias 의 합. 분리 불가능

10-2. 표준 대응

방법본 과제 적용Reviewer 안심 정도
Protocol-stipulated shared scheduleTarget trial protocol에 "양 arm 모두 6개월 monitoring cadence로 emulate" 명시강
Post-hoc time-grid re-binningSurgery arm 데이터를 6개월 grid에 다시 매핑하여 동일 cadence 만들기강
Informative censoring sensitivity"Surgery군에서 progression이 다음 visit 사이 발생했을 확률" sensitivity강
Joint model of monitoring + outcomeLin 2003 visit-process model 적용중
Lead-time correctiontumor growth rate model로 detection lead-time 조정중

10-3. Reviewer가 인정할 protocol 문장 (영문 draft)

"Under the target trial emulation framework, the monitoring schedule is treated as a part of the protocol rather than as an outcome-defining variable. For both arms, progression is ascertained on a 6-month grid, with surgery-arm visits re-aligned to the same grid via administrative re-binning. Informative censoring under monitoring asymmetry is addressed by an inverse-probability-of-censoring weighting sensitivity analysis and a tumor-growth-rate-based lead-time correction."

References: Buyse 2008 Stat Methods Med Res 17:541-560 (informative censoring); Lin DY 2003 (visit-process model).

11Reviewer Q&A — anticipated attacks

5개의 reviewer attack에 대해 protocol-level 응답. 모두 §5-10 도구로 답한다.

Q1. "AS vs Surgery progression endpoint에 대한 ESS는 얼마인가?"

Multi-cohort pooled emulation (MAeSTro + MASTER + KoMPASS) 목표 ≥500/arm. AS 5y progression assumption 10-15%, HR=1.5 detection 80% power 도달. Per-protocol effect는 CI가 더 넓을 것이며, 사전등록된 protocol에 narrow CI 보장을 약속하지 않는다. 대신 E-value와 tipping point로 unmeasured confounding에 대한 robustness를 정량 보고한다.

Q2. "E-value tipping point는 어디인가?"

Primary ATE 추정량과 95% CI 하한 둘 다에 대해 E-value를 보고. Sensitivity grid의 contour plot으로 (RR_U-A, RR_U-Y) 평면에서 corrected null 경계를 명시. 본 과제는 E-value < 1.5인 결과는 main claim에서 배제하고 exploratory로만 보고한다고 사전등록.

Q3. "Monitoring schedule emulation의 rigor는?"

§10 표 5개 방법 중 (a) protocol-stipulated shared 6-month grid, (b) post-hoc re-binning, (c) informative censoring sensitivity를 main analysis에 박는다. Joint model + lead-time correction은 robustness check로 별도 report.

Q4. "Causal forest는 small N에서 신뢰구간이 무한하지 않은가?"

동의. Causal forest의 heterogeneous effect 신뢰구간은 넓을 것이다. 따라서 본 과제는 causal forest output을 "subgroup hypothesis generation"으로만 보고하고, 임상 결정 점수로 약속하지 않는다. Honest claim ceiling은 "AS-suitable / Surgery-suitable subgroup의 후보 정의"이며, 외부 검증 cohort에서 prospective 평가 필요.

Q5. "Per-protocol vs ITT 어느 쪽이 main인가?"

ITT를 main으로 보고, per-protocol을 secondary로 보고. ITT는 crossover 위험에 robust하고 reviewer-safe. Per-protocol은 임상 의사결정에 가까운 effect이지만 censoring weighting이 강하게 들어가 신뢰구간이 넓다. Disagreement가 있는 경우 protocol 위반 패턴을 분석해 mechanism을 보고.

13Claim boundaries

모든 인과 주장은 emulation 한계 안에서.

Allowed claims (허용)

  • "Target trial emulation 하에서 추정된 ATE"
  • "E-value=X.X로 unmeasured confounder RR=X.X 이상 강도여야 효과가 사라진다"
  • "Causal forest로 AS-effect heterogeneity hypothesis 생성"
  • "Monitoring schedule emulation이 surveillance bias의 일부를 닫는다"

Forbidden claims (금지)

  • "본 결과가 RCT를 대체한다"
  • "AS는 Surgery보다 ___% 더 우수하다"는 단순 narrative
  • "Causal forest가 환자 개별 치료 결정을 추천한다"
  • "Unmeasured confounding이 0이다"

13dLead-time bias 별도 다루기

AS arm에서 progression이 더 일찍 발견되면 (시간 0 기준) survival이 단축된 것처럼 보일 수 있다. 이는 surveillance bias의 하위 형태.

13d-1. 보정 방법

  • Tumor doubling time correction: AS arm 환자별 종양 성장 속도로 detection lead-time을 추정 → outcome time을 보정
  • Detection-time matching: Surgery arm에서 같은 시점에 progression이 있었다면 발견되었을지를 imputation
  • Right-censoring at common visit grid: 6mo grid에서만 outcome 측정 → lead-time 차이 제거

13d-2. 본 과제 statement (영문 draft)

"Lead-time bias is addressed by (i) restricting outcome ascertainment to the protocol-stipulated 6-month grid for both arms, (ii) a tumor-doubling-time-based lead-time correction sensitivity analysis using Yu's serial-US growth measurements, and (iii) reporting both raw and lead-time-corrected estimates. We do not claim that lead-time bias is eliminated; we report its plausible magnitude."
