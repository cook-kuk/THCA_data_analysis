**핵심 내용 요약 (4가지)**

**[1] Survival 종류**
OS(전체 생존)와 PFI(재발까지) 두 가지를 모두 분석했습니다.
- OS pooled HR = 2.53 (95% CI 1.31–4.89, I²=0%, p=0.006)
- PFI에서 새로운 발견: **BRAF V600E+ 환자에서만** DM1이 재발을 층화합니다 (HR=0.66, p=0.013). BRAF 음성이나 RAS 양성 환자에서는 효과가 없었습니다 (각 p=0.52, 0.92).

**[2] RNA 발현 → RAI 흡수 연결**
직접 RAI 흡수량(전신스캔, Tg trend) 데이터는 현재 논문에 없다는 점 솔직하게 말씀드립니다. 현재 근거는 두 가지입니다.
① DM1 8개 유전자 자체가 RAI 흡수 기전(NIS·TPO·TG·TSHR·DIO1·PAX8·NKX2-1·FOXE1)이라는 생물학적 논거
② 공개 코호트 GSE151179에서 실제 RAI 내성 종양이 DM1-like 상태로 이동해 있다는 간접 근거 (Cohen's d ≈ −1.0, p ≈ 10⁻⁴)
직접 임상 연결은 논문에서 prospective validation 과제로 명시해 두었습니다.

**[3] 내부 검증 경로**
나희영 교수님께서 "연구용 항체는 신뢰성이 낮다"고 말씀하신 부분이 완전히 맞습니다. 그런데 최신 원고에서 가장 강력한 발견이 **IHC 3-plex (TG + PAX8 + NKX2-1)**인데, 이 세 가지는 연구용이 아니라 이미 분당서울대 병리과에서 일상적으로 사용하시는 **임상 진단용 항체**입니다. 이 조합이 BRAF+ 환자에서 PFI를 가장 강력하게 층화했습니다 (log-rank p = 1.7×10⁻⁴, HR = 0.65).
→ 기존에 보유하신 FFPE 블록 + BRAF mutation + 재발 데이터를 연결하는 후향적 연구가 현실적으로 가능한 첫 번째 검증 경로일 것 같습니다. 교수님들 의견을 여쭤봐도 될까요?

**[4] TSO500 3-gene 조합**
이세준 교수님께서 확인해 주신 TSHR, PAX8, NKX2-1 조합을 원고 분석에서 직접 테스트했는데 실패했습니다 (BRAF+ PFI log-rank p = 0.30). TSO500은 DNA 변이(있음/없음)를 측정하는 플랫폼인데, DM1은 RNA 발현량(얼마나 발현되는가)의 차이입니다. 갑상선암 DM1의 주요 기전이 epigenetic silencing이라 DNA는 정상이어도 RNA가 낮을 수 있어 TSO500으로는 원리적으로 포착이 어렵습니다.
