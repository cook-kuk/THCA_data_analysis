# Nature Communications submission checklist

Journal instructions change. Recheck official pages on the day of submission.

## Initial submission package

- Cover letter.
- Main manuscript text file.
- Individual figure files, or a combined initial-submission file when permitted.
- Separate Supplementary Information file.
- Supporting data and code accessible to editors and reviewers when requested.

## Manuscript content

- Title, author list, affiliations, corresponding author details.
- Abstract with background, main findings, and implications; no unsupported clinical claim.
- Introduction with rationale and a final paragraph summarizing major results and conclusions.
- Results with subheadings and all supporting data represented; no “data not shown.”
- Methods sufficient for reproduction.
- Separate “Statistics and Reproducibility” subsection.
- Data Availability statement.
- Code Availability statement when custom code is used.
- Author Contributions.
- Competing Interests.
- Acknowledgements and funding statement, including sponsor role.
- References checked against source documents.

## Figures and tables

- Figures, tables, and supplementary items cited in numerical order.
- Figure legend begins with a concise whole-figure title, then defines every panel.
- Define abbreviations, symbols, colors, shading, error bars, n, test, sidedness, and adjustment.
- Show individual data points when a graph summarizes individual observations, when feasible.
- Avoid red–green-only contrasts and rainbow scales.
- Ensure legibility at final display size.
- Prepare editable vector graphics where possible.
- Provide source data underlying main graphs and charts as Supplementary Data or a repository deposit.

## Reporting and policy forms

- Life Sciences Reporting Summary, complete and internally consistent with Methods.
- Editorial Policy Checklist when requested by the submission system.
- Human-participant ethics details if any restricted human cohort or primary participant data are included.
- Data-access restrictions clearly disclosed.

## Data and code

- Public accession identifiers and stable URLs/DOIs.
- Exact repository release corresponding to the submitted analysis.
- Environment, package versions, seeds, preprocessing, exclusions, and model formulas.
- Source-data manifest mapping each figure panel to a file and generation script.
- No placeholder such as `TBD`, `XXX`, `<DOI>`, or private local path in final package.

## DM1-specific high-risk checks

- Direct RAI response was not measured in discovery cohorts.
- BRAF interaction is not a treatment interaction.
- HM450 analysis is not causal proof.
- Internal wet-lab validation is absent and no longer “pending.”
- MSK is not a population-representative replication cohort.
- TCGA survival uncertainty and event counts must be visible.
- GSE151179 is post-treatment refractory alignment.
- Three-marker result is an in-silico proxy.
- Every validation count has a clear unit: cohort, entry, gene–dataset cell, patient, or sample.
