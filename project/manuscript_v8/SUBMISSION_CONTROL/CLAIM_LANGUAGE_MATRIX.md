# Claim language matrix

Use this table when drafting title, abstract, Results, Discussion, figure captions, cover letter, and reviewer responses.

| Topic | Preferred wording | Wording requiring stronger evidence | Prohibited or misleading wording in current study |
|---|---|---|---|
| Core state | “thyroid-lineage-low state,” “iodine-handling-low transcriptional state” | “RAI-refractory state” only with “-like” or explicit concordance qualifier | “measured RAI resistance phenotype” |
| Discovery | “identified,” “derived,” “observed in TCGA-THCA” | “discovered and independently validated” only after independence audit | “established” |
| External datasets | “reproduced directionally,” “showed concordant separation,” “replicated the state association” | “validated” if endpoint, preprocessing, thresholds, and independence justify it | “prospectively validated” |
| RAI link | “aligned with post-RAI-refractory tumors,” “provided a biological anchor” | “candidate pretreatment marker” as future-facing hypothesis | “predicts RAI uptake,” “predicts treatment response” |
| BRAF-stratified PFI | “BRAF-context-dependent prognostic stratification,” after direction is verified | “effect modification by BRAF genotype” if interaction model is robust | “treatment-predictive biomarker” |
| Overall survival | “associated with poorer OS,” with cohort limitations | “prognostic biomarker” after multivariable and calibration audit | “determines survival” |
| Methylation | “promoter methylation correlated with reduced expression,” “epigenetic correlate” | “consistent with epigenetic repression” if probe and expression correlations support it | “methylation causes silencing,” “mechanism proven” |
| Fusion enrichment | “enriched for kinase fusions” | “driver-spanning state” after definitions and missingness audit | “independent of all genomic drivers” |
| Missingness | “no evidence of differential availability by tested group” | “consistent with missing at random” only with a justified missingness model | “MAR confirmed” |
| IHC proxy | “in-silico three-marker expression proxy using genes with clinically available antibodies” | “candidate IHC strategy” in Discussion | “validated IHC assay,” “clinical test” |
| Power simulation | “simulation suggested that n=200 could provide >90% power under TCGA-derived assumptions” | “prospective study is adequately powered” only after protocol lock | “n=200 guarantees validation” |
| Clinical implication | “motivates prospective pretreatment evaluation aimed at avoiding futile repeat RAI” | “may ultimately support treatment de-escalation” | “patients should not receive RAI,” “clinically actionable now” |
| Robustness | “robust across the tested datasets and preprocessing choices” | “generalizable” after population-shift audit | “universally robust” |
| Non-significant result | “we did not detect evidence of association” | “similar” only with adequate precision | “equivalent,” “the same” |

## Title rule

The working title contains “predicts radioiodine-refractoriness.” This is vulnerable because the study lacks direct pretreatment RAI uptake/response measurement. The managing editor must evaluate at least these alternatives:

1. *A thyroid-lineage state marks radioiodine-refractory biology in BRAF V600E-mutant papillary thyroid cancer*
2. *A thyroid-lineage state stratifies outcomes and aligns with radioiodine-refractory papillary thyroid cancer*
3. *A thyroid-lineage state defines an adverse BRAF-context in papillary thyroid cancer*

Do not change the title silently. Record an editorial recommendation and let the author decide.

## Abstract rule

The abstract must explicitly reveal the retrospective in-silico design and absence of internal clinical validation. Do not defer all caution to the Discussion.

## Reference-direction rule

Never translate HR <1 or HR >1 into “better” or “worse” without verifying:

- event definition;
- state coding;
- reference category;
- continuous versus binary score direction;
- covariates;
- time origin and censoring.
