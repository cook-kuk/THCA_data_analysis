§ 2

Background & clinical motivation

왜 본인이 이 paper 를 쓸 수 있고, 왜 지금이어야 하는가.
Logical chain · 6 step

Clinical gap → BRAF/RAS dichotomy 한계 → dark matter 정의 → unsupervised axis → 8-gene panel → reflex algorithm

(1) Clinical gap. 분화 갑상선암 5년 생존 98% 이상, but ATA 2015 intermediate-risk 의 ~20% 에서 구조적 재발 (Haugen et al. 2016). RAI 치료 결정은 BRAF V600E 단일 marker 에만 의존.

(2) Existing framework limitation. TCGA 2014 Cell + Yoo 2016 PLOS Genet 의 BRAF-RAS Score (BRS) 는 dominant driver 만 stratify · ~23% 의 BRAF/RAS-음성 dark matter 는 mechanistically untethered.

(3) Dark matter formalization. Xing 2014 NEJM 이 BRAF/TERT-음성 23–37% 가 canonical driver 와 independent recurrence trajectory. East-Asian 더 enriched (Korean 37.8%).

(4) Unsupervised axis. TIERA67 67-gene biology-curated pool (driver 미포함) leiden K=2 → DM1/DM2 unsupervised cluster.

(5) Parsimonious 8-gene panel. Yoo 2016 16-gene TDS-core 의 subset · ΔAUC 8 vs 16 = 0.013 NS · 클리닉 deployable.

(6) Reflex algorithm. DM1 captures 81.8% TCGA RET-fusion → 48 selpercatinib-eligible/1000 PTC + HMA + RAI re-induction rationale (TPO/DIO1/TSHR promoter hypermethylation).

2.1 Convergence framing — Yoo 2016 + Landa 2016

8-gene panel 은 Yoo SK et al. 2016 PLOS Genet 의 RAI uptake biology 16-gene TDS-core 의 subset (panel access 시점 Landa 2016 ATC 데이터 미접근). Landa I et al. 2016 JCI 126(3):1052-1066 의 advanced thyroid cancer (84 PDTC + 33 ATC) genomic landscape 에서 분화 transcript (TG · TSHR · TPO · PAX8 · SLC26A4 · DIO1 · DUOX2) 가 ATC 끝단에서 profoundly suppressed.

Reverse-causality 차단 3-layer
5/8 gene overlap (Yoo 2016 panel ↔ Landa 2016 ATC silenced gene list) = independent design 이 동일 biology 에 도달한 convergent validation. 차단 layer: (1) Methods 에서 Yoo 2016 first cite 명시 (panel origin) · (2) Discussion 3.1 convergence framing · (3) Cover Letter explicit statement ("panel predates Landa access"). 이로써 reviewer 의 "panel 이 ATC silenced gene list 에서 cherry-pick 한 것 아니냐" 우려 사전 차단.

2.2 본인 unique angle

두 분 (주영석 / 최정균) 도 갖고 있지 않은 본인 고유 자산 — (i) TIERA67 67-gene candidate pool 정의 (driver gene 미포함, biology-curated) · (ii) DM1/DM2 classifier · (iii) cBioPortal API 기반 structural variant + HM450 methylation 통합 처리 + R8–R10 multi-omic audit chain. Cell Reports Medicine 의 "actionable mechanism + translation" 표적과 정확히 일치.

5-Pillar evidence chain

5 직교 layer 가 동일 DM1 sub-stratum 을 동시 충족.

3.1 Pillar I — 8-gene panel + DM1/DM2 cluster discovery

분석 design. TIERA67 67-gene candidate pool 을 7 biology category 로 curate (driver gene 미포함 — panel-driven artifact 차단). 8-gene = TDS-core subset (Yoo 2016 PLOS Genet 16-gene 의 8/16 subset). Leiden K=2 unsupervised cluster on 500 TCGA-THCA primary tumour expression → DM1 (MAPK-active, dedifferentiated) + DM2 (thyroid-lineage-preserved).

Figure 1 ·
Pan-genome ARI ladder — 8-gene panel 이 dominant differentiation axis 를 capture
Reasoning. Reviewer 가 제기할 수 있는 핵심 우려: "TIERA67 candidate pool 자체가 cluster 를 인공적으로 강제하는 것 아닌가?" 차단을 위해 panel size 의 함수로 ARI (vs original DM1/DM2) 를 측정. 8-gene alone ARI 0.49 = 단독 weak signal · top-5000 pan-genome 0.92 ≈ TIERA67 0.90 = panel-restricted vs unrestricted 동일 결과 → structure 가 인공이 아닌 biology-driven. Driver_anchor 단독 ARI -0.007 (random) — 즉 driver mutation 만 으로는 cluster 재현 불가.

3.2 Pillar II — Clinical aggressiveness + Meta-analysis ★

분석 design. Xing 2014 dark matter 의 73% sub-stratification rescue (180 BRAF-/TERT- → 131 sub-stratified). TCGA 와 MSK-IMPACT 두 cohort 에서 DM1 vs DM2 OS Cox proportional-hazards · DerSimonian-Laird random-effects pooling.

★PAPER-DEFINING
Figure 2 ·
Random-effects forest — TCGA HR 2.30 + MSK HR 2.67 + Pooled HR 2.53 [1.31, 4.89] I²=0%
Reasoning. 두 cohort 가 (i) 발생 demographics 다름 (TCGA = primary surgical resection, indolent skewed · MSK = recurrent/metastatic enriched), (ii) sequencing platform 다름 (TCGA RNA-seq + WES vs MSK targeted panel), 그럼에도 Cochran Q p=0.79 · I²=0% 의 perfect homogeneity. 이는 single-cohort artifact 가능성을 사실상 0 으로 차단. HR 2.53 의 width [1.31, 4.89] 가 1 을 명확히 exclude — 따라서 DM1 = clinically aggressive sub-stratum 확정.
왜 paper-defining 인가
Reviewer Q
"single-cohort 에서만 보이는 artifact 아닌가?"
답
I²=0% across two cohorts of opposite demographic skew = artifact 가능성 사실상 0.
Translation
HR 2.53 = clinical decision-making 에서 RAI escalation 정당화 가능한 effect size.

3.3 Pillar III — Driver mRNA neutrality + pan-genome reproducibility

분석 design. 8-gene panel 의 mechanism 이 BRAF V600E mutation 과 confounded 인가? Cohen's d 측정 — V600E carriers (n=281) vs wild-type (n=223) 에서 BRAF transcript expression. Confounded 라면 d > 0.3 expected.

Figure 3 ·
Driver mRNA neutrality + ARI ladder pan-genome reproducibility
Reasoning. BRAF transcript Cohen's d = −0.04 (V600E vs WT) — 사실상 zero. 즉 panel mechanism 은 driver mutation status 와 independent · DM1 cluster 의 axis 가 BRAF-driven artifact 가 아님. Pan-genome top-5000 ARI 0.92 ≈ TIERA67 0.90 = "candidate pool restriction 이 인공 structure 강제 아님". Reviewer 의 "panel trivial?" 우려 정량 차단.

분석 design. Bulk transcriptomics 결과가 cell-type composition artifact 인지 검증. Single-cell external — Pu et al. 2021 Nat Commun 12:6058 (GSE184362, 6 PTC patients) · Lu 2023 cohort.

4.1 chr 7 arm-level gain — DM1-specific genomic structural feature (R8-1, R9-2, R9-3)

분석 design. cBioPortal arm-level CNA (462 samples, 39 arms) 로 DM1 vs not_DM 의 arm-level gain 빈도 비교. 추가로 chr 7 RTK gene-level (BRAF · EGFR · MET · RAF1 · RET) Cohen's d 검증 + 2000-bootstrap CI.

Figure 7 ·
Chr arm gain rate-difference (DM1 − not_DM) bootstrap CI · 7p / 7q DM1-specific 3.4% vs 0.0%
Reasoning. DM1 에서 chr 7p / 7q gain 이 3.4% (3/89) vs not_DM 0.0% (0/313) — Fisher p=0.011. 2000 paired-bootstrap rate-difference +0.034 [95% CI 0.000, 0.079] one-sided p=0.053. 5q · 17q 도 trending 이나 bootstrap survive 안 함. chr 7 = BRAF (7q34) + EGFR (7p11.2) + MET (7q31) RTK gene 위치 · 이는 RET fusion 외 alternative driver pathway 를 시사 (sub-B fusion-negative subset 에서 chr 7 amp = 4/23 = 17%).
