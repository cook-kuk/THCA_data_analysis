Q02 "Did you bias the panel toward iodine-metabolism genes?" CLOSEDdata

One-line answer. Yes — by explicit design, on Yoo 2016 RAI-uptake biology. Cross-validation leak-free: 5-fold AUC = 0.962 (8-gene) vs 0.975 (16-gene full TDS-core), Δ AUC = 0.013, NS. Held-out cohort AUC = 0.925 (R1-B leak control).

Lives in: §2.1 + Methods + p1_onepage_audit.html panel-combos table.

Q11 "Why do some Korean reference samples map strongly to DM2?" CLOSEDdata

Continuous axis interpretation. The DM1/DM2 axis is continuous, not binary. The small Korean reference set occupies the low-score end of the same classifier used in TCGA. P(DM1) range = 0.005–0.304 — compatible with preserved differentiation-program expression rather than classifier failure. The reference set is used here only for calibration / score-portability checks; no additional biological interpretation assigned.

Lives in: §2.5 + Supp Fig S7.

Q12 "Why is sub-B 96% mutation-negative? Could this be a clustering artifact?" CHARACTERIZEDdata

Sub-B is the fusion-negative component of DM1, identified by unsupervised within-DM1 clustering with silhouette 0.584 and reproducible cross-cohort score geometry in Korean validation. Mutation-negativity indicates DM1 is not reducible to canonical driver status. Deeper sub-B mechanism reserved for companion paper (Paper 2). Memory v17_D6P7_dm1_subB_NBNR notes: sub-B = TCGA equivalent of K2 NBNR cohort + 4× Hashimoto-like rate.

Lives in: §2.4b + Supp Fig S6 + memory.
