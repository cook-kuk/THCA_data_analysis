01 · Why thyroid cancer

A vertical worth solving — not one model fits four diseases.

PTC, RAI-refractory DTC, ATC/PDTC, and MTC are immunologically and genomically distinct. Lumenix runs them as four parallel tracks on shared infrastructure — so antigen class, backbone, and PD readout stay subtype-correct.
PTC · DTC · ~85%

Papillary / Differentiated Thyroid Cancer

0.4TMB mut/Mb
Cold→WarmTME state
6.8%KEYNOTE-158 ORR
Clinical problem

2025 ATA 4-tier risk stratification; lobectomy default for cT1 ≤2 cm; molecular testing (Afirma GSC, ThyroSeq v3) drives Bethesda III/IV management. Most "indolent" — yet ~5% become RAI-refractory.

Immune / vaccine rationale

Largely "cold" tumor; the PTC + Hashimoto subset shows HLA-II / IFN-γ enrichment (GSE286332 d=+3.65) and ectopic TLS biology — an antigen-presenting niche worth exploiting.

Available data

TCGA-THCA n=496, GSE184362 (158k cells, 11 PTC), GSE191288 (PTC+HT), GSE250521 spatial atlas. Korean public PRJEB11591 n=260.

Translational opportunity

BRAF-anchored differentiation-state vaccine + ICI in adjuvant / MRD setting. The HLA-II–biased PTC+HT subgroup is the most antigen-presenting niche.

RAIR DTC · 5–15% of DTC

RAI-refractory DTC

1.2TMB mut/Mb
VariableTME state
65.5%Lenva+Pembro ITOG ORR
Clinical problem

Lenvatinib (SELECT mPFS 18.3 vs 3.6 mo), sorafenib (DECISION), cabozantinib (COSMIC-311 HR 0.22). NTRK→larotrectinib · RET→selpercatinib. Redifferentiation: trametinib + ¹³¹I (MERAIODE).

Immune / vaccine rationale

Heterogeneous; subset acquires BRAF/RAS-driven dedifferentiation programs with rising MHC-I but exhausted T-cell signatures post-MKI exposure — vaccine prime + ICI maintenance is a rational sequence.

Available data

GSE76039 (Landa MSK n=84 PDTC + 33 ATC), thca_mskcc_2016, COSMIC-021 cohort 18 RNA-seq, ITOG NCT02973997 translational bank.

Translational opportunity

Post-redifferentiation iodine-uptake recovery → vaccine prime → anti-PD-1 maintenance is the most defensible MRD design after lenvatinib.

Highest TMB in thyroid (~6 mut/Mb), inflammatory infiltrate, T-cell exclusion reversible by MAPK inhibition. CT-antigens MAGE-A 62%, MAGE-C1 57%, GAGE 67%, NY-ESO-1 14%.

03 · 9-Stage Pipeline

Clinical intake → drug discovery in 10 deterministic stages.

Every stage produces a versioned artifact (DVC-tracked), runs in containerized form (Docker + Snakemake), and emits an evidence card with citation-anchored claim level. No black box — every decision is auditable.
Why deterministic

LODO discipline by default

v5.2 LODO check (THCA DIAL=0.000 under proper ComBat-LODO, not 0.494 leak artifact). We do not ship subtype claims that survive only one batch design — every artifact carries the LODO check.

Why subtype-aware HLA

Korean-first, not Korean-blind

K2 cohort (PRJEB11591 n=260) was used to validate arcasHLA RNA-seq imputation (DPB1*05:01 ≈56%, replicating Kim 2014). AFND Korean / pan-Asian audit runs before any neoantigen ranking is exposed.

Why a wetlab plan, not just a number

Reagent-level resolution

Every ranked candidate emerges with a tetramer + ELISpot + IFN-γ release + MS-confirmation plan, mapped to commercially-available reagents. Translational, not benchmarky.

★ · Agentic Architecture (SPARK-inspired)

Planner → Tool Router → Verifier → Memory — language as the universal interface.

Agent loop · pseudocode
def agent_run(query):
    plan     = Planner().plan(query)              # ordered tool IDs
    results  = []
    for step in plan:
        res = TOOLS[step]()                       # T1 .. T8
        results.append(res)
    flags    = Verifier().audit(results)          # PASS / WARN / ERROR
    Memory().write(f"run_{ts}", {plan, results, flags})
    return {plan, results, flags}

In production the Planner is an LLM (Claude / GPT-4o-class) that drafts tool plans + rationale + post-hoc commentary; Verifier flags become guardrails the LLM cannot bypass. Each tool's citations field is what survives into the auto-generated PDF report.

Why this design wins

No model retraining

SPARK shows you can build a research-grade autonomous agent by orchestrating existing specialized algorithms with language as the interface — no LLM fine-tuning needed.

Why this design defends

Verifier as guardrail

Direction-invariance + sanity gates are the moat. Pan-cancer signature transfer is famously fragile (DIAL); making the verifier the choke point means surprising LLM outputs cannot reach the BD report without a documented audit trail.

Why this design scales

One agent · two cancers

The same Planner / Tools / Verifier ran thyroid (Lumenix v0.9) and PDAC (this PoC) without code changes to the orchestrator — only the registry, modules, and antigen panels are swapped per-vertical.
