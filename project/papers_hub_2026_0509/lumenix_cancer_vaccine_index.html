4-thread API parallel · 105 sec for 79 CDR3β · interactive 3Dmol.js viewers. Same-peptide TCRs are sequence-closer (Lev μ 9.0 vs 10.4, p=1.0e-32); structurally directionally closer (RMSD 7.5 vs 8.0Å).

Stage 4 · ML

44 analyses (A-P + S1-S5 + Q-X + Y-DD + EE-JJ + KK-PP + ESM2)

5-fold CV biophysics-only RF AUROC=0.854 ± 0.008 [bootstrap 95% CI 0.826-0.869]. XGBoost+SHAP, L1 logistic, per-allele, calibration, active-learning, KRAS pan-cancer scoring.

Stage 5 · honest caveats

LOSO + Simpson's paradox + ESM2 partial fix

LOSO AUROC 0.40-0.55 (NEPdb-out 0.40 — actively below random!) → ESM2-35M lifts to 0.48 partial. Histidine SHAP-top signal turns out to be HLA-distribution Simpson's paradox (per-allele Δf_H ≈ 0). Aromatic Δ holds up per-allele. Domain-adapt re-weighting did NOT help (Δ ≈ -0.007).

Stage 6 · deliverable

10-epitope KRAS PAAD vaccine + 50 active-learning

Concatemer 150 aa GGSGGSGG-linker. 5 TESLA-validated + 4 KRAS predicted (G12D GADGVGKSA family). PAAD/COAD/HNSC = G12D · LUAD = G12C (smoking sig). 290 cancer peptides exact-match in VDJdb (independent TCR validation). 43 self-similar autoimmunity-risk flags.
