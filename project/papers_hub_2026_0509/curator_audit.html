★ Why per-source heterogeneity matters
- NEPdb's 98% negative rate reflects "tested but not recognized" inclusion. Other curators only publish positives. → Models trained without NEPdb don't generalize to NEPdb.
- CEDAR's 96% positive rate reflects API filter "neoantigen=true". → Inverse problem: models trained without CEDAR memorize "if peptide looks like CEDAR-format, predict positive".
- TESLA's 40-45% balance is the only source approaching real biological positive rate. → TESLA is the most reliable benchmark partition.
- TSNAdb predicted (~31k records) has zero validation labels — must be excluded from benchmark or used only as a candidate pool.

Honest curator-bias map

  • Aggregator-style: IEDB v3 — wide HLA, mixed assays, large but heterogeneous
  • Negative-heavy: NEPdb — informative for class balance but distorts naive benchmarks
  • Positive-only: CEDAR / Healthy / dbPepNeo / Neodb / NeoRanking — selection-published
  • Balanced patient-matched: TESLA mmc4/7, IMPROVE — gold-standard benchmark partition
  • Predicted-only (L0): TSNAdb predicted — exclude from benchmark
