⑩ 최종 답변 요약
🥇
외부에서 접근 가능한 최대 대시보드: 10개 (지금 당장)
NSG가 열어준 포트 13개 중 3개 사용 중 → 10개 즉시 배포 가능. 정적 HTML/Streamlit/Dash/Jupyter 모두 포함. RAM(13Gi)과 CPU(4 vCPU)는 이 범위에서 병목이 아님.
🥈
CPU 집약형 대시보드(ML 실시간 추론)는: 2–3개
물리 코어 2개가 한계. HyperThreading이 있지만 연산 집약 작업은 공유 자원으로 속도 저하. 대부분의 분석/시각화 대시보드는 해당 없음.
⚠️
포트 추가가 필요하면: NSG 인바운드 규칙 수정
Azure Portal → NSG → 인바운드 보안 규칙 → 포트 추가. 내부(VM 안에서만) 서비스는 포트 제한 없음 — 단, 브라우저 외부 접근 불가.
