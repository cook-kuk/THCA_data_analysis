# Cancer vaccine timeline index

## 1. What this page is

This is the shortest useful chronology of the cancer vaccine work. It is written for a first-time customer MD who needs to understand:

1. what data was used,
2. what was compared,
3. how the model stack changed over time,
4. where the claim boundary is,
5. which page to open first.

## 3. What the work used

| layer | used data or evidence | why it matters |
|---|---|---|
| public corpus | 13 sources, 119,237 cleaned records | gives the project scale |
| safe evaluation | 19,817 leakage-free benchmark rows | keeps the score honest |
| benchmark context | TESLA, CEDAR, NEPdb, ITSNdb, PRIME, MHCflurry, DeepImmuno, NetMHCpan, TransPHLA | shows the external landscape and where winners differ |
| structural support | 115 ESMFold structures + real pMHC / TCR-pMHC examples | keeps the shortlist biologically grounded |
| deliverable | 7-peptide set cover, KRAS lead `GADGVGKSAL` | makes the output executable |
| customer surface | 96-well plate, interpreter, partner pack, clean brief | makes the work readable outside the lab |

## 4. What changed over time

| stage | old state | new state |
|---|---|---|
| literature | TESLA and public predictors were just context | TESLA became the benchmark reference point, but not the whole claim |
| model | single-score ranking | router logic with regime-aware selection |
| comparison | one winner table | winner map + claim-weighted comparison matrix |
| delivery | score output only | shortlist + structural support + figure wall |
| validation | retrospective only | 96-well interpreter and prospective-ready scaffold |
| customer readiness | internal notes | public front door + external deployment URL |
