# GSE230424 PTC-marker extension

Extension using the article's Supplementary Table S6 PTC-specific markers.

Result: 57 marker genes were available. The PTC-marker module is descriptively higher in PTC+HT than HT samples (mean difference 0.162, n=2/group), and H&E predicts the spatial module weakly-to-modestly with sample-centered LOSO Spearman rho 0.159. QC-only is stronger (rho 0.415), coord+QC is 0.367, and the strict coordinate+QC residual-target H&E rho is only 0.071.

Use as supportive/caveat extension only. The primary GSE230424 Paper 2 support remains the DM1/low-RAI axis and its strict residual-target rho 0.232.
