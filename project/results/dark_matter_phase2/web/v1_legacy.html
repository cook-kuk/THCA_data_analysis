Dark Matter of Thyroid Cancer

Phase 1 + 2 결과 통합. 작성일 2026-04-29 (Phase 1 + Phase 2 D1 + Phase 2 D2 동일 일자 sprint).

📌 TL;DR

Frame B (Molecular Taxonomy) 확정 — Cell Reports Medicine 1차 target, Nat Comm reach 정당화.

BRAF V600E와 RAS hotspot이 모두 음성인 갑상선암 (전체의 28%, "Dark Matter")은 단일 entity가 아니라 cPTC-architectured DM1 (n=89, 평균 42세, mechanism 미확인) vs FVPTC-like DM2 (n=55, 평균 54세, DICER1/EIF1AX/PPM1D 9× enriched, p=0.0175)으로 sub-stratification 됨. 8-gene transcriptional panel이 이 dichotomy를 single-cell resolution에서 r=0.86–0.91로 재현 (Phase 1 1환자 + GSE184362 6 adult PTC + GSE193581 PTC+ATC 13 samples). Korean cohort (Yoo 2016 K2 n=180)에서 NBNR ↔ DM 일치율 93.5%, DICER1+EIF1AX 비율 10.3% ≈ TCGA 10.9% 거의 정확히 일치.

5. True driver-negative is INDOLENT PASS

HR=0.49
Class 6 driver-neg PFI rate 4.8% vs BRAF V600E 11.7% (p=0.071). Counter-intuitive — driver-neg thyroid cancer has BETTER outcomes than canonical drivers.

6. ITH dominates inter-tumor variance PASS

3.48× ratio
Within-sample 8-gene variance is 3.48× larger than between-sample variance — sc-specific claim. Continuous gradient (BC = 0.32, unimodal).

⚠ K2 cluster prediction calibration artifact (limitations)

K2_korean_predictions_v4.tsv의 cluster 호출은 92%가 DM2로 분류 — 이는 memory v17_korean_k2_calibration에 적힌 calibration bias (TPM 절대값 transfer가 K2 scale에서 ~10-100× 부풀림). 따라서 본 paper에서 K2 cluster prediction은 cluster 자체 검증이 아니라 mutation/NBNR 일치율 + DICER1/EIF1AX 비율로 검증 (위 표). within-sample-centered profile (TCGA AUC 0.968) 재예측은 P2 후속 task.

📖 Literature context — 우리 finding이 어떻게 fit하는지

Direct precedents (priority cite)

  1. Yoo SK et al, PLoS Genet 2016 (PMID 27494611) — NBNR (Non-BRAF-Non-RAS) molecular subtype 개념 정립. Korean cohort n=180. NBNR ↔ DICER1/EIF1AX/IDH1/PTEN/SOS1/SPOP/PAX8-PPARG 연관성 보고. 본 paper의 sub-stratification (NBNR → DM1 cPTC-like vs DM2 FVPTC-like)이 직접 후속 작업.
  2. Wang et al, Cancer Cytopathology 2025 — DICER1 ⊥ BRAF V600E in 899 Bethesda II/III/IV nodules. DICER1 검출률 6.2%(II) / 4.9%(III) / 10.4%(IV). 우리의 DM2 DICER1+EIF1AX = 10.9% TCGA / 10.3% K2와 정확히 일치. 본 paper의 sc level extension + DM1 분리가 차별점.
  3. Wasserman JD et al, JCEM 2018 (PMID 29490041) — DICER1 mutations frequent in adolescent-onset PTC. 본 paper의 DM1 mean age=42, DM2 mean age=54 (12세 차이) finding과 일치. DM1이 진짜 미스터리인 이유는 DICER1+ adolescent PTC가 아닌 cPTC 표현형이기 때문.
  4. Chernock RD et al, 2021 (PMID 34008223) — Macrofollicular variant FTC = DICER1 mutated, young females. 본 paper의 DM2 = FVPTC + DICER1+ + 평균 54세 표현형과 직접 매칭.

Method baseline references (Discussion paragraph 1-2)

  1. Xing M et al, JCO 2014 (PMID 25024077) — BRAF + TERT HR 8.51, 표준 prognostic baseline. 본 paper에서는 driver-negative cohort에 적용 불가 (BRAF/TERT 모두 음성이기 때문). 28% 환자가 underserved.
  2. Liu R et al, JAMA Oncol 2017 (PMID 27581851) — TCGA 388 PTC 6-genotype prognostic model. BRAF/RAS+TERT duet HR 가장 높음. 본 paper의 Class 5 (TERT-only HR=4.05) 결과와 일치.
  3. TCGA THCA, Cell 2014 (PMID 25417114) — Original TCGA-THCA molecular landscape. EIF1AX as PTC driver originally identified.
  4. Liu J et al, Cell 2018 (PMID 29625055) — TCGA-CDR PFI/DFI/DSS curated endpoints. 본 paper Phase 1 step 2에서 다운로드 후 Cox HR 검증.

sc landscape parallels (Discussion paragraph 3-4)

  1. Pu W et al, Nat Commun 2021/2023 — GSE184362 158k cells / 11 PTC patients (multi-site T/P/LN). Original paper. 본 paper에서 r=0.889 검증 cohort로 사용.
  2. Lu L et al, JCI 2023 — GSE193581 anaplastic transformation single-cell. 본 paper P2-A1 외부 cohort 1.
  3. Krishnamoorthy et al, Nat Comm 2025 — PDTC/ATC proteogenomics 348 samples. Venue parallel reference.
  4. Frontiers Endocrinol 2026 — DICER1-WT thyroblastoma alternative oncogene framework (AGK-BRAF fusion + EIF1AX duplication + TERT promoter). 본 paper DM1 = "true unknown driver" 가설의 직접 analog.

Method tools (Methods cite)

  1. scanpy (Wolf 2018 Genome Biol) — bulk + sc preprocessing
  2. lifelines (Davidson-Pilon 2019 JOSS) — Cox PH
  3. ConsensusClusterPlus (Wilkerson & Hayes 2010 Bioinformatics) — k-grid stability
  4. scVI (Lopez 2018 Nat Methods) — sc batch integration (planned)

⚠ 정직한 한계 (Discussion paragraph 6)

  1. TCGA-THCA prognostic event 부족 — PFI 9 events / OS 6 events in DM cohort. Cox HR underpowered. Frame A (prognostic) 폐기, Frame B (taxonomy)로 재구성. Korean cohort follow-up data 들어와야 prognostic claim 부활 가능.
  2. sc data 단일/소규모 cohort 의존 — Phase 1 GSE241184는 17세 1환자 (소아 PTC 편향). P2-A1/A2/multi-site로 adult PTC 보강했으나 여전히 ~6 환자 규모. 분당 SNUH 가입 시 multi-patient 강화.
  3. HVG filtering attenuation — P2-A1 GSE193581에서 PTC-only r이 0.69로 낮은 건 HVG filtered h5ad에 DIO1/SLC5A5/FOXE1 부재 때문 (4/7 FVPTC genes). raw data 재처리 시 회복 (P2-A2가 0.889로 정상값 회복했음).
  4. K2 cluster prediction calibration bias — TPM scale 차이로 92%가 DM2 호출. 본 paper에서는 cluster validation 대신 mutation/NBNR concordance + DICER1+EIF1AX 비율로 검증. within-sample-centered profile 재예측이 후속 작업.
  5. DICER1/EIF1AX absolute counts 작음 — TCGA n=6, K2 n=7. Wang 2025 N=899 supplement.
  6. 분당 SNUH outreach pending — 한국인 follow-up survival 데이터 미수신. paper draft 시 "Korean cohort survival validation in progress" 명시.
  7. DIAL-U cluster stability methods 별도 paper — 본 paper에 압축 통합 (Option 2 검토 중) 또는 method companion paper로 분리 (Option 1 default).
