모델 평가

AUC
ROC 곡선 아래 면적

AUC

정의

  • ROC curve 아래의 면적(0~1).
  • 0.5는 무작위, 1.0은 완벽 분리.

실무 해석

  • 0.7~0.8 쓸만함, 0.8~0.9 좋음, >0.95 외부 재현성 점검 필수.

주의

  • 클래스 불균형이 심하면 AUC가 과대평가될 수 있어 PR-AUC를 같이 봐야 합니다.
ROC Curve
FPR vs TPR 곡선

ROC Curve

축

  • x축: FPR (False Positive Rate).
  • y축: TPR (True Positive Rate = Recall).

곡선 그리는 방법

  • threshold를 0→1로 움직이며 각 점의 (FPR, TPR)을 찍습니다.

해석

  • 좌상단에 가까울수록 좋음. 대각선은 무작위.
PR Curve / PR-AUC
Precision-Recall 곡선과 AP

PR Curve / PR-AUC

정의

  • 가로 Recall, 세로 Precision인 곡선.
  • PR-AUC = Average Precision (AP).

언제 쓰나

  • 양성 클래스가 드물 때(예: 10% 이하). ROC보다 정직한 그림을 줍니다.
Confidence Interval (95%)
95% 신뢰구간

Confidence Interval (95%)

정의

  • 동일 실험을 무한 반복했을 때 95%의 경우 이 구간 안에 참값이 들어간다는 의미(빈도주의적 해석).

실무

  • AUC 0.92 (95% CI 0.88–0.95)처럼 표기.
  • 구간이 넓으면 샘플 수가 적거나 분산이 크다는 신호.
Bootstrap
재표집으로 CI 추정

Bootstrap

방법

  • 원래 데이터에서 복원 추출로 N개 표본을 만든다. 이걸 1000번 반복해 통계량 분포를 구한다.

장점

  • 분포 가정 없이 CI를 구할 수 있다.

주의

  • 표본 자체가 편향됐다면 bootstrap CI도 편향됩니다.
Youden J
민감도+특이도-1이 최대인 threshold

Youden J

정의

  • J = TPR − FPR = 민감도 + 특이도 − 1.

사용

  • J가 최대가 되는 threshold를 선택하면 민감도와 특이도 균형이 잡힙니다.

의료 맥락

  • 스크리닝 목적에서 기본 임계값으로 자주 쓰입니다.
Brier Score
확률 예측의 제곱오차

Brier Score

정의

  • Brier = mean((p_i − y_i)^2), y∈{0,1}.

해석

  • 낮을수록 좋음. 0=완벽, 0.25=무의미 예측(모두 0.5 예측).

왜 중요한가

  • AUC만 높으면 순위만 맞다는 뜻. Brier가 낮아야 확률값 자체가 의미 있습니다(calibration).
Cohen's d
두 그룹 간 효과 크기

Cohen's d

정의

  • d = (μ1 − μ2) / pooled_SD.

해석 규칙

  • 0.2 작음, 0.5 중간, 0.8 큼.

활용

  • violin plot에서 subtype 간 차이의 크기를 한 숫자로 요약할 때.
FDR / BH correction
다중 비교 보정

FDR / BH correction

문제

  • 유전자 2만 개를 t-test로 각각 비교하면 우연히 유의한 것이 많이 나온다(p<0.05에서도 5%가 false positive).

Benjamini-Hochberg

  • p-value를 정렬한 뒤 rank 기반으로 보정해 기대 FDR(False Discovery Rate)를 제어.

실무

  • 보통 FDR < 0.05 또는 0.10 기준으로 필터링합니다.
Cross-Validation (k-fold, stratified, nested)
교차검증 유형

Cross-Validation (k-fold, stratified, nested)

k-fold

  • 데이터를 k개로 나눠 (k-1)에서 학습, 1에서 평가. 이걸 k번 돌려 평균.

stratified

  • fold별로 클래스 비율을 원본과 같게 유지. 불균형 데이터에서 필수.

nested

  • 하이퍼파라미터 탐색(inner fold)과 최종 평가(outer fold)를 분리. 정직한 성능 추정을 위해 필요.
Class Imbalance / Balanced Accuracy
불균형과 균형 정확도

Class Imbalance / Balanced Accuracy

class imbalance

  • 한 클래스가 다른 클래스보다 훨씬 많은 상황(예: 85% vs 15%).
  • 일반 accuracy는 다수 클래스를 외워만 해도 0.85가 돼 무의미.

balanced accuracy

  • (TPR + TNR) / 2. 두 클래스에 동등 가중치.

추가 팁

  • MCC, F1, ROC-AUC, PR-AUC와 함께 해석하는 것이 안전합니다.
Decision Threshold
양성 판정 기준값

Decision Threshold

정의

  • 모델 확률 p에 대해 p >= τ이면 양성이라고 부르는 τ 값.

기본값 0.5의 함정

  • 클래스 불균형이나 비용 비대칭이 있으면 0.5는 최적이 아닙니다.

실무

  • Youden J, 비용 함수 최소화, 또는 정책 기반으로 결정.
Feature Selection
유전자(특징) 선택 기법

Feature Selection

종류

  • filter: t-test, mutual information 등으로 각 유전자 점수 매김.
  • wrapper: greedy forward/backward로 실제 모델 성능 기준 탐색.
  • embedded: L1 regression, tree importance.

주의

  • feature selection을 CV 바깥에서 하면 leakage가 생깁니다. nested CV 내부에서 수행해야 정직합니다.
SHAP
모델 해석 값

SHAP

정의

  • Shapley value(게임이론)를 ML 예측에 적용한 해석 도구.

해석

  • 각 feature가 예측을 base에서 위/아래로 얼마나 밀었는지.
  • 모든 feature의 SHAP 합 + base = 실제 예측(덧셈 가능).

주의

  • 상관 feature끼리는 몫이 임의로 나뉘므로 개별 순위 신뢰는 과하게 하지 마세요.

생물학 (분자)

BRAF V600E
PTC에서 가장 흔한 돌연변이

BRAF V600E

정의

  • BRAF 유전자 600번 아미노산이 Valine(V)에서 Glutamate(E)로 바뀌는 점 돌연변이.

임상

  • cPTC의 40~60%에서 발견. BRAF-like subtype의 핵심 driver.
  • vemurafenib, dabrafenib 같은 BRAF inhibitor의 표적.

주의

  • V600E가 있어도 모두 공격적이지는 않습니다. TDS, dediff score와 함께 판단.
NRAS / HRAS / KRAS
RAS family 세 멤버

NRAS / HRAS / KRAS

정의

  • 세포 분열 신호전달을 시작하는 작은 GTPase 세 종류.

갑상선암에서

  • NRAS Q61R이 대표적. FVPTC, FTC에서 흔함.
  • RAS-like subtype의 driver.

치료

  • RAS 직접 표적은 오래 어려웠으나 최근 KRAS G12C inhibitor가 등장.
TDS (Thyroid Differentiation Score)
갑상선 분화 점수

TDS (Thyroid Differentiation Score)

정의

  • 정상 갑상선 기능 유전자(TG, TPO, SLC5A5 등) 발현 평균.

해석

  • 높으면 정상에 가까움, 낮으면 dedifferentiation.

출처

  • TCGA-THCA 논문(Cell, 2014).
BRS (BRAF-RAS Score)
BRAF vs RAS 축 점수

BRS (BRAF-RAS Score)

정의

  • 71개 유전자에서 BRAF-like와 RAS-like 중심의 차이를 반영한 축.

해석

  • 양수(+) → BRAF-like, 음수(−) → RAS-like.

용도

  • molecular subtype 연속 지표로 쓰입니다. 이 대시보드 전반의 핵심 축.

생물학 (조직학)

PTC / cPTC / FVPTC
유두암과 주요 변종

PTC / cPTC / FVPTC

PTC (Papillary Thyroid Carcinoma)

  • 갑상선암 중 가장 흔함(~80%).

cPTC (Classical PTC)

  • PTC의 classical 변종, 유두 구조 명확. BRAF V600E가 많음.

FVPTC (Follicular Variant PTC)

  • 유두 구조 대신 여포 구조. RAS-like에 가깝고 예후는 cPTC와 비슷하거나 더 좋음.
FTC / ATC / PDTC / MTC
기타 갑상선암 종류

FTC / ATC / PDTC / MTC

FTC

  • Follicular Thyroid Carcinoma. 여포암.

ATC

  • Anaplastic Thyroid Carcinoma. 미분화암. 극히 공격적, 생존율 낮음.

PDTC

  • Poorly Differentiated. 저분화, PTC와 ATC 중간.

MTC

  • Medullary Thyroid Carcinoma. 수질성. C-cell 기원이라 follicular-derived와 별도.

생물학 (일반)

Gene Expression
유전자 발현

Gene Expression

정의

  • DNA에서 mRNA가 전사되고 단백질로 번역되는 과정의 강도.
  • 실무에서는 mRNA 양을 측정한 값(RNA-seq count, microarray intensity)을 말합니다.

단위

  • TPM, FPKM (RNA-seq), log2 intensity (microarray).
mRNA / RNA-seq / Microarray
전사체 측정 기술

mRNA / RNA-seq / Microarray

mRNA

  • 단백질을 만들기 위해 DNA에서 복사된 중간 분자.

RNA-seq

  • mRNA를 cDNA로 바꿔 시퀀싱. 넓은 동적 범위, probe 없음.

Microarray

  • 미리 설계된 probe에 mRNA가 붙으면 형광 강도 측정. 저비용, 오래됐음.
Methylation / Beta Value
DNA 메틸화 측정

Methylation / Beta Value

methylation

  • CpG 부위에 붙는 메틸기(-CH3)의 정도. 유전자 발현을 끄는 대표 조절.

beta value

  • methylated / (methylated + unmethylated + offset), 0~1.
  • 0이면 완전 비메틸, 1이면 완전 메틸.
Mutation Types
돌연변이 종류

Mutation Types

missense

  • 아미노산 하나가 바뀜 (예: V600E).

nonsense

  • 중간에 stop codon 생성 → 단백질 잘림.

frameshift

  • 삽입/결실로 reading frame이 밀려 이후가 엉망.

splice site

  • intron/exon 경계 파괴, splicing 이상.
Log2 Fold Change
발현 변화의 로그 비율

Log2 Fold Change

정의

  • log2(A / B). A가 B의 2배이면 +1, 절반이면 −1.

왜 로그인가

  • 발현은 수십 배 차이가 흔하므로 로그로 펼쳐야 시각적 비교가 쉽고 통계도 안정.
Volcano Plot
변화 크기와 유의성 동시 보기

Volcano Plot

축

  • x: log2 fold change, y: -log10(p-value).

해석

  • 우상단·좌상단 점: 크게 변했고 통계적으로 유의함 → 관심 유전자.
  • 색으로 FDR 통과 여부를 구분하기도 합니다.
Heatmap / Clustering
히트맵과 군집화

Heatmap / Clustering

heatmap

  • 행=유전자, 열=샘플, 색=발현. 패턴을 눈으로 확인.

clustering

  • hierarchical(dendrogram) 또는 k-means로 비슷한 유전자/샘플을 묶음.

주의

  • 정규화(row z-score 등) 방식에 따라 보이는 패턴이 달라집니다.
Batch Effect / ComBat
기술 잡음과 보정

Batch Effect / ComBat

batch effect

  • 실험 일자·장비·시약 차이로 생기는 측정 편차.

ComBat

  • empirical Bayes 기반 보정 기법. batch 변수만 알면 적용 가능.

주의

  • batch와 관심 변수가 너무 얽혀 있으면 보정이 관심 신호까지 깎을 수 있습니다.

데이터 소스

TCGA / GEO / GDC
공개 유전체 데이터 저장소

TCGA / GEO / GDC

TCGA

  • The Cancer Genome Atlas. NCI/NHGRI 공동. 33개 암종의 multi-omics 공개.

GEO

  • NCBI Gene Expression Omnibus. 각 연구팀이 업로드한 공개 전사체 데이터 저장소.

GDC

  • Genomic Data Commons. TCGA 후속 공식 배포처. 표준화된 API로 raw/processed 데이터 접근.
PubChem / ChEMBL / DrugBank
화합물/약물 데이터베이스

PubChem / ChEMBL / DrugBank

PubChem

  • NIH 산하. 화합물 구조, 생물활성 데이터 광범위.

ChEMBL

  • EMBL-EBI. 약물성 화합물 위주, 표적과 활성값(pChEMBL) 풍부.

DrugBank

  • 승인약/실험약 정보. 임상/약동학 중심.

드럭 디스커버리

pChEMBL Value
활성값 로그 스케일

pChEMBL Value

정의

  • pChEMBL = -log10(IC50 또는 Ki [mol/L]).

대응표

  • pChEMBL 5 → IC50 10 μM
  • pChEMBL 6 → 1 μM
  • pChEMBL 7 → 100 nM
  • pChEMBL 8 → 10 nM
  • pChEMBL 9 → 1 nM

실무

  • 신약 후보로 보통 pChEMBL ≥ 7 수준을 기대합니다.
SMILES
화합물 문자열 표현

SMILES

정의

  • Simplified Molecular Input Line Entry System.
  • 원자·결합을 ASCII 문자열로 표현해 화합물 구조를 한 줄로 저장.

예시

  • aspirin: CC(=O)OC1=CC=CC=C1C(=O)O.

활용

  • 머신러닝 입력, 2D 구조 렌더링, 검색 키.
PDB / Structure-Based Drug Design
단백질 구조 기반 설계

PDB / Structure-Based Drug Design

PDB

  • Protein Data Bank. 단백질 3D 구조 저장소(X-ray, cryo-EM, NMR).

structure-based drug design

  • 표적의 결합 포켓 구조를 알면 도킹·자유에너지 계산으로 후보를 스크리닝.

한계

  • 구조가 있어도 동적 배치, 용매, 알로스테릭 효과는 포착하기 어렵습니다.
Druggability
표적이 약으로 공략 가능한가

Druggability

정의

  • 작은 분자(<500 Da)가 표적에 충분히 강하게 붙어 생물학적 효과를 낼 수 있는 정도.

판단 요소

  • 결합 포켓의 깊이/모양, 표면 소수성, 기존 ligand 유무.

점수

  • fpocket, SiteMap 같은 도구가 수치화합니다.
ADC (Antibody-Drug Conjugate)
항체-약물 접합체

ADC (Antibody-Drug Conjugate)

정의

  • 표적 세포 표면 단백질에 특이적인 항체에 세포독성 payload를 화학적으로 연결한 약.

장점

  • 종양 세포에 선택적으로 독성을 전달해 off-target을 줄임.

대표약

  • trastuzumab-emtansine (HER2+ 유방암), enfortumab vedotin.
Kinase / Protease / Phosphatase
효소 세 가족

Kinase / Protease / Phosphatase

kinase

  • 단백질/분자에 인산기를 붙이는 효소. BRAF, MAPK 등. 신약 표적으로 가장 인기.

protease

  • 단백질을 자르는 효소. HIV protease inhibitor가 대표 성공사례.

phosphatase

  • 인산기를 떼는 효소. kinase의 반대 역할.
Target Classification (Novel / Emerging / Validated)
표적 성숙도 분류

Target Classification (Novel / Emerging / Validated)

novel_target

  • 신규 발견, 공개 문헌/임상 근거 거의 없음. 발견 가치는 크지만 실패 위험도 큼.

emerging

  • 초기 증거(일부 논문, 초기 임상) 축적. 우리 데이터로 재확인이 의미 있음.

validated

  • 승인약 또는 후기 임상이 존재. 재현 중심.
Literature (PubMed)
문헌 근거 읽는 법

Literature (PubMed)

체크할 점

  • recency: 최근 5년 내 논문 비중이 높을수록 활발한 주제.
  • sample size: n=1000 이상의 대규모 연구에 가중치.
  • relevance: 갑상선 / THCA / PTC / FTC 등 키워드 매칭.

주의

  • 제목/초록만으로 판단하면 overclaim 논문에 속기 쉽습니다. 가급적 원문 method와 결론을 확인.

v3 추가 용어 (v3 additions)

Leakage curve (누출 곡선)
train leak이 성능을 얼마나 부풀리는가

무엇을 측정하나

  • 학습 데이터와 평가 데이터 사이의 겹침(sample leak)이 AUC를 얼마나 끌어올리는지 시뮬레이션한 곡선입니다.
  • x축은 인위적으로 넣은 leak 비율(0→100%), y축은 그에 따른 내부 AUC입니다.

읽는 법

  • leak=0%에서의 AUC가 진짜 성능에 가깝습니다.
  • leak을 조금만 넣어도 AUC가 급격히 오르면, 원래 실험도 우연한 겹침에 취약하다는 신호입니다.
  • 곡선이 완만하면 평가 설계가 leak에 robust.

주의

  • leakage curve는 시뮬레이션이며 실제 leak을 탐지하지는 않습니다. nested CV, group split과 함께 봐야 합니다.
Permutation null (순열 null 분포)
라벨을 섞어서 얻은 empirical p

정의

  • 라벨을 무작위로 <strong>섞은(permute)</strong> 뒤 같은 분류기를 학습/평가해 얻는 null AUC 분포입니다.

왜 쓰나

  • 이론적 p-value 가정(정규성, 독립성)이 흔들리는 고차원 n≪p 상황에서 분포-free로 유의성을 판정.
  • 실제 AUC가 null 분포의 상위 1%에 들어가면 p<0.01이라 말할 수 있습니다.

읽는 법

  • 히스토그램 중심은 0.5 근처여야 정상. 중심이 0.6 이상이면 파이프라인 내부에 leak 의심.

계산 비용

  • 보통 1,000~10,000회 permutation이 필요합니다. GPU 없이도 tabular면 충분합니다.
LODO (Leave-One-Dataset-Out)
한 코호트 통째로 빼고 평가

정의

  • Leave-One-Dataset-Out: 여러 코호트 중 하나를 통째로 테스트 셋으로 빼고, 나머지로만 학습합니다.

왜 중요한가

  • 같은 코호트 내 random CV는 batch-specific 신호까지 공유해 AUC가 과대 평가됩니다.
  • LODO는 실제 임상 배포 상황(새 병원, 새 플랫폼)에 가장 가깝습니다.

해석

  • LODO AUC < 내부 CV AUC면 <em>generalization gap</em>이 존재한다는 증거.
  • 여러 held-out 데이터셋의 평균·최소값을 함께 보고해야 정직합니다.

실무

  • 최소 3개 이상의 코호트가 있어야 LODO가 의미 있습니다.
Batch effect / Dataset identifiability
데이터셋을 맞히면 경고음이 울린다

정의

  • Batch effect: 실험 일자·장비·시약·파이프라인이 달라서 생기는 샘플 간 조직적 편차.
  • Dataset identifiability: 라벨(BRAF/RAS) 대신 데이터셋 이름을 타깃으로 같은 feature로 분류기를 학습했을 때의 AUC.

왜 경고 신호인가

  • dataset-prediction AUC가 0.99 같으면 feature가 생물학보다 어느 lab에서 찍었는지를 학습하고 있다는 뜻입니다.
  • 이 경우 BRAF 분류 AUC가 높아도 재현성이 낮습니다.

완화책

  • ComBat, harmony, RUV 등 보정 기법, 또는 robust feature(정규화 강한 유전자)만 선택.
Isotonic calibration / Platt scaling
확률 재보정 두 가지 방법

정의

  • 분류기의 출력 점수를 잘 맞는 확률로 다시 매핑하는 기법입니다.

Platt scaling

  • 점수에 sigmoid(A·score + B) 로지스틱을 적합. A, B 두 파라미터만 학습해 작은 데이터에서 안전.

Isotonic regression

  • 단조 증가 비모수 회귀. 더 유연하지만 샘플 수가 많아야 과적합 없음.

언제 쓰나

  • SVM, tree ensemble의 raw 점수는 확률처럼 사용하면 잘 안 맞습니다(Brier 큼).
  • reliability diagram 대각선에서 벗어나면 calibration 필요.

주의

  • calibration은 <strong>validation fold</strong>에서 적합해야지 training에서 적합하면 over-confident.
Decision curve analysis (DCA) / Net benefit
AUC 너머의 임상 유용성

정의

  • Net Benefit (NB) = TP/n − FP/n × (p_t / (1−p_t)).
  • 여기서 p_t는 threshold probability(환자·의사가 감내할 위험).

읽는 법

  • x축: 임계확률 p_t, y축: net benefit.
  • 모델 곡선이 Treat-all / Treat-none 두 기준선 위에 있는 구간에서 모델이 의사결정에 도움이 됩니다.

왜 AUC만으론 부족한가

  • AUC는 순위만 보지만 실제 임상은 어느 threshold에서 surgery·biopsy를 결정하는지가 중요합니다.
  • DCA는 오분류 비용 비대칭을 직접 반영합니다 (literature-reviewed: Vickers & Elkin 2006).
NPV / PPV at threshold
임상 운영점 지표

정의

  • PPV (Positive Predictive Value) = TP / (TP + FP): 양성이라고 말한 환자 중 진짜 양성 비율.
  • NPV (Negative Predictive Value) = TN / (TN + FN): 음성이라고 말한 환자 중 진짜 음성 비율.

왜 threshold가 필요한가

  • 확률 모델은 연속값을 뱉으므로, 실제 임상에서는 특정 cutoff에서 양·음을 가릅니다.

유병률 의존성

  • PPV/NPV는 prevalence가 바뀌면 같이 바뀝니다. 스크리닝(유병률 낮음) 환경에서 PPV가 뚝 떨어지는 이유.
  • sensitivity, specificity와 함께 reporting해야 오해가 없습니다.
Bethesda III/IV triage
indeterminate FNA 분류

Bethesda System

  • 갑상선 세침흡인(FNA) 세포검사 결과를 6단계로 표준화한 체계입니다 (literature-reviewed).
  • III (AUS/FLUS): atypia of undetermined significance. 악성 위험 ~10–30%.
  • IV (FN/SFN): follicular neoplasm. 악성 위험 ~25–40%.

왜 문제인가

  • 수많은 환자가 III/IV로 분류돼 진단 수술을 받지만, 실제로는 양성인 경우가 대부분입니다.
  • molecular triage가 NPV를 높이면 불필요한 갑상선절제 수술을 줄일 수 있습니다.

지표

  • Bethesda III/IV만 모은 sub-cohort의 surgery avoidance %가 핵심 KPI.
Log-rank test
KM 곡선 차이의 검정

정의

  • 두(또는 그 이상) 생존 곡선이 동일한지를 검정하는 비모수 방법.
  • 각 event 시점에서 관측/기대 event 수 차이를 카이제곱 형태로 합칩니다.

해석

  • p < 0.05면 두 군의 생존 분포가 통계적으로 다름.
  • effect size는 말해주지 않으므로 HR과 함께 reporting합니다.

가정

  • proportional hazards: hazard 비율이 시간에 걸쳐 일정해야 합니다. 곡선이 교차하면 log-rank의 검정력이 떨어집니다.
Concordance index (C-index)
생존 모델 ranking 지표

정의

  • 무작위로 뽑은 두 환자 pair 중 더 위험한 환자가 더 일찍 event를 겪는 비율.
  • 분류의 AUC를 생존 데이터로 일반화한 지표로 볼 수 있습니다.

해석

  • 0.5 = 무작위, 0.7–0.8 = 쓸만함, >0.8 = 좋음.
  • censoring 있는 pair는 비교에서 제외됩니다 (Harrell 1982, literature-reviewed).

주의

  • C-index는 <strong>calibration</strong>은 보지 않고 순위만 봅니다. 절대 위험이 맞는지는 Brier, calibration plot으로 별도 확인.
Cox proportional hazards
semi-parametric 생존 회귀

정의

  • h(t | x) = h0(t) × exp(β·x).
  • baseline hazard h0(t)는 비모수로 두고, 공변량 효과만 로그-선형으로 모델링.

장점

  • baseline 분포(Weibull 등)를 가정할 필요 없음.
  • exp(β)가 곧 Hazard Ratio (HR) → 해석 쉬움.

가정

  • proportional hazards: 공변량 효과가 시간에 걸쳐 일정. Schoenfeld residual로 검증.
  • 위반 시 time-varying coefficient 또는 stratified Cox로 보완.
Fixed vs random effect meta-analysis
이종성 처리 방식

Fixed-effect

  • 모든 연구가 동일한 진짜 효과 크기를 공유한다고 가정.
  • 연구 간 차이는 sampling error 뿐.

Random-effect

  • 각 연구가 자신의 진짜 효과를 가지며, 그 효과들이 분포(τ²)를 이룬다고 가정.
  • 코호트·플랫폼이 다르면 보통 random-effect가 정직합니다 (DerSimonian-Laird, literature-reviewed).

선택 기준

  • 연구가 근본적으로 비슷(동일 프로토콜, 동일 집단) → fixed.
  • 이질적 데이터(우리 THCA 상황처럼 GEO + TCGA 혼합) → random-effect 기본.
I² statistic
이종성 비율 정량화

정의

  • I² = max(0, (Q − df) / Q) × 100%.
  • 전체 분산 중 연구 간(between-study) 분산 비율(%)입니다.

해석

  • I² ≈ 25%: 낮음, 50%: 중간, 75%+: 높음 (Higgins 가이드라인, literature-reviewed).

왜 중요한가

  • I²가 높으면 단순 평균이 아닌 random-effect pooled estimate를 써야 합니다.
  • subgroup 분석이나 meta-regression으로 이종성 원인을 찾는 것이 다음 단계.

주의

  • 연구 수가 적으면 I² 추정 자체가 불안정합니다. CI를 같이 보고하세요.
Cochran Q test
이종성의 유의성 검정

정의

  • 여러 연구 효과 크기가 같은가를 검정. 귀무가설 H0: 모든 θ_i 동일.
  • 통계량 Q = Σ w_i (θ_i − θ̂)²는 자유도 k−1의 카이제곱 분포를 따릅니다.

해석

  • p < 0.1이 관례적 이종성 기준(일반 0.05보다 느슨).
  • 유의하면 random-effect 모델로 전환.

한계

  • 연구 수가 적으면 검정력 부족, 많으면 사소한 차이도 유의해집니다. 그래서 I²와 세트로 해석합니다.
Statistical power (통계적 검정력)
1 − β의 의미

정의

  • power = 1 − β = P(유의 결과 | 효과가 실제로 존재).
  • 진짜 차이가 있을 때 발견할 확률입니다.

관례

  • 0.80 (=80%)이 표준 목표, 0.90이 엄격 목표.

결정 요소

  • 효과 크기 (Cohen’s d), 표본 수 n, 유의수준 α, 양측/단측 여부.

왜 미리 계산해야 하나

  • post-hoc power는 의미가 적습니다. 사전 power analysis로 n을 맞추지 않으면 음성 결과를 "효과 없음"으로 잘못 해석할 수 있습니다.
  • meta-analysis power는 study 수와 τ²에 의해 결정됩니다.
ssCMap / connectivity score
화합물 reversal 점수

정의

  • ssCMap (single-sample Connectivity Map): 한 환자의 disease signature와 수천 개 화합물의 유전자 발현 지문을 비교해 얻는 상관 점수.
  • 점수가 음수(−)일수록 질병 시그니처를 뒤집는 화합물(=후보 치료제).

해석

  • 양수(+)는 질병을 <em>강화</em>하는 방향 → off-target 위험 신호.
  • 절대값이 0.3 이상이면 신호로 간주하는 것이 일반적.

근거

  • CMap(Lamb 2006), L1000 landmark 978 유전자 기반 확장판(literature-reviewed).

한계

  • in vitro(HA1E, A549 등) 세포주 데이터 기반이라 갑상선 특이도는 직접 실험 검증 필요.
PPI (protein-protein interaction)
단백질 상호작용 그래프

정의

  • 단백질 A와 B가 물리적으로 결합하거나 신호전달에서 상호작용하는 관계를 간선(edge)으로 표현한 네트워크.

노드와 간선

  • 노드: 단백질(=유전자).
  • 간선: STRING, BioGRID 등에서 수집한 상호작용. 점수(confidence)가 0–1로 표시됩니다.

쓰임

  • driver 주변의 hub 단백질을 찾거나, 신약 표적의 downstream 네트워크를 이해하는 데 씁니다.

주의

  • 문헌 편향이 큽니다: 연구가 많이 된 단백질일수록 간선이 많아 보입니다. 신규 단백질이 hub가 아니라는 보장은 없음.
Dedifferentiation axis / dediff proxy score
갑상선암 진행의 생물학 축

개념

  • 갑상선 세포는 정상에서 PTC → 저분화(PDTC) → 미분화(ATC)로 가면서 <strong>갑상선 기능 유전자</strong>(TG, TPO, SLC5A5, TSHR 등)가 꺼집니다.
  • 이 상실 정도를 한 축으로 표현한 것이 dedifferentiation axis입니다.

dediff proxy score

  • TDS(Thyroid Differentiation Score)의 역방향 또는 ATC/PDTC 시그니처 기반 점수로 근사.
  • 높을수록 정상에서 멀어져 더 공격적인 표현형.

임상 함의

  • RAI (방사성요오드) 치료 반응은 분화가 유지돼야 좋습니다. dediff 높으면 RAI-refractory 가능성.
  • BRAF V600E + 높은 dediff 조합은 예후 감시 대상.
