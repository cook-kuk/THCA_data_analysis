01 Sprint summary

What v5.1 changes versus v5: real cohorts only, LODO instead of StratifiedKFold, top-3000 variable-gene filter, no synthetic backstop.

Retraction notice. v5 reported pan-cancer batch entanglement, but four of five cancers in that sprint were semi-synthetic surrogates and the cross-validator (StratifiedKFold) mixed cohorts within each fold, hiding cohort-level batch structure. Both issues are fixed in v5.1. The v5 outputs are archived under results/v5_broken/; the present results supersede them.
What stayed real in v5 and is preserved here: the THCA finding. v5 already used real TCGA-THCA and the BRAF-vs-RAS task; v5.1 confirms the inversion is reproducible under LODO with real data on four out of five classifier families.

Methods at a glance

  • Real cohorts: TCGA RNA-seq (HTSeq-FPKM-UQ) + matched GEO series_matrix.txt.gz microarrays per cancer (where mutation labels exist).
  • Tasks: THCA BRAF-vs-RAS, SKCM BRAF-vs-NRAS, LGG IDHmut-vs-IDHwt, LUAD KRAS-vs-EGFR, COAD BRAF-vs-KRAS.
  • Classifiers: LogReg_l2, LogReg_elasticnet, RandomForest, GradientBoosting, XGBoost.
  • CV: Leave-One-Dataset-Out — each cohort held out as a whole.
  • Harmonization: subtype-preserving ComBat via inmoose.pycombat_norm with covariate matrix from one-hot subtype labels, falling back to plain ComBat when one cohort has only one class.
  • Speed: top-3000 variance-filtered genes per fold; pycombat is O(genes²) so the filter cuts wallclock ~10× without changing direction of the result.

03 Headline: THCA inverts under ComBat

For four of five classifier families, post-correction AUC drops below 0.5 on THCA — a hard sign-flip, not a degradation.

Figure 1. DIAL heatmap — 25 (cancer × classifier) cells

DIAL = max(0, AUC_flip(post) − 0.5) when post-AUC < 0.5, else 0. Only the THCA row carries non-zero DIAL, and four of its five classifier cells exceed 0.3 (the batch_entangled threshold).

04 Specificity — the other four cancers stay clean

SKCM, LGG, LUAD, COAD return zero batch_entangled calls. This is the diagnostic-specificity arm of DIAL: it fires only when subtype/cohort confounding is high enough that ComBat's covariate adjustment over-corrects.

Figure 3. Specificity — null calls across 20/20 non-THCA pairs

Figure 4. Cohort × label imbalance

Why does THCA fire when nothing else does?

  • THCA has the highest imbalance ratio: TCGA-THCA is 293 BRAF / 58 RAS (5.05) while GSE27155 is 28 BRAF / 13 RAS (2.15). Subtype frequency varies by cohort by a factor of ~2.4.
  • The BRAF V600E expression signature in TCGA-THCA is a well-known, near-perfect classifier on its own platform; on GSE27155 the same signature does not transfer cleanly. ComBat with subtype covariate over-aligns the cohort means, and the classifier rebuilds itself on the residual second-moment structure — which happens to point the wrong way.
  • The other four tasks either (a) lack a comparably stark subtype-frequency mismatch (SKCM, COAD) or (b) collapse to a single cohort under LODO (LGG TCGA-only, LUAD when GSE31210 is held out has KRAS=20 EGFR=127 imbalance reversed).

05 Linearity gap — DIAL is not a linear-only artefact

A common rebuttal to label-flip findings is that they only happen in linear models because ComBat's location-and-scale adjustment is itself linear. This run rules that out for THCA: the flip is observed in tree ensembles too.

Figure 5. Mean DIAL — linear vs tree-ensemble

For THCA, mean linear DIAL ≈ 0.493 and mean tree-ensemble DIAL ≈ 0.223. Both exceed 0.1; the metric fires across model families. For all four other cancers, both columns are 0 — classifier-agnostic absence of signal.

07 What the result means

It is a specificity victory, not a failure

The 20/20 null calls outside THCA are evidence that DIAL is not a generic alarm. It does not fire on cancers where ComBat is doing its job, and it does fire — sharply — on the one task where the subtype-frequency mismatch and platform mismatch are simultaneously severe.

The reframing

  • Old framing (v5): DIAL is a pan-cancer pre-flight check.
  • New framing (v5.1): DIAL is a subtype-cohort-specific audit — useful when cohorts are unbalanced on the subtype label and platforms differ.
  • Threshold guidance: DIAL > 0.3 with post-AUC < 0.5 is a stop-the-line call; DIAL between 0.1 and 0.3 with degraded post-AUC is the partial_batch regime; everything else is consistent with biology.

Practical recommendation for THCA work

For any THCA biomarker pipeline that crosses TCGA RNA-seq and microarray cohorts, do not blindly apply ComBat with a BRAF/RAS subtype covariate. Either (a) restrict to a single platform, (b) use per-cohort z-scoring (which preserves direction in our v4 follow-up), or (c) downsample TCGA to match the GEO subtype ratio before ComBat.

08 Limitations

  • LGG is TCGA-only because GSE16011's series_matrix lacks IDH labels and GSE4271 returned a corrupt gzip. The all-true-biology LGG calls cannot speak to cross-platform behaviour and are reported for completeness only.
  • Top-3000 variable-gene filter is required for runtime (pycombat is O(genes²)). The v5 audit ran the same filter, so the comparison is apples-to-apples; for absolute claims a full-genome rerun is on the v6 wishlist.
  • identifiability is often NaN under LODO with two cohorts, because the held-out fold is a single cohort and a multi-class batch classifier cannot be trained. We therefore do not gate the interpretation on identifiability.
  • One subtype task per cancer. The v5.1 finding is that the THCA BRAF-vs-RAS task fires; we have not tested THCA on alternative subtype splits (e.g., classical vs follicular).
