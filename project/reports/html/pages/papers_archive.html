DIAL — Bioinformatics (OUP)

Original Paper · 2026-04-25

DIAL: a direction-invariant audit metric for batch correction, and what happens when ComBat is fit before the cross-cohort split

Seungho Kuk · Independent research, Seoul · kukshomr@gmail.com

We introduce DIAL (Direction-Invariant AUC Leakage) and a per-fold ComBat protocol. On a five-cancer LODO matrix, the natural-but-leaky practice of fitting ComBat on full pooled X before the LODO split produces a sharp ``thyroid-specific'' batch-entanglement pattern (4-of-5 classifiers, DIAL up to 0.494). Refactoring ComBat to be fit per fold returns DIAL = 0 across all 25 cells, including all five thyroid rows (ΔDIAL = −0.494 on LogReg-ℓ₂). DIAL functioned as designed: it diagnosed the evaluation leakage rather than ratifying it.

v5.2 corrected pipeline — proper per-fold ComBat

Audit fix and corrected DIAL table.

A 200-line LinearComBat.fit/transform module replaces the inmoose.pycombat_norm one-shot call inside the LODO loop. ComBat parameters γgb, δgb, αg, βg are estimated on the training cohort only; the held-out cohort is centered locally without using its labels. Under this protocol, every cell of the 5-cancer × 5-classifier matrix returns DIAL = 0; THCA AUCpost moves from 0.006 → 0.995 on LogReg-ℓ₂ (ΔDIAL = −0.494). No other cancer changes its interpretation call.
