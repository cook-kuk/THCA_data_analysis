💡 이 페이지 읽는 법

이 페이지는 바이오마커 리스트를 기능적으로 해석하는 3개 층입니다.

  • 경로 농축 (Pathway ORA) — BRAF-up / RAS-up 유전자 집합이 16개 선별 경로와 유의하게 overlap하는지 하이퍼지오메트릭 검정으로 확인. dot 크기=fold enrichment, 색=-log10(q).
  • 면역 시그니처 — 면역 세포별 마커 유전자 z-score 평균을 샘플 점수로 사용 (ssGSEA-유사). BRAF_like vs RAS_like 분포를 violin + Mann-Whitney U로 비교.
  • 메틸레이션 분류기 — GSE97466 (n=141) 상위 변동 프로브 5,000개에서 tumor vs normal 5-fold CV + 800-iter bootstrap AUC CI. 이 데이터셋은 molecular subtype 라벨이 없어 histology-proxy(종양/정상)를 사용합니다.

소표본 · 면역 deconvolution이 아닌 marker-gene proxy · 외부 메틸레이션 platform 차이 — 각 섹션 caveat 참조.

① 경로 농축 (Pathway enrichment · ORA)

방법: 하이퍼지오메트릭 검정 + BH 보정. Universe = TCGA DE 스캔에 포함된 51711 유전자. BRAF-up = log2FC>0 & FDR<0.05 (10622개), RAS-up = log2FC<0 & FDR<0.05 (9824개), Novel = 검증된 신규 마커 (2773개). 경로 세트는 MSigDB Hallmark(해당 subset 손코딩) + 갑상선 분화/탈분화 문헌 기반.
BRAF-like: 단백분해효소 · 염증 · BRS-up · BRAF-like RAS-like: TDS core · BRS-up · RAS-like · 갑상선 분화
해석 한 줄: BRAF-like에서는 MAPK 출력 + 면역 exhaustion 신호가 강화되고, RAS-like는 TDS + thyroid lineage 분화가 유지됩니다. 노트: 경로 세트는 손선택 subset이며, full MSigDB C2/C5는 아닙니다. Fold enrichment는 universe 선택(51,711개 DE-tested 유전자)에 의존합니다.

② 면역 세포 시그니처 (Immune cell signatures)

방법: 각 시그니처의 마커 유전자 log2 발현을 샘플 축으로 z-score한 뒤 평균(ssGSEA-유사, reference matrix 기반 CIBERSORT/xCell가 아님). TCGA-THCA 572개 샘플 (BRAF_like 442, RAS_like 119). 각 시그니처별 Mann-Whitney U + Cliff's delta.
조절 T세포: BRAF↑ (δ=+0.59, p=5.6e-23)IFN-γ 반응: BRAF↑ (δ=+0.53, p=1.3e-18)대식세포 M1: BRAF↑ (δ=+0.50, p=9.9e-17)
정직한 한계: 이것은 marker gene 평균 proxy입니다. 실제 면역 세포 분율을 reference matrix로 decompose하는 CIBERSORT/xCell과는 다르며, 종양 부정수 유전자가 면역 마커와 co-express할 경우 bias가 발생할 수 있습니다. 신호가 약한 시그니처(n_markers < 5)는 결과가 더 불안정합니다.

③ 메틸레이션 분류기 (GSE97466 validation)

방법: GSE97466 상위 변동 프로브 5,000개 β-value → stratified 5-fold CV (LogReg + RandomForest) → 800-iter bootstrap AUC 95% CI. 라벨 = tumor vs normal (이 데이터셋에는 BRAF/RAS mutation label이 없어 histology proxy를 사용).
n = 141 (74 tumor, 67 normal) LogReg AUC = 0.979 (95% CI 0.95-1.00) RF AUC = 0.967 (95% CI 0.94-0.99)
정직한 한계: (1) n=141은 여전히 작고 특히 tumor 아형 비율이 고르지 않음 (cPTC가 다수). (2) 라벨이 tumor vs normal histology proxy이기 때문에 BRAF vs RAS 같은 분자 이분법은 이 섹션에서 평가하지 않음. (3) 450K (GPL13534) 플랫폼은 TCGA-THCA의 Illumina 플랫폼과 normalization/probes 구성이 다르며, 교차 적용 시 batch 효과가 크다. (4) mRNA(TCGA)와 methylation(GSE97466)은 서로 다른 환자 집단으로 직접 환자-수준 비교는 불가; 여기서는 standalone 외부 유효성 시험으로만 해석.

참고 · 경로 세트 출처

경로 세트는 인터넷 fetch 없이 이 파일 안에 손코딩되어 있으며, 다음 출처의 subset입니다:

  • MSigDB Hallmark (Liberzon et al., Cell Syst 2015; PMID 26771021) — Hallmark_MAPK, Hallmark_PI3K_AKT_MTOR, Hallmark_EMT, Hallmark_Apoptosis, Hallmark_Inflammatory_Response.
  • Thyroid differentiation score (TDS) — TCGA PTC (Cell 2014, PMID 25417114). TDS 16-gene core + BRS-up/down surrogate.
  • Dedifferentiation & aggressive signatures — Landa et al. J Clin Invest 2016 (PMID 27240834), Xing Endocr Rev 2013.
  • Immune checkpoint / exhaustion — Thorsson et al. Immunity 2018 (PMID 29628290); Tirosh et al. Science 2016 (PMID 27124452).
