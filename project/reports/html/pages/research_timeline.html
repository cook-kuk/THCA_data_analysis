분석. ① Welch t-test + BH-FDR discovery (log2FC = mean(BRAF) − mean(RAS)). ② 외부 코호트별 replication: fold-change sign 일치 + p < 0.05. ③ 필터: FDR < 0.05, |Cohen's d| > 0.5, median TCGA log2 > 1, ≥2 코호트 presence, replication_rate ≥ 1. ④ Feature set 3종 — TDS16(16-gene thyroid differentiation), TierA67(67-gene composite), variance-top50. 최종 패널: 54-gene LogReg elastic-net. ⑤ 분류기 sweep: LogReg_l2, LogReg_elasticnet, LinearSVC, RandomForest, GradientBoosting, XGBoost. ⑥ ChEMBL target 매핑 + CMap L1000 reversal + PubMed anchoring으로 target → compound shortlist.

결과. 2,773 replicated biomarker. Top novel: TACSTD2(d=+2.52), TMPRSS4(+2.09), PLEKHA6(+2.22), CYP1B1(+2.22), LDLR(+2.02), GABRB2(+2.24), B3GNT3(+2.02), PTPRE(+2.26). Top known replicated: SERPINA1, KCNN4, DCSTAMP, KRT19, LGALS3, MET, TIMP1. 54-gene 패널 — TCGA 5-fold AUC 1.000(95% CI 1.000–1.000), PR-AUC 1.000, balanced accuracy 1.000. External GSE126698 TierA67 RandomForest AUC 1.000; GSE27155 variance_top50 LogReg_elasticnet AUC 0.980. 8 druggable target · 15 compound · 27 literature record.

데이터.v2와 동일한 코호트(TCGA-THCA train + GSE27155, GSE126698, pooled GPL570(GSE33630+GSE29265), GSE76039 외부) + dataset-identifiability 측정용 코호트 라벨을 명시적으로 추가. PRJEB11591(Yoo et al. 2016)을 primary external로 시도했으나 처리된 count 획득 실패 → proxy로 대체(투명하게 기록).

목적.v2에서 보고된 "TCGA-internal AUC = 1.00"이 실제로 외부 코호트에서도 일반화되는가를 permutation-calibrated로 검증. 동시에 "외부 AUC 숫자 중 얼마가 platform/batch에서 기인하는가"의 상한을 측정 — honest-audit framing 확립.

분석. ① elastic-net LogReg(TierA67_clean_no_MAPK feature set) 학습. ② 외부 코호트에 isotonic recalibration 적용(TCGA score에 fit, 외부에 apply). ③ Permutation null 10,000회 — 라벨 셔플링으로 null AUC 분포 생성. ④ LODO(Leave-One-Dataset-Out) 평가 — 외부 2개 홀드아웃. ⑤ Dataset identifiability macro-AUC (D1) — One-vs-Rest LogReg로 코호트 자체를 예측 — 1.00이면 platform/batch만으로 코호트 100% 식별 가능. ⑥ BRS71 Recovery — proxy 71-gene과 Cell 2014 원본(72 gene) 겹침 = 1 gene(1.4%) → proxy replace 결정. ⑦ Honesty checklist(6-check) 초안.

결과. Best external AUC = 1.000(95% CI 1.000–1.000) on GSE27155(n=41), permutation null 평균 0.469, p < 0.001. D1 macro-AUC = 1.000 → 플랫폼만으로 코호트 완벽 식별. Post-isotonic bACC = 0.500 — 모든 외부 score가 단일 bucket으로 붕괴 = 분포 shift의 직접 증거. LODO 평균 AUC 0.870 — 외부 일반화는 존재하지만 내부 AUC 대비 드롭 명백. BRS71 recovery: proxy 대체.

의미. "외부 AUC 1.00은 임상 일반화의 증거가 아니다." D1=1.00과 bACC 붕괴는 apparent external AUC의 일부가 platform/batch에서 기인함을 직접 시사. 올바른 framing은 "retrospective computational triage / decision-support prototype"이며, 모든 외부 AUC는 상한으로 읽어야 함. 이 감사가 v4 ComBat rescue 시도의 동기.

판정 (batch leakage upper bound revealed). 외부 일반화 주장이 배치 누수 상한으로 묶여 있음을 수치로 공개.

데이터. TCGA + GEO 실 데이터만 — THCA(n=392: TCGA-THCA + GSE27155 · 321 BRAF : 71 RAS), SKCM(n=212: TCGA-SKCM + GSE22153), LGG(n=142: TCGA-LGG TSS 4-split · 116:26), LUAD(n=236: TCGA-LUAD + GSE31210 · 91:145), COAD(n=372: TCGA-COAD + GSE39582 · 76:296). shared-gene intersection 9,179(SKCM) ~ 20,964(LGG), variance-top-3000 gene pool per cancer. Semi-synthetic 제거.

목적.v5의 StratifiedKFold + semi-synthetic pipeline이 cohort leakage로 pre-AUC를 inflate했음을 인정하고, LODO + real data로 재실행하여 batch-subtype entanglement의 실제 일반성을 재평가. 가설: 만약 일반 현상이면 여러 암종에서 flip이 반복되고, 특이 현상이면 THCA에만 국한될 것.

분석. ① LODO(leave-one-dataset-out) — n-1 코호트로 학습, 1 코호트 홀드아웃. ② ComBat fit은 train 코호트에서만 → held-out에 apply(평가 단계). ③ DIAL(Direction-Invariant AUC Leakage) = max(a, 1−a) − 0.5 when AUC_post < 0.5 else 0. 방향이 뒤집혀도 magnitude를 잡는 diagnostic probe. ④ LODO 하에서는 ident gate 제거(held-out cohort가 ident target이므로 정의상 무의미) → rule: DIAL > 0.3 → batch_entangled, DIAL ≤ 0.1 AND auc_post > 0.7 → true_biology, DIAL ≤ 0.1 AND auc_post < 0.6 → no_signal, 나머지 ambiguous. ⑤ 5 cancer × 5 classifier(LogReg_l2 / LogReg_elasticnet / RandomForest / GradientBoosting / XGBoost) = 25 조합.

결과. 25 조합 중 4개만 batch_entangled — 모두 THCA. LogReg_l2 DIAL 0.494 (AUC_pre 0.994 → post 0.006), LogReg_elasticnet DIAL 0.492 (0.994 → 0.008), RandomForest DIAL 0.323 (0.996 → 0.177), GradientBoosting DIAL 0.334 (0.750 → 0.166). XGBoost만 non-flip (0.781 → 0.487) — tree-ensemble 비선형성이 ComBat의 선형 projection을 깬 것으로 해석. 다른 4개 암종 20개 조합 = 0 flip. LGG 5/5 true_biology · COAD 5/5 true_biology · LUAD true_biology + no_signal mix · SKCM ambiguous + no_signal. 즉 DIAL은 "모든 암종에서 false alarm을 내는 탐색기"가 아님.

왜 THCA만 그런가 (3 조건 동시 충족 가설).

  1. Strong label-cohort correlation. TCGA-THCA 293 BRAF : 58 RAS, GSE27155 28 : 13 — 두 코호트가 같은 majority skew · 같은 minority class 공유. subtype-preserving ComBat이 subtype 축과 cohort-mean을 구별 못함.
  2. BRAF-vs-RAS biology projects onto low-rank linear axis. PTC의 MAPK-on vs MAPK-off 구분이 3,000-gene variance pool에서 단일 variance component로 잡힘 → ComBat이 빼는 cohort-mean 방향과 일치.
  3. Classifier fits residual batch signal. biology가 mean-shift으로 지워진 뒤, 선형 분류기(LogReg_l2/elasticnet)가 남은 batch 방향을 latch → 방향이 뒤집힘.

다른 암종은 이 3조건 중 최소 하나를 위반. LGG는 4 TSS split이라 cohort-mean이 IDH 축과 정렬 안 됨(5/5 true_biology). SKCM은 pre-ComBat AUC가 이미 0.49–0.70으로 낮아 뒤집을 방향 자체가 없음. COAD는 극단적 class 불균형(76:296)이지만 subtype 축이 cohort와 정렬 안 됨. LUAD도 flip 영역 미도달.

의미. DIAL은 specificity evidence를 가짐 — THCA에서 정확히 fire하고 다른 암종에서 silent. false-positive detector가 아니고, method generalization failure도 아니다. 동시에 THCA 자체의 BRAF-vs-RAS 분류는 선형 ComBat 조합에서 신뢰할 수 없음을 실증. 비선형 보정 · cohort-free feature pool · 또는 블라인드 외부 코호트가 필요. 프로토타입의 deployment framing은 유지: retrospective computational triage, 진단 기기 아님. 향후 외부 검증 코호트 평가가 필요합니다.

판정 (CURRENT · THCA-specific specificity evidence). DIAL probe는 일반화되며, label-flip regime은 THCA에 특이적. Prospective cohort validation pending.

Caveat — scope of all versions

THYRAI v2 ~ v5.1은 전부 retrospective computational triage / decision-support prototype. 공공 코호트 후향적 분석이며, 어떠한 버전도 임상 진단 기기가 아니고 의학적 조언이 아님. v5.1의 "THCA-specific label-flip"은 computational finding이며, 추가적인 외부 코호트 검증 없이는 임상적 일반화를 주장할 수 없습니다.
