Methodology summary

Feature set: Leakage-clean TierA67_clean — driver-gene (BRAF, NRAS, HRAS, KRAS, RET, PAX8, NTRK etc.) 제거된 67-gene panel. Comparison panels: TDS16, TierA67, variance_top50.
CV: 5-fold stratified, scikit-learn LogReg_l2 · LogReg_elasticnet · RandomForest · GradientBoosting · XGBoost, bootstrap n_iter=1000으로 95% CI.
External: GSE27155 (microarray, n=72) + GSE126698 (microarray, n=12) + GSE213647 (skipped_no_eligible_samples_or_features). Youden threshold는 TCGA fold-wise average로 고정 후 외부에 적용.
Calibration: Brier score + reliability curve (see ML baseline page).
Threshold: Youden’s J on TCGA; balanced_accuracy_youden이 cohort-transportable 지표.
  • z-score는 dataset-level에서 수행 (global z-score는 leakage 유발).
  • DE는 limma-voom backend, FDR < 0.05, |log2FC| > 1.

Honest ML verdict

Classical LogReg 승리 · MLP 동률 · Quantum VQC 패배

  • Internal: LogReg_l2 on TierA67_clean = AUC 1.000 (CI 1.000–1.000), PR-AUC 1.000, Brier 0.00171.
  • Internal: LogReg_l2 on TDS16 = AUC 0.996 (CI 0.990–0.999) — compact panel이 큰 panel과 사실상 동일.
  • External GSE27155: TierA67_clean LogReg_elasticnet AUC 0.978, LogReg_l2 AUC 0.968 — 둘 다 정상.
  • External GSE126698: TierA67 LogReg_elasticnet AUC 1.000, LogReg_l2 AUC 0.889 — n=12이라 variance 큼.
  • MLP (PyTorch): internal AUC 0.99+이지만 외부에서 LogReg와 tie, 외부 overfitting 경향 관찰.
  • Quantum VQC: internal 0.8 대 middling, 외부 0.6~0.7. Hardware-efficient ansatz로는 baseline에 못 미침.

Methodology caveats

⚠ 3 things to read before citing these numbers

  1. Label proxy: external BRAF_like / RAS_like 라벨은 TCGA-derived score로 transfer된 것이라서 엄밀한 분자 라벨이 아닙니다. ground truth는 TCGA에만 존재.
  2. Small external n: GSE27155 n=72, GSE126698 n=12. 95% CI가 넓고 (예: GSE126698 0.41–1.00), 단일 데이터셋 AUC는 직접 일반화 불가.
  3. Dataset-level z-score: feature scaling은 코호트 내부에서만 수행해 leakage를 방지했습니다. Global z-score는 의도적으로 피했습니다.
