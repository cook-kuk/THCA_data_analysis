BRAF-like vs RAS-like는 갑상선암의 분자적 2분법입니다. BRAF V600E 돌연변이가 있는 종양은 MAPK 신호가 강해 탈분화되고, RAS(KRAS/NRAS/HRAS) 돌연변이 종양은 상대적으로 분화 상태를 유지합니다. 두 그룹 사이에서 mRNA 발현이 유의하게 다른 유전자 = 후보 바이오마커입니다.

아래 4개 그림은:

  • Volcano = x축 effect size, y축 유의성. 오른쪽 위 = BRAF_like에서 많이 올라감, 왼쪽 위 = RAS_like에서 올라감.
  • Replication scatter = TCGA에서 본 effect가 외부 코호트에서도 같은 방향으로 나타나는지. 대각선 위에 있는 점일수록 재현 강함.
  • Known vs Novel heatmap = 기존 알려진 마커 + 이번에 새로 찾은 후보들의 발현 패턴 히트맵.
  • Effect vs Coverage = 효과 크기 × 탐지 가능한 코호트 수. 오른쪽 위 = 범용 + 강력.
