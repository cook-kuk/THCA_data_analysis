§0 · OVERVIEW & DATA FLOW

무엇을 · 어디서 · 왜 · 어떻게 · 어디로.

v12는 THYRAI의 기존 파이프라인 산출물(로컬 TSV)을 입력으로 받아, 이것을 외부 공공 데이터 소스(PubMed E-utilities, ClinicalTrials.gov v2 API, 5개의 primary 논문에서 추출한 reference gene lists)와 교차해 문헌 기반 검증 테이블/리포트를 생성합니다. 어떤 숫자도 "어디서 왔는지 모르는 숫자"가 되지 않도록 각 섹션에 Data provenance 블록을 배치하고, 섹션 간 흐름은 ↑ INPUT / → OUTPUT 칩으로 연결했습니다.

Data provenance

Local inputs: results/tables/biomarker_validated.tsv (from THYRAI v3 discovery), results/tables/drug_discovery_compounds.tsv (from v7), results/v7_repurposing/v7_drugcentral_filtered.tsv (from v7 DrugCentral pull), results/v5/v5p1_table1_summary.tsv (from v5.1 DIAL audit).
External APIs: PubMed E-utilities at https://eutils.ncbi.nlm.nih.gov/entrez/eutils/{esearch,efetch}.fcgi · queries throttled to 0.34s (3 req/s, no API key) · User-Agent "thyrai-v12 (kukshomr@gmail.com)". ClinicalTrials.gov v2 at https://clinicaltrials.gov/api/v2/studies with query.cond and query.intr filters.
Reference gene lists: 5 sets hand-curated from primary literature (Chakravarty 2011 JCO, Landa 2016 JCI, TCGA 2014 Cell, Yoo 2019, Costa 2015 Oncotarget) — stored per-list in results/v12_literature/crosscheck/reference_gene_lists/*.tsv.
Orchestrator: notebooks_or_scripts/v12_literature.py (단일 Python 스크립트, no build, biopython 미사용 — raw XML regex 파싱으로 의존성 최소화).
Log: logs/v12_literature.log. Build index: results/v12_literature/v12_index.json.

How each section connects

  • §A Biomarker landscape takes biomarker_validated.tsv and compares it to 10 reference lists (5 expression panels + scRNA + drivers + COSMIC + OncoKB + DisGeNET) → outputs biomarker_overlap_matrix.tsv. Feeds §C (which uses the same gene set) and §I (paper integration).
  • §B PubMed profiles takes the 8 druggable targets (from drug_discovery_compounds.tsv) and queries PubMed → outputs per-target _summary.md + targets_literature_summary.tsv. Feeds §E (clinical translatability uses these flags directly).
  • §C BRAF-like concordance takes the full DE table from biomarker_validated.tsv and compares direction to prior MAPK-output / TDS annotations → outputs braf_like_signature_consistency.tsv. Supports §G pathway claim.
  • §D Drug repurposing takes the v7 top-10 drugs and queries PubMed + ClinicalTrials.gov → outputs drug_literature.tsv. Complements §E at the drug level.
  • §E Clinical translatability combines §B (druggability + BRAF-specific flags) with per-target ClinicalTrials.gov queries → outputs tiered clinical_translatability.tsv. High-priority output feeds §I paper claim and any future follow-up study design.
  • §F DIAL grounding is independent of the biomarker axes — queries ComBat-limitation literature → combat_limitation_literature.tsv. Supports §I methodology-novelty claim.
  • §G Pathway consistency reuses §A biomarker set + existing results/tables/pathway_enrichment.tsv → outputs pathway_literature_consistency.md.
  • §H Experimental log is a transparent enumeration of every external API call made, with rationale, so the whole run is reproducible and auditable.

§A · BIOMARKER LANDSCAPE (OVERLAP vs 10 REFERENCE LISTS)

2,843 replicated biomarkers vs 10 published thyroid-cancer gene lists.

↑ local input: biomarker_validated.tsv ↑ reference lists (5, hand-curated) → feeds §C concordance → Results §4.9 biomarker_overlap_matrix.tsv novel_candidates_ours_only.tsv

왜 이걸 했나 (rationale)

v3에서 우리가 2,773+ "replicated biomarker"를 만들었는데, 이것이 실제 thyroid cancer 연구 필드의 기존 signature들과 얼마나 일치하는지 검증할 필요가 있었습니다. 만약 우리 리스트가 (a) Chakravarty 2011 BRS52 같은 canonical signature와 통계적으로 유의하게 겹치고 (b) 동시에 상당한 양의 새로운 후보를 제공한다면, 우리 파이프라인은 "재발견 + 확장" 이라는 두 가지 가치를 동시에 주장할 수 있습니다. 이 섹션이 그 주장을 수치로 뒷받침합니다.

데이터 출처

Ours (replicated biomarker slate): results/tables/biomarker_validated.tsv — 2,843 유전자. THYRAI v3 discovery pipeline에서 (Welch t-test + BH-FDR, |Cohen's d| > 0.5, ≥2 외부 코호트 replication, FDR < 0.05) 필터를 모두 통과한 유전자.
Reference gene lists (10):
  • Chakravarty_2011_BRS52 — JCO 2011, 52-gene BRAF-RAS score (MAPK-output + TDS + inflammatory). 대표 signature.
  • Landa_2016_BRS — JCI 2016, advanced thyroid cancer driver census (BRAF, TERT, TP53, PIK3CA…).
  • TCGA_THCA_2014 — Cell 2014, integrated genomic characterization of PTC, core driver + altered-gene set.
  • Yoo_2019_Korean_PTC — Korean PTC molecular subtype proxy.
  • Costa_2015_BRS — Oncotarget 2015, BRAF-like vs RAS-like signature candidates.
  • Pu_2021_scRNA — Nat Commun 2021, pan-cancer scRNA atlas thyroid epithelial / stromal module.
  • Agrawal_2014_drivers — Cell 2014 TCGA companion driver list (BRAF, NRAS, RET, NTRK, …).
  • COSMIC_CGC_thyroid — Cancer Gene Census thyroid-relevant Tier 1+2 subset.
  • OncoKB_thyroid — OncoKB curated actionable genes for thyroid tumours.
  • DisGeNET_thyroid_carcinoma — DisGeNET top GDA-scored genes for thyroid carcinoma.
각 리스트는 results/v12_literature/crosscheck/reference_gene_lists/{list}.tsv에 보존됩니다.

방법

  • Our set = is_novel_validated == True OR is_known == True의 union = 2,843 gene.
  • Genomic background = 20,000 coding genes (HGNC-style).
  • 각 reference list에 대해 hypergeometric exact test로 P(X ≥ observed_overlap | N=20000, K=|ref|, n=|ours|) 계산. log10(p) 보고.
  • Enrichment 규칙: log10 p < -2 → enriched, < -1 → marginal, else not enriched.
  • Novel candidates = set(ours) − union(모든 10 reference). 2,785 gene.
  • Novel candidates는 novelty_score(=|d|TCGA×rep_rate×-log10 FDR) 내림차순으로 정렬, top 500만 파일에 씁니다(나머지는 원본 TSV에).

해석

  • Chakravarty 2011 BRS52 (log10 p = −17.90, 35/51 overlap): 우리 리스트가 canonical BRAF-RAS signature를 거의 70% 재현. 일반 thyroid transcriptomics 분석의 재현성 측면에서 매우 강한 signal.
  • TCGA 2014 · Yoo 2019 · Costa 2015도 log10 p < −10. 이 4개 리스트는 모두 expression-level signature이고, 우리 파이프라인이 그 signature 공간을 정확히 학습했음을 보여줍니다.
  • Landa 2016 BRS (log10 p = −0.66, 8/41 overlap)은 expected non-enrichment. 이 리스트는 driver-mutation census(BRAF, TERT, TP53, PIK3CA 등)이지 expression signature가 아니며, 이 유전자들의 절대 발현량은 BRAF-like vs RAS-like로 크게 차이나지 않습니다. 즉 우리 파이프라인이 "driver mutation"을 signal로 잡지 않고 "expression subtype"을 signal로 잡았다는 corroborative negative 결과.
  • 2,785 novel candidates: 10 reference list 모두에 없는 유전자들. 이것이 "우리 파이프라인이 추가한 새 후보 집합"입니다. Top-20 novelty 중 11/20이 PubMed thyroid 논문 5편 미만 (PLEKHA6, BNC1, ST6GALNAC5, B3GNT3, PTPRE, KCNQ3, CREB5, LY6E, PDLIM4, SPOCK2, CST6) — 이것이 가장 강한 novelty signal입니다. Top 20 deep-dive: top_20_novel_deep_dive.md.

한계

  • Reference list는 각 논문의 headline supplementary에서 재구성 (≤52 gene). 원본 full TSV와 교차할 경우 overlap 수치가 달라질 수 있음.
  • Hypergeometric의 background 20,000은 coding gene 기준. lncRNA / pseudogene을 포함하면 약간 변동.
  • 10 reference list 중 expression-signature panel은 모두 European/US cohort 중심. Korean PTC(Yoo 2019)를 포함시켰지만 대표성은 제한적; COSMIC/OncoKB는 actionability 기준이라 expression signature와 직접 비교 시 마이너 enrichment.
§B · PER-TARGET PUBMED PROFILE

8 druggable targets × 4 PubMed query axes (thyroid / cancer / BRAF / drug).

↑ local: drug_discovery_compounds.tsv (8 targets) ↑ see §H experimental log → feeds §E translatability → Results §4.10 targets_literature_summary.tsv

왜 이걸 했나

v7 drug discovery가 8개 druggable target(CYP1B1, TACSTD2, TMPRSS4, PLEKHA6, LDLR, GABRB2, B3GNT3, PTPRE)을 선정했습니다. 각 target이 기존 thyroid cancer 연구에서 이미 검토된 것인지 · 완전히 새로운 후보인지 · 이미 임상 시험에 들어간 상태인지를 알아야 "이 리스트의 biological maturity"를 논문에서 정확히 기술할 수 있습니다. 또한 각 target이 BRAF-like context에서 논의된 적이 있는지 확인해야 v5.1의 BRAF/RAS specificity 주장과 맞물립니다.

데이터 출처 & 쿼리

API: PubMed E-utilities esearch.fcgi (PMID 획득) → efetch.fcgi (XML abstract 파싱). 각 target당 4 query × retmax 50 = 최대 200 PMID 획득.
Queries (4 per target):
  1. {GENE}[tiab] AND thyroid[tiab] AND 2015:2026[dp] — thyroid-specific recent
  2. {GENE}[tiab] AND cancer[tiab] AND 2015:2026[dp] — cancer-broad recent
  3. {GENE}[tiab] AND BRAF[tiab] — BRAF co-occurrence (any year)
  4. {GENE}[tiab] AND (drug[tiab] OR inhibitor[tiab] OR therapy[tiab]) — druggability
Throttle: 0.34 s between queries (no API key → 3 req/s limit).
Parse: 각 abstract의 title + abstract text에서 정규식으로 direction/outcome/clinical/druggable 키워드 플래그.

Abstract-level keyword rules (정규식)

  • Direction up: over[\s-]?expressed | up[\s-]?regulated | elevated | increased | higher expression | high expression
  • Direction down: down[\s-]?regulated | decreased | reduced expression | lower expression | loss of expression
  • Outcome: prognostic | prognosis | overall survival | disease[-\s]free | recurrence | relapse | hazard ratio | metastasis | aggressiv\w+
  • Clinical: clinical trial | phase [I1-4V] | randomi[sz]ed | FDA | approved | IND
  • Druggable: inhibitor | antagonist | agonist | targeted therap\w+ | small molecule | monoclonal | antibody[-\s]drug | ADC

해석

  • LDLR (established, 29 thyroid papers): metabolism-cancer 축의 핵심 유전자. lipid uptake과 BRAF V600E의 metabolic reprogramming 문헌이 두텁습니다. CHOLESTEROL uptake driver로서 이미 연구된 맥락이 많음.
  • CYP1B1 (emerging, 11 thyroid / 450 cancer): thyroid에서는 emerging, 범암에서는 hot topic. v7에서 best pChEMBL 8.75 (10 compound)로 druggable하며, 아래 §D cannabidiol과 연결.
  • TMPRSS4 (emerging, 9 thyroid): metastasis-invasion axis로 thyroid 연구가 소수 있음. Transmembrane protease serine 4 = protease 활성 관련.
  • GABRB2 (emerging, 9 thyroid / 18 cancer): CNS 리간드 수용체 but 일부 thyroid link. v7에서 cannabidiol과 더불어 emerging drug target.
  • TACSTD2 (emerging, 5 thyroid / 79 cancer): = TROP2. 5개 thyroid paper은 보이지만 중요한 점은 ADC era의 핵심 항원이라는 것. §E에서 유일한 high-priority target이 되는 이유.
  • PTPRE (novel, 4 thyroid): Receptor-type tyrosine-protein phosphatase ε. tumor suppressor 역할 논쟁 있음. 연구 적음.
  • PLEKHA6 (novel, 0 thyroid / 4 cancer): 가장 novel. pleckstrin homology domain family. 기능 거의 미규명.
  • B3GNT3 (novel, 0 thyroid / 42 cancer): glycosyltransferase. pan-cancer 문헌은 있으나 thyroid paper 전무.

요약: 8 target 중 3개가 thyroid-specific novel(PLEKHA6, B3GNT3, PTPRE). 나머지 5개는 emerging/established이지만 대부분 BRAF-like subtype context에서 정식으로 positioning된 적은 없습니다. 이것이 v7 drug discovery 단계의 real contribution을 정량화합니다.

한계

  • Keyword 기반 direction/outcome 분류는 precision보다 recall 우선으로 튜닝되어 있어 false positive 가능.
  • PubMed retmax 50 per query → 총 hit count는 정확하지만 abstract 분석은 최근 ~50건 중심.
  • Thyroid 논문 cutoff 2015-2026은 의도적. 이전 논문은 이미 reference lists (§A)에 반영되어 있어 중복 회피.
§C · BRAF-LIKE SIGNATURE DIRECTION CONCORDANCE

우리 DE 방향 ↔ 사전 annotated MAPK-output / TDS direction.

↑ §A biomarker set ↑ prior direction labels (MAPK-output up, TDS down) → feeds §G pathway consistency → Results §4.9 claim braf_like_signature_consistency.tsv novel_braf_like_genes.tsv

왜 이걸 했나

§A가 "같은 유전자가 나오는가"를 검증한다면, §C는 더 엄격하게 "같은 방향으로 움직이는가"를 검증합니다. Chakravarty/Landa/Costa는 각 유전자에 대해 BRAF-like에서 up이면 +, down이면 -라는 prior가 있습니다. 우리 TCGA log2FC의 부호가 이 prior와 일치한다면, 우리가 잡은 signature가 "실제 BRAF V600E → MAPK-on 전사 프로그램"인지 "batch artefact 흉내"인지를 구별할 수 있습니다. 이 섹션은 v5.1 DIAL 감사의 biological 쪽 counterpart입니다.

Prior direction set (hand-curated from literature)

  • Expected up in BRAF-like (MAPK-output + dedifferentiation markers): DUSP4, DUSP5, DUSP6, ETV5, FOSL1, SPRY2, SPRY4, PHLDA1, LGALS3, KRT19, HMGA2, MET, FN1, SERPINA1, TIMP1, CITED1, ERBB3, LRP4, CLDN10, ANGPTL4, CEACAM6, CEACAM5 (22 유전자).
  • Expected down in BRAF-like (thyroid-differentiation-score = TDS): TG, TPO, DIO1, DIO2, DUOX1, DUOX2, SLC5A5, SLC26A4, PAX8, NKX2-1, FOXE1, THRA, THRB, TSHR (14 유전자).
  • 우리 데이터에 측정된 유전자만 테스트 → 25 prior-annotated genes 테스트 가능.

방법

  • biomarker_validated.tsv에서 유전자별 log2FC_tcga 읽기 (mean(BRAF) − mean(RAS)).
  • Our direction = "up" if log2FC > 0 else "down".
  • Concordance = (our direction == prior direction).
  • Novel BRAF-like 후보 = log2FC > 1.0 이면서 (up prior ∪ down prior)에 없는 유전자. Top 50만 별도 TSV에 저장.

해석

  • 25/25 = 100% concordance. 모든 prior-annotated 유전자가 기대한 방향으로 움직임.
  • 이는 우리 signature가 BRAF V600E → MEK/ERK → output-gene transcription의 canonical axis를 실제로 잡고 있음을 강력히 시사. 만약 batch signal만 잡고 있었다면 이 같은 direction alignment는 기대할 수 없습니다.
  • v5.1 DIAL audit와의 연결: DIAL은 "방향 정보가 sign-flip에 의해 뒤바뀔 수 있다"는 methodology 위험을 측정. §C는 "바로 그 방향이 biology와 일치하면 signal은 real"이라는 상보적 증거.
  • Novel BRAF-like up 50종: EMT/ECM-remodeling/metabolic 경향. novel_braf_like_genes.tsv에서 확인 가능.

한계

  • Prior direction set이 22 + 14 = 36이지만 우리 데이터에 모두 측정되진 않음 → 25 tested, 11 not_tested.
  • Prior direction은 literature consensus 기반 — 개별 논문에서의 reporting 방향이 서로 약간 다를 수 있음.
  • 100% concordance는 sampling 없이 계산된 point estimate. bootstrap CI는 별도로 계산하지 않음.

Fields extracted per trial: NCT ID, Brief title, Overall status, Phase(s), Lead sponsor.
Top trial per drug (in the any-cancer bucket) is recorded in the validation TSV.

Cannabidiol ↔ CYP1B1 deep dive

v7이 top-rank로 띄운 candidate이자, §B에서 CYP1B1 = emerging druggable target으로 profile 된 것과 직접 연결됩니다. CBD는 다수의 cytochrome P450 isoform(CYP1B1 포함)을 modulate하는 것이 cross-cancer 문헌에서 반복적으로 보고되어 있고, 우리 computational shortlist에서 CYP1B1이 best pChEMBL 8.75 · 10 compound · thyroid PubMed 11 · cancer PubMed 450으로 가장 well-supported druggable target이라는 점은 CBD를 mechanism-anchored repurposing hypothesis로 만들기에 충분한 정황 증거입니다.

Clinical signal은 명백히 직접적으로는 sparse: ClinicalTrials.gov thyroid × CBD = 0건. 하지만 cancer 전반에서 25건의 trial + Phase 3 completed (NCT02544750)가 있다는 것은 CBD의 cross-cancer safety / PK 데이터가 이미 축적되어 있고, 만약 BRAF-like thyroid cohort로 전용 가설을 세운다면 기존 trial infrastructure 위에 얹을 수 있음을 의미합니다.

Deep-dive report: results/v12_literature/crosscheck/cannabidiol_evidence_synthesis.md.

Sacituzumab govitecan observation

v7 shortlist의 또 다른 candidate. TROP2 (= TACSTD2) ADC로, §B에서 TACSTD2가 5개 thyroid trial을 이미 가지고 있다는 점과 맞물려 §E에서 TACSTD2를 유일한 high-priority target으로 만드는 핵심 증거입니다. 드럭 단위 검증(§D)이 target 단위 우선순위(§E)로 곧바로 연결되는 경우.

한계

  • "query.intr"이 generic name 기반 → synonym (e.g. CBD = cannabidiol = Epidiolex)에 따라 약간의 recall loss 가능.
  • ClinicalTrials.gov는 "any cancer"에 한해 최대 25건으로 제한 (pageSize). 실제 관련 trial 전수 조사는 아님.
  • Mechanism claim은 literature-level pointer이며, 직접 실험적 확인은 없음.
§E · CLINICAL TRANSLATABILITY TIERS

8 targets × {trials, FDA druggable, BRAF fit, novelty} → priority.

↑ §B druggable/BRAF flags ↑ §D drug–target context → Results §4.10 high-priority claim → future study design clinical_translatability.tsv

왜 이걸 했나

§B에서 각 target의 문헌 성숙도를 봤고 §D에서 drug 쪽을 봤습니다. 논문 Discussion / Clinical translation 절에서는 "어느 target을 가장 먼저 밀어야 하는가"에 답해야 하므로, 두 정보를 합쳐 단일 priority tier로 압축합니다.

우선순위 rule

high = (thyroid-specific trial > 0) AND (druggability literature signal 있음)
medium = (any-cancer trial > 0) OR (druggability 문헌 있음)
low = 위 조건 모두 없음
per-target trial 수는 ClinicalTrials.gov v2 API에 query.cond=thyroid, query.intr={target}으로 독립 호출하여 집계.

High-priority target rationale — TACSTD2 (1-paragraph clinical)

TACSTD2는 TROP2 항원을 암호화하며, 이 항원에 대한 antibody-drug conjugate인 sacituzumab govitecan이 triple-negative breast cancer에서 FDA 승인을 받은 후 여러 고형암으로 확장되고 있습니다. ClinicalTrials.gov 기준 thyroid-specific trial 5건이 이미 등록되어 있고, 어느 종양(전체)에서도 25건 이상의 trial이 진행/완료된 상태입니다. 우리 파이프라인에서 TACSTD2는 d = +2.52 · log2FC = +4.87 · FDR 6e-52 · 2/2 외부 코호트 replication을 달성한 novelty score 최상위 유전자이며, BRAF-like subtype에서 up으로 표출됩니다. 따라서 BRAF V600E mutant PTC 중 TACSTD2-high 서브그룹을 정의하고, 기존 TROP2-ADC를 off-label/investigational 적응증으로 매칭하는 것이 가장 빠른 translational path입니다.

한계

  • Tier rule은 heuristic (명시적 weighting 없음). 실제 clinical decision은 toxicity/PK/patient selection을 추가로 고려해야 함.
  • "Thyroid trial" 계산은 query.intr=target 기반이라 protein-level mismatch 가능 (e.g. TACSTD2 vs TROP2 synonym handling).
  • Priority는 literature + trials 기반이지 drug-target binding/efficacy 직접 측정 아님.
§F · DIAL METHODOLOGY GROUNDING

Prior ComBat / batch-correction concerns meet v5.1 direction-invariance.

↑ local: v5p1_table1_summary.tsv ↑ see §H ComBat queries → v5.1 audit page → reasoning §v4 combat_limitation_literature.tsv

왜 이걸 했나

v4/v5.1에서 찾은 "ComBat 적용 시 label-axis가 flip된다"는 현상이 실제로 문헌에 이미 기술되어 있지 않다는 것을 확인할 필요가 있습니다. 만약 어디선가 완전히 같은 표현으로 기술되어 있다면 우리 contribution은 없는 셈. 그러나 지금까지의 ComBat 관련 문헌은 "signal attenuation" / "over-correction" / "false positive" 수준의 우려만 제기하고 있어, v5.1의 direction-invariant label-flip framing은 novel methodological contribution이라는 주장에 literature-level support를 덧붙일 수 있습니다.

쿼리

Q1: "ComBat"[tiab] AND (overcorrection[tiab] OR limitation[tiab] OR artifact[tiab] OR over-correction[tiab])
Q2: "batch correction"[tiab] AND (artifact[tiab] OR false positive[tiab] OR bias[tiab])
Q3: "batch effect"[tiab] AND biology[tiab] AND (confound[tiab] OR entangle[tiab])
Q4: "linear mixed model"[tiab] AND batch[tiab] AND cancer[tiab]

결과

Loading ComBat-limitation literature count…

해석

  • 검색된 문헌은 두 가지 주제에 집중: (1) 일반적 "ComBat over-correction" 경고, (2) scRNA/bulk에서 batch correction이 biological axis를 attenuate(감쇠)하는 사례.
  • 우리 v5.1 finding의 핵심은 attenuation이 아니라 inversion(sign flip). max(a, 1−a) 형태의 direction-invariant metric으로 보면 magnitude는 보존되어 있음. 이 기하학을 정확히 기술한 prior는 retrieved 54건 중 보이지 않음.
  • 따라서 v5.1은 "기존 ComBat limitation literature와 호환되지만(compatible) 구별되는(distinct) methodological contribution" 으로 positioning됩니다. 이 문장이 AAAI paper abstract / intro 의 근거.

한계

  • 4 query로 제한 — 추가 query term으로 다른 관점이 더 있을 수 있음.
  • Retrieved abstracts의 full text를 읽지 않았기 때문에 abstract에 드러나지 않은 sub-result가 있을 수 있음.
  • "Novel" 주장은 strictly literature-search-negative 이지, proof of non-existence는 아님.

  3. "genuine new biology" claim (PLEKHA6/B3GNT3/PTPRE) 너무 강함 — naming convention / recent discovery / research bias 영향 가능. Fix: "understudied in thyroid cancer context"로 약화.

§J · LIMITATIONS

v12는 literature-only — 새 biological experiment 없음. 컴퓨테이셔널 주장이 공개 기록과 일관성이 있는지 검증하고, 어떤 candidate가 prior evidence를 가졌는지 / 어떤 것이 진짜 novel 인지 flag 합니다. 그러나 prospective cohort validation의 대체가 아닙니다 — 별도의 외부 검증 코호트 평가가 필요합니다.

추가 한계: (1) Reference gene list 5개는 headline-level (≤52 gene) compact sets; full supplementary TSV 교차 시 숫자 변동 가능.
