§0 · 용어 풀 사전

0. ★ HLA / 면역 / 임상 용어 — 자세히 풀기

📖 [A] HLA 기본 + 분류 (펼침 default)
  • HLA (Human Leukocyte Antigen) — 인간의 MHC (Major Histocompatibility Complex). 6번 염색체 6p21 영역 (~3.6 Mb). 면역 self/non-self 인식 핵심.
  • HLA Class I (A, B, C) — 거의 모든 유핵세포 표면. endogenous antigen → CD8 T cell. virus / cancer 인식.
  • HLA Class II (DR, DQ, DP) — APC (B cell, DC, macrophage, thyroid epithelial cell 등). exogenous antigen → CD4 T helper. 자가면역의 핵심.
  • HLA-DR (DRA + DRB1) — Class II 의 가장 polymorphic gene. DRB1 ~7,000+ allele. Graves' / RA / T1D 자가면역 main locus.
  • HLA-DQ (DQA1 + DQB1) — Celiac disease 핵심.
  • HLA-DP (DPA1 + DPB1) — Graves' 동아시아 risk allele (DPB1*05:01) source.
📖 [B] Allele resolution + naming
  • 2-digit (e.g. HLA-DRB1*03) — serological / low-res. 같은 antigen group.
  • 4-digit (e.g. HLA-DRB1*03:01) — high-res. 같은 amino acid sequence. Imputation 표준. 자가면역 association 분석에 적합.
  • 6-digit, 8-digit — synonymous + intron. 해상도 ↑, imputation 정확도 ↓.
  • peptide binding repertoire — 같은 4-digit allele 들은 거의 같은 peptide binding. 4-digit 이 functional 분석에 충분.

📖 [E] 통계 / Mechanism 용어 + Peptide binding
  • OR (Odds Ratio) — case/control allele 보유 odds ratio. >1 risk, <1 protective.
  • Fisher exact / Logistic regression with PC covariates — population stratification 보정 (PCA first 2-10 PC).
  • Bonferroni / BH-FDR — multiple testing 보정.
  • conditional analysis — top hit 보정 후 second association 분리. LD 보정.
  • NetMHCIIpan — Class II HLA × peptide binding affinity NN. 9–25mer peptide.
  • NetMHCpan — Class I 8–14mer.
  • IC50 — <50 nM strong, 50–500 nM weak, >500 nM non-binder.
  • %Rank — random peptide background 대비 percentile. <0.5 strong.
  • autoreactive epitope — TSHR / TG protein 의 self-peptide 가 HLA 에 binding 되어 T cell activation → 자가면역.
  • PRS (Polygenic Risk Score) — 여러 risk allele effect 합산. Σ(β_i × dosage_i). Graves' 발병 예측.

PRJEB11591 (262 Korean PTC RNA-seq) 에 arcasHLA imputation 실행.

배경:
- FASTQ at /data/thca/PRJEB11591_fastq/ERR15186??/
- 262 sample, paired-end, ~31M reads/sample, ~5GB/sample
- 결과: 4-digit HLA-A/B/C/DRB1/DQA1/DQB1/DPA1/DPB1 8 gene

Setup:
  pip install arcasHLA  # or conda install -c bioconda arcas-hla
  # IPD-IMGT/HLA database
  arcasHLA reference --update

Pipeline (per sample):
  1. STAR align to GRCh38 → SAM/BAM (chr 6 region only OK)
  2. arcasHLA extract --paired -t 16 sample.bam
  3. arcasHLA genotype -G A,B,C,DRB1,DQA1,DQB1,DPA1,DPB1 \
        -t 16 -p 0.99 sample.extracted.fastq.gz
  4. arcasHLA partial -G A,B,C,DRB1,DQA1,DQB1 \
        sample.genotype.json (filter ambiguous)

병렬 실행 (16-thread, 8 sample 동시):
  for sample in $(ls /data/thca/PRJEB11591_fastq); do
    sbatch arcas_pipeline.sh $sample
  done

출력:
  per-sample 4-digit allele JSON
  → 합쳐서 results/v17_korean/K2_arcasHLA_genotypes.tsv (262 row × 16 allele column)
  → frequency table (Class I/II × allele × population)
  → Graves' risk allele carrier table

분석 단계 (imputation 후):
  1. 한국 PTC × allele frequency vs Korean reference panel (cookHLA 결과 와 비교)
  2. Graves' risk allele (DPB1*05:01, B*46:01, DRB1*04:01) carrier rate
  3. PTC 의 17% Hashimoto-like subgroup × HLA risk allele association
  4. K2 DM1 vs DM2 × HLA cross-tab (현재 14:246 → HLA-leveraged refinement)
  5. NetMHCIIpan TSHR/TG epitope binding (cohort 별 risk allele 의 binding profile)

계산 자원:
  - STAR + BAM: 32GB RAM, 4-8 thread per sample
  - arcasHLA: 8GB RAM per sample
  - 총 디스크: ~600GB intermediate (BAM + extracted FASTQ)
  - 시간: 8-16 hours wall clock (parallelized)

대안 (arcasHLA 안되면):

9-2. Mechanistic chain

  1. imputation (cookHLA 또는 arcasHLA) → 환자별 4-digit allele
  2. epitope library — TSHR (특히 A-subunit 22-260) + TG 의 known immunodominant peptide 100-200 개 (NetMHCIIpan IEDB curated 사용)
  3. NetMHCIIpan / NetMHCpan — peptide × allele binding affinity 예측 (IC50 nM)
  4. per-patient binding burden — 환자가 보유한 risk allele 들의 strong binder 수 합산 → autoimmune liability score
  5. association — autoimmune liability score × Graves' / Hashimoto-like / DM1 status 통계 검증
