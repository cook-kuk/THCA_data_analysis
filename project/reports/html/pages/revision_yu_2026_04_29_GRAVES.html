Graves' disease paper — 메인 trajectory

유 교수님 결정에 따라 8-gene THCA paper 보류, Graves' disease 자가면역 분자 phenotype 으로 paper 전환. 분당 cohort + Yoo SK 262 명 NGS cohort 통합 → debate 적은 방향, fastest path to publication. HLA 와 BRAF/TERT 는 별도 trajectory — 이 분석에서 제외.

📖 ★ Graves' disease 관련 임상 / 면역 / 분자 용어 풀이 (★ 매우 자세히, default 펼침)

━━━ [A] 질환 자체 (Graves' disease) ━━━

  • Graves' disease (그레이브스병) — 자가면역성 갑상선기능항진증. 자가항체 (TRAb) 가 TSH receptor 를 자극 → 갑상선 호르몬 과잉 생산. 가장 흔한 hyperthyroidism 원인 (전체의 60–80%). 한국 유병률 ~1%.
  • Hyperthyroidism (갑상선 기능 항진) — 갑상선 호르몬 (T3/T4) 혈중 농도 상승. 증상: 체중 감소, 빠른 맥박, 손떨림, 안구돌출 (Graves' ophthalmopathy), 더위 못 견딤, 불안.
  • Hypothyroidism (갑상선 기능 저하) — 갑상선 호르몬 부족. Graves' 와 반대. Hashimoto's 의 결과.
  • Hashimoto's thyroiditis (하시모토 갑상선염) — 또 다른 자가면역 갑상선 질환. anti-TPO / anti-TG antibody. 결과: hypothyroidism. Graves' 와 면역 mechanism 일부 공유 (HLA-DR3 등) 지만 표적 항원 다름.
  • BTC (Benign Thyroid Condition) — 양성 갑상선 질환 (cancer 아님). Graves' / Hashimoto / nodular goiter / thyroid adenoma 등 포함. 분당 cohort 의 normal vs Graves' BTC 비교에서 활용.
  • thyroid storm (갑상선 위기) — Graves' 의 가장 심한 응급. T3/T4 폭증 → 발열, 빈맥, 의식 변화. 사망률 10–30%.
  • Graves' ophthalmopathy (그레이브스 안병) — 안와 자가면역 침범. 안구돌출 (proptosis), 복시. Graves' 환자 ~25–50% 동반.

━━━ [B] 자가항원 + 자가항체 ━━━

  • TSHR (TSH Receptor) — 7-transmembrane GPCR. TSH 자극 → cAMP → 갑상선 분화 + proliferation. Graves' 의 표적 항원. extracellular 부분이 cleaved 되어 A-subunit (autoimmune target) 와 B-subunit (membrane-anchored) 로 분리. A-subunit 이 TRAb 의 main 표적.
  • TRAb (TSH Receptor Antibody, 갑상선자극호르몬수용체항체) — Graves' 의 핵심 자가항체. 3 종류:
    • Stimulating TRAb (TSI, Thyroid-Stimulating Immunoglobulin) — TSHR 를 자극 → hyperthyroidism (Graves' 의 dominant phenotype)
    • Blocking TRAb (TBII) — TSHR 를 차단 → hypothyroidism 일으킬 수 있음 (Hashimoto-like)
    • Cleavage TRAb — 수용체 cleavage 조절
    기능적 다양성이 표현형 변이에 기여. 임상에서 측정 (TSI assay).
  • TG (Thyroglobulin) 자가항체 (anti-Tg Ab) — Graves' / Hashimoto 양쪽 에서 발견. 항원성 변화 (post-translational modification, citrullination, iodination 패턴) 가 자가면역 trigger 가능.
  • anti-TPO antibody (anti-Thyroid Peroxidase) — Hashimoto 에서 가장 강한 marker. Graves' 에서도 ~70% 양성 — 두 질환의 spectrum 시사.

━━━ [C] 항체 isotype + subclass ━━━

  • IgG1, IgG2, IgG3, IgG4 — IgG의 4 subclass. 각각 다른 effector function (complement activation, FcγR binding 등).
  • IgG1 우세 in Graves' — Graves' TRAb 는 IgG1 dominant (Th1-biased 면역반응의 결과). 기존 "Graves' 는 Th2 driven" 관점을 수정한 최근 finding. IgG1 = complement fixation 강함, FcγRI/III binding.
  • class switch recombination — B cell 이 IgM → IgG 로 isotype 전환. Tfh (T follicular helper) cell 의 도움 필요. Graves' 에서 활발.
  • somatic hypermutation — germinal center 에서 항체 친화도 ↑. Graves' 의 high-affinity TRAb 생성에 핵심.

━━━ [D] T cell subset (이번 분석의 핵심) ━━━

  • Th1 cell (T helper 1) — IFN-γ, TNF-α, IL-2 분비. cell-mediated immunity. Graves' 에서 ↑. master TF: T-bet (TBX21).
  • Th2 cell — IL-4, IL-5, IL-13 분비. humoral immunity (B cell help). 기존 Graves' 모델 에서 강조됐으나 최근 Th1 도 중요로 수정.
  • Th17 cell — IL-17A, IL-17F 분비. 자가면역 + 만성염증. master TF: RORC (RORγt). Graves' 에서 ↑ — 최근 추가된 layer.
  • Th22 cell — IL-22 분비. epithelial barrier + 만성염증. Graves' 에서 ↑.
  • Tfh cell (T follicular helper) — germinal center 에서 B cell 도움. CXCR5+, BCL6 expression. Graves' 에서 ↑. high-affinity TRAb 생성 driver.
  • Treg cell (Regulatory T cell) — FOXP3+, CD25+ (IL2RA). 자기관용 (self-tolerance) 유지. Graves' 에서 ↓ 또는 기능 장애 — 자가면역 진행의 mechanism. 재발 예측 marker.
  • cytokine signature — Graves' = IFN-γ + IL-2 + TNF-α (Th1) + IL-17 (Th17) + IL-22 (Th22) + IL-4/IL-13 (Th2) mixed. RNA-seq 으로 측정 가능.

━━━ [E] B cell subset + plasmablast ━━━

  • plasmablast — 활성화된 B cell 이 antibody-secreting cell 로 분화 중간 단계. CD19+ CD27hi CD38hi. 자가면역 활성도 marker. Graves' 에서 ↑.
  • plasma cell — terminal differentiated antibody-secreting cell. 골수 / lymph node 에 거주.
  • IgD⁻ CD27⁻ B cell ("double negative" 또는 DN B cell) — extrafollicular pathway 의 marker. SLE / Sjögren / Graves' 등 자가면역에서 ↑. 질환 활성도 + 재발 위험 marker.
  • memory B cell (CD27+) — 재감염 시 빠른 항체 생산. Graves' 에서 도와주는 layer.
  • germinal center reaction — B cell 이 affinity maturation + class switch 일어나는 lymph node sub-region. Tfh 가 핵심 helper.
  • extrafollicular response — germinal center 외 B cell 활성. IgD⁻CD27⁻ B cell 이 marker. 자가면역의 또 다른 path.

━━━ [F] 유전 / 면역유전자 (HLA 제외) ━━━

  • 유전 79% / 환경 21% — 쌍생아 연구 기반 Graves' heritability 추정. 자가면역 질환 중 상당히 강한 유전 기여.
  • TSHR intron 1 SNP (rs179247) — TSHR gene 의 first intron 변이. alternative splicing 영향 → A-subunit / B-subunit 비율 변화 → 자가면역 trigger.
  • CTLA4 (Cytotoxic T Lymphocyte Antigen 4, CD152) — T cell 음성 조절 receptor (negative checkpoint). CD28 와 같은 ligand (B7-1/2) binding 경쟁. AAA haplotype 이 Graves' risk allele. 면역항암제 (ipilimumab) 의 표적.
  • CD40 — APC (antigen-presenting cell) 의 co-stimulator. CD40L (T cell) 와 binding → B cell activation + class switch. Graves' SNP 와 association.
  • PTPN22 (Protein Tyrosine Phosphatase Non-receptor 22) — T cell receptor signaling 음성 조절. R620W variant 가 여러 자가면역 (Graves', T1D, RA, SLE) 의 risk allele. lymphoid-specific.
  • IL2RA (CD25) — IL-2 receptor α subunit. Treg 의 surface marker + IL-2 high affinity binding. Graves' association.
  • FOXP3 — Treg master TF. 발현 ↓ → Treg 감소. X-linked. mutation 이 IPEX syndrome 일으킴.

━━━ [G] 분석 도구 ━━━

  • STAR + featureCounts — RNA-seq 표준 alignment + count pipeline. 우리 GSE213647 / Yoo cohort 처리에 사용.
  • DESeq2 — differential expression analysis 표준 R package. negative binomial GLM. fold change + adjusted p-value.
  • GSEA (Gene Set Enrichment Analysis) — gene set 단위 enrichment 분석. Hallmark / KEGG / Reactome database 활용. preranked GSEA 가 표준.
  • CIBERSORTx — bulk RNA-seq 에서 면역세포 비율 deconvolution. LM22 (22 immune cell type) reference 사용. Graves' 분석에 필수.
  • scanpy — Python 의 scRNA-seq 분석 framework. Seurat (R) 와 같은 역할. UMAP, Leiden clustering.
  • composite signature score — 여러 gene 발현을 하나의 score 로 통합. z-score sum 또는 ssGSEA.

  • Thyroid (American Thyroid Association journal) — 갑상선 specialty (IF ~6). Graves' / autoimmune thyroid 에 강함.

★ 4. 분석 step-by-step

4. 분석 단계 (5 step)

Step a. Differential Expression Analysis (Graves' vs Normal)
DESeq2 (또는 limma-voom) 으로 raw count → log2FC + adjusted p-value. Graves' specific gene set (위 3.1–3.5) 우선 보고. 전체 transcriptome 결과는 supplementary.
Step b. GSEA — Hallmark immune response, IFN-γ response, TNF-α
MSigDB Hallmark 50 set 중 immune 관련 (IFN-γ response, IFN-α response, TNF-α via NF-κB, complement, inflammatory response, IL2-STAT5 signaling, IL6-JAK-STAT3) 우선 보고. preranked GSEA 가 표준.
Step c. CIBERSORTx 면역세포 deconvolution
bulk RNA-seq → LM22 reference 로 22 면역세포 비율 추정. Graves' vs Normal 의 Th1 / Th17 / Tfh / Treg / plasmablast 비율 비교. 결과: T cell subset 분포 figure (Fig 2).
Step d. TSHR 발현 + isoform analysis
TSHR gene 의 exon-level expression. A-subunit (extracellular) 발현 강조. salmon / kallisto 로 transcript-level quantification 가능. Graves' 에서 A-subunit / B-subunit 비율 변화 검증.
Step e. "Graves' activity score" composite signature 만들기 (10–20 gene)
Step a–d 결과 통합 → top 10–20 gene 의 z-score sum 또는 ssGSEA → 단일 score. Graves' vs Normal AUC 평가. 분당 cohort 에서 발견 → Yoo cohort 에서 validate.
★ 5. Validation

5. Validation strategy

  • 분당서울대 (discovery) → Yoo SK 262 (validation) — discovery 에서 만든 signature 를 Yoo cohort 에서 검증. AUC + Cohen's d + bootstrap CI.
  • Normal vs Graves' 분류 AUC — 합리적 target ≥ 0.85 (Graves' 는 분자적으로 깨끗하게 분리되는 질환).
  • (가능 시) PTC autoimmune component 와 비교 — Yoo 110 PTC 중 17% Hashimoto-like (Q12 결과) 와 Graves' signature overlap 확인 → 두 자가면역의 spectrum 분석.
  • Stratified validation — FFPE vs Frozen (preservation), 성별, 연령대, 약물 사용력 (anti-thyroid drug, levothyroxine).
★ 6. 임상 의의

6. 임상 application 4 가지

  1. Graves' disease 진단 정확도 향상 — 현재 진단 = TSI assay + clinical (안구돌출, hyperthyroid symptom). 분자 signature 추가로 borderline case 보강.
  2. 재발 예측 (plasmablast / IgD⁻CD27⁻ B cell) — anti-thyroid drug 후 재발 risk stratification. surgical / RAI / drug 선택 결정 support.
  3. 치료 반응 예측 (Th1 / Th17 dominant 환자) — Th1-dominant 면 cytokine inhibitor (anti-IFN-γ) 이 더 효과 가능성. precision medicine layer.
  4. 임상 deployable signature score — 10–20 gene NanoString panel 또는 qPCR 로 임상 deployment. FFPE 호환 → 일반 병원에서도 가능.
