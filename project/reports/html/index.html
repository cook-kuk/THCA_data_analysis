Platform · 1/4 OMEGA-THCA Discovery · Multi-omics

데이터. TCGA-THCA Illumina RNA-seq (BRAF-like n=392, RAS-like n=111) + 외부 GEO 4종: GSE27155(GPL570 microarray, n=41), GSE126698(RNA-seq, PTC P* / FTC F* / ATC A* / normal N*), GSE33630 + GSE29265(pooled GPL570), GSE76039(dedifferentiated). 총 1,509 샘플 · 51,711 gene. 병행: Illumina 450k methylation(GSE97466 within-cohort tumor vs normal AUC 0.986), CIBERSORT 면역 deconvolution.

목적. 단일 코호트 overfitting을 제거하고, BRAF-like vs RAS-like 분자 아형을 구분하는 cross-cohort replicated biomarker만 통과시킴. 모든 marker는 외부 코호트에서 fold-change 방향과 유의성이 동시에 일치해야 함.

분석. ① Welch t-test + BH-FDR (TCGA discovery, log2FC = mean(BRAF) − mean(RAS)). ② 외부 코호트별 replication: 동일 검정 재실행, 동일 방향 + p<0.05이면 replicate=1. ③ 필터: FDR<0.05, |Cohen's d|>0.5, median TCGA log2>1, ≥2 코호트 presence, replication_rate≥1. ④ Dataset identifiability AUC(OvR macro, 6 코호트 식별) = 1.000 → 플랫폼만으로 100% 식별 가능, batch leakage 상한을 수치로 노출. ⑤ LODO 평균 AUC = 0.870. ⑥ Top-|Cohen's d| 10/30개 제거 ablation: AUC 0.992 → 0.984 → 0.895 (signal이 소수 유전자에 집중되지 않음 확인).

결과. 2,773개 novel-validated biomarker. 148/221 known marker 중 70개 replicate. Replicated known: SERPINA1(d=+2.38, 2/2), KCNN4(+2.37, 2/2), DCSTAMP(+2.24, 2/2), KRT19(+2.07, 2/2 · Clinical IHC), LGALS3(+2.04, 2/2), MET(+1.92, 2/2), TIMP1(+1.83, 2/2). Top novel: TACSTD2(d=+2.52, 2/2), TMPRSS4(+2.09, 2/2), PLEKHA6(+2.22, 2/2), CYP1B1(+2.22), LDLR(+2.02), GABRB2(+2.24), B3GNT3(+2.02), PTPRE(+2.26).

의미. 방향 일치 replication filter 덕분에 상위 marker들은 TCGA-only artefact가 아님. 동시에 D1=1.00이 batch leakage 위험을 솔직히 드러내므로, "perfect AUC"는 plat­form signal을 일부 학습한 결과일 수 있음 — honest framing의 근거. 이 2,773 리스트가 CHEM/PANEL/CLINIC 모든 하위 레이어의 feature pool.

Platform · 2/4 CHEM-THCA Target → Compound triage

데이터. OMEGA-THCA에서 선정된 top-8 druggable target. 외부 소스: ChEMBL bioactivity DB (pChEMBL ≥ 5 필터), PubMed(thyroid-specific paper 수), CMap L1000 perturbagen reversal signature, STRING PPI 네트워크.

목적. 바이오마커를 "drug-discoverable target"으로 변환 — 각 target에 대해 시작점(hit list)을 만들고, MoA 명확성 · 문헌 anchoring · 역-발현 compound까지 하나의 triage view로 정리. 임상·전임상 효능 주장은 하지 않음.

분석. ① Gene → ChEMBL target ID 매핑(예: CYP1B1 → CHEMBL4878, LDLR → CHEMBL3311, GABRB2 → CHEMBL1920). ② pChEMBL ≥5 화합물을 affinity 내림차순으로 수집. ③ CMap L1000에서 expression reversal top-K perturbagen 스코어 overlay. ④ STRING PPI로 target neighborhood 시각화(QUBO 기반 novel-target 서브네트워크 포함). ⑤ target별 "novel / emerging / validated" 분류.

결과. 8 target · 15 compound · 27 literature record. CYP1B1 = validated (10 compound, best pChEMBL 8.75 = CHEMBL3132932, thyroid PubMed 5). LDLR = emerging (4 compound, best 6.22 = CHEMBL115992). GABRB2 = emerging (1 compound: CANNABIDIOL, 6.89). TACSTD2 / TMPRSS4 / PLEKHA6 / B3GNT3 / PTPRE = novel (0 known compound) → first-in-class.

의미. 5개 novel target은 기존 chemical matter가 없어 fragment screening · DNA-encoded library campaign의 합리적 출발점. Validated / emerging 3개는 기존 compound repurposing 후보. 전체는 computational hit list — 전임상·임상 주장이 아니며, in vitro/in vivo 확인이 전제.

Platform · 3/4 PANEL-THCA 54-gene classifier benchmark

데이터. OMEGA의 2,773 biomarker feature pool. 학습: TCGA-THCA 5-fold CV. 외부 평가: GSE27155(n=41), GSE126698, pooled GPL570(GSE33630+GSE29265), GSE76039. Benchmark 대상: 112-gene reference panel.

목적. "더 작은 패널(54-gene)이 같은 AUC를 유지할 수 있는가" 벤치마크. 또한 패널이 batch signal이 아닌 bio signal을 학습하는지 ablation + permutation으로 정량 검증.

분석. ① Feature 선택: univariate Cohen's d · k sweep(2,4,…,16,…) → best k=16, TCGA 5-fold AUC 0.932. 최종 54-gene 패널은 elastic-net LogReg. ② 외부 코호트별 isotonic recalibration(TCGA score에 fit, 외부에 apply). ③ Permutation null 10,000회 → observed AUC 0.923, empirical p = 0.001. ④ MAPK-output ablation(DUSP4/5/6, SPRY1/2/4, ETV4/5, FOSL1, PHLDA1 제거) → AUC 0.923 → 0.924 (MAPK signal 제거해도 robust). ⑤ TierA67_clean top-k 제거 sensitivity: k=0 AUC 0.992, k=10 0.984, k=30 0.895.

결과. TCGA 내부 5-fold AUC 1.000. 외부: GSE27155 pre-isotonic AUC 1.000(post-isotonic bACC 0.500 → 분포 shift로 score bucket 붕괴), GSE27155 train_tcga_plus_others AUC 0.883 · PR-AUC 0.951 · bACC 0.815. GSE126698 train_tcga_only AUC 0.694, train_tcga_plus_others AUC 0.778 · NPV@Se≥0.95 = 1.000. LODO 평균 0.870. 3-class(BRAF/RAS/NBNR) macro OvR AUC 0.937(LogReg) / 0.938(GBM).

의미. 54-gene 패널은 TCGA 내부에서 perfect, 외부 isotonic 보정 후 일부 코호트에서 bACC가 0.5로 붕괴하는 것은 score 분포 shift의 정직한 증거. D1=1.00과 함께 읽으면 "완벽한 transfer"가 아님을 명시. 그래도 pre-calibration AUC · LODO 0.87 · permutation p 0.001 · MAPK ablation robustness는 signal이 실제로 존재함을 보여줌 — retrospective decision-support prototype, 진단 기기 아님.

Platform · 4/4 CLINIC-THCA Bethesda III/IV 시뮬레이션

데이터. PANEL-THCA의 54-gene LogReg 계수 + 공공 prior에서 Bethesda III/IV indeterminate cytology의 malignancy 유병률 10% · 15% · 20% · 25% · 30% · (비교) 기준. 각 유병률마다 20,000명 가상 환자 시뮬레이션.

목적. 만약 이 패널이 실제 indeterminate 진단 슬롯에 들어간다면 어떤 threshold에서 어떤 Sens/Spec/NPV/수술 감소 trade-off이 가능한지 — 컴퓨테이셔널 triage simulation. 임상 가이드가 아니며 Afirma · ThyGenX 같은 상용 패널 대비 reference point로 제공.

분석. Prevalence × threshold grid sweep. 총 18 operating point. 각 점에서 Sens / Spec / NPV / surgery-reduction vs treat-all · KRW cost-utility (단, 수가 일반화 불가 명시). Brier score · ECE로 calibration 품질 병행 측정.

결과.  10% 유병률 · th 0.26 → Sens 99.1% · Spec 41.1% · NPV 99.8% · 수술 37% ↓;  15% → Sens 98.7% · Spec 40.6% · NPV 99.5% · 35% ↓;  20% → Sens 99.5% · Spec 40.8% · NPV 99.7% · 33% ↓;  25% → Sens 99.2% · Spec 39.7% · NPV 99.3% · 30% ↓;  30% → Sens 99.2% · Spec 41.5% · NPV 99.1% · 29% ↓.

의미. 낮은 유병률에서도 NPV가 99%대를 유지하며 수술 29~37%를 이론적으로 감소시킬 수 있음 — "ruling out"용 computational triage로서의 의미. 다만 모든 값은 외부 코호트 isotonic 보정 이후의 simulation이며, D1=1.00(batch leakage 상한) 조건에서의 수치이므로 임상 성능으로 해석할 수 없음. v4 감사에서 KRW cost-utility는 generalizable 하지 않음으로 명시 플래그됨.

External Validation v3

데이터. Train = TCGA-THCA Illumina RNA-seq. 외부 test-bed = PRJEB11591(Yoo et al. 2016, primary — 처리된 count 획득 실패로 proxy 대체), 보조 = GSE27155(GPL570), GSE33630, GSE29265(pooling), GSE126698(RNA-seq), GSE76039(dediff).

목적. v2 단계의 "TCGA-internal AUC = 1.00"이 외부 코호트에서도 일반화되는가를 permutation-calibrated로 검증하고, 동시에 dataset-identifiability AUC로 batch leakage 상한을 측정.

분석. elastic-net LogReg(feature set = TierA67_clean_no_MAPK) 학습 → 외부에 isotonic recalibration 적용 → permutation null 10,000회 → LODO 2-holdout. D1(dataset identifiability macro-AUC) 병행 측정.

결과. Best 외부 AUC = 1.000(95% CI 1.000–1.000) on GSE27155(n=41), permutation p < 0.001, null 평균 AUC 0.469. D1 = 1.000 — 플랫폼만으로 코호트 100% 식별. Post-isotonic bACC = 0.500(모든 외부 score가 단일 bucket으로 붕괴 = 분포 shift 증거). LODO 평균 0.870.

의미. 외부 AUC 1.00은 임상 generalization의 증거가 아님 — D1=1.00 & bACC 붕괴는 apparent AUC의 일부가 platform/batch에서 기인함을 시사. 올바른 framing은 "retrospective computational triage / decision-support prototype". 본 결과는 honest audit(page 19)과 함께 공개되어 reviewer가 leakage 한계를 직접 확인 가능.

v5.1 · REVISED · LODO

v5.1 THCA-Specific Audit — BRAF/RAS batch entanglement 확인, 타 암종은 null.

데이터. TCGA + GEO 멀티코호트 실데이터 — THCA · SKCM · LGG · LUAD · COAD × 5 classifier(LogReg_l2 · LogReg_elasticnet · RandomForest · GradientBoosting · XGBoost). variance-top-3000 유전자 풀, 반합성 없음.

목적. 기존 v5(StratifiedKFold + semi-synthetic) 파이프라인은 코호트 leak으로 pre-AUC가 inflate되어 철회. LODO 재실행으로 batch-subtype entanglement의 실제 일반성을 재평가.

분석. leave-one-dataset-out 평가, 학습 cohort에 ComBat fit → held-out cohort에 적용 → DIAL = max(a, 1−a) − 0.5 when AUC_post < 0.5 else 0. LODO 하에서는 ident_post gate 없이 DIAL > 0.3 단독 기준.

결과. 25 조합 중 4개 batch_entangled — 모두 THCA(LogReg_l2 DIAL 0.494, LogReg_elasticnet 0.492, RandomForest 0.323, GradientBoosting 0.334). 타 20개 조합 중 0 flip. true_biology 13(LGG 5, LUAD 3, COAD 5), no_signal 6, ambiguous 2.

의미. v5의 "cross-cancer generalization" 서사는 철회. 실제 현상은 THCA BRAF-vs-RAS에 특이적인 label-flip — 공유되는 class skew(TCGA 293:58, GSE27155 28:13)와 linear한 MAPK 축이 ComBat의 cohort-mean subtraction과 공선성을 이루는 3개 조건의 동시 충족이 원인으로 가설화. 특이성 증거이지 일반화 실패가 아님. 유형원 교수(분당서울대) 협력 전향적 검증 진행 중.
