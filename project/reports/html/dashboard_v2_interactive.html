Headline Readout

  • The rerun fixed the gene panel definitions and replaced the earlier unresolved placeholders.
  • TCGA mutation-anchor training labels now separate BRAF_like and RAS_like using open GDC masked MAFs.
  • GSE213647 was not kept as a 2-class external validation cohort after relabeling because the corrected cohort lacks a comparable RAS-like differentiated tumor class.
  • The best-looking external numeric result is GSE126698 AUC 1.000, but this uses only 12 samples and should be treated as exploratory.
  • The more realistic stress-test dataset remains GSE27155, where the best AUC is 0.980 but threshold-dependent metrics still degrade.
Read AUC together with balanced accuracy and MCC. Several GSE27155 rows show high AUC but poor thresholded performance, which is what you would expect from a label-inferred histology proxy set rather than a clean molecularly labeled validation cohort.

What Is Still Uncertain

  • BRS71 is a proxy list, not the original published supplementary list.
  • GSE27155 external labels are phenotype proxies inferred from histology and morphology.
  • GSE126698 is too small for strong external claims.
  • GSE213647 processed expression currently shows zero TDS16/BRS71/TierA67 coverage in the existing matrix output, which is a processing red flag and should not be overinterpreted biologically.
  • TierA67 contains 67 requested entries but one duplicated symbol by design: PAX8.

Training Data

  • Backbone cohort: TCGA-THCA bulk RNA-seq processed matrix already saved in the project.
  • Anchor source: locally available open GDC masked somatic MAF files.
  • BRAF_like: BRAF hotspot anchor only.
  • RAS_like: KRAS, HRAS, or NRAS mutation with no BRAF anchor.
  • Samples with both anchors or neither anchor were excluded from training.

Feature Sets

  • TDS16: official 16-gene list from Cell 2014.
  • TierA67: requested hardcoded composite panel. Implemented as 67 entries and 66 unique HGNC symbols.
  • variance_top50: selected inside each training fold only, not globally before CV.
  • BRS71 was derived and saved as a proxy, but not used as a direct feature set because the rerun task specified TDS16, TierA67, and variance-top50.

Leakage Control

  • 5-fold stratified CV on TCGA only.
  • Median imputation, scaling, and model fitting all happen inside the sklearn pipeline.
  • Variance-based feature selection is performed inside the training fold.
  • No pooled TCGA + GEO training was used.

External Validation Logic

  • GSE27155: histology and morphology were binarized into BRAF-like and RAS-like proxies. MTC was excluded.
  • GSE126698: restricted exploratory subset mapping cPTC to BRAF-like proxy and FTC to RAS-like proxy.
  • GSE213647: relabeling fixed the GEO misinterpretation, but the corrected cohort does not support a comparable BRAF-like vs RAS-like 2-class differentiated tumor test, so it was excluded.
A high external AUC is not sufficient here. When label construction is proxy-based or sample size is very small, the thresholded metrics and cohort context matter more than a single headline number.

ROC Generation

  • Internal ROC curves were generated from cross-validated out-of-fold scores on TCGA.
  • External ROC curves were generated from model scores on the chosen external cohort rows.
  • Implementation used sklearn roc_curve and roc_auc_score, then saved HTML wrappers embedding PNG plots.
  • Available models in this rerun: Logistic Regression L2, Logistic Regression Elastic Net, Random Forest, Gradient Boosting. xgboost was skipped because the package was not installed.

Relabel Outcome: GSE213647

  • Original GEO interpretation created a false normal-vs-follicular-neoplasm issue.
  • The rerun used the paper supplementary RNA cohort sheet instead of trusting the ambiguous GEO characteristics alone.
  • Corrected tissue-type categories in the supplementary sheet are PTC, Normal, ATC, and PDTC.
  • That correction improves metadata integrity, but it also removes GSE213647 from the BRAF-like vs RAS-like 2-class external validation use case.

Why GSE27155 Still Matters

  • It is not a molecularly anchored validation set.
  • It does cover a broader histology spectrum than the tiny restricted GSE126698 subset.
  • Its high AUC but poor threshold metrics expose how unstable a proxy-labeled external validation can look.
  • That makes it more useful as a sanity-check cohort than as a final benchmark.
