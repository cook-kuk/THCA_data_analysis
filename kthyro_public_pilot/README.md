# K-Thyro Public Pilot

This directory contains a reproducible public-data feasibility pilot for the K-Thyro Surgical-Spatial Theranostic Perturbation Atlas proposal.

The pilot uses only public/local data and separates observed measurements, inferred scores, exploratory hypotheses, and proposed validation. Existing project data are linked or referenced, not overwritten.

Main outputs are written under `results/tables`, `results/figures`, and `results/reports`.

Run:

```bash
bash scripts/run_all.sh
```
